- Python and TypeScript cores: a Connector Mutation whose manifest says **agent.repeatOnUnknown: limited** resends a bounded number of times. Its effect stays **non_idempotent_write**, and each call stores its send cap. When a send's outcome is unknown, the Connector reads back first when the operation supports it, and resends at most **agent.maxSends** times per call. A definite failure is never resent. A tool policy's **max_sends** (**maxSends**) sets the cap per tool, from 1 to 10. Enable such a tool only after no Worker before 0.6.12 can run the session Flow type; a cap of 1 is safe on any Worker. [Reference](/reference/agents/connector-tools#bounded-resends).
- Python and TypeScript cores: a send that an earlier attempt's fence record counts keeps a later Connector branch **outcome_unknown**, also when the later attempt returned before it read that record, or when a later Worker refuses the call's arguments. [Reference](/reference/agents/connector-tools#outcomes).
