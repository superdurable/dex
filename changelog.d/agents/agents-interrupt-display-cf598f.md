section: Added

- Python and TypeScript cores: a tool approval can say what the call acts on and what it does. A tool source returns an **AgentInterruptDisplay** with a target, a summary, and an optional preview, and the session stores it in the new optional **AgentInterrupt.display**, on the call's record, and in the **interrupt_raised** event. The session cuts a long target or summary and drops a long preview. **ConnectorToolSource** names the operation, the connection, and short arguments, and shows a credential, such as a **credentials** or **apiKey** argument or a Bearer value, as redacted. An approval without a display, such as one a Worker before 0.6.0 raised, has none: show its arguments.
- Python and TypeScript CLI commands: a file write's approval carries a diff against the file as it is when the model asks, left out for credential files and content with credentials. A shell command's approval carries the working directory and the command with its credentials redacted. A Connector tool's approval carries its operation, connection, and short arguments.
