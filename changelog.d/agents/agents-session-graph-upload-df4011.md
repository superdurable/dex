---
section: Breaking
---
- Every package requires Dex SDK 1.45.0 instead of 1.44.0, for Worker-side Flow definition upload. Before upgrading, read the breaking change of SDK 1.45 in the [Python](/reference/python/changelog#v1-45), [TypeScript](/reference/typescript/changelog#v1-45), and [Go](/reference/go/changelog#v1-45) SDK change logs: a Step type with "-" can no longer start SubFlows.
