section: Changed
---
- A left rail holds Dex Web's sections: Flows, then Designs, Work Queue and Connectors under an Experimental heading when they apply. It starts as icons with their names on hover, expands to show the names, and remembers the choice; on a phone it opens from the bar's menu button. The rail starts at the Dex mark and shows whether Dex Web reaches the Dex Server. The bar starts with the page's name.
- Early features carry the word **Experimental** in place of a violet dot.
- The run tabs are Events, State and Streams, then Actions when it applies. Events shows the run's events as Timeline or Graph, with a switch at its top; the browser remembers the choice for every run. Graph was Execution graph. The run page has no Design tab; a Flow type's design is on Designs, and old Design links open it under Events. State was Overview. A Dex Agents session's run opens on its first tab, Conversation, which was Agent session. Links that name a former tab still open its view.
- Live moved out of the bar to the event range on Events. It reads **Live** while the page follows the run, and **Updates paused · Resume** after a click.
- **Input** and **Result** beside the event range on Events select Flow started and Flow closed, which show the run's start input and how it ended.
- **Group by type**, on by default, on the Flows page groups the page's runs by Flow type, with counts by status and a link to the type's design.
- `web/embedded`: `Target.HasHostNavigation` tells Dex Web that your page draws the navigation around it, so Dex Web draws no rail.
- The Timeline strip is about half as tall. Labels lie flat, one for each run of consecutive events about the same subject, such as **SyncBatch ×20**; a short page spreads its events so every name fits. The overview is a thin strip under the lane, one row above it holds the time range and failure count, and **Legend** opens over the strip.
- A running or ended run no longer has a line under the bar for its state. The Timeline lane's newest end says what the run does now, such as **Now · waiting · fires in 2d 6h**, and selects that event on click. A failed run keeps its error line.
- The event pager reads **Oldest**, **Older**, **Newer** and **Latest**, older pages on the left as in the strip.
- The selected event panel puts **JSON** in its header in place of the Details and Raw JSON switch, names related events in one line under the title, groups **Context** into Timing, Attempt, and Worker and retry, and shows a failure's stack trace open.
- Timeline keeps the event panel below the strip at every desktop width, so the page scrolls as one; the one-line event list and **Show lane** at 1280 pixels and wider are gone. A vertical wheel over the strip scrolls the page, and a sideways swipe or Shift+wheel scrolls the strip. J, K and T work from anywhere on the page.
