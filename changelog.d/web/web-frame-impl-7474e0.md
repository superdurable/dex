section: Changed
---
- Every page has one bar instead of a header plus page breadcrumbs. The bar holds a trail from home, the page's views and actions, a jump box (⌘K or Ctrl+K) that suggests Flows by ID prefix, opens a pasted run link, and lists recent runs, and a settings menu for theme, timezone and Docs. A dot beside the trail's start shows whether Dex Web reaches the Dex Server. The trail's Flows link returns to your last search, and its menu switches to Work Queue, Designs and Connectors when they apply.
- The run page puts its status, Flow ID, views, Live and one action button in that bar, so the Timeline starts right below it. The status shows the run's duration. The action button follows the run: **Stop** while it runs, with **Time travel…** in its menu; **Time travel from #N** at the failed event on a failed run; **Time travel** once it ended otherwise. Timeline is now the first view. A failed run states its error under the bar and opens on the failing event; other runs state their newest event there. The selected event offers **Time travel from here…**. A child Flow's trail names its parent, and a run's child count sits beside its Flow ID. When the bar is short of room, the duration, the status text and the attempt picker give way first, then the IDs shorten in the middle, and only then do later tabs drop to icons. Run facts and the Flow and run IDs open from the Flow ID.
- The event pager sits above the Timeline and Execution graph and shows icon page buttons only when there is more than one page. On screens 1280 pixels wide or more the Timeline's event panel sits beside the strip, with a one-line event list under it that J, K and the arrow keys move through, with time travel forks as dividers, child Flows linked from the row that started them, and the selected event kept in the address; the labelled lane is behind Show lane. Overview lists the run's parent and child Flows. The run attempt picker appears only after time travel. The Timeline legend starts folded.
- Refresh and Copy link are gone from the run page. Resuming Live reads the run again, and the address bar is the link.
- Run dialogs take focus on their first field, keep Tab inside, and close with Escape. Bar menus take arrow keys. A whole Flows row opens its run, the Run ID column is off by default, and status buttons search by status in one click. Run tabs are ARIA tabs.
- `web/embedded`: `Target.HostLink` names the page that opened Dex Web, so the trail starts there.
