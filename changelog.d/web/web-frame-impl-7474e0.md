section: Changed
---
- Every page has one bar instead of a header plus page breadcrumbs. The bar holds a trail from home, the page's views and actions, and a settings menu for theme, timezone and Docs. The trail's Flows link returns to your last search, and its menu switches to Work Queue, Designs and Connectors when they apply.
- The run page puts its status, Flow ID, views, Live and a new **Operate** menu (Stop and Time travel) in that bar, so the Timeline starts right below it. Timeline is now the first view. Run facts and the Flow and run IDs open from the Flow ID. The event pager sits above the Timeline and Execution graph, and shows page buttons only when there is more than one page. The run attempt picker appears only after time travel.
- Refresh and Copy link are gone from the run page. Resuming Live reads the run again, and the address bar is the link.
- `web/embedded`: `Target.HostLink` names the page that opened Dex Web, so the trail starts there.
