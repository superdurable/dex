---
section: Changed
---
- **Work Queue** has a new look: the list names its Flow type instead of
  repeating the page title, filters are chips that search as soon as you choose
  one, and each row shows a status icon, the run's status, and how long ago it
  started. **Start Flow** is the page's one accent button. A long Flow type
  name wraps to two lines.
- In **Work Queue**, an Action that only **Working as** locks offers a
  **Work as** button, as the **Conversation** tab does; choosing it sets
  **Working as** for the page and makes the Action available.
- With no run selected, **Work Queue** says what to do next and how many runs
  are listed. On a phone it shows the list or the selected run. Rows, chips,
  and panels change smoothly; reduced motion turns this off.
