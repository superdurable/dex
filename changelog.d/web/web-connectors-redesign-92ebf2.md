---
section: Changed
---
- **Connectors** has a calmer, borderless layout. The connection list no longer
  repeats the page title. Each row shows the Connector's initial, the connection
  name, and the state as an icon and a word. Each state has one next step:
  **Reauthorize** for an expired connection and **Set up** for a missing one.
  The token expiry reads as a relative time, such as "3 hours ago", with the
  exact time on hover.
- The authorization guide is a numbered list that you can fold away.
  Authentication methods are one segmented choice. Copy buttons are icons, and
  selections, buttons, and the guide change smoothly. Reduced motion turns this
  off.
