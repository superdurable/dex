- **Settings > Codec endpoint** in **Custom** mode takes an optional bearer token for codec servers that require one, such as **dexcli codec-server**. Dex Web sends it as **Authorization: Bearer** only to the codec server's **/decode** and **/encode**, and only while the Custom URL is the one it was saved with. With **Remember on this browser**, on by default, all tabs of this browser share the token until you delete it. Without it, the token is kept in this tab's session storage; a tab opened from it or a duplicated tab may inherit it. The small delete button next to the token field deletes it, and other open tabs follow. It works together with **Send cookies**. A 401 from the codec server names the bearer token as the likely cause. [Reference](/reference/server/payload-encryption#dex-web).
