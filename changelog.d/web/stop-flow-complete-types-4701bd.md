- The **Stop flow** dialog offers **Graceful complete** and **Force complete**, which close the Flow as completed, with an optional JSON **Output** that becomes a Flow result. Each stop type shows one line on what it does, and **Cancel** stays the default. **Flow closed** shows a result that no Step returned with **Step** as **None (added by a stop request)**. The complete types need server-zd 0.1.34 or later.
