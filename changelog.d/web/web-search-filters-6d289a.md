section: Changed
---
- On **Flows**, **Queries** shows **Saved** and **Recent** as lists with a header and count each. An entry shows its query on up to two lines and when it was saved or last run. It runs on click and offers **Copy**, plus **Save** and **Remove** for a recent query or **Delete** for a saved one. **Clear** empties **Recent**. An empty list says how to fill it. Arrow keys move between entries, and **Escape** closes the panel. [Reference](/reference/web/dex-web#flows-saved-queries).
- **Save query** names the query in a field inside the panel instead of a browser prompt, so it also works inside an embedding page that blocks prompts. When the clipboard or browser storage is unavailable, the panel says so.
