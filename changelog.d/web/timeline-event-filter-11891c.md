- **Filter**, next to **Legend** on the Timeline, hides events by type and, for
  Step, RPC, Channel, and Attribute events, by Step type, RPC name, Channel
  name, or Attribute name. **Select all** and **Clear all** work for all types
  and for the names of each type. While a filter hides events, the button shows
  how many types it filters, the Timeline head says how many events on the page
  are hidden, and **Show all** resets it. The overview still shows every event
  and dims the hidden ones; a selected event always shows. The browser
  remembers the filter per Flow type.
