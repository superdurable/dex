- **Flows** has a **Fields** panel that lists what a search query can name, with each field's type: the built-in fields, the indexed Attributes each loaded Flow definition declares, grouped by Flow type, and other indexed Attribute keys seen in the results. Choosing a field adds a filter row or a query condition. It reads the existing **GET /api/v2/catalog**. [Reference](/reference/web/dex-web#flows-search-fields).
- **Flows** links to the [query syntax](/reference/server/search#query-syntax) reference from the **Fields** panel and under **Search query**.
