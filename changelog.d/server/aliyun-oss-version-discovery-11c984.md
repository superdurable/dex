- **objectStore.versionDiscovery: head** lets **aliyunOSS** find the newest version of a replaced object, such as the cluster manifest or a node lease, with HEAD and GET requests of single objects instead of a listing. It then depends only on reads and writes of single objects being current, which Aliyun documents, and on no clock. The default stays **list**. Set **head** only on an empty prefix, such as a new cluster's; an existing prefix stays on **list**. A node with **head** marks the prefix with **version-discovery/head**, and a node with **list** fails to start on a marked prefix. On a prefix without the marker, a node with **head** fails to start when a listing shows versions; this check is best effort and reliable only where listings show every write. Every node that shares a **head** prefix must run 0.1.30 or later with **head**, and a rollback below 0.1.30 is not supported once a prefix uses **head**. **dexzd_object_store_versioned_listing_stale_total** gains the **newest_version_lookup** site. [Reference](/reference/server/object-storage#version-discovery).
