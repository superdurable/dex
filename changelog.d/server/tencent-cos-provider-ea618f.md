- **objectStore.provider: tencentCOS** lets **serve** keep its object storage in a Tencent COS bucket through the COS S3-compatible endpoint, such as **https://cos.ap-guangzhou.myqcloud.com**. The server creates objects with AppendObject, so the bucket must be single-AZ, must not use INTELLIGENT_TIERING, and must never have had versioning enabled; startup checks this. Objects that the server replaces, such as the cluster manifest and node leases, are stored as versions that the server manages. COS listings can repeat an earlier listing for a few seconds, so the server finds the newest version with HEAD requests, and **objectStore.versionDiscovery** must be **head**. **objectStore.hardDeleteStore.provider** accepts **tencentCOS** and defaults to it when the primary store uses it. With **tencentCOS**, **localStorage.writeBufferBytes** can be at most 1 GiB, and **commit.maxInFlight** can be at most 32. The server treats an empty object, which COS shows during an append and can keep after an interrupted one, as absent and creates its object over it. A listing request whose truncated pages hold no key after its position for 5 seconds fails as retryable. Snapshot retention keeps the snapshot that the cluster manifest points to, each snapshot pointed to within the last **snapshot.logDeletionDelay**, the newest **snapshot.retainedCount** snapshots of the running server, and the files of a failed snapshot upload until the server reads it or **snapshot.logDeletionDelay** passes. It deletes every other snapshot and file once it has stayed unprotected for **snapshot.logDeletionDelay**, measured on the server's monotonic clock from the first cleanup run that found it unprotected; a restart starts that wait again, and a replaced or failed snapshot can stay up to twice the delay. Back up a **tencentCOS** prefix by stopping its nodes and downloading every object under it. A run purge deletes the run's referenced hard-delete objects by key and then needs two empty listings 5 seconds apart. Data cannot move between **tencentCOS** and other providers.
