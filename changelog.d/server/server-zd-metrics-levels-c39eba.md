- With the default **metrics.level** of **advanced**, **GET /metrics** no longer exports these families: **dexzd_snapshot_last_bytes**, **dexzd_startup_read_retries_total**, **dexzd_recovery_last_replayed_bytes**, **dexzd_matching_unsupported_type_entries**, **dexzd_matching_heads_restored_refs_total**, **dexzd_matching_heads_incomplete_scans_total**, **dexzd_step_task_queue_incomplete_seeks_total**, **dexzd_worker_stream_protocol_errors_total**, **dexzd_worker_stream_events_total**, **dexzd_attribute_sync_fenced_writes_total**, **dexzd_search_outbox_max_partition_entries**, **dexzd_search_outbox_projected_entries_total**, **dexzd_search_outbox_projected_runs_total**, **dexzd_search_outbox_ack_proposals_total**, **dexzd_search_initial_load_documents_total**, **dexzd_search_initial_loads_total**, **dexzd_search_projection_mode_skipped_partitions_total**, **dexzd_history_upload_concurrency_limit**, **dexzd_history_upload_in_flight_bytes**, **dexzd_history_upload_bytes_total**, **dexzd_history_reads_total**, **dexzd_history_value_revivals_total**, **dexzd_history_expired_objects_deleted_total**, **dexzd_history_orphan_objects_deleted_total**, **dexzd_hot_standby_lag_batches**, **dexzd_takeover_duration_seconds**, and, on Linux, **process_resident_memory_bytes**, **process_cpu_seconds_total**, **process_start_time_seconds**, and **process_open_fds**. Set **metrics.level** to **verbose** to export them again. [Reference](/reference/server/metrics#metrics-levels).
- Removed **dexzd_commit_batches_total**. It always equaled **dexzd_commit_latency_seconds_count**; use that series instead. [Reference](/reference/server/metrics#metrics-levels).
