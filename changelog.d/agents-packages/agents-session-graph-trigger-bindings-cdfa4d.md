- Session graph Connector Trigger bindings: `dex-agents-session-graph` takes a repeatable `--trigger-binding <connectionName>=<packageName>@<packageVersion>:<triggerName>:<bindingName>` and a `--trigger-bindings <file.json>` array, so a hosting platform can configure the Connector Triggers that deliver into the session Flow. Each binding reads the installed Connector package's `dex-connector.json` and becomes the same `v2.connectorTriggerBindings` entry that `dexcli visualize` writes for a binding declared in code, with the manifest's UI units unless the file sets its own. A missing package, another version, or an unknown Trigger exits with status 2. In code, `resolveSessionTriggerBinding` / `resolve_session_trigger_binding` and the `connectorTriggerBindings` / `connector_trigger_bindings` option of the session graph functions do the same. A graph rendered without bindings is unchanged.
