# Waits

**WaitFor** returns a **Wait**: a wait type and the conditions to wait for.
Dex stores the wait durably and checks the conditions whenever related state
changes. A condition waits for a [Timer](/concepts/primitives/timer), a
[Channel](/concepts/primitives/channel), a [SubFlow](/concepts/primitives/subflow),
or a [graceful completion request](#graceful-completion-requests).

- **Until** waits for one condition.
- **AnyOf** is met when any condition is met.
- **AllOf** is met when all conditions are met.
- **AnyCombinationOf** is met when any one group of conditions is all met.

**Until**, **AnyOf**, and **AllOf** do not need condition IDs. Read Channel
results from the Channel definition, and check Timer outcomes through the
**Context**. Add a condition ID only where an API requires one, such as
**AnyCombinationOf** or a Timer that you select by ID.

```java
return Wait.anyOf(
        channelA.forOne(),
        Timer.byDuration(timeout));
```

```java
return Wait.allOf(
        channelA.forOne(),
        channelB.forOne());
```

## Condition results {#condition-results}

After **WaitFor** completes, **Execute** can read what satisfied the Wait. For a
[Channel](/concepts/primitives/channel), call **getConditionResults** on the Channel to read the
messages the wait consumed. For a [SubFlow](/concepts/primitives/subflow),
call **SubFlow.getConditionResults** to read the child Flow result.

In an **AnyOf**, Dex consumes messages only from the Channel condition that it
selects to satisfy the Wait. Other Channel conditions consume nothing, even if
they are also ready, and their messages stay queued.

When several **AnyOf** conditions are ready at the same check, Dex selects the
first ready one in this order: Timer conditions, then Channel conditions, then
SubFlow conditions, then the graceful completion condition, each kind in the
order you declared them. A condition that
is not ready does not block a later one that is. So across kinds, the order of
the arguments in your call does not decide which condition wins.

Use **AnyOf** when any ready condition may win. If the Step must keep waiting
for a higher-priority input, return only that condition until it resolves.

<a id="channel-结果"></a>

### Channel results {#channel-results}

```java
final class ChannelWaitStep implements Step<Integer> {
    @Override
    public Class<Integer> getInputType() {
        return Integer.class;
    }

    @Override
    public Wait waitFor(final Context context, final Integer input) {
        return Wait.anyOf(
                approval.forOne(),
                Timer.byDuration(Duration.ofSeconds(input)));
    }

    @Override
    public StepDecision execute(final Context context, final Integer input) {
        if (context.hasTimerFired()) {
            return StepDecision.gracefulComplete("approval timed out");
        }
        final List<String> approvals = approval.getConditionResults(context);
        return StepDecision.gracefulComplete(approvals.get(0));
    }
}
```

```java
public StepDecision execute(final Context context, final Integer input) {
    final Integer output =
            SubFlow.getConditionResults(context).getSingleOutput(Integer.class);
    return StepDecision.gracefulComplete(SubFlow.getFlowId(context) + "|" + output);
}
```

## Graceful completion requests {#graceful-completion-requests}

Since 1.45.3. `GracefulCompletion.requested()` returns a condition that
completes once the Flow has a graceful completion request. The request comes
from a Step that returns `StepDecision.gracefulComplete`, or from
`Client.stopFlow` with `StopType.GRACEFUL_COMPLETE`. A request made before the
Wait starts completes the condition at once.

Use it in a Step that would otherwise wait indefinitely, such as one that waits
for the next user message. Combine it with that message in `Wait.anyOf`. In
`execute`, handle a message that the Wait consumed first. A ready message
wins the `anyOf`, but the condition still reports completed when a request
exists. When there is no message and
`context.isGracefulCompletionConditionCompleted()` is true, return
`StepDecision.deadEnd()`. The Flow completes once no other Step is active.

When the request arrives, Dex checks only the Waits that include this
condition. A Wait holds at most one. It needs Server protocol version 7, and
against an older Server the Step fails with
`GracefulCompletionConditionUnsupportedException`. To keep working with older
Servers, add the condition only when
[`context.supportsGracefulCompletionCondition()`](pathname:///api/java/latest/io/superdurable/dex/Context.html#supportsGracefulCompletionCondition())
returns true in `waitFor`; it reads the Worker's negotiated protocol and
sends no request. The
[`GracefulCompletion` API reference](pathname:///api/java/latest/io/superdurable/dex/GracefulCompletion.html)
shows an example. The server rules are in
[Wait for a completion request](/reference/server/step-and-flow-close#graceful-completion-condition).

## Join parallel branches {#join}

Since 1.44.0. A **Join** waits for the parallel branches that one Step
started. It stores branch results in a ChannelMap with the Join's name, so
its conditions are Channel conditions. They combine with **AnyOf**, **AllOf**,
and Timers.

- **Join.define** defines a Join. Pass it to **PersistenceSchema.of**, like a ChannelMap.
- **Join.fork** starts one round from a split Step. It returns the branch movements
  and the join Step movement. **Join.forkWithRoundKey** does the same with an explicit
  round key, for example in an RPC.
- A branch reports its result with **Join.endBranch** or **Join.reportBranchResult**.
- The join Step waits with **Join.forAllBranches**, **Join.forFirstBranch**, or **Join.forBranches**, and reads **Join.getBranchResults**.
- The next round's split Step resets the previous round with
  **Join.forRemainingBranches**, and reads **Join.getRemainingBranchResults**.
- **Join.getChannelMap** returns the underlying ChannelMap, for reading a round's
  pending results. Never publish to it directly.

The [Join API reference](pathname:///api/java/latest/io/superdurable/dex/Join.html) documents each method. The
[Await Parallel Steps](/design-patterns/parallel/await) pattern shows the whole
shape.

Example: [examples/java/src/main/java/io/superdurable/dex/patterns/parallel/AwaitParallelStepsFlow.java](https://github.com/superdurable/dex/tree/main/examples/java/src/main/java/io/superdurable/dex/patterns/parallel/AwaitParallelStepsFlow.java)

## AnyCombinationOf {#anycombinationof}

**AnyCombinationOf** is met when every condition in any one group is met. Each
group is an all-of combination.

Dex consumes messages only from the Channel conditions of the group it selects.
Conditions that belong only to other ready groups consume nothing, and their
messages stay queued.

Every condition in the groups needs a unique **condition ID**.

```java
return Wait.anyCombinationOf(
        ConditionCombination.of(
                channelA.forOne("signal-a"),
                Timer.byDuration(timeout, "timeout")),
        ConditionCombination.of(channelB.forOne("signal-b")));
```

## Skip immediately {#skip-immediately}

**SkipWaitImmediately** waits for no condition. Use it when **WaitFor**
decides at run time that the Step should not wait.

```java
return Wait.skipImmediately();
```
