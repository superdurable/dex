# Rust SDK reference

This reference covers the Dex Rust SDK. Check the SDK version your application
uses before you rely on a detail:

```bash
cargo tree --package dex-sdk --depth 0
```

## Install

The Rust SDK is the crate **dex-sdk**. Pin an exact release in **Cargo.toml**:

```toml
dex-sdk = "=1.37.0"
```

The crate requires Rust 1.97 or newer. Releases use the tag
**sdk-rust/vX.Y.Z**.

## Supported versions

| SDK minor | Server requirement |
| --- | --- |
| 1.37, 1.35 | server-zd 0.1.17 or newer (protocol version 4) |
| 1.31, 1.26, 1.25 | See the [compatibility matrix](/reference/#compatibility-matrix) |

Minor numbers follow the shared Dex release train. A missing minor means the
Rust SDK did not change in that release.
