# Graceful Timeout

当应用必须处理整个 Flow 的截止时间时，使用 Flow timeout handler。截止时间属于 Flow，所以不需要另写一个与工作赛跑的 Step。

`FlowGracefulTimeout` 启动 `LongWait`。Flow 截止时间到达后，Dex 运行 `handleTimeout`。这个 handler 的用法和 `Execute` 方法一样。

<DocsFlowDefinitionGraph graph={flowDefinition} />

## 核心实现

Flow 注册 `LongWait` 和 timeout handler。启动 Flow 时设置一个正的 timeout。示例显式把 timeout policy 设为 `HANDLER`。Flow 定义了 timeout handler 时，`HANDLER` 也是默认值。`FlowTimeoutHandlerOptions` 为 handler 单独设置 attempt timeout 和重试策略。

class LongWait(Step[bool]):
    def wait_for(self, context: Context, input: bool) -> Wait:
        if input:
            return Wait.skip_immediately()
        return Wait.until(Timer.by_duration(SLOW_TASK_DURATION))

    def execute(self, context: Context, input: bool) -> StepDecision:
        return force_complete("Workflow completed successfully")


class FlowGracefulTimeout(Flow[bool]):
    def __init__(self) -> None:
        self.long_wait_step = LongWait()

    def get_steps(self) -> StepList[bool]:
        return StepList.start_step(self.long_wait_step)

    def handle_timeout(self, context: Context) -> StepDecision:
        return force_fail("Workflow did not finish the task in time")

func (*FlowGracefulTimeout) GetSteps() []dex.StepDef {

type longWait struct {
	dex.StepDefaults
}

func (longWait) WaitFor(_ dex.Context, successful bool) (*dex.Wait, error) {
	if successful {
		return dex.SkipWaitImmediately(), nil
	}
	return dex.Until(dex.Timer(65 * time.Second)), nil
}

func (longWait) Execute(_ dex.Context, _ bool) (*dex.StepDecision, error) {
	return dex.ForceComplete("Workflow completed successfully"), nil
}

func (*FlowGracefulTimeout) HandleTimeout(_ dex.Context) (*dex.StepDecision, error) {
	return dex.ForceFail("Workflow did not finish the task in time"), nil
}

final class FlowGracefulTimeout implements Flow<Boolean> {
    private final LongWait longWait = new LongWait();

    @Override
    public StepList<Boolean> getSteps() {
        return StepList.startStep(longWait);
    }

    final class LongWait implements Step<Boolean> {
        @Override
        public Class<Boolean> getInputType() {
            return Boolean.class;
        }

        @Override
        public Wait waitFor(final Context context, final Boolean successful) {
            return Boolean.TRUE.equals(successful)
                    ? Wait.skipImmediately()
                    : Wait.until(Timer.byDuration(Duration.ofSeconds(65)));
        }

        @Override
        public StepDecision execute(final Context context, final Boolean successful) {
            return StepDecision.forceComplete("Workflow completed successfully");
        }
    }

    @Override
    public StepDecision handleTimeout(final Context context) {
        return StepDecision.forceFail("Workflow did not finish the task in time");
    }
}

class LongWait implements Step<boolean> {
  public readonly inputCodec = booleanCodec;

  public waitFor(_context: Context, successful: boolean): Wait {
    if (successful) {
      return Wait.skipImmediately();
    }
    return Wait.until(Timer.byDuration(65_000));
  }

  public execute(_context: Context, _successful: boolean): StepDecision {
    return forceComplete("Workflow completed successfully");
  }
}

class FlowGracefulTimeout implements Flow<boolean> {
  private readonly longWait = new LongWait();

  public getFlowType(): string {
    return "FlowGracefulTimeout";
  }

  public getSteps() {
    return StepList.startStep(this.longWait);
  }

  public handleTimeout(_context: Context): StepDecision {
    return forceFail("Workflow did not finish the task in time");
  }
}

```rust
#[derive(Default)]
pub struct FlowGracefulTimeout {
    long_wait_step: LongWait,
}

impl Flow for FlowGracefulTimeout {
    type StartInput = bool;

    fn steps(&self) -> StepList<'_, Self::StartInput> {
        StepList::start(&self.long_wait_step)
    }

    fn timeout_handler(&self) -> Option<FlowTimeoutHandler<Self>> {
        Some(Self::handle_timeout)
    }
}

impl Step for LongWait {
    type Input = bool;

    fn wait_for(&self, _context: &mut Context, successful: bool) -> HandlerResult<Wait> {
        let duration = if successful { 1 } else { 65 };
        Ok(Wait::until(Timer::by_duration(Duration::from_secs(duration))))
    }

    fn execute(&self, _context: &mut Context, _successful: bool) -> HandlerResult<StepDecision> {
        Ok(StepDecision::force_complete("task-completed".to_string()))
    }
}

impl FlowGracefulTimeout {
    pub(crate) fn timeout_handler_options(&self) -> FlowTimeoutHandlerOptions {
        FlowTimeoutHandlerOptions::new()
            .method_timeout(Duration::from_secs(30))
            .retry(RetryPolicy::new().maximum_attempts(3))
    }

    fn handle_timeout(&self, _context: &mut Context) -> HandlerResult<StepDecision> {
        Ok(StepDecision::force_fail("task exceeded graceful timeout"))
    }
}
```

Timeout handler 成功时，Dex 应用它暂存的写入、best-effort 的 Channel 删除、Channel 发布和 decision。如果 handler 重试用完后仍然失败，Dex 会让 Flow 失败。
