# 等待并行 Step

![AwaitParallelStepsFlow](/img/design-patterns/parallel-await-steps-flow.png)

**InitStep** 同时启动 **DoWorkStep** 和 **AwaitStep**。每个 worker 随机等待一小段时间，然后向 **CompleteCh** 发布一条消息。**AwaitStep** 等到所需数量的消息后才完成 Flow。Channel 消息是持久化的，因此即使消息先于 **AwaitStep** 开始等待，也仍然会被计入。

## 核心实现

协调 Step 与 worker 一起启动，并等待每个 worker 各发布一条完成消息。

```python
class DoWorkStep(Step[int]):
    async def execute(  # type: ignore[override]
        self, context: Context, input: int
    ) -> StepDecision:
        del input
        await asyncio.sleep(random.uniform(0.05, 0.5))
        self.complete_ch.publish(context, None)
        return dead_end()

class AwaitStep(Step[int]):
    def wait_for(self, context: Context, input: int) -> Wait:
        del context
        return Wait.until(self.complete_ch.for_n(input))
```

```go
func (awaitWorkStep) Execute(ctx dex.Context, _ int) (*dex.StepDecision, error) {
	randomWorkDelay()
	if err := CompleteCh.Publish(ctx, nil); err != nil {
		return nil, err
	}
	return dex.DeadEnd(), nil
}

func (awaitStep) WaitFor(_ dex.Context, count int) (*dex.Wait, error) {
	return dex.Until(CompleteCh.ForN(count)), nil
}
```
