# 静态并行 Step

![StaticParallelStepsFlow](/img/design-patterns/parallel-static-steps-flow.png)

**InitStep** 同时为 **WorkAStep** 和 **WorkBStep** 返回 movement。两个 Step 独立完成，适用于分支职责和输入类型都已知的场景。

## 核心实现

起始 Step 在同一个 decision 中返回两个 movement。

```python
class InitStep(Step[str]):
    def execute(self, context: Context, input: str) -> StepDecision:
        del context
        return go_to_multi(
            StepMovement.of(WorkAStep, input),
            StepMovement.of(WorkBStep, input),
        )
```

```rust
fn execute(&self, _: &mut Context, input: String) -> HandlerResult<StepDecision> {
    Ok(StepDecision::go_to_many([

        StepMovement::to(&WorkB, input),
    ]))
}
```
