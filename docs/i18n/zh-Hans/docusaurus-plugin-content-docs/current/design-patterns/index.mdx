# 设计模式

来自 Dex 示例的可复用 Flow 形状。每个模式页说明问题和做法，并链接到多语言代码。

## Flow 控制

- [Parallel Steps](/design-patterns/parallel) — 选择静态、动态、等待全部完成或首个获胜的并发 Step 协调方式。
- [Parallel SubFlows](/design-patterns/parallel-subflows) — 用 SubFlow fan-out、父 Flow 并发上限、分区和 durable 背压处理大规模并行工作。
- [可中断执行](/design-patterns/interruptible) — 根据 durable 控制消息，优雅地停止或转向长时间工作。
- [Durable Timer](/design-patterns/durable-timer) — 选择 cron schedule、Reminder 或 inactivity tracker。

## 可靠性

- [Failure Handling](/design-patterns/failure-handling) — 恢复 Execute 或 WaitFor 失败、升级给操作人员，或强制执行业务截止时间。
- [Polling](/design-patterns/polling) — 在一个长时间运行的 Step 中等待外部系统。

## 消息

- [Drain Channels](/design-patterns/drain-channels) — 在内部或外部 Channel 消息都处理完之后结束 Flow。
- [响应式更新](/design-patterns/responsive-update) — 在 Step 边界返回、等待 durable 状态，或流式传递增量更新。

## 数据

- [AttributeMap 分区](/design-patterns/attribute-map-partitioning) — 把不断增长的集合拆成有上限的 chunk 或 hash partition。
- [Entity Flow with SQL Projection](/design-patterns/entity-store) — 将每个实体的 durable Flow Attribute 投影到应用自有的 SQL 表。

完整示例位于 **examples/** 下。可在 [examples playground](https://github.com/superdurable/dex/tree/main/examples/playground) 中试用 HTTP 示例。
