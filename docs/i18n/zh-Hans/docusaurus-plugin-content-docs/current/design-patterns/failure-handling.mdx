# Failure Handling

Dex 会对失败的 Step 方法执行指数退避重试。见 [Step options](/reference/server/runtime-steps#retry-and-failure-policies)。如果要等待外部系统，请改用 [Polling](/design-patterns/polling)。

当只靠重试无法满足需求时，选择以下恢复模式之一。

- [Execute Failure Recovery](/design-patterns/failure-handling/execute-failure-recovery) — 重试失败的工作，耗尽后转到恢复 Step。
- [Manual Recovery](/design-patterns/failure-handling/manual-recovery) — 将重试耗尽的失败升级给人工，由人工决策或介入处理。
- [Graceful Timeout](/design-patterns/failure-handling/graceful-timeout) — 利用 Dex 内置的 graceful timeout 功能处理整个 Flow 的超时。
- [WaitFor Failure Recovery](/design-patterns/failure-handling/wait-for-failure-recovery) — 在 **WaitFor** 失败耗尽后继续执行并恢复。
