# 有业务标识的子 Flow

当每个子任务都有自己的业务编号时，使用这个模式。人和其他系统用这个编号查找、重试或停止子任务。

例如，一个订单分成几个包裹发货。每个发货单有一个发货单号。承运商、客服团队和订单都用这个单号找到发货单。订单仍然需要知道每个发货单最后的结果。

订单把每个发货单作为独立的顶层 Flow 启动。发货单号就是它的 Flow ID。

## 工作方式 {#how-it-works}

1. `StartShipments` 先检查订单：对账间隔为正数，送达延迟不是负数，发货单号都不重复。无效的订单在启动任何发货单之前失败。然后这个 Step 在订单的记录里把每个单号登记为 `starting`，再为每个发货单启动一个分支。
2. `StartShipment` 通过 Client 启动一个 `ShipmentFlow`。它的 Flow ID 是发货单号。它的 request ID 是完整启动请求的摘要，所以重试的 Step 重复的是同一次启动。发货单有自己的 Flow timeout。
3. 接着 `StartShipment` 认领这个 run：它记录启动返回的 run ID。从这以后，订单只接受这个 run 的报告和读取。
4. 发货单送达。`DeliverShipment` 把结果存进 `shipmentOutcome` Attribute。
5. `ReportShipmentOutcome` 带着自己的 run ID 调用订单的报告 RPC。这个 RPC 在 Go 里是 `RecordShipmentOutcome`，在 Python 里是 `record_shipment_outcome`，在 Java、TypeScript 和 Rust 里是 `recordShipmentOutcome`。它把结果填进该发货单的记录。
6. `AwaitShipment` 每隔一段时间读取一次被认领的 run。仍在运行的发货单稍后再读。发货单关闭后，它记录终止状态；如果报告还没有填入结果，它也记录已存储的结果。

自己失败或超时的发货单不会报告，因为它的报告 Step 不会运行。第 6 步的定时读取会处理它。子 Flow 也可以把最终失败转到一个恢复 Step，或把超时交给 timeout handler，由它们向父 Flow 报告。每个发货单的 Flow timeout 要长于它的重试预算。

class StartShipment(Step[TrackedShipment]):
    """Starts ShipmentFlow with the shipment number as its Flow ID and claims its run."""

    def __init__(
        self,
        client_provider: Callable[[], AsyncClient],
        shipment_flow: ShipmentFlow,
    ) -> None:
        self.client_provider = client_provider
        self.shipment_flow = shipment_flow

    def get_step_options(self) -> StepOptions:
        """Takes the records lock, so the claim and the rejection never race a report."""
        return StepOptions(execute_lock_attributes=(SHIPMENT_RECORDS_LOCK.lock(),))

    async def execute(  # type: ignore[override]
        self, context: AsyncContext, tracked: TrackedShipment
    ) -> StepDecision:
        number = tracked.shipment.shipment_number
        try:
            run_id = await self.client_provider().start_flow(
                self.shipment_flow,
                number,
                ShipmentRequest(order_flow_id=context.flow_id, shipment=tracked.shipment),
                StartFlowOptions(
                    timeout=SHIPMENT_TIMEOUT,
                    id_reuse_policy=IdReusePolicy.DISALLOW,
                    request_id=shipment_start_request_id(context.flow_id, tracked.shipment),
                    ignore_already_started=True,
                ),
            )
        except FlowAlreadyStartedError:
            # Another request owns this shipment number; this order does not track it.
            SHIPMENT_RECORDS.set(context, number, ShipmentRecord(status=SHIPMENT_REJECTED))
            return graceful_complete()
        # Claim the run: reports and reads of any other run of this number are ignored.
        SHIPMENT_RECORDS.set(
            context, number, ShipmentRecord(status=SHIPMENT_STARTED, run_id=run_id)
        )
        return go_to(AwaitShipment, dataclasses.replace(tracked, shipment_run_id=run_id))

class AwaitShipment(Step[TrackedShipment]):
    """Reads the claimed shipment run at each interval until it ends, then records it."""

    def __init__(self, client_provider: Callable[[], AsyncClient]) -> None:
        self.client_provider = client_provider

    def get_step_options(self) -> StepOptions:
        """Takes the same lock as the report RPC and loads the records."""
        return StepOptions(
            execute_lock_attributes=(SHIPMENT_RECORDS_LOCK.lock(),),
            execute_load_attribute_maps=(SHIPMENT_RECORDS,),
        )

    def wait_for(self, context: Context, tracked: TrackedShipment) -> Wait:
        return Wait.until(
            Timer.by_duration(timedelta(seconds=tracked.reconcile_interval_seconds))
        )

    async def execute(  # type: ignore[override]
        self, context: AsyncContext, tracked: TrackedShipment
    ) -> StepDecision:
        number = tracked.shipment.shipment_number
        reading = await reconcile_shipment(
            self.client_provider(), number, tracked.shipment_run_id
        )
        if reading.status == FlowStatus.RUNNING.value:
            return go_to(AwaitShipment, tracked)
        # Merge with the record, which may already hold the reported outcome.
        record, _ = load_shipment_record(context, number)
        SHIPMENT_RECORDS.set(
            context,
            number,
            ShipmentRecord(
                status=reading.status,
                run_id=tracked.shipment_run_id,
                outcome=record.outcome or reading.outcome,
            ),
        )
        return graceful_complete()

async def reconcile_shipment(client: AsyncClient, number: str, run_id: str) -> ShipmentRecord:
    """Reads the claimed run of a shipment: its status first, then its outcome.

    Returns a "running" record while that run runs, and an "unavailable" record
    when that run no longer exists or another run replaced it. Keeps an outcome
    only when the run is still the claimed one after the read. Any other failure
    raises, so the Step retries.
    """
    info, found = await describe_claimed_run(client, number, run_id)
    if info is None or not found:
        return ShipmentRecord(status=SHIPMENT_UNAVAILABLE)
    if info.status is FlowStatus.RUNNING:
        return ShipmentRecord(status=info.status.value)
    try:
        values = await client.get_attributes(number, SHIPMENT_OUTCOME)
    except FlowNotFoundError:
        return ShipmentRecord(status=info.status.value)
    # The Attribute read targets the latest run, so confirm it is still the claimed one.
    _, still_claimed = await describe_claimed_run(client, number, run_id)
    if not still_claimed:
        return ShipmentRecord(status=info.status.value)
    # An unset outcome Attribute leaves the outcome empty: the shipment ended without one.
    return ShipmentRecord(
        status=info.status.value, outcome=values.get(SHIPMENT_OUTCOME, "")
    )

// dex:explanation text:"Starts the shipment as a top-level Flow named by its shipment number and claims its run."
type StartShipment struct {
	dex.StepDefaultsNoWaitFor[TrackedShipment]
	getClient    func() *dex.Client
	shipmentFlow *ShipmentFlow
}

// GetStepOptions takes the records lock, so the claim and the rejection never race a report.
func (StartShipment) GetStepOptions() *dex.StepOptions {
	return &dex.StepOptions{ExecuteLockAttributes: []dex.AttributeLock{dex.LockAttribute(ShipmentRecordsLock)}}
}

func (step StartShipment) Execute(ctx dex.Context, tracked TrackedShipment) (*dex.StepDecision, error) {
	client := step.getClient()
	if client == nil {
		return nil, errClientUnavailable
	}
	number := tracked.Shipment.ShipmentNumber
	requestID, err := ShipmentStartRequestID(ctx.FlowID(), tracked.Shipment)
	if err != nil {
		return nil, err
	}
	timeout := ShipmentTimeout
	runID, err := client.StartFlow(ctx, step.shipmentFlow, number, ShipmentRequest{
		OrderFlowID: ctx.FlowID(),
		Shipment:    tracked.Shipment,
	}, dex.StartFlowOptions{
		Timeout:        &timeout,
		IDReusePolicy:  dex.IDReuseDisallow,
		RequestID:      &requestID,
		AlreadyStarted: &dex.AlreadyStartedOptions{IgnoreError: true},
	})
	var alreadyStarted *dex.FlowAlreadyStartedError
	if errors.As(err, &alreadyStarted) {
		// Another request owns this shipment number; this order does not track it.
		if err := ShipmentRecords.Set(ctx, number, ShipmentRecord{Status: ShipmentRejected}); err != nil {
			return nil, err
		}
		return dex.GracefulComplete(nil), nil
	}
	if err != nil {
		return nil, err
	}
	// Claim the run: reports and reads of any other run of this number are ignored.
	if err := ShipmentRecords.Set(ctx, number, ShipmentRecord{Status: ShipmentStarted, RunID: runID}); err != nil {
		return nil, err
	}
	tracked.ShipmentRunID = runID
	return dex.GoTo(AwaitShipment{}, tracked), nil
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Reads the claimed shipment run at each interval and records how it ended."
type AwaitShipment struct {
	dex.StepDefaults
	getClient func() *dex.Client
}

// GetStepOptions takes the same lock as the report RPC and loads the records.
func (AwaitShipment) GetStepOptions() *dex.StepOptions {
	return &dex.StepOptions{
		ExecuteLockAttributes:    []dex.AttributeLock{dex.LockAttribute(ShipmentRecordsLock)},
		ExecuteLoadAttributeMaps: []dex.AttributeDef{ShipmentRecords},
	}
}

func (AwaitShipment) WaitFor(_ dex.Context, tracked TrackedShipment) (*dex.Wait, error) {
	return dex.Until(dex.Timer(time.Duration(tracked.ReconcileIntervalSeconds) * time.Second)), nil
}

func (step AwaitShipment) Execute(ctx dex.Context, tracked TrackedShipment) (*dex.StepDecision, error) {
	client := step.getClient()
	if client == nil {
		return nil, errClientUnavailable
	}
	number := tracked.Shipment.ShipmentNumber
	reading, err := reconcileShipment(ctx, client, number, tracked.ShipmentRunID)
	if err != nil {
		return nil, err
	}
	if reading.Status == dex.FlowRunning.String() {
		return dex.GoTo(AwaitShipment{}, tracked), nil
	}
	// Merge with the record, which may already hold the reported outcome.
	record, _, err := loadShipmentRecord(ctx, number)
	if err != nil {
		return nil, err
	}
	record.Status = reading.Status
	record.RunID = tracked.ShipmentRunID
	if record.Outcome == "" {
		record.Outcome = reading.Outcome
	}
	if err := ShipmentRecords.Set(ctx, number, record); err != nil {
		return nil, err
	}
	return dex.GracefulComplete(nil), nil
}

// reconcileShipment reads the claimed run of a shipment: its status first, then its outcome.
// It returns a "running" record while that run runs, and an "unavailable" record when that
// run no longer exists or another run replaced it. It keeps an outcome only when the run
// is still the claimed one after the read. It returns an error for any other failure so the Step retries.
func reconcileShipment(ctx context.Context, client *dex.Client, number string, runID string) (ShipmentRecord, error) {
	info, found, err := describeClaimedRun(ctx, client, number, runID)
	if err != nil || !found {
		return ShipmentRecord{Status: ShipmentUnavailable}, err
	}
	record := ShipmentRecord{Status: info.Status.String()}
	if info.Status == dex.FlowRunning {
		return record, nil
	}
	// An unset outcome Attribute leaves Outcome empty: the shipment ended without one.
	var outcome string
	_, err = client.GetAttributes(ctx, number, dex.ReadAttribute(ShipmentOutcome, &outcome))
	var notFound *dex.FlowNotFoundError
	if errors.As(err, &notFound) {
		return record, nil
	}
	if err != nil {
		return ShipmentRecord{}, err
	}
	// The Attribute read targets the latest run, so confirm it is still the claimed one.
	_, stillClaimed, err := describeClaimedRun(ctx, client, number, runID)
	if err != nil {
		return ShipmentRecord{}, err
	}
	if stillClaimed {
		record.Outcome = outcome
	}
	return record, nil
}

static final class StartShipment implements Step<TrackedShipment> {
    private final ObjectProvider<Client> clientProvider;
    private final ShipmentFlow shipmentFlow;

    StartShipment(final ObjectProvider<Client> clientProvider, final ShipmentFlow shipmentFlow) {
        this.clientProvider = clientProvider;
        this.shipmentFlow = shipmentFlow;
    }

    @Override
    public Class<TrackedShipment> getInputType() {
        return TrackedShipment.class;
    }

    /** Takes the records lock, so the claim and the rejection never race a report. */
    @Override
    public StepOptions getStepOptions() {
        return lockShipmentRecords();
    }

    @Override
    public StepDecision execute(final Context context, final TrackedShipment tracked) {
        final Client client = clientProvider.getObject();
        final String number = tracked.shipment().shipmentNumber();
        final String requestId = shipmentStartRequestId(context.getFlowId(), tracked.shipment());
        final String runId;
        try {
            runId = client.startFlow(
                    shipmentFlow,
                    number,
                    new ShipmentRequest(context.getFlowId(), tracked.shipment()),
                    StartFlowOptions.newBuilder()
                            .timeout(SHIPMENT_TIMEOUT)
                            .idReusePolicy(IdReusePolicy.DISALLOW)
                            .requestId(requestId)
                            .ignoreAlreadyStarted(true)
                            .build());
        } catch (final FlowAlreadyStartedException alreadyStarted) {
            // Another request owns this shipment number; this order does not track it.
            shipmentRecords.set(
                    context, number, new ShipmentRecord(SHIPMENT_REJECTED, null, null));
            return StepDecision.gracefulComplete();
        }
        // Claim the run: reports and reads of any other run of this number are ignored.
        shipmentRecords.set(context, number, new ShipmentRecord(SHIPMENT_STARTED, runId, null));
        return StepDecision.goTo(AwaitShipment.class, new TrackedShipment(
                tracked.shipment(), tracked.reconcileIntervalSeconds(), runId));
    }
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Reads the claimed shipment run at each interval and records how it ended."
static final class AwaitShipment implements Step<TrackedShipment> {
    private final ObjectProvider<Client> clientProvider;

    AwaitShipment(final ObjectProvider<Client> clientProvider) {
        this.clientProvider = clientProvider;
    }

    @Override
    public Class<TrackedShipment> getInputType() {
        return TrackedShipment.class;
    }

    /** Takes the same lock as the report RPC and loads the records. */
    @Override
    public StepOptions getStepOptions() {
        return StepOptions.newBuilder()
                .addExecuteLock(AttributeLock.of(shipmentRecordsLock))
                .addExecuteLoadAttributeMap(shipmentRecords)
                .build();
    }

    @Override
    public Wait waitFor(final Context context, final TrackedShipment tracked) {
        return Wait.until(
                Timer.byDuration(Duration.ofSeconds(tracked.reconcileIntervalSeconds())));
    }

    @Override
    public StepDecision execute(final Context context, final TrackedShipment tracked) {
        final String number = tracked.shipment().shipmentNumber();
        final ShipmentRecord reading = reconcileShipment(
                clientProvider.getObject(), number, tracked.shipmentRunId());
        if (statusName(FlowStatus.RUNNING).equals(reading.status())) {
            return StepDecision.goTo(AwaitShipment.class, tracked);
        }
        // Merge with the record, which may already hold the reported outcome.
        final String storedOutcome = loadShipmentRecord(context, number)
                .map(ShipmentRecord::outcome)
                .orElse(null);
        final String outcome = storedOutcome != null ? storedOutcome : reading.outcome();
        shipmentRecords.set(context, number,
                new ShipmentRecord(reading.status(), tracked.shipmentRunId(), outcome));
        return StepDecision.gracefulComplete();
    }

    /**
     * Reads the claimed run of a shipment: its status first, then its outcome. It keeps an
     * outcome only when the run is still the claimed one after the read.
     *
     * @return a "running" record while that run runs, an "unavailable" record when that run no
     *     longer exists or another run replaced it, or the terminal status with the stored
     *     outcome; any other failure throws so the Step retries
     */
    private static ShipmentRecord reconcileShipment(
            final Client client, final String number, final String runId) {
        final Optional<FlowInfo> claimed = describeClaimedRun(client, number, runId);
        if (claimed.isEmpty()) {
            return new ShipmentRecord(SHIPMENT_UNAVAILABLE, null, null);
        }
        final FlowInfo info = claimed.get();
        final String status = statusName(info.getStatus());
        if (info.getStatus() == FlowStatus.RUNNING) {
            return new ShipmentRecord(status, null, null);
        }
        final String outcome;
        try {
            // An unset outcome Attribute leaves the outcome empty: the shipment ended without one.
            outcome = client.getAttributes(number, ShipmentFlow.shipmentOutcome)
                    .get(ShipmentFlow.shipmentOutcome)
                    .orElse(null);
        } catch (final FlowNotFoundException notFound) {
            return new ShipmentRecord(status, null, null);
        }
        // The Attribute read targets the latest run, so confirm it is still the claimed one.
        final boolean stillClaimed = describeClaimedRun(client, number, runId).isPresent();
        return new ShipmentRecord(status, null, stillClaimed ? outcome : null);
    }

    /**
     * Describes the latest run of a shipment.
     *
     * @return the run's Flow info, or empty when the shipment does not exist or its latest run
     *     is not {@code runId}; any other failure throws
     */
    private static Optional<FlowInfo> describeClaimedRun(
            final Client client, final String number, final String runId) {
        final FlowInfo info;
        try {
            info = client.describeFlow(number);
        } catch (final FlowNotFoundException notFound) {
            return Optional.empty();
        }
        return runId != null && runId.equals(info.getRunId())
                ? Optional.of(info)
                : Optional.empty();
    }
}

// dex:explanation text:"Reads the claimed shipment run at each interval and records how it ended."
class AwaitShipment implements Step<TrackedShipment> {
  public constructor(private readonly getClient: () => Client) {}

  public getStepType(): string {
    return "AwaitShipment";
  }

  /** Takes the same lock as the report RPC and loads the records. */
  public getStepOptions(): StepOptions {
    return {
      executeLockAttributes: [shipmentRecordsLock.lock()],
      executeLoadAttributeMaps: [shipmentRecords],
    };
  }

  public waitFor(_context: Context, tracked: TrackedShipment): Wait {
    return Wait.until(Timer.byDuration(tracked.reconcileIntervalSeconds * 1000));
  }

  public async execute(context: Context, tracked: TrackedShipment): Promise<StepDecision> {
    // Calling a field through this would hide the Step class from the Flow visualizer.
    const getClient = this.getClient;
    const number = tracked.shipment.shipmentNumber;
    const runId = tracked.shipmentRunId ?? "";
    const reading = await reconcileShipment(getClient(), number, runId);
    if (reading.status === "running") {
      return goTo(AwaitShipment, tracked);
    }
    // Merge with the record, which may already hold the reported outcome.
    const { record } = loadShipmentRecord(context, number);
    shipmentRecords.set(context, number, {
      status: reading.status,
      runId,
      outcome: record.outcome ?? reading.outcome,
    });
    return gracefulComplete();
  }
}

/**
 * Reads the claimed run of a shipment: its status first, then its outcome.
 *
 * @returns A "running" record while that run runs, an "unavailable" record
 * when that run no longer exists or another run replaced it, or the terminal
 * status. It keeps an outcome only when the run is still the claimed one after
 * the read. It throws any other failure so the Step retries.
 */
async function reconcileShipment(client: Client, number: string, runId: string): Promise<ShipmentRecord> {
  const { info, found } = await describeClaimedRun(client, number, runId);
  if (info === undefined || !found) {
    return { status: SHIPMENT_UNAVAILABLE };
  }
  const record = { status: shipmentStatusOf(info.status) };
  if (info.status === "running") {
    return record;
  }
  let outcome: string | undefined;
  try {
    // An unset outcome Attribute leaves outcome empty: the shipment ended without one.
    [outcome] = await client.getAttributes(number, shipmentOutcome);
  } catch (error) {
    if (error instanceof FlowNotFoundError) {
      return record;
    }
    throw error;
  }
  // The Attribute read targets the latest run, so confirm it is still the claimed one.
  const { found: stillClaimed } = await describeClaimedRun(client, number, runId);
  return stillClaimed && outcome !== undefined ? { ...record, outcome } : record;
}

    client: Option<Arc<Client>>,
}

impl Step for StartShipment {
    type Input = TrackedShipment;

    /// Takes the records lock, so the claim and the rejection never race a report.
    fn options(&self) -> StepOptions<Self::Input> {
        StepOptions::new().execute_lock(SHIPMENT_RECORDS_LOCK.lock())
    }

    fn execute(
        &self,
        context: &mut Context,
        mut tracked: Self::Input,
    ) -> HandlerResult<StepDecision> {
        let client = require_client(self.client.as_ref())?;
        let order_flow_id = context.flow_id().to_string();
        let number = tracked.shipment.shipment_number.clone();
        let request_id = shipment_start_request_id(&order_flow_id, &tracked.shipment);
        let request = ShipmentRequest {
            order_flow_id,
            shipment: tracked.shipment.clone(),
        };
        let options = StartFlowOptions::new()
            .timeout(SHIPMENT_TIMEOUT)
            .id_reuse_policy(IdReusePolicy::Disallow)
            .request_id(request_id)
            .ignore_already_started(true);
        match client.start_flow_with_options(&ShipmentFlow::default(), &number, request, options) {
            Ok(run_id) => {
                // Claim the run: reports and reads of any other run of this number are ignored.
                let record = ShipmentRecord {
                    status: Some(SHIPMENT_STARTED.to_string()),
                    run_id: Some(run_id.clone()),
                    outcome: None,
                };
                SHIPMENT_RECORDS.set(context, &number, record)?;
                tracked.shipment_run_id = Some(run_id);
                Ok(StepDecision::go_to(&AwaitShipment::default(), tracked))
            }
            Err(SdkError::FlowAlreadyStarted { .. }) => {
                // Another request owns this shipment number; this order does not track it.
                let record = ShipmentRecord {
                    status: Some(SHIPMENT_REJECTED.to_string()),
                    ..ShipmentRecord::default()
                };
                SHIPMENT_RECORDS.set(context, &number, record)?;
                Ok(StepDecision::graceful_complete(()))
            }
            Err(error) => Err(HandlerError::from_error(error)),
        }
    }
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Reads the claimed shipment run at each interval and records how it ended."
#[derive(Default)]
struct AwaitShipment {
    client: Option<Arc<Client>>,
}

impl Step for AwaitShipment {
    type Input = TrackedShipment;

    /// Takes the same lock as the report RPC and loads the records.
    fn options(&self) -> StepOptions<Self::Input> {
        StepOptions::new()
            .execute_lock(SHIPMENT_RECORDS_LOCK.lock())
            .execute_load_attribute_map(&SHIPMENT_RECORDS)
    }

    fn wait_for(&self, _context: &mut Context, tracked: Self::Input) -> HandlerResult<Wait> {
        Ok(Wait::until(Timer::by_duration(duration_from_seconds(
            tracked.reconcile_interval_seconds,
        ))))
    }

    fn execute(&self, context: &mut Context, tracked: Self::Input) -> HandlerResult<StepDecision> {
        let client = require_client(self.client.as_ref())?;
        let number = tracked.shipment.shipment_number.clone();
        let run_id = tracked.shipment_run_id.clone().unwrap_or_default();
        let reading = match reconcile_shipment(client, &number, &run_id)? {
            ShipmentReading::Running => {
                return Ok(StepDecision::go_to(&AwaitShipment::default(), tracked));
            }
            ShipmentReading::Closed(reading) => reading,
        };
        // Merge with the record, which may already hold the reported outcome.
        let mut record = load_shipment_record(context, &number)?.unwrap_or_default();
        record.status = reading.status;
        record.run_id = tracked.shipment_run_id;
        if record.outcome.is_none() {
            record.outcome = reading.outcome;
        }
        SHIPMENT_RECORDS.set(context, &number, record)?;
        Ok(StepDecision::graceful_complete(()))
    }
}

/// Reads the claimed run of a shipment: its status first, then its outcome.
///
/// Returns `Running` while that run runs, and an "unavailable" record when that
/// run no longer exists or another run replaced it. Keeps an outcome only when
/// the run is still the claimed one after the read. Returns an error for any
/// other failure so the Step retries.
fn reconcile_shipment(
    client: &Client,
    number: &str,
    run_id: &str,
) -> HandlerResult<ShipmentReading> {
    let Some(info) = describe_claimed_run(client, number, run_id)? else {
        return Ok(ShipmentReading::Closed(ShipmentRecord {
            status: Some(SHIPMENT_UNAVAILABLE.to_string()),
            ..ShipmentRecord::default()
        }));
    };
    if info.status == FlowStatus::Running {
        return Ok(ShipmentReading::Running);
    }
    let mut record = ShipmentRecord {
        status: Some(flow_status_name(info.status).to_string()),
        ..ShipmentRecord::default()
    };
    // An unset outcome Attribute leaves the outcome empty: the shipment ended without one.
    let outcome = match client.get_attributes(number, (&*SHIPMENT_OUTCOME,)) {
        Ok((outcome,)) => outcome,
        Err(SdkError::FlowNotFound { .. }) => return Ok(ShipmentReading::Closed(record)),
        Err(error) => return Err(HandlerError::from_error(error)),
    };
    // The Attribute read targets the latest run, so confirm it is still the claimed one.
    if describe_claimed_run(client, number, run_id)?.is_some() {
        record.outcome = outcome;
    }
    Ok(ShipmentReading::Closed(record))
}

## 结果提交后再报告 {#report-after-the-outcome-commits}

发货单在一个 Step 里提交结果，在下一个 Step 里报告。两个 Step 都为 `Execute` 显式声明 SYNC durability。这样即使 Flow 默认是 ASYNC，报告 Step 也只会在结果存好之后开始。

报告带上发货单自己的 run ID。Client 支持 RPC request ID 时，报告还带有稳定的 request ID：`report:`、发货单号、`:` 和 run ID。

订单已经关闭时，报告会返回带类型的错误。发货单到此结束尝试。它的结果仍然可以通过 Client 读取。

## 每个发货单一条记录 {#records}

订单在 `shipmentRecords` AttributeMap 里为每个发货单保存一条记录，以发货单号为键。记录把状态、被认领的 run ID 和结果分成三个字段。

所有写这些记录的地方都锁住单例 Attribute `shipmentRecordsLock`：登记、认领和读取发货单的 Step，以及报告 RPC。这个锁 Attribute 不存任何值，只让写入方一次一个地修改记录。报告遇到锁时会返回锁冲突错误，发货单会重试它。

报告 RPC 只接受被认领的 run 发来的报告：

- 状态仍是 `starting` 的发货单还没有被认领的 run。RPC 返回错误，发货单会重试报告。
- 未知或 `rejected` 的单号、来自其他 run 的报告、或者记录里已经有结果时，报告都不会改变什么。
- 其余情况下，RPC 填入结果。

/// order claimed; the first report wins, and any other report changes nothing.
///
/// Returns a `ShipmentNotClaimed` error while the order is still starting
/// that shipment, so the shipment retries its report.
fn record_shipment_outcome(
    &self,
    context: &mut Context,
    report: ShipmentReport,
) -> HandlerResult<()> {
    let loaded = load_shipment_record(context, &report.shipment_number)?;
    if let Some(record) = &loaded
        && record.status.as_deref() == Some(SHIPMENT_STARTING)
    {
        return Err(HandlerError::new(
            SHIPMENT_NOT_CLAIMED_ERROR_TYPE,
            SHIPMENT_NOT_CLAIMED_MESSAGE,
        ));
    }
    // Ignore an unknown or rejected shipment, another run, and a repeated report.
    let Some(mut record) = loaded.filter(|record| {
        record.run_id.as_deref() == Some(report.shipment_run_id.as_str())
            && record.outcome.is_none()
    }) else {
        return Ok(());
    };
    record.outcome = Some(report.outcome);
    SHIPMENT_RECORDS.set(context, &report.shipment_number, record)
}

fn rpcs(&self) -> RpcList<Self> {
    RpcList::new().procedure(
        RECORD_SHIPMENT_OUTCOME
            .lock(SHIPMENT_RECORDS_LOCK.lock())
            .load_attribute_map(&SHIPMENT_RECORDS),
        Self::record_shipment_outcome,
    )
}

`AwaitShipment` 按这个顺序读取被认领的 run：

1. 描述发货单。被认领的 run 仍在运行时，在下一个间隔再读，即使它的报告已经到达。
2. 被认领的 run 已关闭：先记录状态，再读它的结果 Attribute。Attribute 未设置表示发货单结束时没有结果。Attribute 读取看到的是发货单最新的 run，所以 Step 会再描述一次发货单。只有被认领的 run 仍是最新的 run 时，它才保留结果。
3. 找不到发货单，或者同一单号的另一个 run 取代了被认领的 run 时，订单记录 `unavailable`。这是业务策略。
4. 其他错误让 Step 失败，Dex 会重试它。

订单运行期间，只要被认领的 run 仍是发货单最新的 run，订单就能知道它的终止状态。其他调用方重新使用这个单号，或者这个 run 的数据被删除之后，订单就读不到它了。

客服团队可以按单号取消发货单。在结果提交之前被取消的发货单没有结果，订单把它记录为 `canceled`。在结果提交之后、或在报告发出之后被取消的发货单仍可能有结果，订单会保留它。

一个发货单号只属于一个订单。另一个请求已经用过这个单号时，启动会返回带类型的 already-started 错误。示例把这个发货单记录为 `rejected`，并忽略发给它的报告。每次业务尝试都使用自己的发货单号。

// It returns found as false after it responded: 404 when no ShipmentFlow has that Flow ID.
func (controller *controller) describeShipment(request *gin.Context) (string, dex.FlowInfo, bool) {
	number, found := httputil.RequiredQuery(request, "shipmentNumber")
	if !found {
		return "", dex.FlowInfo{}, false
	}
	info, err := controller.client.DescribeFlow(request.Request.Context(), number)
	var notFound *dex.FlowNotFoundError
	if errors.As(err, &notFound) || (err == nil && info.FlowType != shipmentFlowType) {
		request.JSON(http.StatusNotFound, gin.H{"error": "shipment " + number + " not found"})
		return "", dex.FlowInfo{}, false
	}
	if err != nil {
		httputil.Respond(request, nil, err)
		return "", dex.FlowInfo{}, false
	}
	return number, info, true
}

  response: Response,

/// Looks a shipment up by its shipment number, which is its Flow ID.
async fn get_shipment(
    State(client): State<SharedClient>,
    Query(query): Query<ShipmentQuery>,
) -> Response {
    let (number, info) = match describe_shipment(&client, query).await {
        Ok(described) => described,
        Err(response) => return response,
    };
    let lookup_number = number.clone();
    let lookup = run_blocking(move || client.get_attributes(&lookup_number, (&*SHIPMENT_OUTCOME,)));
    match lookup {
        Ok((outcome,)) => ok_json(ShipmentView {
            shipment_number: number,
            status: flow_status_name(info.status).to_string(),
            outcome: outcome.unwrap_or_default(),
        }),
        Err(error) => map_sdk_error(error).into_response(),
    }
}

/// Stops a shipment by its number. Its order records it at the next reconcile read.
async fn cancel_shipment(
    State(client): State<SharedClient>,
    Query(query): Query<ShipmentQuery>,
) -> Response {
    let (number, _info) = match describe_shipment(&client, query).await {
        Ok(described) => described,
        Err(response) => return response,
    };

/// Describes the Flow named by the `shipmentNumber` query.
///
/// Returns the shipment number and its Flow info, or the error response to send:
/// 404 when no `ShipmentFlow` has that Flow ID.
async fn describe_shipment(
    client: &SharedClient,
    query: ShipmentQuery,
) -> Result<(String, FlowInfo), Response> {
    let number = query.shipment_number;
    if number.is_empty() {
        return Err(error_response(
            StatusCode::BAD_REQUEST,
            "shipmentNumber is required",
        ));
    }
    let lookup_client = Arc::clone(client);
    let lookup_number = number.clone();
    match run_blocking(move || lookup_client.describe_flow(&lookup_number)) {
        Ok(info) if info.flow_type == ShipmentFlow::default().flow_type() => Ok((number, info)),
        Ok(_) | Err(SdkError::FlowNotFound { .. }) => Err(error_response(
            StatusCode::NOT_FOUND,
            &format!("shipment {number} not found"),
        )),
        Err(error) => Err(map_sdk_error(error).into_response()),
    }
}

## 选择这个模式还是 SubFlow {#choose}

子任务只为父 Flow 存在时，选择 [SubFlow](/concepts/primitives/subflow)。Dex 从父 Flow 派生它的 Flow ID，父 Flow 用 Condition 等待它。

子任务需要自己的标识时，选择顶层子 Flow：

- 人或系统按它自己的编号查找、重试或停止它。
- 父 Flow 之外的调用方也可以启动它。
- 它可以比父 Flow 活得更久，有自己的 Flow timeout。

代价是更多代码。父 Flow 要启动子 Flow、认领它的 run、接收它的报告，并一直读取它，直到它结束。
