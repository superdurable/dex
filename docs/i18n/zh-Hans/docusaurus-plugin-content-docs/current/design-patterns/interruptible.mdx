# 可中断执行

在收到 durable 中断信号后，安全地停止长时间工作。

**InterruptibleFlow** 会并行启动 **WorkAStep** 和 **WorkBStep**。每个 Step 会在安排下一项工作前检查 durable 的 **interruptSignal**。**interrupt** RPC 写入该信号，使任一分支都能优雅地完成 Flow。

![InterruptibleFlow 图](https://lucid.app/lucidchart/b2866468-d530-4f76-9cc7-4441c5742460/edit?page=3-Wo.4lcXZvd)

可运行示例位于 [Go](https://github.com/superdurable/dex/tree/main/examples/go/patterns/interruptible)、[Java](https://github.com/superdurable/dex/tree/main/examples/java/src/main/java/io/superdurable/dex/patterns/interruptible)、[Python](https://github.com/superdurable/dex/tree/main/examples/python/dex_examples/patterns/interruptible)、[TypeScript](https://github.com/superdurable/dex/tree/main/examples/typescript/src/patterns/interruptible) 和 [Rust](https://github.com/superdurable/dex/tree/main/examples/rust/src/patterns/interruptible) 目录。
