# 为外部发布排空 Channel

处理外部发布到 Channel 的消息；队列为空时完成这条短生命周期的 Flow。

## 问题与做法

当一条 Flow 要处理 Worker 外部发来的一批消息，但这批消息处理完后没有其他 durable 工作时，使用这个模式。外部发布者通过 Client **PublishToChannel** API 或 Flow RPC 追加消息。**ProcessMessage** 等待一条消息、处理它，然后返回 **ForceCompleteIfChannelsEmpty**。

这个 decision 会在记录下一步动作时原子地检查 Channel。Channel 为空时完成 Flow；仍有消息时，Dex 会走 fallback movement 回到 **ProcessMessage**。前一次 execution 完成后，下一个请求必须用相同的 Flow ID 启动新的 Flow execution，才能追加下一条消息。

被 **ForceCompleteIfChannelsEmpty** 检查的 Channel 只能由一个 Step 消费。

def wait_for(self, context: Context, input: str) -> Wait:
    del context
    if input is None:
        return Wait.until(self.queue_channel.for_one())
    return Wait.skip_immediately()

return force_complete_if_channels_empty(
    None,
    StepMovement.of(self, None),
    self.queue_channel,
)

func (processMessageStep) WaitFor(_ dex.Context, input string) (*dex.Wait, error) {
	if input == "" {
		return dex.Until(QueueChannel.ForOne()), nil
	}
	return dex.SkipWaitImmediately(), nil
}

return dex.ForceCompleteIfChannelsEmpty(
	nil,
	[]dex.ChannelDef{QueueChannel},
	dex.MovementOf(processMessageStep{}, ""),
), nil
