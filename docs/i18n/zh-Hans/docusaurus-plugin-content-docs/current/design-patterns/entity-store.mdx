# 带 SQL 投影的实体 Flow

每个实体（例如一个用户）对应一个 Flow。Dex 把这个 Flow 中选定的 Attribute 投影（复制）到你的应用自己的 SQL 表中。权威状态保存在 Flow 里，所有写入都经过 Flow。Dex 异步更新 SQL 表，表中只保存最新的值，用于读取和查询。

可运行示例为每个用户保留一个 `UserProfileFlow`。它的 Flow ID 就是 `public.user_profiles` 表的 `user_id` 主键。Server 配置把目标 Attribute Store 命名为 `entityStore`。

## 适用场景

当一个实体需要持久化状态或通过 RPC 更新，而你的应用还要在数据库中查询它的最新状态时，使用这个模式。不要根据 SQL 表做 Flow 决策，应读取 Flow 状态。

## 工作方式

用实体 ID 作为 Flow ID。标记每个要投影的 Attribute，并在启动 Flow 时选择 Attribute Store。通过 Flow 更新或删除 Attribute，Dex 会把结果值投影到 SQL。配置见[在 Flow 之后保留数据](/concepts/primitives/attribute#attribute-store-projection)。

示例投影 text、boolean、integer、double、datetime 和 JSON 值。删除 Attribute 时，SQL 行会保留，对应列投影为 `NULL`。列类型、同步时延和重试见 [Attribute Store sync reference](/reference/server/attribute-store-sync)。

## 核心实现

### 定义同步的 Attribute

每种 SDK 都把同一组 profile 字段标记为需要投影。Flow 的 persistence schema 包含这些 Attribute，所以 Dex 先把每个值持久保存，再把它同步到 SQL。

### 通过 Flow RPC 更新

客户端调用这个 RPC 更新 profile。RPC 先校验 profile，再更新每个要投影的 Attribute。

func (flow *UserProfileFlow) GetRPCs() []dex.RPCDef {
	return []dex.RPCDef{
		dex.DefineRPC(flow.UpdateProfile, nil),
		dex.DefineRPC(flow.GetProfile, nil),
		dex.DefineRPC(flow.ClearProfile, nil),
	}
}

func (*UserProfileFlow) UpdateProfile(
	ctx dex.Context,
	profile UserProfile,
) (*dex.RPCResult[dex.None], error) {
	if err := validateProfile(profile); err != nil {
		return nil, err
	}
	if err := DisplayName.Set(ctx, profile.DisplayName); err != nil {
		return nil, err
	}
	if err := Email.Set(ctx, profile.Email); err != nil {
		return nil, err
	}
	if err := MarketingOptIn.Set(ctx, profile.MarketingOptIn); err != nil {
		return nil, err
	}
	if err := Credits.Set(ctx, profile.Credits); err != nil {
		return nil, err
	}
	if err := Weight.Set(ctx, profile.Weight); err != nil {
		return nil, err
	}
	if err := LastLoggedIn.Set(ctx, profile.LastLoggedIn); err != nil {
		return nil, err
	}
	if err := Metadata.Set(ctx, profile.Metadata); err != nil {
		return nil, err
	}
	return &dex.RPCResult[dex.None]{}, nil
}

## API endpoints

- **POST /patterns/entity-store/profile**：创建 profile Flow
- **POST /patterns/entity-store/profile/update**：更新同步的字段
- **GET /patterns/entity-store/profile?userId=...**：从 Flow 读取 profile
- **POST /patterns/entity-store/profile/clear?userId=...**：删除同步的值
