# CLI（dexcli）

`dexcli` 是 Dex 的命令行工具。它优先输出 JSON，所以除了人，shell 脚本和 AI agent 也能直接使用它。

## 功能

- **dexcli dev** 在你的机器上启动本地 Dex：server-zd 和 Dex Web。发布包在 `dexcli` 旁边附带 **dex-server-zd**。
- **dexcli flow** 查看、搜索、跟踪和操作 Flow。
- **dexcli api** 调用任何公开 API 方法。
- **dexcli web** 针对一个已有的 server 提供 Dex Web。
- **dexcli visualize** 根据 Flow 源码画出 Flow Definition Graph。
- **dexcli flow-definition** 把 Flow Definition Graph 发布到 server，Dex Web 从那里读取。
- **dexcli version check** 检查与 server 的协议兼容性。
- **dexcli admin** 查看 active server 进程，或让它让位。

## 与其他组件的关系

`dexcli` 调用 [server](/components/server) 的 API，也就是 [Worker 和 Client](/components/application) 使用的同一个 API。它默认连接 **127.0.0.1:8801**，也就是 **dexcli dev** 监听的地址。

```bash
dexcli dev
dexcli flow inspect order-123
```
