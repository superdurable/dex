# 在 Dex Cloud 上运行

在 Dex Cloud 中，Super Durable 为你的应用运行 Dex Server。你的 Worker 仍然运行你的 Flow 代码，可以在你的服务器、你的云或者你的笔记本上。

## 开始使用 {#get-started}

[注册 Dex Cloud](https://dex.superdurable.io/register)，然后创建一个 server。价格、区域和 SLA，请[联系 Super Durable](https://superdurable.io/about/#contact)。

## 连接 Worker 和 Client {#connect}

你在 Dex Cloud 创建的每个 server 都有自己的 endpoint 和 API key。Worker 和 Client 通过 TLS、使用这个 key 连接到这个 endpoint：

- key 放在 [API key credential](/reference/server/authentication#sdk-credentials) 里。
- TLS 用 SDK 的 [TLS 选项](/reference/server/authentication#tls)。

## 各部分由谁运行 {#what-runs-where}

你的代码调用你自己的 API 时使用的凭证留在你的 Worker 里。[Dex Server 运行在哪里](/components#where-to-run)对比了 Dex Cloud 和自托管 server。
