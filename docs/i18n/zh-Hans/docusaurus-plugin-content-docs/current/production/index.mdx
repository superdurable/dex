# 部署到生产环境

安全地在生产环境中运行 Dex 应用和服务器。

- [应用运维](/production/application-operations) — Worker 健康状况、只读排障、恢复和
  Flow 代码版本控制
- [拉取模式 Worker](/production/pull-workers) — Worker 出站连接、路由、容量和关闭
- [部署 Agent](/production/agents) — agent session 的 Stream 后端、Worker 和 Stream
  容量规划、session 限制、审批、重新部署和凭证
- [Dex Web](/production/dex-web) — 独立的 dex-web 二进制文件和镜像、访问控制、v1 run 搜索，
  以及 v2 Run 与 Work Queue 工作区
- [server-zd 运维](/production/server-zd-operations) — server-zd 的单节点 Kubernetes
  部署、lease、对象存储、Pull Worker 分发、指标、身份验证和备份
- [自定义 Attribute Store](/production/attribute-store) — PostgreSQL
  投影、schema 契约和重试语义
