# 指标

启用 Prometheus reporter 后，Dex Server 会导出本页的指标目录。这些是最终指标名。对应操作
发生前不会出现 series；可选组件只会在启用时导出其指标。

duration timer 用于记录耗时。在 Prometheus 中单位为秒；reporter 会按其配置将它导出为
histogram 或 summary。下文其余类型都是 Prometheus counter 或 gauge。

## 标签与基数

Server 生成的 series 会在运行时提供标签值时携带以下公共标签：

| 标签 | 值和限制 |
| --- | --- |
| **namespace** | 配置的 execution namespace。保持 namespace 数量较小。 |
| **client_name** | 固定的 runtime client identifier。每个已部署 runtime 只有一个有界值。 |
| **worker_type** | 有界的 worker category；不适用时为 **none**。 |
| **workflow_type** | 已注册的 workflow implementation name；不适用时为 **none**。不要使用 execution ID 作为 type name。 |
| **activity_type** | 已注册的 activity implementation name；不适用时为 **none**。 |
| **task_queue** | 配置的 task-queue name；不适用时为 **none**。使用有界的 queue name 集合。 |

Dex 会为 Flow 和 Step 指标添加下列之一的语义标签集：

| 指标主体 | 额外标签 |
| --- | --- |
| 应用 Flow | **flow_type** |
| 同步或异步 Step | **flow_type**、**step_type** |
| 同步或异步 SubFlow start | **flow_type**、**sub_flow_type** |
| 同步或异步 Worker RPC | **flow_type**、**rpc_name** |
| 同步或异步 system Step | **flow_type** |

对于 Dex 语义标签，**none** 表示该指标 family 有该标签，但此观测没有适用值。例如，
应用 Flow 之外的 system Step 具有 **flow_type="none"**。它不表示未知 Flow type。

目录还使用以下有界标签：

| 标签 | 值和限制 |
| --- | --- |
| **poller_type** | **workflow_task**、**workflow_sticky_task**、**activity_task** 或 **nexus_task** 之一。 |
| **operation** | 稳定的 server RPC operation name。不要将 request ID 或用户输入放在这里。 |
| **status_code** | 有限的 gRPC status code，例如 **UNAVAILABLE** 或 **INTERNAL**。它出现在失败 request 指标上。 |
| **failure_reason** 和 **cause** | 有界的 runtime reason value。不要把 error message 复制到任一标签中。 |
| **nexus_service** 和 **nexus_operation** | 配置的 Nexus name。两个集合都应保持有界。 |
| **prefix** | 配置的 Blob Store namespace 或 domain。 |
| **step_method** | **wait_for** 或 **execute**。 |
| **reason** | 有界的 Step-stream write failure reason。 |

不要把 Flow ID、Run ID、Step execution ID、customer ID、request ID、payload value 或 error text
作为 metric label。它们会造成无界的 Prometheus cardinality。

## Flow 结果

应用 Flow 指标带有公共标签和 **flow_type**。system Flow 指标带有公共标签，但没有
**flow_type** 标签。

| 最终指标名 | 类型 | 含义 |
| --- | --- | --- |
| **dex_flow_completed**<br/>**dex_sys_flow_completed** | Counter | 成功完成的 Flow。 |
| **dex_flow_canceled**<br/>**dex_sys_flow_canceled** | Counter | 以 canceled 状态关闭的 Flow。 |
| **dex_flow_failed**<br/>**dex_sys_flow_failed** | Counter | 以 failed 状态关闭的 Flow。 |
| **dex_flow_continue_as_new**<br/>**dex_sys_flow_continue_as_new** | Counter | continue-as-new 为新 run 的 Flow run。 |
| **dex_flow_endtoend_latency**<br/>**dex_sys_flow_endtoend_latency** | Duration timer，秒 | 从 Flow-run start 到 close 的时间。 |

## Flow task 调度与执行

应用 Flow task 指标带有公共标签和 **flow_type**。system Flow task 指标带有公共标签，但没有
**flow_type** 标签。

| 最终指标名 | 类型 | 含义 |
| --- | --- | --- |
| **dex_flow_task_replay_latency**<br/>**dex_sys_flow_task_replay_latency** | Duration timer，秒 | replay 一个 Flow task 所花的时间。 |
| **dex_flow_task_queue_poll_empty**<br/>**dex_sys_flow_task_queue_poll_empty** | Counter | 空的 Flow-task poll。 |
| **dex_flow_task_queue_poll_succeed**<br/>**dex_sys_flow_task_queue_poll_succeed** | Counter | 返回 task 的 Flow-task poll。 |
| **dex_flow_task_schedule_to_start_latency**<br/>**dex_sys_flow_task_schedule_to_start_latency** | Duration timer，秒 | 从 Flow-task schedule 到 start 的时间。 |
| **dex_flow_task_execution_latency**<br/>**dex_sys_flow_task_execution_latency** | Duration timer，秒 | 执行一个 Flow task 所花的时间。 |

| **dex_flow_task_no_completion**<br/>**dex_sys_flow_task_no_completion** | Counter | 返回时没有 completion 的 Flow task。 |

## 请求

request 指标带有公共标签和 **operation**。failure 和 resource-exhausted 指标还带有
**status_code**。以 **_attempt** 结尾的名称统计单次 transport attempt（包括 retry）；
其他名称统计逻辑 request。

| 最终指标名 | 类型 | 含义 |
| --- | --- | --- |
| **dex_request**<br/>**dex_request_attempt** | Counter | 已开始的非长 request。 |
| **dex_request_failure**<br/>**dex_request_failure_attempt** | Counter | 失败的非长 request。 |
| **dex_request_latency**<br/>**dex_request_latency_attempt** | Duration timer，秒 | 非长 request latency。 |
| **dex_request_resource_exhausted**<br/>**dex_request_resource_exhausted_attempt** | Counter | 因 resource exhaustion 被拒绝的非长 request。 |
| **dex_long_request**<br/>**dex_long_request_attempt** | Counter | 已开始的 long-poll request。 |
| **dex_long_request_failure**<br/>**dex_long_request_failure_attempt** | Counter | 失败的 long-poll request。 |
| **dex_long_request_latency**<br/>**dex_long_request_latency_attempt** | Duration timer，秒 | long-poll request latency。 |
| **dex_long_request_resource_exhausted**<br/>**dex_long_request_resource_exhausted_attempt** | Counter | 因 resource exhaustion 被拒绝的 long-poll request。 |

## 缓存

这些指标带有公共标签。它们报告 Server sticky cache；Blob Store cache 指标在下一节。

| 最终指标名 | 类型 | 额外标签 | 含义 |
| --- | --- | --- | --- |
| **dex_sticky_cache_hit** | Counter | **workflow_type**、**task_queue** | 找到 entry 的 sticky-cache lookup。 |
| **dex_sticky_cache_miss** | Counter | **workflow_type**、**task_queue** | 未找到 entry 的 sticky-cache lookup。 |
| **dex_sticky_cache_total_forced_eviction** | Counter | **workflow_type**、**task_queue**、**cause** | 从 sticky cache 强制逐出的 entry。 |
| **dex_sticky_cache_size** | Gauge | **workflow_type**、**task_queue** | 当前 sticky-cache entry count。 |

## Blob Store

Blob Store 指标带有公共标签和 **prefix**。cache 行只会在启用 S3 Attribute cache 时出现。

| 最终指标名 | 类型 | 含义 |
| --- | --- | --- |
| **write_object_error** | Counter | Blob Store write failure。 |
| **read_object_error** | Counter | Blob Store read failure。 |
| **write_object_success** | Duration timer，秒 | 成功的 Blob Store write latency。 |
| **read_object_success** | Duration timer，秒 | 成功的 Blob Store read latency。 |
| **blob_cache_hit** | Counter | Attribute Blob cache hit。 |
| **blob_cache_miss** | Counter | Attribute Blob cache miss。 |
| **blob_cache_write_through** | Counter | 写入 Attribute Blob cache 的 object。 |
| **blob_cache_read_fill** | Counter | source read 后填充 Attribute Blob cache。 |
| **blob_cache_bypass** | Counter | 有意不缓存的 Attribute object。 |
| **blob_cache_error** | Counter | Attribute Blob cache error。 |

## 查询和告警方向

使用 counter 创建可移植的 dashboard 和 alert。下面的示例不依赖 histogram 或 summary 配置。

按 Flow type 查看失败的应用 Flow：

~~~promql
sum(rate(dex_flow_failed[5m])) by (flow_type)
~~~

按 Flow 和 Step type 查看失败的同步 Step：

~~~promql
sum(rate(dex_sync_step_execution_failed[5m])) by (flow_type, step_type)
~~~

失败的 Worker RPC 调用：

~~~promql
sum(rate(dex_sync_invoke_rpc_execution_failed[5m])) by (flow_type, rpc_name)
~~~

Step-stream write failure：

~~~promql
sum(rate(dex_step_stream_write_failure[5m])) by (flow_type, step_type, reason)
~~~

Blob Store read 和 write error：

~~~promql
sum(rate(read_object_error[5m])) by (prefix)
+ sum(rate(write_object_error[5m])) by (prefix)
~~~

当 **dex_flow_failed**、Step failure counter、request failure、Blob Store error 或 Step-stream
write failure 持续增加时告警。将 alert 与有界的 **flow_type**、**step_type**、**rpc_name**、
**operation** 或 **prefix** breakdown 配对，让响应者无需查询高基数标签就能识别受影响服务。
