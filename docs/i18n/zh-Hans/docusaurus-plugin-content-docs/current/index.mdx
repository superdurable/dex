# Dex 文档

Dex 是一个轻量的 **持久化执行（Durable Execution）** 平台，用于 AI Agent 和工作流。你写普通代码，Dex 让它在崩溃、部署和长时间等待中持续运行，而且不重放你的代码。Dex 把状态存放在对象存储中，运行时不需要数据库。
