# Dex 文档

Dex 是一个 **Durable Execution** 平台。数据库保存你的数据；Dex 还会保存流程的进度：哪些 Step 已经运行、返回了什么、流程正在等什么。进程崩溃、重启，或者等了很久之后，流程都会从停下的地方继续。

你用普通的应用代码写流程，用到的是 Flow、Step、Attribute、Channel、RPC 和 Connector。
