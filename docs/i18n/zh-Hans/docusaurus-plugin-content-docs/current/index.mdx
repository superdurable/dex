# Dex 文档

Dex 是 **Durable Execution**——面向后端工程的分布式系统抽象。Durable 存储持久化数据；Durable Execution 持久化 **数据和作为 execution 的动作**。Dex 把这个想法做成结构：Flow、Step、Connector、Attribute、Channel、RPC，就是普通应用代码。
