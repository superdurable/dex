# 产品示例

每个例子都是用 Dex 构建的完整后端流程。一个设计模式只讲一种技巧，这些例子把几种技巧组合在一起。

## 示例

- [AI Agent](/use-cases/ai-agent)：基于内置 agent loop 的通用 agent，带审批、提问和 MCP 工具
- [Order Support Agent](/use-cases/order-support-agent)：同一个订单客服 agent，每个 agent 框架各一份
- [Order Processing](/use-cases/order-processing)：扣款、卖家审批带提醒、发货或退款
- [订阅与计费生命周期](/use-cases/subscription)：试用与定期计费
- [用户入驻流程](/use-cases/user-onboarding-process)：邮箱验证和两个按顺序完成的设置任务
- [Money transfer](/use-cases/money-transfer)：saga 借记/贷记和补偿
- [求职者沟通](/use-cases/job-seeker-engagement)：提醒、退订、拒绝和接受
- [Deal DSL](/use-cases/deal-dsl)：适用于任意商品的持久化交易解释器
- [Microservice orchestration](/use-cases/microservice-orchestration)：并发 API + Channel/Timer
- [职位发布](/use-cases/job-post)：带 lock 的更新与两个独立 FIFO 招聘网站 consumer
- [客户退款](/use-cases/customer-refund)：确定性与 agentic 退款流程


可运行代码在 GitHub 的 examples/go、examples/java、examples/python、examples/typescript 和 examples/rust 下。带 HTTP 服务的例子使用 /products/name/ 路径前缀。大多数例子可以在 examples playground（`examples/playground`）里运行；见 `examples/README.md`。Deal DSL 和 AI agent email 有自己的 UI，不在 playground 上。
