# 产品示例

比设计模式更完整的产品向例子。每一个都把 Dex primitive 组合成真实的后端场景。

## 共用例子

- [订单处理](/intro/what-is-dex) — 扣款、卖家审批带提醒、发货或退款
- [Money transfer](/use-cases/money-transfer) — saga 借记/贷记和补偿
- [Microservice orchestration](/use-cases/microservice-orchestration) — 并发 API + Channel/Timer
- [求职者沟通](/use-cases/job-seeker-engagement) — 提醒、退订、拒绝和接受
- [订阅](/use-cases/subscription) — 试用与定期计费
- [用户入驻流程](/use-cases/user-onboarding-process) — 邮箱验证和两个按顺序完成的设置任务
- [职位发布](/use-cases/job-post) — 带 lock 的更新与两个独立 FIFO 招聘网站 consumer

## 语言特定

- [Dataset Deal](/use-cases/dataset-deal) — Go DSL 例子
- [AI agent email](/use-cases/ai-agent-email) — Python durable AI 邮件应用

可运行代码：GitHub 上的 examples/go, examples/java, examples/python, examples/typescript, and examples/rust（适用时 HTTP 前缀 /products/name/...）。共用例子可在 examples playground（**examples/playground**）里试；见 **examples/README.md**。Dataset Deal 和 AI agent email 有自己的 UI，不在 playground 上。
