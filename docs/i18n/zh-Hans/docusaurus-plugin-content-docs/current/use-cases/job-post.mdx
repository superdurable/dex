# 职位发布

保存一条职位信息并支持搜索，同时把每个已接受的更新按顺序发送到 LinkedIn 和 Indeed。

## 产品需求

每个 Flow 在整个生命周期内代表一条职位信息。它必须：

1. 使用职位名称、描述、最后更新时间和初始值为 0 的更新版本创建 Flow。名称保存在 **text1** 全文检索 Search Attribute 中。描述会保存，但不建索引。
2. 只运行一次 **InitStep**，并行启动 **UpdateLinkedInPosting** 和 **UpdateIndeedPosting**。之后每个 Step 在自己的 Channel 上等待。
3. 通过读取 RPC 返回当前名称、描述和备注。
4. 通过更新 RPC 接收新的名称、描述和备注。RPC 声明对 **UpdatePostingLock** 的 lock。这个 Attribute 没有值，只用来加 lock。这样 Dex 一次只运行一个更新，同一时间只有一个更新能分配版本并发布消息。
5. 递增 **UpdateVersion**，持久化当前职位信息，并把同一个不可变 **PostingUpdate** 发布到 **LinkedInPostingUpdates** 和 **IndeedPostingUpdates**。消息包含版本、稳定的幂等键和职位快照。
6. 每个 consumer Step 每次从自己的 FIFO Channel 取一条消息。招聘网站调用成功后，Step 回到自身，等待下一条消息。
7. 独立重试两个招聘网站的调用：首次间隔三秒，最大间隔 60 秒，最多 100 次，总时长不超过一小时。
8. 删除职位时停止 Flow。搜索操作通过建立索引的 Attribute 查找活跃职位。

更新 RPC 不等待 LinkedIn 或 Indeed。Dex 保存好职位信息和两条 Channel 消息后，RPC 立即返回新版本。

需要处理的故障：

- 如果缺少必需的初始 Attribute，或者值无法编码，创建 Flow 会失败。这时 Dex 不会创建 Flow，也不会留下只有部分状态的 Flow。
- Flow ID 不存在、Flow 已停止、输入无法持久化，或者另一个 RPC 持有 **UpdatePostingLock** 时，更新 RPC 会失败。lock conflict 可以安全重试。
- LinkedIn 或 Indeed 可能不可用、超时、限流或拒绝职位信息。一个 consumer 可以继续运行，而另一个仍在重试或最终失败。
- 远端请求可能已经成功，但响应丢失。幂等键由版本生成，外部适配器可以据此丢弃重复的重试。
- consumer 重试期间，发往该招聘网站的后续消息会一直等到它成功或用完重试。这样能保持 FIFO 顺序：较新的职位信息不会越过较旧的。
- 删除请求到达时，已接受的更新可能还在排队或正在发送。按产品的删除规则，决定停止 Flow 时取消这些工作还是让它们完成。

lock 按 Dex 接受更新的先后排序，而不是按客户端发出请求的先后。两个调用方同时更新时，谁先拿到 lock 都有可能。返回的版本就是接受的顺序，每个招聘网站都按这个顺序收到更新。

## Flow 设计

<DocsFlowDefinitionGraph graph={flowDefinition} />

一个带 lock 的 RPC 产生更新，两个 consumer Step 各自按自己的进度投递：

```text
创建职位（版本 0）
             │
             ▼
          InitStep
        ┌────┴────┐
        ▼         ▼
 UpdateLinkedIn  UpdateIndeed
 Posting        Posting
        │         │
 等待 LinkedIn  等待 Indeed
 Channel        Channel
        ▲         ▲
        │         │
        └────┬────┘
             │
 更新 RPC [UpdatePostingLock]
 持久化版本 N + 发布相同的 PostingUpdate
             │
             └── 返回版本 N
```

它用到以下模式：

- [**实体存储**](/design-patterns/entity-store)为每条职位信息分配稳定的 Flow ID，并使用 Attribute 保存可检索的当前状态。
- **状态和消息一起保存**：Dex 把职位信息和两条 Channel 消息作为同一个 RPC 结果保存。已接受的更新不会只发到一个招聘网站。
- **消息自带快照**：每条消息都带着 RPC 当时看到的职位信息。consumer 不会事后再读可能已经改变的 Attribute。
- **FIFO consumer 循环**：每个 consumer 处理一条消息后回到自身。即使更新连续快速到达，每个招聘网站也总是先收到 v1，再收到 v2。

consumer Step 不需要 Attribute lock。每个招聘网站同一时间只有一个 consumer 在运行，顺序由 Channel 保证。在这里加 lock 可以避免重叠，但单靠它既保不住快照，也保证不了 FIFO 顺序。

```python
    update_version = UPDATE_VERSION
    update_posting_lock = UPDATE_POSTING_LOCK
    linkedin_posting_updates = LINKEDIN_POSTING_UPDATES
    indeed_posting_updates = INDEED_POSTING_UPDATES

            self.update_linkedin_posting,
            self.update_indeed_posting,
        )

    @rpc(lock_attributes=(update_posting_lock.lock(),))
    def update(self, context: Context, input: JobInfo) -> RPCResult[int]:

        self.job_description.set(context, input.description or "")
```

```go
type JobPostingFlow struct {
	dex.FlowDefaults
	service service.MyService
}

func (flow *JobPostingFlow) GetSteps() []dex.StepDef {
	return []dex.StepDef{
		dex.DefineStartStep(InitStep{}),
		dex.DefineStep(UpdateLinkedInPosting{service: flow.service}),
		dex.DefineStep(UpdateIndeedPosting{service: flow.service}),
	}
}

func (flow *JobPostingFlow) GetRPCs() []dex.RPCDef {
	return []dex.RPCDef{
		dex.DefineRPC(flow.Get, nil),
		dex.DefineRPC(flow.GetWithStrongConsistency, nil),
		dex.DefineRPC(flow.Update, &dex.RPCOptions{
			LockAttributes: []dex.AttributeLock{dex.LockAttribute(UpdatePostingLock)},
		}),
	}
}

func (*JobPostingFlow) Update(
	ctx dex.Context,
	input JobInfo,
) (*dex.RPCResult[int], error) {
	version, err := UpdateVersion.Get(ctx)
	if err != nil {
		return nil, err
	}
	version++
	if err := UpdateVersion.Set(ctx, version); err != nil {
		return nil, err
	}
	update := PostingUpdate{
		Version:        version,
		IdempotencyKey: fmt.Sprintf("%s:%d", ctx.FlowID(), version),
		Posting:        input,
	}
	if err := LinkedInPostingUpdates.Publish(ctx, update); err != nil {
		return nil, err
	}
	if err := IndeedPostingUpdates.Publish(ctx, update); err != nil {
		return nil, err
	}
	return &dex.RPCResult[int]{Output: version}, nil
}

func (InitStep) Execute(
	_ dex.Context,
	_ dex.None,
) (*dex.StepDecision, error) {
	return dex.GoToMany(
		dex.MovementOf(UpdateLinkedInPosting{}, nil),
		dex.MovementOf(UpdateIndeedPosting{}, nil),
	), nil
}

func (UpdateLinkedInPosting) WaitFor(
	_ dex.Context,
	_ dex.None,
) (*dex.Wait, error) {
	return dex.Until(LinkedInPostingUpdates.ForOne()), nil
}

func (step UpdateLinkedInPosting) Execute(
	ctx dex.Context,
	_ dex.None,
) (*dex.StepDecision, error) {
	update, err := linkedInPostingUpdate(ctx)
	if err != nil {
		return nil, err
	}
	step.service.UpdateExternalSystem(fmt.Sprintf(
		"update LinkedIn job posting v%d [%s]: %s",
		update.Version,
		update.IdempotencyKey,
		update.Posting.Title,
	))
	return dex.GoTo(UpdateLinkedInPosting{}, nil), nil
}
```

```java
@Component
public class JobPostingFlow implements Flow<Void> {
    public final Attribute<Integer> updateVersion =
            Attribute.define("UpdateVersion", Integer.class);
    public final Attribute<Void> updatePostingLock =
            Attribute.define("UpdatePostingLock", Void.class);
    public final Channel<PostingUpdate> linkedInPostingUpdates =
            Channel.define("LinkedInPostingUpdates", PostingUpdate.class);
    public final Channel<PostingUpdate> indeedPostingUpdates =
            Channel.define("IndeedPostingUpdates", PostingUpdate.class);

    @Override
    public StepList<Void> getSteps() {
        return StepList.startStep(init)
                .otherSteps(updateLinkedInPosting, updateIndeedPosting);
    }

    @RPC(lockAttributes = {"UpdatePostingLock"})
    public RPCResult<Integer> update(final Context context, final JobInfo input) {
        final int version = updateVersion.get(context) + 1;
        title.set(context, input.title);
        updateVersion.set(context, version);
        final PostingUpdate update = new PostingUpdate(
                version,
                context.getFlowId() + ":" + version,
                input);
        linkedInPostingUpdates.publish(context, update);
        indeedPostingUpdates.publish(context, update);
        return RPCResult.of(version);
    }

    final class InitStep implements Step<Void> {
        @Override
        public StepDecision execute(final Context context, final Void input) {
            return StepDecision.goToMany(
                    StepMovement.of(UpdateLinkedInPosting.class, null),
                    StepMovement.of(UpdateIndeedPosting.class, null));
        }
    }

    final class UpdateLinkedInPosting implements Step<Void> {
        @Override
        public Wait waitFor(final Context context, final Void input) {
            return Wait.until(linkedInPostingUpdates.forOne());
        }

        @Override
        public StepDecision execute(final Context context, final Void input) {
            final PostingUpdate update =
                    linkedInPostingUpdates.getConditionResults(context).get(0);
            service.updateExternalSystem(String.format(
                    "update LinkedIn job posting v%d [%s]: %s",
                    update.version,
                    update.idempotencyKey,
                    update.posting.title));
            return StepDecision.goTo(UpdateLinkedInPosting.class, null);
        }
    }
}
```

```typescript
export class JobPostingFlow implements Flow {
  public readonly updateVersion = new Attribute("UpdateVersion", doubleCodec);
  public readonly updatePostingLock = updatePostingLock;
  public readonly linkedInPostingUpdates = linkedInPostingUpdates;
  public readonly indeedPostingUpdates = indeedPostingUpdates;

  public getSteps() {
    return StepList.startStep(this.init).otherSteps(
      this.updateLinkedInPosting,
      this.updateIndeedPosting,
    );
  }

  @rpc({
    inputCodec: jobInfoCodec,
    outputCodec: doubleCodec,
    lockAttributes: [updatePostingLock.lock()],
  })
  public update(context: Context, input: JobInfo): RPCResult<number> {
    const version = this.updateVersion.get(context) + 1;
    this.title.set(context, input.title);
    this.updateVersion.set(context, version);
    const update = {
      version,
      idempotencyKey: `${context.flowId}:${version}`,
      posting: input,
    };
    this.linkedInPostingUpdates.publish(context, update);
    this.indeedPostingUpdates.publish(context, update);
    return { output: version };
  }
}

class InitStep implements Step<void> {
  public execute(_context: Context, _input: void): StepDecision {
    return goToMany(
      StepMovement.of(UpdateLinkedInPosting, undefined),
      StepMovement.of(UpdateIndeedPosting, undefined),
    );
  }
}

class UpdateLinkedInPosting implements Step<void> {
  public waitFor(_context: Context, _input: void): Wait {
    return Wait.until(this.flow.linkedInPostingUpdates.forOne());
  }

  public execute(context: Context, _input: void): StepDecision {
    const update = this.flow.linkedInPostingUpdates.results(context)[0];
    if (update === undefined) throw new Error("LinkedIn posting update is required");
    this.flow.service.updateExternalSystem(
      `update LinkedIn job posting v${update.version} `
      + `[${update.idempotencyKey}]: ${update.posting.title}`,
    );
    return goTo(UpdateLinkedInPosting, undefined);
  }
}
```

```rust
pub const UPDATE_JOB_POST: Rpc<JobPost, i32> = Rpc::new("UpdateJobPost");

#[derive(Default)]
pub struct JobPostingFlow {
    init: Init,
    update_linkedin_posting: UpdateLinkedInPosting,
    update_indeed_posting: UpdateIndeedPosting,
}

impl JobPostingFlow {
    fn update(
        &self,
        context: &mut Context,
        replacement: JobPost,
    ) -> HandlerResult<RpcResult<i32>> {
        let version = UPDATE_VERSION.get_required(context)? + 1;
        POST.set(context, replacement.clone())?;
        UPDATE_VERSION.set(context, version)?;
        let update = PostingUpdate {
            version,
            idempotency_key: format!("{}:{version}", context.flow_id()),
            posting: replacement,
        };
        LINKEDIN_POSTING_UPDATES.publish(context, update.clone())?;
        INDEED_POSTING_UPDATES.publish(context, update)?;
        Ok(RpcResult::new(version))
    }
}

impl Flow for JobPostingFlow {
    type StartInput = JobPost;

    fn steps(&self) -> StepList<'_, Self::StartInput> {
        StepList::start(&self.init)
            .and(&self.update_linkedin_posting)
            .and(&self.update_indeed_posting)
    }

    fn rpcs(&self) -> RpcList<Self> {
        RpcList::new().function(
            UPDATE_JOB_POST.lock(UPDATE_POSTING_LOCK.lock()),
            Self::update,
        )
    }
}

impl Step for Init {
    type Input = JobPost;

    fn execute(
        &self,
        context: &mut Context,
        input: Self::Input,
    ) -> HandlerResult<StepDecision> {
        POST.set(context, input.clone())?;
        UPDATE_VERSION.set(context, 0)?;
        Ok(StepDecision::go_to_many([
            StepMovement::to(&UpdateLinkedInPosting::default(), ()),
            StepMovement::to(&UpdateIndeedPosting::default(), ()),
        ]))
    }
}

impl Step for UpdateLinkedInPosting {
    type Input = ();

    fn wait_for(
        &self,
        _context: &mut Context,
        _input: Self::Input,
    ) -> HandlerResult<Wait> {
        Ok(Wait::until(LINKEDIN_POSTING_UPDATES.for_one()))
    }

    fn execute(
        &self,
        context: &mut Context,
        _input: Self::Input,
    ) -> HandlerResult<StepDecision> {
        let update = LINKEDIN_POSTING_UPDATES
            .condition_results(context)?
            .into_iter()
            .next()
            .ok_or_else(|| {
                HandlerError::new("MissingPostingUpdate", "LinkedIn update is missing")
            })?;
        self.service.update_external_system(&format!(
            "update LinkedIn job posting v{} [{}]: {}",
            update.version, update.idempotency_key, update.posting.title
        ));
        Ok(StepDecision::go_to(&UpdateLinkedInPosting::default(), ()))
    }
}
```
