# Session

持久化 Agent Session 是承载一段对话的一次 Flow run。每次模型调用和每次 Tool Call 都在一个 Step 中运行。因此崩溃、部署或长时间等待都不会重复已经完成的工作。

<SessionTurnDiagram markdownDescription="你的应用的 Client 把消息发送到 Session Flow。在 Flow 内部，你的框架的 Agent Loop 以 Step 运行：模型调用（RunModel）、Tool Call（CallTool）、审批（AwaitToolApproval），然后是下一次模型调用。Turn 继续之前，Dex 先记录每个 Step 的结果，这些 Step 调用你的模型和 Tool。" />

## 持久化 Agent Session {#a-durable-agent-session}

一次 Flow run 就是一个 Agent Session，Flow ID 就是 Session ID。Session Flow 由 Dex Agents 构建：Python 中是 **dex-agents** package，TypeScript 中是 `@superdurable/dex-agents`。框架适配器在其上接入一个 Agent 框架。

Session 把对话保存在 Attribute 中。Session 等待下一条用户消息时不占用 Worker 的 task slot。

模型调用在 `RunModel` Step 中运行。在大多数 harness 中，每个 `RunModel` Step 进行一次模型调用，每次 Tool Call 在自己的 Step 中运行。一个 turn 的 Step 如下：

| Step | 作用 |
| --- | --- |
| `RunModel` | 进行一次模型调用并记录响应。 |
| `CallTool` | 运行一次读操作或幂等写操作调用。Dex 可以重试它。 |
| `CallSingleAttemptTool` | 运行一次其他写操作调用。Dex 最多运行它一次。 |
| `AwaitToolApproval` | 等待人批准或拒绝一次 Tool Call。见 [审批](/agent-frameworks/approvals)。 |
| `ResumeTurn` | 等待这次模型响应的所有 tool result，然后回到 `RunModel`。 |

同一次模型响应中的 Tool Call 并行运行。全部完成后，`ResumeTurn` 把它们的结果发给模型。

### 延迟与成本 {#latency-and-cost}

每个 Session Step 都是 SYNC 的：Dex 在 Worker 拿到 Step 之前提交它的开始，在 Session 继续之前提交它的结果，两者都写入对象存储。如果模型在一个 turn 中请求三个 tool 然后作答，这个 turn 需要六个 Step：两个 `RunModel`、三个 tool Step 和一个 `ResumeTurn`。[性能](/intro/performance#latency-below-the-peak) 测得，在一台 2 vCPU 的 server 上、负载为峰值一半时，一个 SYNC Step 的 p50 约为 105 ms。三个 tool Step 并行运行，所以这个 turn 依次等待四个 Step。按这个 p50 计算，它们在模型和 tool 本身的时间之外，给这个 turn 增加约 0.4 秒。

`RunModel` Step 在 30 分钟内最多尝试三次。每次重试都会把模型调用再发给 provider 一次，因此要再付一次 token 费用。对于昂贵的调用，可以用 Python 中的 `run_model_limit` 或 TypeScript 中的 `runModelLimit` 减少尝试次数。默认值见 [Step timeouts](/reference/agents/workers#timeouts)（英文）。

崩溃只会重复当时正在运行的 Step。Dex 不会重放整个循环。因此 Agent 代码不需要遵守确定性规则，代码修改会在下一个 Step 生效。

有两个 harness 会把更多工作放进一个 Step：

- **Claude Agent SDK。** Claude Code CLI 在一个 `RunModel` Step 中运行 turn 的一个 segment。Segment 包含模型调用和读操作 Tool Call，失败的 segment 会整体重新运行。写操作一次一个地离开 segment，各自在自己的 Step 中运行，所以它们永远不会并行。
- **LangChain 与 LangGraph。** 一个 `RunModel` Step 把 graph 运行到它的下一批 Tool Call。Graph 在途中可能进行多次模型调用，重试时会把它们一起重复。

### Session 记住什么 {#what-a-session-remembers}

一个 Session 保存一段对话：它的 message、Tool Call 以及 Tool Call 的结果。新的 Session 从空白开始。Dex Agents 没有在不同 Session 之间共享的 memory。

长期 memory，例如用户的偏好或过往订单，请保存在你自己掌控的存储中。它可以是你的数据库，也可以是你为每个用户保留的一个 Flow。给 Agent 一个读取它的 tool，以及一个使用合适 [policy](/agent-frameworks/tool-calls#tool-policies-and-approvals) 写入它的 tool。

已停止的 Session 在保留期内仍然可读，之后 Dex 会删除它。默认值见 [History and retention](/reference/agents/session-limits#history)（英文）。

## 只发送一次消息 {#send-a-message-once}

`send_user_message` 是 RPC。响应丢失后，如果你的代码再次发送，Dex 会再次运行这个 RPC，同一条消息就可能排队两次。[RPC 的保证](/concepts/primitives/rpc#guarantees)解释原因，[部署期间的 RPC](/agent-frameworks/production#rpcs-during-a-deploy)说明什么时候会发生。

下面这个辅助函数只发送一次消息。每个标签页都展示完整模块。它重试可能没有送达的发送，每次重试前检查 Session，并删除多出的排队副本。它按文本区分消息，所以用户每发一条消息就调用它一次。

```python
"""Sends a user message to a session once, even when a send must be retried."""
from __future__ import annotations

import asyncio
from typing import Protocol

import grpc  # type: ignore[import-untyped]
from dex import DexServiceError
from dex_agents import AgentSnapshot, MessageRole

# A lost response leaves a send's outcome unknown; these codes mean "check first".
UNCERTAIN_CODES = (grpc.StatusCode.UNAVAILABLE, grpc.StatusCode.DEADLINE_EXCEEDED)

class MessageSessions(Protocol):
    async def get_agent_snapshot(self, session_id: str) -> AgentSnapshot: ...

    async def send_user_message(self, session_id: str, text: str) -> bool: ...

    async def delete_queued_message(self, session_id: str, message_id: str) -> bool: ...

async def send_user_message_once(
    sessions: MessageSessions,
    session_id: str,
    text: str,
    *,
    attempts: int = 5,
    retry_delay_seconds: float = 1.0,
) -> None:
    """Queues one user message, retrying a failed send without queuing it twice.

    Before each retry it reads the session, and stops when a new copy of the
    text is there. At the end it deletes any extra queued copy. It tells
    messages apart by their text, so call it once for each message a user sends.

    Raises:
        DexServiceError: When no attempt reached a Worker, or on any other error.
    """
    copies_before = _copies(await sessions.get_agent_snapshot(session_id), text)
    for attempt in range(1, attempts + 1):
        try:
            await sessions.send_user_message(session_id, text)
            break
        except DexServiceError as error:
            if error.code not in UNCERTAIN_CODES or attempt == attempts:
                raise
        await asyncio.sleep(retry_delay_seconds)
        if _copies(await sessions.get_agent_snapshot(session_id), text) > copies_before:
            break
    await _delete_extra_copies(sessions, session_id, text, copies_before + 1)

async def _delete_extra_copies(
    sessions: MessageSessions, session_id: str, text: str, wanted: int
) -> None:
    snapshot = await sessions.get_agent_snapshot(session_id)
    extra = _copies(snapshot, text) - wanted
    queued = [item for item in snapshot.queued_messages if item.message.text == text]
    if extra <= 0:
        return
    for item in reversed(queued[max(0, len(queued) - extra) :]):
        await sessions.delete_queued_message(session_id, item.message_id)

def _copies(snapshot: AgentSnapshot, text: str) -> int:
    delivered = sum(
        1 for message in snapshot.messages if message.role == MessageRole.USER and message.text == text
    )
    queued = sum(1 for item in snapshot.queued_messages if item.message.text == text)
    return delivered + queued
```

```ts
// Queues one user message without queuing it twice when a send is retried.

import { DexServiceError, type Client } from "@superdurable/dex";
import {
  readAgentSnapshot,
  sendAgentUserMessage,
  type AgentSessionFlow,
  type AgentSnapshot,
} from "@superdurable/dex-agents";

// gRPC codes UNAVAILABLE and DEADLINE_EXCEEDED: the send may or may not have arrived.
const UNCERTAIN_CODES: readonly number[] = [14, 4];

export interface MessageSessions {
  getAgentSnapshot(sessionId: string): Promise<AgentSnapshot>;
  sendUserMessage(sessionId: string, text: string): Promise<boolean>;
  deleteQueuedMessage(sessionId: string, messageId: string): Promise<boolean>;
}

export function messageSessions(client: Client, flow: AgentSessionFlow): MessageSessions {
  return {
    getAgentSnapshot: (sessionId) => readAgentSnapshot(client, flow, sessionId),
    sendUserMessage: (sessionId, text) => sendAgentUserMessage(client, flow, sessionId, { text }),
    deleteQueuedMessage: (sessionId, messageId) =>
      client.invokeRPC(flow.deleteQueuedMessage, sessionId, { messageId }),
  };
}

/**
 * Queues one user message, retrying a failed send without queuing it twice.
 * Before each retry it reads the session and stops when a new copy of the text is there.
 * At the end it deletes any extra queued copy. It tells messages apart by their text,
 * so call it once for each message a user sends.
 */
export async function sendUserMessageOnce(
  sessions: MessageSessions,
  sessionId: string,
  text: string,
  { attempts = 5, retryDelayMs = 1_000 }: { attempts?: number; retryDelayMs?: number } = {},
): Promise<void> {
  const copiesBefore = countCopies(await sessions.getAgentSnapshot(sessionId), text);
  for (let attempt = 1; attempt <= attempts; attempt++) {
    try {
      await sessions.sendUserMessage(sessionId, text);
      break;
    } catch (error) {
      const isUncertain = error instanceof DexServiceError && UNCERTAIN_CODES.includes(error.code);
      if (!isUncertain || attempt === attempts) {
        throw error;
      }
    }
    await new Promise((resolve) => setTimeout(resolve, retryDelayMs));
    if (countCopies(await sessions.getAgentSnapshot(sessionId), text) > copiesBefore) {
      break;
    }
  }
  await deleteExtraCopies(sessions, sessionId, text, copiesBefore + 1);
}

async function deleteExtraCopies(
  sessions: MessageSessions,
  sessionId: string,
  text: string,
  wanted: number,
): Promise<void> {
  const snapshot = await sessions.getAgentSnapshot(sessionId);
  const extra = countCopies(snapshot, text) - wanted;
  if (extra <= 0) {
    return;
  }
  const queued = (snapshot.queuedMessages ?? []).filter((item) => item.message.text === text);
  for (const item of queued.slice(Math.max(0, queued.length - extra)).reverse()) {
    await sessions.deleteQueuedMessage(sessionId, item.messageId);
  }
}

function countCopies(snapshot: AgentSnapshot, text: string): number {
  const delivered = snapshot.messages.filter((message) => message.role === "user" && message.text === text).length;
  const queued = (snapshot.queuedMessages ?? []).filter((item) => item.message.text === text).length;
  return delivered + queued;
}
```
