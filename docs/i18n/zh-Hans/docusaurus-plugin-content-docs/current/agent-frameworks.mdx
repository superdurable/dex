# 持久化 Agent

Dex 把 AI Agent 作为持久化的 Agent Session 运行。你可以用 Dex Agents 的内置 agent loop 构建 Agent，也可以保留已经用 Agent 框架写好的 Agent；两者运行在同一个 Session Flow 上。

## Dex 为你的 Agent 带来什么 {#what-dex-adds}

你的 Agent 框架保持不变，Dex 让每个 Session 持久化：

- **[持久化的 Session](/agent-frameworks/sessions)。** 崩溃或部署之后，Session 从最后一次完成的模型调用或 Tool Call 继续。
- **[按策略执行的 Tool Call](/agent-frameworks/tool-calls)。** 每次 Tool Call 都在自己的 Step 中运行：读操作会重试，非幂等写操作最多运行一次。
- **[可以长时间等待的审批](/agent-frameworks/approvals)。** 需要人来审批的调用可以等几分钟或几天，重启和部署之后依然有效。
- **[把 Connector 用作 tool](/agent-frameworks/connectors-as-tools)。** Agent 调用官方 Connector 的操作，遵循同样的 tool 策略。
- **[可观测与可控](/agent-frameworks/production)。** Dex Web 展示每个 Session，tracing 覆盖每次模型调用和 Tool Call，花费上限检查模型花费。

想亲手试一试，可以运行 [Agent 快速开始](/agent-frameworks/quick-start)。[Dex vs. 其他引擎](/intro/compared-to-durable-execution#agent-frameworks-on-a-durable-execution-engine)把 Dex 与框架的 checkpointer 和其他引擎做了对比，[术语表](/glossary)解释了这些页面用到的术语。
