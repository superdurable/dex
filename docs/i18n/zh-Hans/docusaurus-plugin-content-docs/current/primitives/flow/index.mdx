# Flow

**Flow** 是 Dex 的顶层 primitive 与概念。

A Flow 通常是一个业务实体。它包含一些 [Step](/primitives/step)、由 [Attribute](/primitives/attribute) 与 [Channel](/primitives/channel) 组成的 persistence schema，以及可选的 [RPC](/primitives/rpc) handler。

- [基础](/primitives/flow/basic) — 基础概念与 interface
- [Flow options](/primitives/flow/flow-options) — 高级 StartFlowOptions、FlowConfig
