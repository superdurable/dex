# Flow

**Flow** 是 Dex 的顶层 durable 程序。一个 Flow 拥有 typed [Step](/primitives/step)、由 [Attribute](/primitives/attribute) 与 [Channel](/primitives/channel) 组成的 persistence schema，以及可选的 [RPC](/primitives/rpc) handler。

- [基础](/primitives/flow/basic) — 标识符、Flow 接口，以及 Step 与 persistence 如何组合
- [Flow options](/primitives/flow/flow-options) — **StartFlowOptions**、**FlowConfig**、timeout、retry 与运行时覆盖

可运行示例位于 **examples/go**、**examples/java**、**examples/python**、**examples/typescript** 和 **examples/rust**。
