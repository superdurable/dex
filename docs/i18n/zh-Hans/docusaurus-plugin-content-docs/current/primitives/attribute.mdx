# Attribute 基础

**Attribute** 是一个 Flow 拥有的、带类型的 durable state。Step 或 RPC 从 **Context** 读取它，修改它，然后返回正常结果。Dex 会把修改和这个结果一起持久化。

当后续 Step、RPC 或 Client 都需要看到某个状态时，就用 Attribute：比如订单状态、选择的套餐，或者当前审批结果。Worker 重启、Step retry、Flow continue-as-new 后，它都还属于这个 Flow。

## 定义 Attribute {#define-an-attribute}

在 Flow 上定义 Attribute，然后把它列入 persistence schema。这份声明就是 Flow durable state 的 contract。Step、RPC 或 Client 尝试使用未声明的 Attribute 时，Dex 会拒绝。

Handler 从当前 invocation 读取 Attribute，并在同一个 invocation 里暂存写入。如果 handler attempt 失败，这些暂存写入不会成为 Flow state；如果它正常返回，Dex 会把这些写入与 Step decision 或 RPC result 一起提交。

class AttributeStep(Step[str]):
    def __init__(self, flow: "AttributeFlow") -> None:
        self.flow = flow

    def wait_for(self, context: Context, input: str) -> Wait:
        self.flow.message.set(context, input)
        return Wait.skip_immediately()

    def execute(self, context: Context, input: str) -> StepDecision:
        del input
        return graceful_complete(self.flow.message.get(context))


class AttributeFlow(Flow[str]):
    message = Attribute("primitive-attribute-message", str)

    def __init__(self) -> None:
        self.start = AttributeStep(self)

    def get_steps(self) -> StepList[str]:
        return StepList.start_step(self.start)

    def get_persistence_schema(self) -> PersistenceSchema:
        return PersistenceSchema.of(self.message)

var Message = dex.DefineAttribute[string](messageAttributeName)

type AttributeFlow struct {
	dex.FlowDefaults

func (*AttributeFlow) GetPersistenceSchema() dex.PersistenceSchema {
	return dex.PersistenceSchema{Attributes: []dex.AttributeDef{Message}}

type attributeStep struct {
	dex.StepDefaults
}

func (attributeStep) WaitFor(ctx dex.Context, input string) (*dex.Wait, error) {
	if err := Message.Set(ctx, input); err != nil {
		return nil, err
	}
	return dex.SkipWaitImmediately(), nil
}

func (attributeStep) Execute(ctx dex.Context, _ string) (*dex.StepDecision, error) {
	value, err := Message.Get(ctx)
	if err != nil {
		return nil, err
	}
	return dex.GracefulComplete(value), nil
}

    private final Attribute<String> message =
            Attribute.define("primitive-attribute-message", String.class);
    private final AttributeStep start = new AttributeStep();

    @Override
    public StepList<String> getSteps() {
        return StepList.startStep(start);
    }

    @Override
    public PersistenceSchema getPersistenceSchema() {
        return PersistenceSchema.of(message);
    }

    final class AttributeStep implements Step<String> {
        @Override
        public Wait waitFor(final Context context, final String input) {
            message.set(context, input);
            return Wait.skipImmediately();
        }

        @Override
        public StepDecision execute(final Context context, final String input) {
            return StepDecision.gracefulComplete(message.get(context));
        }
    }
}

class AttributeStep implements Step<string> {
  public readonly inputCodec = stringCodec;

  public constructor(private readonly flow: AttributeFlow) {}

  public getStepType(): string {
    return "AttributeStep";
  }

  public waitFor(context: Context, input: string): Wait {
    this.flow.message.set(context, input);
    return Wait.skipImmediately();
  }

  public execute(context: Context, _input: string): StepDecision {
    return gracefulComplete(this.flow.message.get(context));
  }
}

export class AttributeFlow implements Flow<string> {
  public readonly message = new Attribute("primitive-attribute-message", stringCodec);
  private readonly start = new AttributeStep(this);

  public getSteps() {
    return StepList.startStep(this.start);
  }

  public getPersistenceSchema(): PersistenceSchema {
    return { attributes: [this.message] };
  }
}

    Attribute::new("primitive-attribute-message")

pub struct AttributeFlow {
    start: AttributeStep,

impl Flow for AttributeFlow {
    type StartInput = String;

    fn steps(&self) -> StepList<'_, Self::StartInput> {
        StepList::start(&self.start)
    }

    fn persistence(&self) -> PersistenceSchema {
        PersistenceSchema::new().attribute(&message())
    }

#[derive(Default)]
struct AttributeStep;

impl Step for AttributeStep {
    type Input = String;

    fn wait_for(&self, context: &mut Context, input: Self::Input) -> HandlerResult<Wait> {
        message().set(context, input)?;
        Ok(Wait::skip_immediately())
    }

    fn execute(&self, context: &mut Context, _input: Self::Input) -> HandlerResult<StepDecision> {
        Ok(StepDecision::graceful_complete(
            message().get_required(context)?,
        ))
    }
}

## 什么应该是 Attribute？ {#what-should-be-an-attribute}

| 值 | 使用场景 |
| --- | --- |
| **Attribute** | Flow 需要一份 durable state，且不止一个 Step、RPC 或 Client 会读取或更新它。 |
| **Step input / output** | 值只沿着一条具体的 Step path 传递。 |
| **Step execution local** | 值只属于一个 Step execution。 |
| **Channel** | 需要传递一条或多条消息，而不是保存最新状态。 |

Attribute 保存的是最新值，不是 event log。不要把每一条业务事件都 append 到一个很大的 Attribute 里。消息应该用 Channel；大 body 放到自己的 database 或 Blob Store，Attribute 里只放一个小的 identifier。

## 初始状态与 Client 访问 {#initial-state-and-client-access}

**StartFlowOptions** 可以在创建 Flow 时设置初始 Attribute。初始值与创建 Flow 是一个操作，所以第一个 Step 立刻能看到它们。见 [Flow options](/primitives/flow/flow-options#attributes)。

Client 使用同一个已注册的 Attribute definition 调用 **GetAttributes** 和 **SetAttributes**。Client 也可以用 **WaitForAttributeEqual**，等待一个 singleton Attribute 或某个 AttributeMap instance 变成指定 scalar value。这些都是通过 Dex Server 的 Flow operation，不会直接读写 application database。见 [Client APIs](/primitives/client-apis)。

## AttributeMap {#attributemap}

**AttributeMap** 是一组 key 在运行时才确定的 Attribute。只定义并注册一次 map；每次读、写、删除或 lock 时提供一个 instance key。

例如 invoice Flow 可以有一个 **payment-status** map。**invoice-1** 的 **payment-status** 与 **invoice-2** 的 **payment-status** 是独立的 durable value。更新一个不会重写另一个。AttributeMap 适合不断变化的一组小值；它不能替代可查询的 application table。

map name 与 instance key 组成 Dex 的 physical Attribute name。Dex 会 escape instance key，所以 application code 应始终使用 SDK definition，不要自己拼这个 name。Step 或 RPC 可以列出已有 instance key；这个列表也包含当前 invocation 暂存的写入。
