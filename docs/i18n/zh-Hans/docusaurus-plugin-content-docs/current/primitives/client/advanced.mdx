# Client Advanced

## 等待 Flow

**WaitForFlow** 等待 Flow 到达 terminal status。bounded wait 在 Flow 仍然 open 时会返回 long-poll timeout；再次调用即可继续等待。

<SdkTabs examples={{python: 'examples/python/dex_examples/primitives/client-apis/controller.py', go: 'examples/go/primitives/client-apis/controller.go', java: 'examples/java/src/main/java/io/superdurable/dex/primitives/clientapis/ClientApisController.java', typescript: 'examples/typescript/src/primitives/client-apis/controller.ts', rust: 'examples/rust/src/primitives/client_apis/controller.rs'}}>
<SdkSnippet lang="python">

```python
result = await client.wait_for_flow("order-123", timedelta(minutes=1))
```

</SdkSnippet><SdkSnippet lang="go">

```go
result, err := client.WaitForFlow(ctx, "order-123", sdk.WaitForFlowOptions{Timeout: time.Minute})
```

</SdkSnippet><SdkSnippet lang="java">

```java
final FlowResult result = client.waitForFlow("order-123", Duration.ofMinutes(1));
```

</SdkSnippet><SdkSnippet lang="typescript">

```typescript
const result = await client.waitForFlow("order-123", 60_000);
```

</SdkSnippet><SdkSnippet lang="rust">

```rust
let result = client.wait_for_flow_with_timeout("order-123", Duration::from_secs(60))?;
```

</SdkSnippet></SdkTabs>

## 等待 Step {#wait-for-a-step}

**WaitForStepCompletion** 在 Flow 继续运行时等待一个 **StepExecutionID**。它只确认完成，不返回 Step output。

<SdkTabs examples={{python: 'examples/python/dex_examples/products/order-processing/controller.py', go: 'examples/go/products/order-processing/controller.go', java: 'examples/java/src/main/java/io/superdurable/dex/products/orderprocessing/OrderProcessingController.java', typescript: 'examples/typescript/src/products/order-processing/controller.ts', rust: 'examples/rust/src/products/order_processing/controller.rs'}}>
<SdkSnippet lang="python">

```python
await client.wait_for_step_completion("order-123", StepExecutionId("ChargeOrder"), timedelta(minutes=1))
```

</SdkSnippet><SdkSnippet lang="go">

```go
err := client.WaitForStepCompletion(ctx, "order-123", sdk.StepExecutionID{StepType: "ChargeOrder"}, sdk.WaitOptions{Timeout: time.Minute})
```

</SdkSnippet><SdkSnippet lang="java">

```java
client.waitForStepCompletion("order-123", StepExecutionId.of("ChargeOrder"), Duration.ofMinutes(1));
```

</SdkSnippet><SdkSnippet lang="typescript">

```typescript
await client.waitForStepCompletion("order-123", StepExecutionId.of("ChargeOrder"), 60_000);
```

</SdkSnippet><SdkSnippet lang="rust">

```rust
client.wait_for_step_completion("order-123", StepExecutionId::of(&charge_order), Duration::from_secs(60))?;
```

</SdkSnippet></SdkTabs>

## 等待 Attribute 值 {#wait-for-an-attribute-value}

**WaitForAttributeEqual** 等待 Attribute 等于一个 primitive value。它只适用于 active Flow。对于 AttributeMap，在 expected value 前面传入 instance。

<SdkTabs examples={{python: 'examples/python/dex_examples/products/engagement/controller.py', go: 'examples/go/products/engagement/controller.go', java: 'examples/java/src/main/java/io/superdurable/dex/products/engagement/EngagementController.java', typescript: 'examples/typescript/src/products/engagement/controller.ts', rust: 'examples/rust/src/products/engagement/controller.rs'}}>
<SdkSnippet lang="python">

```python
await client.wait_for_attribute_equal("order-123", status, "approved", timedelta(minutes=1))
```

</SdkSnippet><SdkSnippet lang="go">

```go
err := client.WaitForAttributeEqual(ctx, "order-123", Status, "approved", sdk.WaitOptions{Timeout: time.Minute})
```

</SdkSnippet><SdkSnippet lang="java">

```java
client.waitForAttributeEqual("order-123", status, "approved", Duration.ofMinutes(1));
```

</SdkSnippet><SdkSnippet lang="typescript">

```typescript
await client.waitForAttributeEqual("order-123", status, "approved", 60_000);
```

</SdkSnippet><SdkSnippet lang="rust">

```rust

```

</SdkSnippet></SdkTabs>

<SdkSnippet lang="python">

```python
info = await client.describe_flow("order-123")
```

</SdkSnippet><SdkSnippet lang="go">

```go
info, err := client.DescribeFlow(ctx, "order-123")
```

</SdkSnippet><SdkSnippet lang="java">

</SdkSnippet><SdkSnippet lang="typescript">


</SdkSnippet><SdkSnippet lang="go">


</SdkSnippet><SdkSnippet lang="java">

```java
client.skipTimer("order-123", StepExecutionId.of("ChargeOrder"), TimerId.byConditionId("retry"));
```

</SdkSnippet><SdkSnippet lang="typescript">

```typescript

```

</SdkSnippet><SdkSnippet lang="rust">


</SdkSnippet><SdkSnippet lang="go">


</SdkSnippet><SdkSnippet lang="java">
