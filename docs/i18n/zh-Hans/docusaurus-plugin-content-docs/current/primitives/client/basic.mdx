# Client Basics

Client 调用来自 application，不来自 Step。下面的例子使用 **order-123** 这个 **Flow ID**。

## 启动 Flow

**StartFlow** 创建 Flow execution，并在 Dex Server 接受请求后立即返回。它接收已注册的 Flow、业务 **Flow ID**、start Step input 和 **StartFlowOptions**。

Flow ID 是 application 选择的身份。Dex Server 创建 Run ID。关于 timeout、request idempotency、ID reuse、retry、initial Attributes 和 config override，见 [Flow options](/primitives/flow/flow-options)。

## 停止 Flow

**StopFlow** 关闭一个 active Flow。默认是请求它 cooperative cancellation。你也可以立刻 terminate，或者带 reason 把它标记为 failed。

<SdkTabs examples={{python: 'examples/python/dex_examples/products/job-post/controller.py', go: 'examples/go/products/job-post/controller.go', java: 'examples/java/src/main/java/io/superdurable/dex/products/jobpost/JobPostingController.java', typescript: 'examples/typescript/src/products/job-post/controller.ts', rust: 'examples/rust/src/products/job_post/controller.rs'}}>
<SdkSnippet lang="python">

```python
await client.stop_flow("order-123", StopFlowOptions(reason="customer cancelled"))
```

</SdkSnippet>
<SdkSnippet lang="go">

```go
err := client.StopFlow(ctx, "order-123", sdk.StopOptions{Reason: "customer cancelled"})
```

</SdkSnippet>
<SdkSnippet lang="java">

```java
client.stopFlow("order-123", new StopFlowOptions(StopType.CANCEL, "customer cancelled"));
```

</SdkSnippet>
<SdkSnippet lang="typescript">

```typescript

```

</SdkSnippet>
<SdkSnippet lang="rust">

```rust

```

</SdkSnippet>
</SdkTabs>

## 调用 RPC

**InvokeRPC** 调用 active Flow 上已注册的 [RPC](/primitives/rpc) handler，并返回结果。

<SdkTabs examples={{python: 'examples/python/dex_examples/primitives/rpc/controller.py', go: 'examples/go/primitives/rpc/controller.go', java: 'examples/java/src/main/java/io/superdurable/dex/primitives/rpc/RpcController.java', typescript: 'examples/typescript/src/primitives/rpc/controller.ts', rust: 'examples/rust/src/primitives/rpc/controller.rs'}}>
<SdkSnippet lang="python">

```python
result = await client.invoke_rpc(flow.trigger, "order-123", "approved")
```

</SdkSnippet>
<SdkSnippet lang="go">

```go
var result string
err := client.InvokeRPC(ctx, "order-123", flow.Trigger, "approved", &result, sdk.InvokeOptions{})
```

</SdkSnippet>
<SdkSnippet lang="java">

```java
final RpcFlow stub = client.newRpcStub(RpcFlow.class, "order-123");

```

</SdkSnippet>
<SdkSnippet lang="typescript">

```typescript
const result = await client.invokeRPC(rpcFlow.trigger, "order-123", "approved");
```

</SdkSnippet>
<SdkSnippet lang="rust">

```rust
let result = client.invoke_rpc("order-123", RPC_TRIGGER, "approved".to_owned())?;
```

</SdkSnippet>
</SdkTabs>

## 读写 Flow 状态

应用应通过 Flow RPC 读写 Attribute、AttributeMap、Channel 和 ChannelMap 状态。为每个 command 或 query 定义 typed RPC，只选择它需要的状态，再用 **InvokeRPC** 调用。这样 authorization、validation、lock、transaction 和状态变更都会留在 Flow 内。

Client 仍提供 **WaitForAttributeMatch** 作为阻塞式 observation API。当应用需要等待已知的 scalar Attribute 条件，而不是读取任意状态快照时，使用这个接口。
