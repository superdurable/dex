# Client Basics

Client 调用来自 application，不来自 Step。下面的例子使用 **order-123** 这个 **Flow ID**。

## 启动 Flow

**StartFlow** 创建 Flow execution，并在 Dex Server 接受请求后立即返回。它接收已注册的 Flow、业务 **Flow ID**、start Step input 和 **StartFlowOptions**。

Flow ID 是 application 选择的身份。Dex Server 创建 Run ID。关于 timeout、request idempotency、ID reuse、retry、initial Attributes 和 config override，见 [Flow options](/primitives/flow/flow-options)。

<SdkTabs examples={{python: 'examples/python/dex_examples/primitives/client-apis/controller.py', go: 'examples/go/primitives/client-apis/controller.go', java: 'examples/java/src/main/java/io/superdurable/dex/primitives/clientapis/ClientApisController.java', typescript: 'examples/typescript/src/primitives/client-apis/controller.ts', rust: 'examples/rust/src/primitives/client_apis/controller.rs'}}>
<SdkSnippet lang="python">

```python
run_id = await app_state.client.start_flow(
    app_state.client_apis, "order-123", "first order", start_options()
)
```

</SdkSnippet>
<SdkSnippet lang="go">

```go
runID, err := client.StartFlow(ctx, flow, "order-123", "first order", options)
```

</SdkSnippet>
<SdkSnippet lang="java">

```java
final String runId = client.startFlow(flow, "order-123", "first order", options);
```

</SdkSnippet>
<SdkSnippet lang="typescript">

```typescript
const runId = await client.startFlow(clientApisFlow, "order-123", "first order", options);
```

</SdkSnippet>
<SdkSnippet lang="rust">

```rust
let run_id = client.start_flow(&flow, "order-123", "first order")?;
```

</SdkSnippet>
</SdkTabs>

## 停止 Flow

**StopFlow** 关闭一个 active Flow。默认是请求它 cooperative cancellation。你也可以立刻 terminate，或者带 reason 把它标记为 failed。

<SdkTabs examples={{python: 'examples/python/dex_examples/products/job-post/controller.py', go: 'examples/go/products/job-post/controller.go', java: 'examples/java/src/main/java/io/superdurable/dex/products/jobpost/JobPostController.java', typescript: 'examples/typescript/src/products/job-post/controller.ts', rust: 'examples/rust/src/products/job_post/controller.rs'}}>
<SdkSnippet lang="python">

```python
await client.stop_flow("order-123", StopFlowOptions(reason="customer cancelled"))
```

</SdkSnippet>
<SdkSnippet lang="go">

```go
err := client.StopFlow(ctx, "order-123", sdk.StopOptions{Reason: "customer cancelled"})
```

</SdkSnippet>
<SdkSnippet lang="java">

```java
client.stopFlow("order-123", new StopFlowOptions(StopType.CANCEL, "customer cancelled"));
```

</SdkSnippet>
<SdkSnippet lang="typescript">

```typescript
await client.stopFlow("order-123", { reason: "customer cancelled" });
```

</SdkSnippet>
<SdkSnippet lang="rust">

```rust
client.stop_flow("order-123", StopFlowOptions::cancel().reason("customer cancelled"))?;
```

</SdkSnippet>
</SdkTabs>

## 调用 RPC

**InvokeRPC** 调用 active Flow 上已注册的 [RPC](/primitives/rpc) handler，并返回结果。

<SdkTabs examples={{python: 'examples/python/dex_examples/primitives/rpc/controller.py', go: 'examples/go/primitives/rpc/controller.go', java: 'examples/java/src/main/java/io/superdurable/dex/primitives/rpc/RpcController.java', typescript: 'examples/typescript/src/primitives/rpc/controller.ts', rust: 'examples/rust/src/primitives/rpc/controller.rs'}}>
<SdkSnippet lang="python">

```python
result = await client.invoke_rpc(flow.trigger, "order-123", "approved")
```

</SdkSnippet>
<SdkSnippet lang="go">

```go
var result string
err := client.InvokeRPC(ctx, "order-123", flow.Trigger, "approved", &result, sdk.InvokeOptions{})
```

</SdkSnippet>
<SdkSnippet lang="java">

```java
final RpcFlow stub = client.newRpcStub(RpcFlow.class, "order-123");
final String result = client.invokeRPC(stub::trigger, "approved");
```

</SdkSnippet>
<SdkSnippet lang="typescript">

```typescript
const result = await client.invokeRPC(rpcFlow.trigger, "order-123", "approved");
```

</SdkSnippet>
<SdkSnippet lang="rust">

```rust
let result = client.invoke_rpc("order-123", RPC_TRIGGER, "approved".to_owned())?;
```

</SdkSnippet>
</SdkTabs>

## 发布到 Channel {#publish-to-a-channel}

**PublishToChannel** 向已注册的 durable [Channel](/primitives/channel) 追加 message。等待该 Channel 的 Step 可以稍后消费这些消息。Flow 必须仍然 active。

<SdkTabs examples={{python: 'examples/python/dex_examples/primitives/channel/channel_flow.py', go: 'examples/go/primitives/channel/workflow.go', java: 'examples/java/src/main/java/io/superdurable/dex/primitives/channel/ChannelFlow.java', typescript: 'examples/typescript/src/primitives/channel/channel-flow.ts', rust: 'examples/rust/src/primitives/channel/flow.rs'}}>
<SdkSnippet lang="python">

```python
await client.publish("order-123", approval, "approved")
```

</SdkSnippet>
<SdkSnippet lang="go">

```go
err := client.PublishToChannel(ctx, "order-123", Approval, "approved")
```

</SdkSnippet>
<SdkSnippet lang="java">

```java
client.publish("order-123", approval, "approved");
```

</SdkSnippet>
<SdkSnippet lang="typescript">

```typescript
await client.publish("order-123", approval, "approved");
```

</SdkSnippet>
<SdkSnippet lang="rust">

```rust
client.publish("order-123", &approval(), "approved".to_owned())?;
```

</SdkSnippet>
</SdkTabs>

对于 ChannelMap，使用对应的 map overload 并传入 instance。Go 和 Rust SDK 可以在一次调用里发布一批消息。

## 读取 Attribute

**GetAttribute** 从已有 Flow 的 current 或 latest run 读取一个已注册的 [Attribute](/primitives/attribute)。如果 Attribute 从未写入，它不会返回值。

对于 AttributeMap，也传入 map instance。

<SdkTabs examples={{python: 'examples/python/dex_examples/primitives/client-apis/controller.py', go: 'examples/go/primitives/client-apis/controller.go', java: 'examples/java/src/main/java/io/superdurable/dex/primitives/clientapis/ClientApisController.java', typescript: 'examples/typescript/src/primitives/client-apis/controller.ts', rust: 'examples/rust/src/primitives/client_apis/controller.rs'}}>
<SdkSnippet lang="python">

```python
keyword = await client.get_attribute("order-123", ClientApisFlow.keyword)
```

</SdkSnippet>
<SdkSnippet lang="go">

```go
var keyword string
found, err := client.GetAttribute(ctx, "order-123", Keyword, &keyword)
```

</SdkSnippet>
<SdkSnippet lang="java">

```java
final String keyword = client.getAttribute("order-123", flow.keyword);
```

</SdkSnippet>
<SdkSnippet lang="typescript">

```typescript
const keyword = await client.getAttribute("order-123", clientApisFlow.keyword);
```

</SdkSnippet>
<SdkSnippet lang="rust">

```rust
let keyword: Option<String> = client.get_attribute("order-123", &keyword())?;
```

</SdkSnippet>
</SdkTabs>

## 写入 Attribute

**SetAttribute** 在 active Flow 上写入一个已注册的 Attribute。

对于 AttributeMap，也传入 map instance。几个 Attribute write 应该在同一个 request 时，各 SDK 也提供 batch helper。

<SdkSnippet lang="python">

```python
await client.set_attribute("order-123", ClientApisFlow.keyword, "priority")
```

</SdkSnippet>

```go
err := client.SetAttribute(ctx, "order-123", Keyword, "priority")
```
