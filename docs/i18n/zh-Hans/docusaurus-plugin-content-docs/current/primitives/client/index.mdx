# Client

**Client** 是 Worker 外面的 application code 用来与 Dex Server 交互 Flow execution 的方式。

- [Client basics](/primitives/client/basic) 介绍如何启动和停止 Flow、调用 RPC，以及读取或写入 Attribute。
- [Client advanced](/primitives/client/advanced) 介绍 Channel input、wait、inspection、search 和 operator control。
