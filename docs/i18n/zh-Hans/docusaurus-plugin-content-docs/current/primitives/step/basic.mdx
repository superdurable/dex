# Durable Step 基础功能

本页介绍**默认**等待条件、Step decision 与 Step options（含默认 retry）。每种 Step 类型最多实现两个短方法。WaitFor 注册 durable Condition 并返回 Wait。Condition 完成后，Dex 重新 hydrate 该 Step 并调用 Execute。Execute 返回 **StepDecision** 推动 Flow 前进。

## anyOf — 任一 Condition 完成 {#anyof}

anyOf 在**任一** listed Condition 完成时恢复 Step。先完成的胜出。其他 Condition 可能继续运行——例如失败的 [SubFlow](/primitives/subflow) 子 Flow 可能继续直到被取消。

## StepDecision（movement）{#stepdecision-movements}

Execute 返回 **StepDecision**——指向一个或多个后续 Step 的 movement，或关闭决策。一次决策可指向多个 Step，用于表达分支、循环与并行。见 [parallel](/design-patterns/parallel) 与 [scalable-parallel](/design-patterns/scalable-parallel) 模式。

关闭决策、取消、Flow 输出与 forceCompleteIfChannelsEmpty 见 [Step decision](/primitives/step/step-decision)。超时、retry 及相关策略的自定义见 [Step options](/primitives/step/step-options)。

## Durable input {#durable-input}

起始 Step 接收 Flow input。之后每个 Step 接收调度它的 movement 带来的 input。Step input 随图传递，不是隐藏的全局变量。
