# 等待

WaitFor 返回由 durable **Condition** 构成的 **Wait**——[Timer](/primitives/timer)、[Channel](/primitives/channel)、[SubFlow](/primitives/subflow) 及其组合。本页介绍 OR-of-AND 等待，以及 Wait 完成后读取 Condition 结果。

## anyCombinationOf — AND 组的 OR {#anycombinationof}

anyCombinationOf 表示 AND 组的 OR。每组内用 all_of 组合构建。**每个** Condition 都需要非空 **condition ID**，以便 Dex 追踪哪条分支满足了 Wait。

## ConditionResults {#condition-results}

WaitFor 完成后，Execute 可读取满足 Wait 的内容。对 [Channel](/primitives/channel)，用 GetConditionResults / results / condition_results 读取已发布消息。对 [SubFlow](/primitives/subflow)，用 SubFlowResult / getConditionResults / condition_result 解码子 Flow 输出。

## Step execution local {#step-execution-local}

**SetStepExecutionLocal** 把值存在当前 **StepExecution** 上，供 **Execute** 用 **GetStepExecutionLocal** 读取。适用于 **WaitFor** 算出了 **Execute** 需要的数据，又不想为此定义 Flow 级 **Attribute**。

Step input 本身会传给两个方法，不要把 input 再拷进 local。

<SdkTabs
  examples={{

    go: 'examples/go/primitives/step-execution-local/workflow.go',
    java: 'examples/java/src/main/java/io/superdurable/dex/primitives/stepexecutionlocal/StepExecutionLocalFlow.java',
    typescript: 'examples/typescript/src/primitives/step-execution-local/step-execution-local-flow.ts',
    rust: 'examples/rust/src/primitives/step_execution_local/flow.rs',
  }}>
<SdkSnippet lang="python">

```python
def wait_for(self, context: Context, input: int) -> Wait:
    context.set_step_execution_local("note", f"approval:{input}")
    return Wait.until(approval.for_one())

def execute(self, context: Context, input: int) -> StepDecision:
    del input
    note = context.get_step_execution_local("note", str)
    return graceful_complete(note or "")
```

</SdkSnippet>
  <SdkSnippet lang="go">

```go
func (noteWaitStep) WaitFor(ctx dex.Context, input int) (*dex.Wait, error) {
	if err := ctx.SetStepExecutionLocal("note", fmt.Sprintf("approval:%d", input)); err != nil {
		return nil, err
	}
	return dex.Until(Approval.ForOne()), nil
}

func (noteWaitStep) Execute(ctx dex.Context, _ int) (*dex.StepDecision, error) {
	var note string
	found, err := ctx.GetStepExecutionLocal("note", &note)
	if err != nil {
		return nil, err
	}
	if !found {
		return nil, fmt.Errorf("note was not set")
	}
	return dex.GracefulComplete(note), nil
}
```

</SdkSnippet>

## Skip immediately {#skip-immediately}
