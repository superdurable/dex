## 评估 Dex {#evaluate-dex}

1. [为什么是 Dex？](/intro/what-is-dex) 用一个订单流程从头讲到尾。
2. [与数据库对比](/intro/compared-to-database) 先用数据库和队列构建这个流程，再写成 Flow。
3. [Compared to Existing Durable Execution](/intro/compared-to-durable-execution)（英文）把其他工具的术语对应到 Dex，并说明什么时候别的工具更合适。
4. [Performance and Maturity](/intro/performance-and-maturity)（英文）给出实测数据、发布状态和许可证。
5. [Limits and Sharp Edges](/intro/limits-and-sharp-edges)（英文）列出 Dex 目前还不做什么，以及上生产前要了解的默认值。

## 修复中途失败的流程 {#fix-a-process}

1. [为什么是 Dex？](/intro/what-is-dex) 展示扣款成功、发货却一直没有执行的情况。
2. [与数据库对比](/intro/compared-to-database) 先用状态列和队列构建这个流程，再写成 Flow。
3. [Quick Start](/quick-start)（英文）运行一个小版本，并在中途停掉它的 Worker。
4. [Order Processing](/use-cases/order-processing) 是带审批、提醒和退款的完整流程。
5. [Port Your Process to a Flow](/intro/port-your-process)（英文）把你自己的函数拆成 Step，最后给出一份检查清单。
6. [Limits and Sharp Edges](/intro/limits-and-sharp-edges)（英文）列出上生产前要了解的事情。
7. [Run Dex in Production](/components/production)（英文）列出你要运行的东西：一个 Dex Server 节点、一个可选的备用节点，以及对象存储。
