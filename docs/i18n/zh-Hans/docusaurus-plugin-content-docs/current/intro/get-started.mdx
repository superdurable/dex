# 开始使用

Dex 让一个流程在崩溃、重启和长时间等待之后继续运行。你用普通代码把流程写成由 Step 组成的 Flow。Dex 记录每个 Step 的结果，所以出错之后，Flow 从最后一个记录下来的 Step 继续。

## 从哪里开始

- **10 分钟试一试。** [Quick Start](/quick-start) 运行一个 Flow，在等待中途停掉 Worker，再看 Dex 让它继续。
- **让 coding agent 来写。** [使用 AI 构建](/build-with-ai/dex-developer-skill) 安装 Dex Skills，让 agent 写出正确的 Dex 代码。
- **让已有的 agent 变成 durable。** [Agent Quick Start](/agent-frameworks/quick-start) 把你用框架写的 agent 跑成 durable session。
- **先理解模型。** [概念](/concepts) 介绍 Flow、Step 和六个 Primitive。
