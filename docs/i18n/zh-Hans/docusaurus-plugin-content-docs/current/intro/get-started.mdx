# 开始使用

Dex 把你的流程作为一组 Step 组成的 Flow 来运行。崩溃、重启或长时间等待之后，它从最后完成的 Step 继续。

## 运行快速开始

安装 `dexcli`，在本机启动 Dex：

```bash
brew install superdurable/tap/dexcli
dexcli dev
```

然后按照 [快速开始](/quick-start) 操作。它运行一个 Flow，在中途停掉 Worker，然后看 Dex 让 Flow 继续。[本地运行](/components/run-locally) 介绍不用 Homebrew 的安装方式。

## 常见任务

- <a id="fix-a-process"></a>[把 Dex 加入现有代码](/intro/add-to-existing-code)：把你已有的函数、任务或队列消费者改写成 Flow。
- <a id="durable-agent"></a>[构建持久化 Agent](/agent-frameworks/quick-start)：用你的框架运行 Agent，让它的 Tool Call 和审批在重启后继续。
- <a id="coding-agent"></a>[让 coding agent 来写](/build-with-ai/dex-developer-skill)：安装 Dex Skills，让 coding agent 写出正确的 Dex 代码。
- <a id="evaluate-dex"></a>[评估 Dex](/evaluate)：Dex 和你现在用的方案对比如何，它的限制，以及实测数据。

Dex Server 可以运行在 Dex Cloud，也可以运行在你自己的基础设施上。[选择 Dex 的运行方式](/components/choose-how-to-run)对比了两者。
