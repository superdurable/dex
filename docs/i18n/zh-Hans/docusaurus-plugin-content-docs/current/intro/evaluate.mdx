# 评估 Dex

这些页面帮你判断 Dex 是否适合你的系统。可以按顺序读，也可以直接看你关心的问题。

- [Dex 与你的数据库](/components/your-database) 说明 Step 怎样写入你已有的数据库，以及何时把 Flow 数据复制到 PostgreSQL。
- [Dex 与 Temporal 对比](/intro/compared-to-temporal) 从 Worker 内存和 CPU、server 吞吐量、运维、功能和代码几个方面比较两个引擎，附实测数字。它下面的页面分别讲[性能](/intro/compared-to-temporal/performance)、[运维](/intro/compared-to-temporal/operations)、[Dex 独有的功能](/intro/compared-to-temporal/features)、[操作和恢复 Flow](/intro/compared-to-temporal/experience)和[编程模型](/intro/compared-to-temporal/programming-model)。
- [性能](/intro/performance) 给出单节点加 S3 的实测吞吐和延迟、运行成本，以及如何复现结果。
- [限制](/intro/limits) 列出团队在生产中可能遇到的意外、发布状态和许可证。
- [示例](/use-cases) 是完整的流程，例如订单、计费和转账，每个 SDK 都有代码。
- [故障转移和部署](/concepts/failover-and-deploys) 说明 server 或 Worker 停止时会发生什么，以及在 Flow 未结束时怎样部署新代码。
- [正确性与表达能力](/correctness-and-expressiveness) 给出经计算机检查的证明：崩溃能改变什么、不能改变什么，以及 Dex 能表达什么。
- [Workflow Patterns 评估](/correctness-and-expressiveness/workflow-patterns) 按研究者用来比较 workflow 引擎的 43 个 control-flow 模式为 Dex 评级。
