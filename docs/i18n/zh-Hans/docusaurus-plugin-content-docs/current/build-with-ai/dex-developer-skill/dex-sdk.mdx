# Dex SDK

Dex SDK 是原来负责 Python、Go、Java、TypeScript 和 Rust SDK 工作的 Skill 名称。它的指导现在是 [Dex App Builder](./dex-app-builder.mdx) 的一部分，Dex App Builder 同时负责产品工作和范围明确的 SDK 工作。见 [SDK 工作](./dex-app-builder.mdx#sdk-work)。

## 安装与使用 {#install-and-use}

先[安装 Dex Skills](/build-with-ai/dex-developer-skill#install-and-use-dex-skills)，一次安装全部三个 Skills。按名字调用 `dex-sdk` 仍然可用，例如在 Codex 中，以及在装了 Plugin 的 Claude Code 中：

```text
$dex-sdk Diagnose why this Flow retries after the payment Step completes.
/superdurable-dex:dex-sdk Diagnose why this Flow retries after the payment Step completes.
```

`dex-sdk` Skill 现在只有一条指令：加载 Dex App Builder，并走它的 SDK 路线。Agent 遇到 SDK 需求时会自己选择 Dex App Builder，所以你不需要点名 `dex-sdk`。之后的 Dex Skills 版本会删除它。
