# 使用 AI 构建

Dex Skills 教 Claude Code、Codex、Cursor 等 coding agent 设计、构建和测试 Dex 应用。它是给 Agent 的指导，不含运行时代码。每个 Agent 只需安装一次。

## 安装 Dex Skills {#install-and-use-dex-skills}

<DexSkillHostTabs skill="all" />

<a id="copy-a-prompt"></a>

安装之后，带有 coding agent 框的页面用一条命令让 Agent 按这一页来做。从[快速开始](/quick-start)开始，或者用[把 Dex 加入现有代码](/intro/add-to-existing-code)让 Agent 处理你自己的代码。

## 包含什么 {#whats-included}

Dex Skills 是一个插件，包含一个主 Skill 和两个子 Skill。描述你的任务，coding agent 会加载合适的 Skill：构建应用用 Dex App Builder，单独的 SDK 工作用 Dex SDK，Connector 工作用 Dex Connector Contributor。Dex App Builder 在需要时也会加载另外两个 Skill。

| Skill | 角色 | 负责 |
| --- | --- | --- |
| [Dex App Builder](./dex-developer-skill/dex-app-builder.mdx) | 主 Skill | 产品、应用和业务流程类需求，从流程设计到经过测试、已经提交的 Go 应用 |
| [Dex SDK](./dex-developer-skill/dex-sdk.mdx) | 子 Skill | 使用 Python、Go、Java、TypeScript 或 Rust 的 SDK 工作，例如调试一个 Flow，或添加一个 Step |
| [Dex Connector Contributor](./dex-developer-skill/dex-connector-contributor.mdx) | 子 Skill | 新增或修复官方 Connector、operation、Trigger 或配置界面单元 |

## 给 coding agent 的文档 {#docs-for-coding-agents}

- 每个页面都有 Markdown 版本。在 URL 后面加上 `.md`，例如 `https://docs.superdurable.io/quick-start.md`。
- `https://docs.superdurable.io/llms.txt` 列出所有页面。`llms-full.txt` 包含完整文档，`llms-full.python.txt`、`llms-full.go.txt`、`llms-full.typescript.txt`、`llms-full.java.txt` 和 `llms-full.rust.txt` 分别包含一种 SDK 语言的文档。

## 信任与权限 {#trust-and-permissions}

只从可信来源安装 Agent 扩展。Dex Skills 的源码和发布版本在 [superdurable/dex-skills](https://github.com/superdurable/dex-skills)。Dex Skills 不添加 MCP server，不需要任何凭据，也不包含应用运行时代码。可选的 hook 会读取已安装的版本和 GitHub 上公开的发布版本信息。如果有新版本，它会告诉你，但不会自动安装。Agent 创建 GitHub fork、推送 branch、打开 pull request 或修改运行中的 Flow 之前，仍然需要你的授权。
