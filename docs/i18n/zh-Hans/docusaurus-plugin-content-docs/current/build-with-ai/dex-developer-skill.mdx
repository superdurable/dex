# 使用 AI 构建 Dex 应用

Dex Skills 是 Dex 官方的 coding-agent plugin。它帮助 Codex、Claude Code、Cursor
和其他 Agent Skills client 设计并构建 Dex 应用、直接使用公开 Dex SDK，以及贡献
官方 [Connector](/primitives/connector)。

该 plugin 提供开发指导，不包含 runtime code。Dex Server、Worker 和应用不会加载它。

:::tip 从 Dex App Builder 开始

产品、应用或业务流程类请求应从 **dex-app-builder** 开始。它负责端到端工作流，并在
需要 SDK 或 Connector 工作时加载对应的专用 skill。

:::

## 需要代码工作区

Dex Skills 是 developer plugin，不是托管式 application builder。要创建或修改应用，
需要在 Codex 或其他 coding-agent host 中使用，并提供可写 repository 或 project
workspace、文件编辑工具和命令执行能力。现有 repository 和新建的空 repository 都可以。

如果普通聊天没有 repository 和命令执行能力，这些 skill 仍可用于业务 discovery、
架构设计和实现交接，但不能创建项目文件、运行测试、构建 artifact 或部署应用。
开始实现前，需要把确认后的方案转到由 repository 支持的代码工作区。

## 选择 Skill

| Skill | 定位 | 使用场景 |
| --- | --- | --- |
| [**Dex App Builder**](./dex-developer-skill/dex-app-builder.mdx) | **主要 skill** | 发现、原型设计、实现并在本地验证使用 Go backend 的端到端 process product。 |
| [**Dex SDK**](./dex-developer-skill/dex-sdk.mdx) | 专用 sub-skill | 使用 Python、Go、Java、TypeScript 或 Rust 实现、调试、测试和运维 Dex 应用。 |
| [**Dex Connector Contributor**](./dex-developer-skill/dex-connector-contributor.mdx) | 专用 sub-skill | 创建、验证并提交官方 Connector operation、Trigger 和 configuration UI unit。 |

只有独立 SDK 任务才直接使用 **dex-sdk**。只有独立修改官方 Dex Connectors Library
时才直接使用 **dex-connector-contributor**。

## 三个 Skill 如何协作

Dex App Builder 是主要协调入口。进入 backend 设计与实现时，它加载 Dex SDK；它会
直接使用已发布 Connector，并把确认的官方 Connector gap 路由给 Dex Connector
Contributor。Connector Contributor 需要共享的 Flow 和 Step 语义时也会加载 Dex SDK。

安装完整 plugin 后，agent 才能在三个 skill 之间正确路由。源码和 release 位于
[superdurable/dex-skills](https://github.com/superdurable/dex-skills)。

## 安装到 Codex

### ChatGPT Desktop 中的 Codex

这种方式不需要 terminal command，也不要求另行安装 Codex CLI。

1. 打开 plugin browser，选择添加菜单，然后点击 **Add a marketplace**。
2. 使用以下内容填写表单：

   | 字段 | 内容 |
   | --- | --- |
   | **Source** | **https://github.com/superdurable/dex-skills** |
   | **Git ref** | **main** |
   | **Sparse paths** | 保持为空。marketplace 和 plugin 位于 repository root。 |

3. 点击 **Add marketplace**。
4. 打开 **Super Durable** marketplace，选择 **Dex** 并安装。
5. 打开现有 repository 或创建空 repository，然后启动新 task。

产品工作可以直接描述应用需求，也可以显式调用 App Builder：

~~~text
$dex-app-builder Design and build this process application.
~~~

Codex 可以根据 task context 自动选择 **dex-app-builder**。SDK 和 Connector Contributor
是只能显式调用的专用入口，但 App Builder 仍可在产品流程中加载它们：

~~~text
$dex-sdk Diagnose this Flow retry behavior.
$dex-connector-contributor Add this capability to an official Connector.
~~~

### 可选：Codex CLI

只有另行安装了 Codex CLI，并且 shell 的 **PATH** 可以找到它时，下面的命令才可用。
请先检查：

~~~bash
codex --version
codex plugin marketplace add superdurable/dex-skills
codex
~~~

进入 Codex CLI 后，打开 **/plugins**，选择 **Super Durable** marketplace，并安装
**Dex**。如果 shell 显示 **command not found: codex**，请使用上面的 Desktop 步骤，
或另行安装 Codex CLI。Desktop app 不需要走 CLI 安装流程。

## 安装到 Claude

### Claude Web 或 Desktop app

1. 打开 **Customize**，进入 **Plugins** tab。
2. 点击 **Add**，然后选择 **Add marketplace**。
3. 选择 **Add from a repository**，输入
   **https://github.com/superdurable/dex-skills**。
4. 打开 **Super Durable** marketplace，安装 **Dex**。

Claude 会把安装状态保存到账号。使用同一账号登录的 Claude Code session 也可以使用
该 plugin。

### Claude Code CLI

如果 shell 已经安装 **claude** command，可以运行：

~~~bash
claude plugin marketplace add superdurable/dex-skills
claude plugin install superdurable-dex@superdurable
~~~

也可以在 interactive Claude Code session 内运行 slash-command 版本：

~~~text
/plugin marketplace add superdurable/dex-skills
/plugin install superdurable-dex@superdurable
~~~

不要把 slash-command 版本直接输入普通 shell。安装后启动新的 Claude Code session。
三个 skill 调用入口按推荐顺序排列：

~~~text
/superdurable-dex:dex-app-builder
/superdurable-dex:dex-sdk
/superdurable-dex:dex-connector-contributor
~~~

## 安装到 Cursor

### Cursor Desktop app

1. 打开侧栏中的 **Customize**。
2. 选择 **From GitHub Repository**，输入
   **https://github.com/superdurable/dex-skills**。
3. 打开 **Dex**，点击 **Install**，然后选择 user 或 project scope。

该 repository 包含 Cursor 要求的 marketplace manifest。三个 skill 会显示为：

~~~text
/dex-app-builder
/dex-sdk
/dex-connector-contributor
~~~

### Cursor CLI

Cursor 官方文档只说明通过 **Customize** 安装 plugin，没有记录用于安装该 GitHub
marketplace 的独立 shell command。因此应通过 Desktop app 安装 Dex，不要猜测
**cursor plugin install** 命令。Cursor 官方说明已经安装的 plugin 可以用于 Desktop、
Web 和 CLI surface。

Agent Skills client 也可以直接安装完整 bundle：

~~~bash
npx skills add superdurable/dex-skills --all
~~~

## 保持 Plugin 为最新版本

Agent 使用已经安装或缓存的副本。它们不会在每次 prompt 时获取 GitHub 最新内容，
运行中的 task 也会继续使用 task 启动时加载的 version。

- 在 Codex 中升级 marketplace，重新安装 Dex plugin，然后启动新 task。
- 在 Claude Code 中更新 marketplace 并 reload plugin。
- 在 Cursor 中 refresh 或重新安装 plugin，然后 reload window。
- 直接通过 Agent Skills 安装时，请重新运行安装命令。

Plugin version 与 Dex SDK version 相互独立。每个 skill 在使用具体 API 前，都会检查
应用实际安装的 dependency 和不可变 release source。

## 信任与权限

只从可信来源安装 agent extension。Dex plugin 不声明 MCP server、hook、credential
或应用 runtime code。创建 GitHub fork、发布 branch、打开 pull request，以及修改运行中
Flow，仍然是需要授权的操作。

接下来阅读主要工作流 [Dex App Builder](./dex-developer-skill/dex-app-builder.mdx)。
