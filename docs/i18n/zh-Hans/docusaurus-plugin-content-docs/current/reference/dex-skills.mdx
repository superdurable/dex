# 深入了解 Dex Skills

Dex Skills 教 coding agent 使用 Dex。[使用 AI 构建](/build-with-ai/dex-developer-skill)介绍怎样安装这些 Skill，以及从哪一个开始。下面每个页面完整介绍一个 Skill：什么时候调用它，它检查什么，以及它交付什么。

- [Dex App Builder](/build-with-ai/dex-developer-skill/dex-app-builder)：构建一个完整的 Dex 应用，从业务流程到经过测试的 Go 后端。
- [Dex SDK](/build-with-ai/dex-developer-skill/dex-sdk)：用 Python、Go、Java、TypeScript 或 Rust 构建、调试、测试和运行 Dex 应用。
- [Dex Connector Contributor](/build-with-ai/dex-developer-skill/dex-connector-contributor)：创建、测试并贡献官方 Connector 的 operation、Trigger 和配置界面单元。
