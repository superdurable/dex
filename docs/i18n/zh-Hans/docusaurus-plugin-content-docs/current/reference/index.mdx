# 开发者参考

开发者参考记录随版本变化的细节：配置项、flag、默认值、限制、指标、边界情况和版本差异。概念请看 [概念](/concepts) 和 [运行 Dex](/components)。开发者参考只有英文版。

## 先确认版本 {#check-your-version-first}

每个组件有自己的参考。依赖某个细节之前，先确认你运行的组件版本。每份参考默认打开最新版本。要看其他版本，用左侧栏中该组件下方的版本选择器。[兼容性矩阵](#compatibility-matrix) 列出支持的组件组合。

Dex 按一个共享的 release train 发版。每次发版只给有改动的组件打 tag，所以组件的 minor 版本号可能跳过。参考里说某个组件的 N 版本时，指的是该组件不超过 N 的最新版本。

## SDK 主题页 {#flows-and-steps}

每个 SDK 参考为[概念](/concepts)中的每个主题各写一页：Flow、Step、Attribute、RPC、Channel、Stream、Timer、SubFlow 和 Client。另外几页讲 StartFlowOptions、StepOptions、Step decision、wait、失败与重试，以及 Worker。每页都用该语言的名称和代码：[Go](/reference/go/)、[Python](/reference/python/)、[Java](/reference/java/)、[TypeScript](/reference/typescript/) 和 [Rust](/reference/rust/)。

## 兼容性矩阵 {#compatibility-matrix}

Worker 和 Client 会和 server 协商协议版本。server-zd 0.1.17 及更新版本提供协议版本 4。

| 组件 | 版本 | 需要的 server-zd |
| --- | --- | --- |
| Go、Python、Java、TypeScript 和 Rust SDK | 1.37, 1.35 | 0.1.17 或更新（协议版本 4） |
| Dex Web | 1.37, 1.35 | 0.1.17 或更新（协议版本 4） |

server-zd 协议版本 4 没有提高最低协议版本。1.35 之前的 SDK 在 server-zd 0.1.17 及更新版本上继续可用。先升级 server，再升级 SDK。见 [Upgrades and compatibility](/reference/server/upgrades)。

每个 `dexcli` 版本打包一个 server-zd 版本，**dexcli dev** 运行的就是它：

| dexcli | 打包的 server-zd |
| --- | --- |
| 1.37 | 0.1.20 |
| 1.36 | 0.1.19 |
| 1.35 | 0.1.18 |
| 1.34 | 0.1.16 |
| 1.33 | 0.1.15 |

用 **dexcli dev** 运行 SDK 1.35 的应用时，使用 `dexcli` 1.35 或更新版本。

## 发版说明 {#release-notes}

每个组件都在 GitHub 的 [Dex releases](https://github.com/superdurable/dex/releases) 发布发版说明。server-zd 每个版本的说明都列出 breaking change、新功能、修复和升级步骤。
