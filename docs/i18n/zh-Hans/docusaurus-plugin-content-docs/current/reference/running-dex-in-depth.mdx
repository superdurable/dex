# 深入了解 Dex 的运行

[运行 Dex](/components)在一页里概括了每个组件。这些页面包含每个组件的完整细节。

## 本组页面 {#pages}

- [本地运行](/components/run-locally)：用或不用 Homebrew 安装 `dexcli`，启动 **dexcli dev**，解决端口或连接问题。
- [你的应用](/components/application)：把 SDK 加入服务，启动 Worker，把服务传给 Flow，从 handler 启动 Flow。
- [Dex Server](/components/server)：server 依赖什么，怎样保存 Flow，依赖故障时它会怎样。
- [CLI（dexcli）](/components/cli)：每个 `dexcli` 命令的作用。
- [Web（Dex Web）](/components/web)：Dex Web 显示什么，以及怎样在生产环境运行它。
- [故障转移和部署](/concepts/failover-and-deploys)：从 Worker 崩溃到 Time Travel，每种事件下哪些会重新运行。
