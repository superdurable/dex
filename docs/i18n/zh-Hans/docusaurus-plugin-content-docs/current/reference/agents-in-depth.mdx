# 深入了解 Agent

这些页面是[持久化 Agent 如何工作](/agent-frameworks/how-it-works)和[框架支持](/agent-frameworks/framework-support)背后的完整内容。

- [Session](/agent-frameworks/sessions)：Session 保存什么、一个 turn 的开销，以及 Session 记住什么。

- [审批](/agent-frameworks/approvals)：从你的应用或在 Dex Web 中回答审批。
- [把 Connector 用作 tool](/agent-frameworks/connectors-as-tools)：为每个框架把官方 Connector 操作作为 tool 提供。
- [内置 Agent Loop](/agent-frameworks/built-in-agent-loop)：支持持久上下文、Steer、提问、计划和实时事件的 harness。
- [各框架如何在 Dex 上运行](/agent-frameworks/framework-details)：每个适配器怎样把一个 turn 作为 Step 运行，以及它的全部限制。

有版本的 [Agents 参考](/reference/agents/)（英文）包含配置、限制和版本细节。
