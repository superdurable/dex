# 概念

Dex 的编程模型很小。Flow 是一个持久化程序。Step 推动它前进。原语（Primitive）保存它的状态，并把它和外部世界连起来。你的应用通过 Client 驱动 Flow。

<a id="how-they-fit-together"></a>

## Dex 保证什么 {#guarantees}

Dex 把每个 Step 的结果和转到下一个 Step 的动作一起保存，所以已经完成的 Step 不会再运行。被中途打断的 Step 可能再运行一次；[Step 的保证](/concepts/step#guarantees)列出了每一条保证和它的限制。

## Flow 和 Step {#flow-and-step}

| 概念 | 它是什么 | 用它来 |
| --- | --- | --- |
| [Flow](/concepts/flow) | 一个带业务 ID 的持久化程序。它拥有自己的 Step、状态和消息。 | 建模一个业务流程或一个实体。 |
| [Step](/concepts/step) | Flow 里的一个工作单元。它等待、执行，并决定接下来运行什么。 | 做工作，推动流程前进。 |

## 原语 {#the-primitives}

原语是 Flow 使用的构件。每个原语都属于一个 Flow。

| 原语 | 它是什么 | 用它来 |
| --- | --- | --- |
| [Attribute](/concepts/primitives/attribute) | 属于一个 Flow 的持久化状态。 | 在 Step 之间保存数据，从外部读取它，并按它搜索。 |
| [RPC](/concepts/primitives/rpc) | 对一个 Flow 的同步调用。 | 从你的应用发送命令、读取视图。 |
| [Channel](/concepts/primitives/channel) | Flow 里的一个持久化消息队列。 | 投递 Step 等待的消息。 |
| [Stream](/concepts/primitives/stream) | 一个尽力而为、读者可以续读的数据流。 | 把实时进度推送给 UI。 |
| [Timer](/concepts/primitives/timer) | 一个等到某个时间点的持久化等待。 | 设置截止时间、提醒和计划任务。 |
| [SubFlow](/concepts/primitives/subflow) | 由另一个 Flow 作为子 Flow 启动的 Flow。 | 把大块或并行的工作拆成子 Flow。 |

## Client {#client}

[Client](/concepts/client) 是你的应用在 Worker 之外使用的 API。用它来启动、调用、读取、等待和操作 Flow。

## Connector {#connector}

[Connector](/concepts/connector) 把 Flow 连接到外部服务商，例如邮件或支付服务。它为你的 Flow 提供调用该服务商的现成 Step，以及根据服务商事件启动或更新 Flow 的 Trigger。
