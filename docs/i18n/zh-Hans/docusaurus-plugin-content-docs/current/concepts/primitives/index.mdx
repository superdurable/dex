# 原语

原语（Primitive）是 Flow 使用的构件：[Attribute](/concepts/primitives/attribute)、[RPC](/concepts/primitives/rpc)、[Channel](/concepts/primitives/channel)、[Stream](/concepts/primitives/stream)、[Timer](/concepts/primitives/timer) 和 [SubFlow](/concepts/primitives/subflow)。[概念](/concepts#the-primitives)对它们做了比较，并说明它们如何和 Flow、Step、Client、Connector 配合。
