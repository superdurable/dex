# Correctness and expressiveness

本节回答关于 Dex 的两个问题。

- **表达能力（expressiveness）**：Dex 能否表达你需要的程序？
- **正确性（correctness）**：进程、机器或网络出故障时，Dex 是否仍然正确？

## 表达能力 {#expressiveness}

[Workflow Patterns 评估](/concepts/correctness-and-expressiveness/workflow-patterns)按 43 个 control-flow Workflow Patterns 为 Dex 评级。研究者用这些模式比较各种 workflow 语言和引擎。每个评级都配有可运行的示例和集成测试。

[表达能力证明](/concepts/correctness-and-expressiveness/expressiveness-proof)说明：一门带线程、锁、Timer 和取消的小型并发语言中，任何程序都能写成行为相同的 Dex Flow。证明的每一步都由计算机检查。完整论证见[论文](/papers/dex-expressiveness.pdf)。

## 正确性 {#correctness}

[Step 的保证](/concepts/step#guarantees)说明 Step 方法失败或重复运行时 Dex 的承诺。第二个证明将说明崩溃、重试和消息重投不会改变 Flow 的行为，在 [issue 1514](https://github.com/superdurable/dex/issues/1514) 中跟进。
