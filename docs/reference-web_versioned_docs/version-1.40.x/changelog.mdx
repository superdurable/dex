# Change log

This page lists user-visible changes to Dex Web, newest first; each section covers the changes since the previous release of this component.

## 1.40 {#v1-40}

Released 2026-11-09 as [web/v1.40.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.40.0). Patch releases [web/v1.40.1](https://github.com/superdurable/dex/releases/tag/web%2Fv1.40.1) and [web/v1.40.2](https://github.com/superdurable/dex/releases/tag/web%2Fv1.40.2) followed the same day.

### Added

- **History settings** on the Run page shows the run's retention window, and **Edit** changes it through UpdateFlowConfig while the run is active. [Reference](/reference/web/1.40.x/dex-web#v1-pages).

### Changed

- The **v1** Run page is redesigned with a horizontal Timeline, a minimap, and a selected event panel with **Input**, **Output**, and **Context** columns. [Reference](/reference/web/1.40.x/dex-web#v1-pages).

### Fixed

- Long values stay inside their column in the event panel. This arrived in 1.40.1.
- Attribute and Context rows stack in the narrow Execution graph panel. This arrived in 1.40.2.

## 1.39 {#v1-39}

Released 2026-11-09 as [web/v1.39.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.39.0).

### Added

- A **Session** tab shows Dex Agents sessions in Dex Web v2. [Reference](/reference/web/1.40.x/dex-web#agent-session-view).
- The Work Queue shows an agent inbox. [Reference](/reference/web/1.40.x/dex-web#agent-inbox).
- Dex Web sends the declared RPC locks when a person runs an Action, and a Flow Definition Graph is available for Dex Agents session Flows. [Reference](/reference/web/1.40.x/dex-web#actions).

### Changed

- Dex Web sends LoadBlobs requests in batches of at most 1,000 entries.

## 1.38 {#v1-38}

Released 2026-11-07 as [web/v1.38.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.38.0).

### Added

- Dex Web v2 searches by active Step type and across several Flow types. [Reference](/reference/web/1.40.x/dex-web#search-several-flow-types).
- An Action RPC returns its output to the page, and an Action may have no condition. [Reference](/reference/web/1.40.x/dex-web#actions).

### Changed

- Large values in history events appear as value references, and Dex Web loads them on demand because server-zd 0.1.21 bounds history pages by the gRPC response limit. [Reference](/reference/server/changelog#v0-1-21).

## 1.37 {#v1-37}

Released 2026-11-06 as [web/v1.37.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.37.0). Reference: [1.37.x](/reference/web/1.37.x/).

### Fixed

- Dex Web stops promptly even while a Flow history long poll is open. [Release notes](https://github.com/superdurable/dex/releases/tag/web%2Fv1.37.0).

## 1.35 {#v1-35}

Released 2026-11-06 as [web/v1.35.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.35.0). Reference: [1.35.x](/reference/web/1.35.x/).

### Breaking

- Active Step invocation details require server-zd 0.1.17 or later and protocol version 4. Upgrade the server before upgrading Dex Web. [Reference](/reference/web/1.40.x/dex-web#worker-routing).

### Added

- Active Steps show each method’s phase, pending reason, attempt number, and wait time. History also shows when the attempt became scheduled. [Reference](/reference/web/1.40.x/dex-web#worker-routing).

## 1.32 {#v1-32}

Released 2026-11-01 as [web/v1.32.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.32.0). Reference: [1.32.x](/reference/web/).

No Dex Web behavior changes were identified in this release; the Web source is unchanged from 1.30.

## 1.30 {#v1-30}

Released 2026-10-31 as [web/v1.30.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.30.0). Reference: [1.30.x](/reference/web/).

No Dex Web behavior changes were identified in this release; the Web source is unchanged from 1.29.

## 1.29 {#v1-29}

Released 2026-10-31 as [web/v1.29.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.29.0). Reference: [1.29.x](/reference/web/1.40.x/).

### Added

- Related-event links jump to other pages and distinguish pruned events from unloaded events. The oldest retained page shows the pruned event range. [Reference](/reference/web/1.40.x/dex-web#run-against-server-zd).

### Changed

- The Run details Timeline loads history in pages of at most 1,000 events, with Older, Newer, Newest, and Back navigation. Event numbers are event IDs. [Reference](/reference/web/1.40.x/dex-web#run-against-server-zd).
- The v2 canvas loads a bounded recent history window and appends new events on polls. The Execution graph, Overview, and time-travel dialog also use the newest window. [Reference](/reference/web/1.40.x/dex-web#run-against-server-zd).

Older releases: [GitHub releases](https://github.com/superdurable/dex/releases?q=web%2F&expanded=true).
