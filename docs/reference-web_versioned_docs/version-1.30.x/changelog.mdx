# Change log

This page lists user-visible changes to Dex Web, newest first; each section covers the changes since the previous release of this component.

## 1.30 {#v1-30}

Released 2026-10-31 as [web/v1.30.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.30.0). Reference: [1.30.x](/reference/web/1.30.x/).

No Dex Web behavior changes were identified in this release; the Web source is unchanged from 1.29.

## 1.29 {#v1-29}

Released 2026-10-31 as [web/v1.29.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.29.0). Reference: [1.29.x](/reference/web/1.29.x/).

### Added

- Related-event links jump to other pages and distinguish pruned events from unloaded events. The oldest retained page shows the pruned event range. [Reference](/reference/web/1.30.x/dex-web#run-against-server-zd).

### Changed

- The Run details Timeline loads history in pages of at most 1,000 events, with Older, Newer, Newest, and Back navigation. Event numbers are event IDs. [Reference](/reference/web/1.30.x/dex-web#run-against-server-zd).
- The v2 canvas loads a bounded recent history window and appends new events on polls. The Execution graph, Overview, and time-travel dialog also use the newest window. [Reference](/reference/web/1.30.x/dex-web#run-against-server-zd).

Older releases: [GitHub releases](https://github.com/superdurable/dex/releases?q=web%2F&expanded=true).
