# Dex Web reference

This reference covers Dex Web, the operator UI for Dex, and the Flow source
analyzer that draws its Flow canvas. See [Web](/components/web) for
how Dex Web fits with the other components.

## Pages

- [Dex Web](/reference/web/1.41.x/dex-web): run the **dex-web** process, access
  control, **dexcli web**, the UI pages, and running against server-zd.
- [Flow source visualization](/reference/web/1.41.x/flow-visualization): the analyzer
  behind **dexcli visualize**, its supported source profile, lints, and the JSON
  contract.
- [Local Connector setup](/reference/web/1.41.x/local-connector-setup): configure
  Connector accounts and Trigger bindings for local development.
- [Troubleshoot a Flow run](/reference/web/1.41.x/debugging): Worker availability, Flow
  failures, and a read-only debugging workflow with Dex Web and **dexcli**.

## Release notes

Dex Web is released as **web/vX.Y.Z**, and every **dexcli** release embeds the
Dex Web of the same commit. See the
[web releases](https://github.com/superdurable/dex/releases?q=web%2Fv&expanded=true)
on GitHub.
