# Authentication

Public API authentication is off by default. Configure **auth.authenticators**
to require a bearer credential on every **FlowService** and **WorkerTaskService** call.
gRPC health checks need no credential. The server tries the authenticators in
order.

~~~yaml
auth:
  authenticators:
    - kind: jwt
      issuer: https://issuer.example.com
      audiences: ["dex"]
      adminAudiences: []
      jwksURL: ""
      allowInsecureJWKSURL: false
      caFile: ""
    - kind: staticTokens
      file: /etc/dex-server-zd/tokens.yaml
~~~

**allowInsecureJWKSURL** allows a plain HTTP **jwksURL**; use it only on a
trusted network. When **jwksURL** is empty, the server finds the key set through
the issuer's OpenID configuration. **caFile** adds
a PEM bundle to the system roots. **adminAudiences** lists the audiences that
authorize [admin calls](#admin-credentials).

The static token file lists SHA-256 hashes, never plaintext tokens:

~~~yaml
tokens:
  - sha256: 9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08
~~~

The file must be valid at startup. Changes take effect within a second. If an
update is malformed, the server keeps using the last valid content. An empty or
missing file revokes every token.

The server checks a credential once, when a call starts. An open pull Worker
stream stays open after its token expires or is revoked. The Worker needs a
valid credential when it reconnects.

## Send credentials from Workers and Clients {#sdk-credentials}

Workers and Clients each take a **credential** option, and Dex sends its token
with every call. A file credential reads the token from a file and rereads it
when the file changes, so a rotated token needs no restart:

| SDK | Credential option | File credential |
|---|---|---|
| Python | **credential** on **ClientOptions** and **WorkerOptions** | **FileCredential(path)** |
| Go | **Credential** field on **ClientOptions** and **WorkerOptions** | **dex.FileCredential(path)** |
| Java | **credential(...)** on the **ClientOptions** and **WorkerOptions** builders | **new FileCredential(path)** |
| TypeScript | **credential** in the Client and Worker options | **new FileCredential(path)** |
| Rust | **credential(...)** on the **ClientOptions** and **WorkerOptions** builders | **FileCredential::new(path)** |

Each SDK also has an **ApiKeyCredential**, which exchanges an API key for a
short-lived token at a token endpoint. The endpoint takes an HTTPS
**POST** with a JSON body of **server_id** and **api_key**, and answers 200
with a JSON body of **access_token**, **token_type** set to **Bearer**, and
**expires_in** in seconds.

## TLS {#tls}

**api.listen** serves plaintext gRPC, so bearer credentials cross the network in
clear text. Terminate TLS in front of the server, or restrict the network to
trusted callers. When TLS is in front, set the SDK's **flow_service_tls**
option (**FlowServiceTLS** in Go, **flowServiceTls** in Java and TypeScript,
**flow_service_tls(...)** on the Rust builders) on
Workers and Clients.

## Admin credentials {#admin-credentials}

Admin calls, such as
[describe and step down](/reference/server/0.1.28/high-availability#step-down), need
their own credential. Each **jwt** authenticator can list **adminAudiences**: a
token from that issuer with one of these audiences is an admin credential. The
list is empty by default, so no issuer authorizes admin calls until you
configure one.

~~~yaml
auth:
  authenticators:
    - kind: jwt
      issuer: https://issuer.example.com
      audiences: ["dex"]
      adminAudiences: ["dex-operators"]
~~~

When **auth.authenticators** is not empty, an admin call needs a JWT that its
issuer's **jwt** authenticator accepts. One of the token's audiences must be in
that authenticator's **adminAudiences**. Static tokens never authorize admin
calls. A missing or invalid credential fails with **UNAUTHENTICATED**. A valid
public API credential without an admin audience fails with
**PERMISSION_DENIED**.

Set **adminAudiences** only on an issuer that decides the audiences of its
tokens itself. Never set it on an issuer that lets callers choose **aud**,
such as Kubernetes projected service account tokens or a CI OIDC provider shared
with other projects. Anyone who can get a token from such an issuer could ask
for an admin audience and step the node down.

**adminAudiences** applies only to **jwt** authenticators. Its entries must not
be empty. They must differ from the same authenticator's **audiences**, so a
public API credential never authorizes an admin call.

If an issuer only signs admin credentials, set **adminAudiences** and leave
**audiences** empty. Its tokens then never authorize **FlowService** or
**WorkerTaskService** calls. If that issuer is the only authenticator, public
API authentication is still on, so the server denies every **FlowService** and
Worker call.

**dexcli** exchanges an API key by sending only the server ID and the key, so it
cannot ask for an admin audience. An API key works for admin commands only if
the token endpoint itself issues tokens with an admin audience for that key.

When authentication is off, as on a local development server, admin calls need
no credential. Anyone who can reach **api.listen** can then step the node down
repeatedly.

server-zd validates **adminAudiences** at startup. It logs each authorized admin
call with the caller's **iss** and **sub** claims. It logs denied admin calls as
warnings, at most once every 10 seconds.
