# Change log

This page lists user-visible changes to the TypeScript SDK, newest first; each section covers the changes since the previous release of this component.

## 1.37 {#v1-37}

Released 2026-11-06 as [sdk-typescript/v1.37.0](https://github.com/superdurable/dex/releases/tag/sdk-typescript%2Fv1.37.0). Reference: [1.37.x](/reference/typescript/1.37.x/).

This release has no runtime behavior changes; the SDK changes in this interval are API documentation and example updates.

## 1.35 {#v1-35}

Released 2026-11-06 as [sdk-typescript/v1.35.0](https://github.com/superdurable/dex/releases/tag/sdk-typescript%2Fv1.35.0). Reference: [1.35.x](/reference/typescript/1.35.x/).

### Breaking

- Workers and the Client’s first call now require server-zd 0.1.17 or later (protocol version 4). Upgrade all server processes before upgrading the SDK. [Reference](/reference/server/upgrades).
- Worker startup fails when **maxConcurrentTasks** exceeds **matching.maxConcurrentTasksCap** (256 by default). Lower the Worker setting or raise the server cap and **matching.maxStreams** first. [Reference](/reference/typescript/1.37.x/workers#capacity-and-shutdown).
- **RetryPolicy.totalDurationMs** now starts at the first hand-out and only gates scheduling another retry. Set method timeouts to bound running attempts. [API reference](pathname:///api/typescript/1.35/interfaces/RetryPolicy.html#totaldurationms).
- A Step with no available or supporting Worker waits durably without consuming a retry. Set a Flow timeout to bound that wait. [Reference](/reference/server/workers#step-task-queue).
- A Step attempt interrupted after its hand-out was committed fails with **NOT_COMPLETED** and consumes a retry. Review retry policies and side effects before upgrading. [Reference](/reference/typescript/1.37.x/flows-and-steps/failure-and-redelivery#same-attempt-redelivery).

### Added

- **RecoveryErrorInfo.attemptProgress** distinguishes a failed Step method that never started from one that may have run. [API reference](pathname:///api/typescript/1.35/interfaces/RecoveryErrorInfo.html).
- **declareRPCMethod** declares RPC handlers without decorators. **RPCMethodName** checks eligible method names at compile time. [API reference](pathname:///api/typescript/1.35/functions/declareRPCMethod.html).
- **flowServiceTls** on Client and Worker options enables verified TLS, with optional **additionalRootCAsPem** and **serverName**. Omitting it keeps plaintext connections. [API reference](pathname:///api/typescript/1.35/interfaces/FlowServiceTlsOptions.html).

### Changed

- Workers open one execution stream per slot; **reservedRpcTasks** selects RPC-only slots. By default, a Worker with at least two slots reserves one for RPCs. [Reference](/reference/typescript/1.37.x/workers#capacity-and-shutdown).
- **close** drains running handlers and returns tasks that did not start without consuming a retry. [Reference](/reference/typescript/1.37.x/workers#capacity-and-shutdown).

### Deprecated

- **idleStreamsPerQueue** is accepted but ignored, and **pullReservedRpcDeclines** always reports zero. Use execution-slot capacity and queue metrics instead. [Reference](/reference/typescript/1.37.x/workers#reserved-rpc-capacity).

## 1.32 {#v1-32}

Released 2026-11-01 as [sdk-typescript/v1.32.0](https://github.com/superdurable/dex/releases/tag/sdk-typescript%2Fv1.32.0). Reference: [1.32.x](/reference/typescript/1.32.x/).

### Added

- Generated protocol bindings include **AdminService**, with **DescribeActiveNode** and **StepDownActiveNode** for inspecting and stepping down the active server process. [Release notes](https://github.com/superdurable/dex/releases/tag/sdk-typescript%2Fv1.32.0).

## 1.30 {#v1-30}

Released 2026-10-31 as [sdk-typescript/v1.30.0](https://github.com/superdurable/dex/releases/tag/sdk-typescript%2Fv1.30.0). Reference: [1.30.x](/reference/typescript/).

### Added

- Generated protocol bindings add **ERROR_SUB_STATUS_ATTRIBUTE_INDEX_CAPACITY_EXCEEDED** and **ERROR_SUB_STATUS_INDEXED_KEYWORD_TOO_LONG** for Attribute index admission errors. [Release notes](https://github.com/superdurable/dex/releases/tag/sdk-typescript%2Fv1.30.0).

## 1.29 {#v1-29}

Released 2026-10-31 as [sdk-typescript/v1.29.0](https://github.com/superdurable/dex/releases/tag/sdk-typescript%2Fv1.29.0). Reference: [1.29.x](/reference/typescript/).

### Added

- Generated history responses expose the pruned event range and first retained event ID. Step event contexts also carry related event IDs and the WaitFor completion time. [Release notes](https://github.com/superdurable/dex/releases/tag/sdk-typescript%2Fv1.29.0).
- **Client.getAttributes** reads committed Attributes and AttributeMap instances in one request without a Worker. **AttributeMap.instance** selects an instance, and results form a typed tuple in read order. [API reference](pathname:///api/typescript/1.29/classes/Client.html).

Older releases: [GitHub releases](https://github.com/superdurable/dex/releases?q=sdk-typescript&expanded=true).
