# Primitives

These pages list the TypeScript SDK names for the six [primitives](/concepts/primitives).
Each page links the doc comments in the [TypeScript SDK API reference](./index.mdx#api-reference).

- [Attribute](./attribute.mdx): TypeScript names for Attributes and AttributeMaps.
- [RPC](./rpc.mdx): TypeScript names for RPC handlers and their results.
- [Channel](./channel.mdx): TypeScript names for Channels and ChannelMaps.
- [Stream](./stream.mdx): TypeScript names for writing and reading Streams.
- [Timer](./timer.mdx): TypeScript names for Timer conditions.
- [SubFlow](./subflow.mdx): TypeScript names for SubFlow conditions and results.
