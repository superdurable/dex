## Version notes {#version-notes}

Changed in 0.1.17 (Server protocol 4, required by SDK 1.35):

- A Step attempt deadline is the hand-out time plus the method timeout. It is
  no longer shortened to the remaining retry budget. Queue and lock waits are
  excluded.
- An interrupted attempt that was handed out consumes a retry.
- **TotalDuration** never ends a running attempt. The server no longer
  produces the RETRY_DEADLINE failure kind. The SDK helper
  **IsRetryTotalDurationExceeded**, and its equivalent in other SDKs, can be
  true only for records written before the upgrade.
