# Attribute

This page lists the TypeScript SDK names for [Attributes](/concepts/primitives/attribute).
The doc comment of each API gives its parameters, defaults, and errors. Read
them in the [TypeScript SDK API reference](./index.mdx#api-reference).

## API names {#api-names}

| Task | TypeScript API | Dex behavior |
| --- | --- | --- |
| Define a singleton Attribute | **Attribute** | [Attributes](/reference/server/runtime-data#attributes) |
| Define an AttributeMap | **AttributeMap** | [Attributes](/reference/server/runtime-data#attributes) |
| Declare it in the Flow | **attributes** of the **PersistenceSchema** returned from **getPersistenceSchema** | [Flow definition](./flow.mdx#flow-definition) |
| Read, write, and delete a value in a Step or RPC | **get**, **set**, and **delete** | [Commits](./step.mdx#commit-boundary) |
| Address one AttributeMap instance | **AttributeMap.instance**, or the instance argument of **get**, **set**, and **delete** | [Attributes](/reference/server/runtime-data#attributes) |
| Count AttributeMap instances and list their keys | **AttributeMap.getMapSize** and **AttributeMap.getAllInstanceKeys** | [Selective state loading](./step-options.mdx#selective-state-loading) |
| Load AttributeMap values for a method | **AttributeMap.load**, with the load fields of **StepOptions** or **RPCOptions** | [Selective state loading](./step-options.mdx#selective-state-loading) |
| Lock a value for a read-modify-write | **lock**, with the lock fields of **StepOptions** or **lockAttributes** of **RPCOptions** | [Locks](/reference/server/runtime-data#attribute-locks) |
| Index a value for search | **AttributeIndex** and **IndexType** | [Indexes](/reference/server/runtime-data#attribute-indexes) |
| Project writes to an Attribute Store | **syncToAttributeStore** | [Attribute sync](/reference/server/attribute-store-sync) |
| Store a value that can be erased | **hardDeleteOnNull** | [Hard-delete Attributes](/reference/server/runtime-data#hard-delete-attributes) |
| Set a value when the Flow starts | **attributes** of **StartFlowOptions**, with **InitialAttribute.of** or **InitialAttribute.mapValue** | [Attributes at start](./start-flow-options.mdx#attributes) |
| Read values from outside the Flow | **Client.getAttributes** | [Read Attributes](/reference/server/runtime-client#read-attributes) |
| Wait until a value matches | **Client.waitForAttributeMatch** | [Wait for an Attribute match](/reference/server/runtime-client#wait-for-an-attribute-match) |
