# Channel

This page lists the TypeScript SDK names for [Channels](/concepts/primitives/channel).
The doc comment of each API gives its parameters, defaults, and errors. Read
them in the [TypeScript SDK API reference](./index.mdx#api-reference).

## API names {#api-names}

| Task | TypeScript API | Dex behavior |
| --- | --- | --- |
| Define a Channel | **Channel** | [Channels](/reference/server/runtime-data#channels) |
| Define a ChannelMap | **ChannelMap** | [ChannelMap](/reference/server/runtime-data#channelmap) |
| Declare it in the Flow | **channels** of the **PersistenceSchema** returned from **getPersistenceSchema** | [Flow definition](./flow.mdx#flow-definition) |
| Publish a message from a Step or RPC | **publish** | [Commits](./step.mdx#commit-boundary) |
| Wait for messages | **forOne**, **forN**, **atLeast**, **atMost**, and **range** | [Wait conditions](/reference/server/runtime-data#channel-conditions) |
| Read the messages a wait consumed | **results** | [Channel results](./waits.mdx#channel-results) |
| Load pending messages for a method | **ChannelMap.loadMessages**, with the load fields of **StepOptions** or **RPCOptions** | [Selective state loading](./step-options.mdx#selective-state-loading) |
| Read loaded pending messages | **pendingMessages** and **findPendingMessage** | [Pending messages](/reference/server/runtime-data#manage-pending-messages) |
| Delete a pending message | **delete** | [Pending messages](/reference/server/runtime-data#manage-pending-messages) |
| Read the number of pending messages | **size** | [Selective state loading](./step-options.mdx#selective-state-loading) |
| Count ChannelMap instances and list their keys | **ChannelMap.getMapSize** and **ChannelMap.getAllInstanceKeys** | [ChannelMap](/reference/server/runtime-data#channelmap) |
| Complete the Flow only when Channels are empty | **forceCompleteIfChannelsEmpty** | [ForceCompleteIfChannelsEmpty](./step-decisions.mdx#forcecompleteifchannelsempty) |
