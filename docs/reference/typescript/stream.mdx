# Stream

This page lists the TypeScript SDK names for [Streams](/concepts/primitives/stream).
The doc comment of each API gives its parameters, defaults, and errors. Read
them in the [TypeScript SDK API reference](./index.mdx#api-reference).

## API names {#api-names}

| Task | TypeScript API | Dex behavior |
| --- | --- | --- |
| Define a Stream and its byte capacity | **Stream**, with **streamCapacityBytes** | [Capacity and trimming](/reference/server/runtime-data#stream-capacity) |
| Declare it in the Flow | **streams** of the **PersistenceSchema** returned from **getPersistenceSchema** | [Flow definition](./flow.mdx#flow-definition) |
| Write a message from a Step | **Stream.write** | [Write semantics](/reference/server/runtime-data#stream-write-semantics) |
| Write text chunks in batches from a Step | **Stream.bufferedText** | [Buffer text chunks](/reference/server/runtime-data#stream-buffered-text) |
| Write a message from a Client | **Client.writeStream** | [Write semantics](/reference/server/runtime-data#stream-write-semantics) |
| Read the next message | **Client.readStream**, with the **resumeToken** of the last message | [Resumable reads](/reference/server/runtime-data#stream-resumable-reads) |
| List retained messages, newest first | **Client.listStreamMessages** | [List messages](/reference/server/runtime-data#stream-listing) |

**Stream.write** sends the message immediately and returns nothing. Use
**Stream.bufferedText** in an asynchronous Step. RPC handlers cannot write a
Stream.
