# Attribute

This page lists the Rust SDK names for [Attributes](/concepts/primitives/attribute).
The doc comment of each API gives its parameters, defaults, and errors. Read
them in the [Rust SDK API reference](./index.mdx#api-reference).

## API names {#api-names}

| Task | Rust API | Dex behavior |
| --- | --- | --- |
| Define a singleton Attribute | **Attribute** | [Attributes](/reference/server/runtime-data#attributes) |
| Define an AttributeMap | **AttributeMap** | [Attributes](/reference/server/runtime-data#attributes) |
| Declare it in the Flow | **PersistenceSchema::attribute** and **PersistenceSchema::attribute_map**, returned from **Flow::persistence** | [Flow definition](./flow.mdx#flow-definition) |
| Read, write, and delete a value in a Step or RPC | **get**, **get_required**, **set**, and **delete** | [Commits](./step.mdx#commit-boundary) |
| Address one AttributeMap instance | **AttributeMap::instance**, or the instance key argument of **get**, **set**, and **delete** | [Attributes](/reference/server/runtime-data#attributes) |
| Count AttributeMap instances and list their keys | **AttributeMap::map_size** and **AttributeMap::all_instance_keys** | [Selective state loading](./step-options.mdx#selective-state-loading) |
| Load AttributeMap values for a method | **AttributeMap::load**, with the load methods of **StepOptions** or **Rpc** | [Selective state loading](./step-options.mdx#selective-state-loading) |
| Lock a value for a read-modify-write | **lock**, with **wait_for_lock** or **execute_lock** of **StepOptions**, or **lock** of **Rpc** | [Locks](/reference/server/runtime-data#attribute-locks) |
| Index a value for search | **indexed**, with an **AttributeIndex** such as **AttributeIndex::keyword** | [Indexes](/reference/server/runtime-data#attribute-indexes) |
| Project writes to an Attribute Store | **sync_to_attribute_store** | [Attribute sync](/reference/server/attribute-store-sync) |
| Store a value that can be erased | **hard_delete_on_null** | [Hard-delete Attributes](/reference/server/runtime-data#hard-delete-attributes) |
| Set a value when the Flow starts | **StartFlowOptions::initial_attribute** and **StartFlowOptions::initial_attribute_map** | [Attributes at start](./start-flow-options.mdx#attributes) |
| Read values from outside the Flow | **Client::get_attributes** | [Read Attributes](/reference/server/runtime-client#read-attributes) |
| Wait until a value matches | **Client::wait_for_attribute_match** and **Client::wait_for_attribute_map_instance_match**, with **AttributeMatch** | [Wait for an Attribute match](/reference/server/runtime-client#wait-for-an-attribute-match) |
