# Timer

This page lists the Go SDK names for [Timers](/concepts/primitives/timer).
The doc comment of each API gives its parameters, defaults, and errors. Read
them in the [Go SDK API reference](./index.mdx#api-reference).

## API names {#api-names}

| Task | Go API | Dex behavior |
| --- | --- | --- |
| Wait for a duration | **Timer** in **WaitFor** | [Firing time](/reference/server/runtime-data#timer-firing-time) |
| Give the Timer a stable ID | **WithConditionID**, passed to **Timer** | [AnyCombinationOf](./waits.mdx#anycombinationof) |
| Combine a Timer with other conditions | **AnyOf**, **AllOf**, and **AnyComboOf** with **Combo** | [Waits](./waits.mdx) |
| Check whether a Timer fired | **Context.HasTimerFired** and **Context.HasTimerFiredByIndex** in **Execute** | [Condition results](./waits.mdx#condition-results) |
| Make a waiting Timer ready now | **Client.SkipTimer**, with **StepExecutionID** and **TimerID** | [Skip a Timer](/reference/server/runtime-client#skip-a-timer) |
