# Go Workers

This page shows how to start a Go Worker and lists the Go names of its
settings. [Workers and the task queue](/reference/server/workers) describes
how these settings behave in every SDK.

## Start a Worker

This example serves a Greeting Flow through a pull Worker. Its Step stores a
greeting, and the greeting RPC reads it. The Worker allows eight concurrent tasks
and keeps one slot for RPCs. See the [Go SDK README](https://github.com/superdurable/dex/blob/main/sdk-go/README.md#running-a-worker) for
startup details.

```go
type PullGreetingDiagnostics struct {
	IsReady bool
}

func StartPullGreeting(cache *blobcache.Cache, serverAddress string) (*GreetingFlow, *dex.Worker, *dex.Client, <-chan error, error) {
	flow := &GreetingFlow{}
	registry, err := dex.NewRegistry([]dex.Flow{flow})
	if err != nil {
		return nil, nil, nil, nil, err
	}
	worker, err := dex.NewWorker(registry, cache, dex.WorkerOptions{
		FlowServiceAddress: serverAddress,
		Pull: &dex.PullWorkerOptions{
			MaxConcurrentTasks: 8,
			// Keep one slot for RPCs so Flows stay responsive.
			ReservedRPCTasks: ptr.Any(1),
		},
	})
	if err != nil {
		return nil, nil, nil, nil, err
	}
	client, err := dex.NewClient(registry, cache, dex.ClientOptions{
		FlowServiceAddress: serverAddress,
	})
	if err != nil {
		return nil, nil, nil, nil, errors.Join(err, worker.Stop(context.Background()))
	}
	workerResult := make(chan error, 1)
	go reportWorkerResult(worker, workerResult)
	startupContext, cancel := context.WithTimeout(context.Background(), 30*time.Second)
	defer cancel()
	if err := worker.WaitPullRegistered(startupContext); err != nil {
		return nil, nil, nil, nil, errors.Join(err, StopPullGreeting(context.Background(), worker, client, workerResult))
	}
	return flow, worker, client, workerResult, nil
}

func StopPullGreeting(ctx context.Context, worker *dex.Worker, client *dex.Client, workerResult <-chan error) error {
	clientCloseErr := client.Close()
	workerStopErr := worker.Stop(ctx)
	var workerRunErr error
	select {
	case workerRunErr = <-workerResult:
	case <-ctx.Done():
		workerRunErr = ctx.Err()
	}
	return errors.Join(clientCloseErr, workerStopErr, workerRunErr)
}

func PullGreetingReadiness(worker *dex.Worker) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if !worker.PullRegistrationState().IsReady {
			http.Error(w, "pull slot registrations unavailable", http.StatusServiceUnavailable)
			return
		}
		w.WriteHeader(http.StatusOK)
	})
}

func GetPullGreetingDiagnostics(worker *dex.Worker) PullGreetingDiagnostics {
	return PullGreetingDiagnostics{
		IsReady: worker.PullRegistrationState().IsReady,
	}
}

func reportWorkerResult(worker *dex.Worker, workerResult chan<- error) {
	workerResult <- worker.Start()
}
```

Example: [examples/go/production/pull-workers/worker.go](https://github.com/superdurable/dex/blob/main/examples/go/production/pull-workers/worker.go)

## Readiness

**WaitPullRegistered** waits until the Worker's slot streams have registered with
Dex. **PullRegistrationState** reports the current registration state. By default,
a Worker keeps retrying when Dex permanently rejects a slot stream. Set
**StopOnPermanentStreamRejection** to stop and drain the Worker instead when a permanent
rejection leaves a slot kind without registered streams. Since 1.13.0.

Start the Worker in a goroutine, then call **WaitPullRegistered** with a
startup deadline. In a rolling deployment, wait for it before you activate the
new Worker or stop the old one.

A **PullRegistrationError** reports **POLL_WORKER_SLOT_KIND_STEP_AND_RPC** or
**POLL_WORKER_SLOT_KIND_RPC_ONLY** as its slot kind.

Register the Go HTTP handler at your readiness probe endpoint.

```go
func PullGreetingReadiness(worker *dex.Worker) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if !worker.PullRegistrationState().IsReady {
			http.Error(w, "pull slot registrations unavailable", http.StatusServiceUnavailable)
			return
		}
		w.WriteHeader(http.StatusOK)
	})
}
```

Example: [examples/go/production/pull-workers/worker.go](https://github.com/superdurable/dex/blob/main/examples/go/production/pull-workers/worker.go)

## Capacity and shutdown

| Setting | Go name |
| --- | --- |
| Concurrent tasks | **MaxConcurrentTasks** |
| Reserved RPC slots | **ReservedRPCTasks** |
| Stop drain timeout | **StopDrainTimeout** |
| Shutdown | **Stop** |

The idle stream option, **IdleStreamsPerQueue**, is deprecated. It is still accepted and
has no effect.

## Reserved RPC capacity

The reserve-decline counter, **PullReservedRPCDeclines()**, is deprecated. It remains for
source compatibility and always reads zero.

Report registration readiness instead, as this diagnostics helper does. A Worker with every slot busy stays ready.

```go
type PullGreetingDiagnostics struct {
	IsReady bool
}

func GetPullGreetingDiagnostics(worker *dex.Worker) PullGreetingDiagnostics {
	return PullGreetingDiagnostics{
		IsReady: worker.PullRegistrationState().IsReady,
	}
}
```

Example: [examples/go/production/pull-workers/worker.go](https://github.com/superdurable/dex/blob/main/examples/go/production/pull-workers/worker.go)

## Upload Flow definitions {#flow-definitions}

A Worker can store the Flow Definition Graph (FDG 2.0) JSON of its Flows on the
Dex server at startup. Since 1.45.0.

| Setting | Go name |
| --- | --- |
| Files or directories of FDG JSON | **WorkerOptions.FlowDefinitionPaths** |
| In-memory documents | **WorkerOptions.FlowDefinitions**, a list of **FlowDefinitionDocument** |
| Read files with the same rules | **ReadFlowDefinitionFiles** |
| Upload from a script | **Client.UploadFlowDefinitions** |

- A directory is read recursively. Only its **.json** files are read.
- Each file must have a **schemaVersion** that starts with **2.** and a
  **flow.name**. **flow.name** is the Flow type.
- The generated time is the top-level **generatedAt**. Without it, the file
  modification time is used.
- **NewWorker** returns an error for an invalid file and for a Flow type given
  twice, including once in each option.
- **Start** uploads only the documents of Flow types in the Registry. It logs the
  others and skips them.
- An absolute **source.path** is uploaded relative to the working directory, or
  as its base name when the file lies outside it.
- Upload failures are warnings. The Worker still starts, also against a server
  without the upload API.
- The server keeps the document with the latest generated time. Give every
  process of one release the same generated time. Use **force** with
  **Client.UploadFlowDefinitions**, or **dexcli flow-definition upload --force**,
  to roll a definition back.

See the [API reference](pathname:///api/go/latest/dex/#type-workeroptions) and the
[dexcli upload command](/reference/cli/#flow-definition).
