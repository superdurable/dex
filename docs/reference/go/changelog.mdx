# Change log

This page lists user-visible changes to the Go SDK, newest first; each section covers the changes since the previous release of this component.

## 1.41 {#v1-41}

Not released yet. The next minor release, sdk-go/v1.41.0, ships these changes.

### Breaking

- Removed **Client.TriggerContinueAsNew**, **FlowContinuedAsNew**, **FlowConfig.ContinueAsNewThreshold**, **FlowConfig.ContinueAsNewPageSizeBytes**, **SearchFlowsOptions**, **Client.SearchFlowsWithOptions**, and **IncludeContinuedAsNew**. Use **Client.SearchFlows** for run searches. [Reference](/reference/go/flow#flow-config).
- Removed **WaitForStepCompletionOptions.InternalHandlerTimeout** and **WaitForAttributeOptions.InternalHandlerTimeout**. **RequestID** remains accepted but the server does not read it for these waits. [Reference](/reference/server/runtime-client#wait-timeouts-and-limits).
- Generated bindings rename **FlowExecutionID** to **FlowRunID** and **FlowExecutionId** to **FlowRunId** on response and history messages. ProtoJSON uses **flowRunId**. [Reference](/reference/server/runtime-client#describe-a-flow).

### Added

- **Join** and **JoinRound** synchronize parallel branches of one Flow. **DefineJoin** defines a Join over a ChannelMap of branch results. **Join.Fork** starts the branches and the join Step with one **JoinRound**; **Join.ForkWithRoundKey** takes an explicit round key for RPCs. Branches report with **Join.EndBranch** or **Join.ReportBranchResult**. The join Step waits with **Join.ForAllBranches**, **Join.ForFirstBranch**, or **Join.ForBranches** and reads **Join.BranchResults**. The next round's split Step resets the previous round with **Join.ForRemainingBranches** and reads **Join.RemainingBranchResults**. **Join.ChannelMap** returns the underlying ChannelMap for reading or loading a round's pending results. [Reference](/reference/go/waits).

## 1.40 {#v1-40}

Released 2026-11-09 as [sdk-go/v1.40.0](https://github.com/superdurable/dex/releases/tag/sdk-go%2Fv1.40.0). Patch release [sdk-go/v1.40.2](https://github.com/superdurable/dex/releases/tag/sdk-go%2Fv1.40.2) followed the same day.

### Added

- **FlowConfig.OffloadHistory** chooses whether a run offloads its history to object storage. Nil means true. Set it to false for many short runs that close soon. Set it at start through **StartFlowOptions.ConfigOverride** or in **SubFlowOptions.ConfigOverride**. A SubFlow otherwise inherits its parent's value, and **Client.UpdateFlowConfig** rejects it with INVALID_ARGUMENT. It requires server-zd 0.1.23 or later. [Reference](/reference/server/configuration#history-offload).

### Changed

- **FlowConfig.DeleteExpiredHistoryObjects** is deprecated. It has no effect, and the SDK no longer sends it. Existing code that sets it still compiles.
- The Worker error type now reports the original error's type for an error wrapped by **dex.ErrorWithStack**, instead of the wrapper type. The message and stack are unchanged. This arrived in 1.40.2.

## 1.39 {#v1-39}

Released 2026-11-09 as [sdk-go/v1.39.0](https://github.com/superdurable/dex/releases/tag/sdk-go%2Fv1.39.0).

### Added

- **FlowConfig.DeleteExpiredHistoryObjects** controls expired history object deletion at start, on update, and for SubFlows. It requires history offload and server-zd 0.1.22 or later.

### Changed

- A LoadBlobs request names at most 1,000 entries. The SDK batches larger requests and keeps the input order.

## 1.38 {#v1-38}

Released 2026-11-07 as [sdk-go/v1.38.0](https://github.com/superdurable/dex/releases/tag/sdk-go%2Fv1.38.0).

### Added

- **FlowConfig.HistoryWindowEvents** sets about how many of the newest history events a run keeps for history reads and Time Travel. Set it at start, change it with **Client.UpdateFlowConfig**, or override it for a SubFlow. Nil uses the server's **history.windowEvents** setting. Dex rejects a value that is not positive or exceeds **history.maxWindowEvents** with INVALID_ARGUMENT. It requires server-zd 0.1.21 or later. [Reference](/reference/server/configuration#history-window).

### Fixed

- A LoadBlobs request splits when the server rejects its response with OUT_OF_RANGE for exceeding the send limit. Before, hydrating more than 32 MiB of uncached blobs failed.

Released 2026-11-06 as [sdk-go/v1.37.0](https://github.com/superdurable/dex/releases/tag/sdk-go%2Fv1.37.0). Reference: [1.37.x](/reference/go/1.37.x/).

## 1.35 {#v1-35}

Released 2026-11-06 as [sdk-go/v1.35.0](https://github.com/superdurable/dex/releases/tag/sdk-go%2Fv1.35.0). Reference: [1.35.x](/reference/go/1.35.x/).

### Breaking

- Workers and the Client’s first call now require server-zd 0.1.17 or later (protocol version 4). Upgrade all server processes before upgrading the SDK. [Reference](/reference/server/upgrades).
- Worker startup fails when **MaxConcurrentTasks** exceeds **matching.maxConcurrentTasksCap** (256 by default). Lower the Worker setting or raise the server cap and **matching.maxStreams** first. [Reference](/reference/go/workers#capacity-and-shutdown).
- **RetryPolicy.TotalDuration** now starts at the first hand-out and only gates scheduling another retry. Set method timeouts to bound running attempts. [API reference](pathname:///api/go/1.35/dex/#type-retrypolicy).
- A Step with no available or supporting Worker waits durably without consuming a retry. Set a Flow timeout to bound that wait. [Reference](/reference/server/workers#step-task-queue).
- A Step attempt interrupted after its hand-out was committed fails with **NOT_COMPLETED** and consumes a retry. Review retry policies and side effects before upgrading. [Reference](/reference/go/failure-and-retries#same-attempt-redelivery).

### Added

- **RecoveryErrorInfo.AttemptProgress** distinguishes a failed Step method that never started from one that may have run. [API reference](pathname:///api/go/1.35/dex/#type-recoveryerrorinfo).
- **RPCOptions.Name** sets an RPC’s protocol name while Go callers continue referring to its bound method. [API reference](pathname:///api/go/1.35/dex/#type-rpcoptions).

### Changed

- Workers open one execution stream per slot; **ReservedRPCTasks** selects RPC-only slots. By default, a Worker with at least two slots reserves one for RPCs. [Reference](/reference/go/workers#capacity-and-shutdown).
- **Stop** drains running handlers and returns tasks that did not start without consuming a retry. [Reference](/reference/go/workers#capacity-and-shutdown).

### Deprecated

- **IdleStreamsPerQueue** is accepted but ignored, and **PullReservedRPCDeclines()** always reports zero. Use execution-slot capacity and queue metrics instead. [Reference](/reference/go/workers#reserved-rpc-capacity).

### Fixed

- A Worker accepts omitted input for an RPC whose input type is **dex.None**, allowing TypeScript Clients to invoke it. Missing input for other RPC types still fails with **INVALID_ARGUMENT**. [API reference](pathname:///api/go/1.35/dex/).
