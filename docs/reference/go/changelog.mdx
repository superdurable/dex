### 1.45.16 (2026-11-20) {#v1-45-16}

**Added**

- Set **PayloadEncryptionOptions** on **ClientOptions** and **WorkerOptions** to encrypt payloads before sending them to Dex. Readers decrypt them and pass plaintext through, so both kinds of Flows can share a Worker. [Reference](/reference/server/payload-encryption).
- The built-in **AESGCMPayloadCodec** uses AES-256-GCM, with optional gzip compression. **FilePayloadEncryptionKeyProvider** reads keys from a JSON key file and supports key rotation. Implement **PayloadCodec** or **PayloadEncryptionKeyProvider** to use your own key management.
- Worker error details and stack traces, ForceFail reasons, and Stop, Time Travel, and clone-fork reasons are encrypted too, in a **dex-encoded:** text format.
- The **Plaintext** Attribute option keeps an Attribute in clear. **WaitForAttributeMatch** and Action conditions need an Indexed or **Plaintext** Attribute when encryption is on. An encrypted Attribute synced to the Attribute Store needs a bytea column.
- The Java and Rust SDKs cannot read encrypted Flows yet.

### 1.45.8 (2026-11-18) {#v1-45-8}

No user-visible changes.

### 1.45.7 (2026-11-18) {#v1-45-7}

**Added**

- Set **PullWorkerOptions.MinOpenSlots** below **MaxConcurrentTasks** to vary open streams with load. Both count reserved RPC slots and defaulting the floor to **MaxConcurrentTasks** keeps the stream count fixed. [Reference](/reference/go/workers#capacity-and-shutdown).
- Adaptive Workers warn and clamp **MaxConcurrentTasks** to **matching.maxConcurrentTasksCap**. Growth and post-readiness reconnects retry after **RESOURCE_EXHAUSTED** without reporting **PullRegistrationError**. [Reference](/reference/server/workers#adaptive-slot-streams).
- **Worker.PullSlotStreamState** returns a snapshot of the slot streams: open, registering, busy, and idle streams, orphaned handlers, the floor and capacities, and grow and shrink counters.
- **SupportedServerProtocolVersionRange** returns the inclusive range of Dex Server protocol versions the Go SDK negotiates with, so a tool can check compatibility before it connects.

**Changed**

- Fixed pull Workers with unset **MaxConcurrentTasks** now warn and clamp the CPU-count default to **matching.maxConcurrentTasksCap**. An explicit limit above the cap still prevents startup. [Reference](/reference/server/workers#adaptive-slot-streams).

### 1.45.6 (2026-11-16) {#v1-45-6}

**Added**

- **GracefulCompletionRequested** lets a Step wait for a request and **IsGracefulCompletionConditionCompleted** reports whether it arrived. Requires Server protocol 7 (server-zd 0.1.34 or later). [Reference](/reference/go/waits#graceful-completion-requests).
- **GracefulCompleteFlow** and **ForceCompleteFlow** stop types and **StopOptions.Output** let **Client.StopFlow** complete a Flow with a result, like the **GracefulComplete** and **ForceComplete** Step decisions. They need a server that supports the complete stop types.
- **SupportsGracefulCompletionCondition** uses the negotiated protocol to report whether **WaitFor** can use **GracefulCompletionRequested**. Use it to stay compatible with Servers older than protocol 7. [Reference](/reference/go/waits#graceful-completion-requests).

### 1.45.5 (2026-11-15) {#v1-45-5}

**Added**

- **Client.CloneForkFlow** copies a run's state at a selected point, including **TimeTravelToCurrent**, into a new Flow without stopping the source. Requires Server protocol 6 (server-zd 0.1.33 or later). [Reference](/reference/server/runtime-client#clone-fork).
- **Client.TimeTravel** returns to the point after one history event with **TimeTravelByEventID** and **TimeTravelOptions.EventID**, and takes a **SubFlowResetPolicy** that decides what happens to the SubFlow conditions of restored Steps.
- **FlowErrorSubFlowAbandoned** marks a failed SubFlow result whose parent Flow stopped waiting for the child, because a Time Travel's SubFlow reset policy failed the restored SubFlow condition. **Execute** reads it from **SubFlowResult** like any other failed child.

**Fixed**

- A Flow result with an error type this SDK version does not recognize no longer fails the Worker invocation or the read. **FlowResult.ErrorType** is then the zero value.

### 1.45.4 (2026-11-15) {#v1-45-4}

**Changed**

- A pull Worker ignores the Server's busy-stream keepalive, a response with no frame, without a debug log line.

### 1.45.3 (2026-11-14) {#v1-45-3}

**Added**

- Set **RPCInvokeOptions.RequestID** on **Client.InvokeRPCWithOptions** to apply Flow changes at most once across retries. Transactional or locking RPCs return the recorded reply, and nil keeps the generated ID. [API reference](pathname:///api/go/latest/dex/#type-rpcinvokeoptions).

### 1.45.2 (2026-11-14) {#v1-45-2}

**Added**

- **ClientOnlyFlow** types RPCs and Streams served by other Workers for **Client.InvokeRPC** and **Client.ReadStream**. **NewRegistry** rejects Steps and **NewWorker** returns **ClientOnlyFlowError** for a client-only Flow. [API reference](pathname:///api/go/latest/dex/#type-clientonlyflow).
- Set named queues with **PullWorkerOptions.TaskQueue**, **StartFlowOptions.TaskQueue**, and **SubFlowOptions.TaskQueue**. Requires Server protocol 5. [Go Workers](/reference/go/workers#task-queue) and [API reference](pathname:///api/go/latest/dex/#type-pullworkeroptions).

### 1.45.0 (2026-11-11) {#v1-45-0}

**Breaking**

- A custom Step type containing "-" can no longer start SubFlows, and a **SubFlow** Condition from **WaitFor** logs a warning and fails the attempt without retry. Change **GetStepType** to return a name without "-". [Reference](/reference/go/subflow#step-type-rule).

**Added**

- **WorkerOptions.FlowDefinitionPaths** and **WorkerOptions.FlowDefinitions** upload registered Flow graphs at startup and warn on failure. **ReadFlowDefinitionFiles** reads graph files and **Client.UploadFlowDefinitions** reports upload outcomes. [Reference](/reference/go/workers#flow-definitions).

**Fixed**

- The **Join** documentation no longer recommends reporting a result for a cancelled branch from the cancelling RPC, which could count that branch twice. A cancelled branch never reports, and no other code can safely report for it. [API reference](pathname:///api/go/latest/dex/#type-join).

### 1.35.0 (2026-11-06) {#v1-35-0}

**Breaking**

- Workers and the Client’s first call now require server-zd 0.1.17 or later (protocol version 4). Upgrade all server processes before upgrading the SDK. [Reference](/reference/server/upgrades).
- Worker startup fails when **MaxConcurrentTasks** exceeds **matching.maxConcurrentTasksCap** (256 by default). Lower the Worker setting or raise the server cap and **matching.maxStreams** first. [Reference](/reference/go/workers#capacity-and-shutdown).
- **RetryPolicy.TotalDuration** now starts at the first hand-out and only gates scheduling another retry. Set method timeouts to bound running attempts. [API reference](pathname:///api/go/latest/dex/#type-retrypolicy).
- A Step with no available or supporting Worker waits durably without consuming a retry. Set a Flow timeout to bound that wait. [Reference](/reference/server/workers#step-task-queue).
- A Step attempt interrupted after its hand-out was committed fails with **NOT_COMPLETED** and consumes a retry. Review retry policies and side effects before upgrading. [Reference](/reference/go/failure-and-retries#same-attempt-redelivery).

**Added**

- **RecoveryErrorInfo.AttemptProgress** distinguishes a failed Step method that never started from one that may have run. [API reference](pathname:///api/go/latest/dex/#type-recoveryerrorinfo).
- **RPCOptions.Name** sets an RPC’s protocol name while Go callers continue referring to its bound method. [API reference](pathname:///api/go/latest/dex/#type-rpcoptions).

**Changed**

- Workers open one execution stream per slot; **ReservedRPCTasks** selects RPC-only slots. By default, a Worker with at least two slots reserves one for RPCs. [Reference](/reference/go/workers#capacity-and-shutdown).
- **Stop** drains running handlers and returns tasks that did not start without consuming a retry. [Reference](/reference/go/workers#capacity-and-shutdown).

**Deprecated**

- **IdleStreamsPerQueue** is accepted but ignored, and **PullReservedRPCDeclines()** always reports zero. Use execution-slot capacity and queue metrics instead. [Reference](/reference/go/workers#reserved-rpc-capacity).

**Fixed**

- A Worker accepts omitted input for an RPC whose input type is **dex.None**, allowing TypeScript Clients to invoke it. Missing input for other RPC types still fails with **INVALID_ARGUMENT**. [API reference](pathname:///api/go/latest/dex/).
