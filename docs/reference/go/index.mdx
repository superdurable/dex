# Go SDK reference

This reference covers the Dex Go SDK. Details can change between releases,
so check which version your application uses:

```bash
go list -m github.com/superdurable/dex/sdk-go
```

## Install

The Go SDK is the module **github.com/superdurable/dex/sdk-go**. Pin an exact
release in **go.mod**:

```bash
go get github.com/superdurable/dex/sdk-go@v1.37.0
```

The module requires Go 1.24 or newer. Releases use the tag
**sdk-go/vX.Y.Z**.

## Supported versions

| SDK minor | Server requirement |
| --- | --- |
| 1.37, 1.35 | server-zd 0.1.17 or newer (protocol version 4) |
| 1.32, 1.30, 1.29 | See the [compatibility matrix](/reference/#compatibility-matrix) |

Minor numbers follow the shared Dex release train. A missing minor means the Go
SDK did not change in that release.
