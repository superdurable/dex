# Primitives

These pages list the Go SDK names for the six [primitives](/concepts/primitives).
Each page links the doc comments in the [Go SDK API reference](./index.mdx#api-reference).

- [Attribute](./attribute.mdx): Go names for Attributes and AttributeMaps.
- [RPC](./rpc.mdx): Go names for RPC handlers and their results.
- [Channel](./channel.mdx): Go names for Channels and ChannelMaps.
- [Stream](./stream.mdx): Go names for writing and reading Streams.
- [Timer](./timer.mdx): Go names for Timer conditions.
- [SubFlow](./subflow.mdx): Go names for SubFlow conditions and results.
