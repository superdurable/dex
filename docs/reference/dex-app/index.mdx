# Dex app reference

The Dex app reference describes the repository format that Dex Cloud imports as
a [Managed Dex App](/components/managed-dex-app). Each reference version matches
one manifest schema version. The current version is schema v1.

A new reference version appears only when the manifest format changes
incompatibly, such as a schema v2. Changes that keep v1 manifests valid update
this version in place.

## Pages

- [Manifest and repository layout](/reference/dex-app/manifest): the files,
  the fields of `dex-app.yaml` and `.dex/template.json`, the YAML rules,
  the limits, the rules S1 to S8, and every import finding.
- [Troubleshooting and FAQ](/reference/dex-app/troubleshooting): common
  problems when you import, build, test, and publish, with their fixes.
