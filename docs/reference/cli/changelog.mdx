# Change log

This page lists user-visible changes to dexcli, newest first; each section covers the changes since the previous release of this component.

## 1.47 {#v1-47}

Released 2026-11-12 as [cli-v1.47.0](https://github.com/superdurable/dex/releases/tag/cli-v1.47.0); 1.47.1 released 2026-11-12 as [cli-v1.47.1](https://github.com/superdurable/dex/releases/tag/cli-v1.47.1); 1.47.2 released 2026-11-13 as [cli-v1.47.2](https://github.com/superdurable/dex/releases/tag/cli-v1.47.2); 1.47.3 released 2026-11-13 as [cli-v1.47.3](https://github.com/superdurable/dex/releases/tag/cli-v1.47.3); 1.47.4 released 2026-11-14 as [cli-v1.47.4](https://github.com/superdurable/dex/releases/tag/cli-v1.47.4); 1.47.5 released 2026-11-14 as [cli-v1.47.5](https://github.com/superdurable/dex/releases/tag/cli-v1.47.5).

### Added

- **dexcli agents-tui**: **/model** without an ID opens a list of the
  command's suggested models with the current one marked; **/model ID** still
  takes any model ID. The new **/effort** opens the reasoning effort values the
  command offers, and **/effort LEVEL** checks the value against them;
  **default** returns to the model's default. Both change the session's
  settings from the next turn. The status line shows the reasoning effort when
  the session sets one. The lists come from dex-agents 0.6.2; with an older
  command, **/model** lists only its configured model and **/effort** says the
  command has no reasoning effort setting.
- **dexcli agents-tui** shows a user message that carries a sender name, such as one sent from Dex Web with **Your name**, as **› Alice: text**, live, on resume, and in **/history**. Messages from another client without a name keep the **(another client)** label. Since 1.47.1.
- **dexcli agents-tui** hands a session switch back to the agents command when
  the launch document sets **launcher_session_switch**. Then **/sessions** and
  **/new** end the terminal UI, and the command opens the chosen session after
  it waits until no other terminal has that session open. Without the
  capability, the terminal UI switches in place as before. **--describe**
  lists the capability. Since 1.47.2.
- **dexcli visualize** accepts **--typescript-compiler**, or the
  **DEX_TYPESCRIPT_COMPILER** environment variable, naming a trusted
  **typescript** package directory. The analyzer then loads only that
  compiler and starts Node.js without **NODE_** environment variables, so no
  code from the analyzed source tree runs. Without it, the analyzer loads the
  **typescript** package that the source project resolves, which a source tree
  can supply through its own or a parent **node_modules** or a package named
  **typescript**, even when **NODE_PATH** is set. Set it whenever you
  visualize untrusted TypeScript source, and keep the analyzed tree's
  directories out of **PATH**. An empty flag value or an empty variable is a
  usage error, never a fallback to the source project's compiler.
  [Reference](/reference/web/flow-visualization#typescript-compiler). Since 1.47.2.
- **dexcli visualize** reads TypeScript **waitFor** methods, RPC handlers,
  and **handleTimeout** in the same graph shape as Go. A Wait built directly
  from **Wait** factories shows its Timer, Channel, ChannelMap, Join, and
  SubFlow conditions, and a **waitFor** that only throws shows a failure
  Wait. An RPC's **RPCResult** shows its **nextSteps** and **cancelingSteps**.
  The graph also records resource reads, writes, and publishes in each
  handler and in the same-file helpers it calls, and warns about unused
  resources. A Wait, RPC result, or resource access that the analyzer cannot
  prove, a Stream write in an RPC or timeout handler, and several Flows in
  one file are blocking diagnostics. Such a source no longer reports
  **typescript_wait_for_unsupported**.
  [Reference](/reference/web/flow-visualization#supported-source-profile). Since 1.47.3.

### Changed

- **dexcli visualize** reports a missing TypeScript compiler with a message
  that names both places it looks: the source project and the
  **node_modules** directories listed in **NODE_PATH**. A source project
  without **node_modules** can use a separately installed, pinned
  **typescript** package through **--typescript-compiler**; see
  [Trusted TypeScript compiler](/reference/web/flow-visualization#typescript-compiler). Since 1.47.2.
- The Dex Web of **dexcli dev** and **dexcli web** is Dex Web 1.45.4. A left rail holds its sections, every page has one bar, and the run tabs are Events, State and Streams. [Change log](/reference/web/changelog#v1-45). Since 1.47.4.
- The release archives bundle **dex-server-zd** 0.1.30 instead of 0.1.26, so **dexcli dev** serves named task queues (Server protocol version 5). A Flow can name a task queue when it starts, and only Workers of that task queue run it. [Reference](/reference/server/workers). Since 1.47.5.

## 1.46 {#v1-46}

Released 2026-11-12 as [cli-v1.46.0](https://github.com/superdurable/dex/releases/tag/cli-v1.46.0); 1.46.1 released 2026-11-12 as [cli-v1.46.1](https://github.com/superdurable/dex/releases/tag/cli-v1.46.1).

### Added

- **dexcli agents-tui** shows the message with which an approved plan starts
  running as the notice "Running plan revision N", not as a user message from
  another client. It hides the notes the session writes for the model after a
  failed, steered, or cancelled turn. It reads **AgentMessage.origin**, which
  dex-agents 0.6.0 sets on these messages.
- The **dexcli agents-tui** chat opens a tool's whole stored output in a
  pager with **Ctrl-O**, or picks one of the latest turn's tools with
  **/tools**. **/history** pages through the messages stored before the ones
  a resumed chat shows. The pager scrolls with **j**/**k** and the page keys,
  searches with **/**, and closes with **q**.
- Replies render tables, strikethrough, and task lists. Tool rows count the
  images a tool returned.
- The approval popup shows what a call acts on, what it does, and the diff
  of a file write, when the tool's source describes them; otherwise it shows
  the concrete arguments.
- Pasting the path of an image file, as a terminal does for a dropped file,
  asks whether to attach it. **Tab** completes the path after **/image** and
  keeps its quotes or backslash escapes; **/image** reads them the same way.
- The welcome area shows the Dex logo when the terminal is large enough.
- **/run** shows as unavailable in the command list, with the reason, until
  the session waits for approval of a draft plan.
- **dexcli agents-tui** also runs the **sessions** and **connectors** modes of
  terminal UI contract 1. The **sessions** mode is a full-screen, paged list of
  a command's sessions. It shows the title, last activity, and turn count when
  the sessions have them, and only the ID, status, and start time otherwise.
  **/** filters the loaded sessions and searches titles in Dex. Enter on a
  running session hands it back to the command to resume. The
  **connectors** mode lists the connections of the connector tools, refreshes
  them with **r**, and opens the Dex Web Connectors page with **a**.
- In the agents chat, **/sessions** opens the same session list and switches
  the chat to the picked session with its history. Before **/sessions** or
  **/new** switches, the chat asks whether to drop attached images, and it
  waits for the current session's requests to finish. Messages and commands
  meant for the previous session are not sent to the new one; the chat says
  so.
- **dexcli agents-tui** runs the full-screen chat of the agents CLI commands
  under terminal UI contract 1. It is a hidden command that a command's
  launcher starts with **--channel-fd**; **--describe** prints the contracts
  and modes it supports. The **chat** mode talks to the
  agent session directly, with the snapshot as the record and live events
  for streaming, and asks the launcher for local work such as **/image** and
  **/new**.

### Changed

- **dexcli agents-tui**: the exit summary now says the session keeps running
  and how to resume it, in the same words as the plain chat of the agents
  commands, instead of "stays in Dex".
- In the **dexcli agents-tui** chat, an idle **Ctrl-C** asks for a second
  press within two seconds before it exits. A first press still clears a
  draft. **Esc** on an empty input cancels the running turn, as **Ctrl-C**
  does; the status line names it.
- An approval or question that waited before the chat loaded the session
  stays in the pending bar until **Tab** opens it. One that arrives while the
  user types opens once the input stays empty for a second.
- In the pending bar, **Up** and **Down** pick the queued message that **s**
  and **x** act on. Any other letter returns to the input and is typed there.
- Typing in a question's choice list starts a free-text answer, when the
  question allows one.
- **write_todos** rows list the plan's steps as a checklist, and **Ctrl-P**
  shows the whole plan. **ask_user** rows show no raw result, and a waiting
  question is called a question.
- **/model** without an ID shows the current model and leaves **/model** in
  the input to type one; an ID with spaces is refused.
- The status line says "writing reply" while text streams. A stopped Worker
  dims the input. The welcome area keeps the session the chat started with,
  and the exit line names it after a switch.
- Paths under the home directory show as **~**. **/web** with the browser
  switched off shows the link as information.
- In the **dexcli agents-tui** chat, **Up** and **Down** on an empty input
  scroll the messages one line, so the mouse wheel scrolls in terminals that
  send it as arrow keys. **Ctrl-P** and **Ctrl-N** recall earlier messages.
  **Up** and **Down** keep recalling while the input holds an unedited
  recalled message, and move between the lines of a typed message. The plan's
  steps open with **Ctrl-T** instead of **Ctrl-P**. Since 1.46.1.
- The **dexcli agents-tui** chat shows Dex Web addresses, in the welcome area
  and in notices, as underlined links that terminals with hyperlink support
  open on a click. The welcome logo uses the Dex brand green, picking the
  light or dark shade from the terminal background, and draws its bar in the
  terminal's text color. Since 1.46.1.

### Fixed

- The **dexcli agents-tui** chat shows the first reply after **/new** or
  **/sessions**, and counts the new session's turns and usage from zero.
- A reply that follows a tool call prints below its tool row, whole, even
  when the session reports the finished row after the reply's text.
- A finished reply keeps single line breaks, as it showed while streaming,
  so it no longer jumps when the turn ends.
- A resumed chat no longer labels the user's own queued messages as from
  another client, and marks the cancelled turns of its history.
- A cancelled turn says that the reply is incomplete only when part of it
  was shown.
- When the Dex server becomes unreachable, the chat says so once, instead
  of reporting that the session has not loaded.
- A suspend (SIGTSTP) stops the chat once, and **fg** brings it back. Before,
  the stop could come back as a second suspend, and keys typed then were
  lost. Without a job-control shell, as in a command started in its own
  session, the chat keeps running instead of stopping.
- The **dexcli agents-tui** chat no longer captures the mouse, so a plain drag
  selects text and the terminal's copy works. Since 1.46.1.

## 1.45 {#v1-45}

Released 2026-11-11 as [cli-v1.45.0](https://github.com/superdurable/dex/releases/tag/cli-v1.45.0).

### Added

- **dexcli flow-definition upload** stores Flow Definition Graph 2.0 JSON files or directories on the server and prints the outcome for each Flow type. **--force** replaces a stored definition even when its generation time is later. **dexcli flow-definition list** lists the Flow types that have a stored definition. [Reference](/reference/cli/#flow-definition).
- **dexcli visualize** writes a top-level **generatedAt** field, an RFC 3339 UTC timestamp, into each Version 2.0 Flow Definition Graph. Set **SOURCE_DATE_EPOCH** to make it reproducible; an invalid value is a usage error. Version 1.0 output is unchanged. Dex Web older than 1.45 rejects a graph that has **generatedAt**, so upgrade Dex Web with dexcli. [Reference](/reference/web/flow-visualization#generated-at).

### Changed

- **dexcli dev** bundles server-zd 0.1.26, which stores uploaded Flow Definition Graphs. [Reference](/reference/server/changelog#v0-1-26).

### Fixed

- **dexcli visualize** writes an empty array, never **null**, for every list in the Flow Definition Graph. A WaitFor that only fails used to get **"conditions": null**. [Reference](/reference/web/flow-visualization#json-contract).

## 1.44 {#v1-44}

Released 2026-11-10 as [cli-v1.44.0](https://github.com/superdurable/dex/releases/tag/cli-v1.44.0).

### Added

- **dexcli visualize** recognizes the SDK Join helper in Go, Python, and TypeScript sources. A Join appears as a ChannelMap; the branch Steps and the join Step that **Fork** starts become transitions, marked ×N when the branches are built in a loop. The Go and Python graphs also show the Join's wait, publish, and read edges. [Reference](/reference/web/flow-visualization).

## 1.43 {#v1-43}

Released 2026-11-10 as [cli-v1.43.0](https://github.com/superdurable/dex/releases/tag/cli-v1.43.0).

### Breaking

- Removed **dexcli flow trigger-continue-as-new** and the **--follow-runs** flag from **dexcli flow watch**. **dexcli flow watch** stops when the watched run closes. [Reference](/reference/cli/#friendly-flow-operations).
- **dexcli flow start --config** and **dexcli flow update-config --config** ignore **continueAsNewThreshold** and **continueAsNewPageSizeInBytes** and no longer send them. Remove those JSON properties. [Reference](/reference/cli/#friendly-flow-operations).
- **dexcli api** response JSON uses **flowRunId** instead of **flowExecutionId**. **dexcli api call** rejects a request that still names a removed field, such as **includeContinuedAsNew** or **continueAsNewThreshold** in a **FlowConfig**. [Reference](/reference/cli/#complete-public-api-access).
- History output from **dexcli flow history**, **dexcli flow inspect**, **dexcli flow watch**, and **dexcli api** no longer contains **continuedStart** or **continuedToRunId**. Flow status is never **FLOW_STATUS_CONTINUED_AS_NEW**. [Reference](/reference/cli/#complete-public-api-access).

### Added

- The Dex Web of **dexcli dev** and **dexcli web** can start a Dex Agents session, send it messages, and edit its settings from the **Agent session** tab. [Reference](/reference/web/dex-web#agent-new-session).
- **dexcli dev** finds or starts the Dex Connectors MCP server and serves its agent tools at **/mcp** on the Dex Web port. It downloads and verifies a compatible release, and restarts the server when it stops. New flags: **--connectors-mcp**, **--connectors-mcp-version**, **--connectors-mcp-binary**, and **--connectors-mcp-connection**. [Reference](/reference/cli/#connectors-mcp).

### Changed

- The Dex Web of **dexcli web** answers its **/api/v2/connector-** routes with HTTP 404 **CONNECTOR_SETUP_UNAVAILABLE**, because it has no local Connector setup. **dexcli web** and **dexcli dev** still serve Dex Web at the root of their port. [Reference](/reference/web/embed-dex-web#limits).

## 1.42 {#v1-42}

Released 2026-11-10 as [cli-v1.42.0](https://github.com/superdurable/dex/releases/tag/cli-v1.42.0).

### Added

- **dexcli dev** serves a Dex Web **Connectors** page that can add a named connection that no loaded Flow uses, such as the Slack connection an agent tool opens, without **--flow-rendering-dir**. [Reference](/reference/web/local-connector-setup#add-a-connection).
- **dexcli dev** and **dexcli web** accept **--allowed-hosts**, a comma-separated list of host names that Dex Web **/api** requests may use. [Reference](/reference/web/dex-web#allowed-hosts).

### Changed

- The Dex Web of **dexcli dev** refuses an **/api** request whose **Host** is a DNS name other than a loopback name or an **--allowed-hosts** entry, with HTTP 403 **HOST_NOT_ALLOWED**. This stops DNS rebinding. Pass **--allowed-hosts** when a tunnel or a hosted development environment forwards Dex Web under its own name. [Reference](/reference/web/dex-web#allowed-hosts).

## 1.40 {#v1-40}

Released 2026-11-09 as [cli-v1.40.0](https://github.com/superdurable/dex/releases/tag/cli-v1.40.0). Patch releases [cli-v1.40.1](https://github.com/superdurable/dex/releases/tag/cli-v1.40.1) and [cli-v1.40.2](https://github.com/superdurable/dex/releases/tag/cli-v1.40.2) followed the same day.

### Breaking

- **dexcli dev** bundles server-zd 0.1.23. Its breaking changes apply to every **dexcli dev** data directory. Each run now chooses at start whether it offloads history, and the **history.offloadEnabled**, **history.deleteExpiredObjects**, and **history.maxRetainedSupersededBytes** keys are removed. A **history.offloadEnabled** value of false in a **--zd-config** file now fails startup. [Reference](/reference/server/changelog#v0-1-23).
- The default **history.windowEvents** for **dexcli dev** is 5,000 events, where it was 10,000. Runs keep the window they recorded at start.
- Do not run an earlier dexcli on a data directory after 1.40 has used it.

### Added

- **dexcli flow start --config** accepts **offloadHistory**. [Reference](/reference/server/configuration#history-offload).
- The Connector manifest schema accepts **agent.branches**, so **dexcli visualize** reads it without a diagnostic. [Reference](/reference/web/flow-visualization#connector-package-manifests).
- **dexcli web** and **dexcli dev** serve the Dex Web v1 Flows and Run pages redesign, including a horizontal Timeline and editing of a run's history window. [Reference](/reference/web/dex-web#v1-pages).

### Changed

- **FlowConfig.delete_expired_history_objects** is deprecated. **dexcli** no longer sends it.
- **dexcli dev** bundles server-zd 0.1.25 since 1.40.2. [Reference](/reference/server/changelog#v0-1-25).

## 1.39 {#v1-39}

Released 2026-11-09 as [cli-v1.39.0](https://github.com/superdurable/dex/releases/tag/cli-v1.39.0). Patch release [cli-v1.39.1](https://github.com/superdurable/dex/releases/tag/cli-v1.39.1) followed the same day.

### Added

- **dexcli visualize** reads Actions declared by Python and TypeScript applications, and emits their RPC lock edges. This arrived in 1.39.1. [Reference](/reference/web/flow-visualization#actions-in-python-and-typescript).
- **dexcli visualize** provides a Flow Definition Graph for Dex Agents session Flows.
- Dex Web sends the declared RPC locks when a person runs an Action. [Reference](/reference/web/dex-web#actions).
- Dex Web adds a Session tab for Dex Agents sessions and an agent inbox in the Work Queue. [Reference](/reference/web/dex-web#agent-session-view).

### Changed

- **dexcli** sends LoadBlobs requests in batches of at most 1,000 entries.
- **dexcli dev** bundles server-zd 0.1.22 since 1.39.1. This turns history offload on by default for **dexcli dev**. [Reference](/reference/server/changelog#v0-1-22).
- **dexcli flow start --config** accepts **deleteExpiredHistoryObjects**.

## 1.37 {#v1-37}

Released 2026-11-06 as [cli-v1.37.0](https://github.com/superdurable/dex/releases/tag/cli-v1.37.0). Reference: [1.37.x](/reference/cli/1.37.x/).

### Breaking

## 1.36 {#v1-36}

Released 2026-11-06 as [cli-v1.36.0](https://github.com/superdurable/dex/releases/tag/cli-v1.36.0). Reference: [1.36.x](/reference/cli/).

- **dexcli dev** bundles server-zd 0.1.19, which caps node Stream data at 1 GiB and each requested Stream capacity at 64 MiB by default. ## 1.35 {#v1-35}

Released 2026-11-06 as [cli-v1.35.0](https://github.com/superdurable/dex/releases/tag/cli-v1.35.0). Reference: [1.35.x](/reference/cli/).

### Breaking

- **dexcli dev** bundles server-zd 0.1.18 and defaults to strict durability, with slower writes that survive host crashes. Pass **--durability process-crash-safe** for the previous behavior. [Reference](/reference/cli/#start-locally).
- **dexcli dev** refuses data directories left unclean by server-zd releases before 0.1.4. Delete such a directory to start empty. [Reference](/reference/cli/#start-locally).

### Added

- **--durability** accepts **strict**, **process-crash-safe**, or **relaxed**. An explicit flag overrides **dev.durabilityMode** in **--zd-config**. [Reference](/reference/cli/#start-locally).

### Changed

- The bundled server supports protocol version 4, including durable Step queues and planned-stop draining. This CLI release can run SDK 1.35 applications locally. [Reference](/reference/cli/#start-locally).
- **dexcli visualize** uses **RPCOptions.Name** for Actions and Summary and Display RPCs when the name is a compile-time string. [Reference](/reference/cli/#start-locally).
