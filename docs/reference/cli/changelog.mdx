### 1.47.23 (2026-11-25) {#v1-47-23}

**Breaking**

- **dexcli visualize** generates only Flow Definition Graph 2.0. Remove **--schema-version 1.0** from scripts to avoid a usage error. Add one **dex:group** and one **dex:explanation** per Step. In Go, define **GetDexSummary** and **GetDexDisplay** and register both in **GetRPCs**. Missing metadata produces blocking diagnostics. With **--json**, the command still writes partial JSON and exits with status 1.

**Added**

- Use **dexcli visualize --flow** to select a Flow by its registered type when a source file defines multiple Flows.
- Generate **Indexed Attributes**, **Summary** and **Display** fields, and **Start** input schemas when visualizing Python and TypeScript Flows.
- Add Java support to **dexcli visualize**, including Flow Definition Graph 2.0 metadata. Requires JDK 17 or newer.
- Add Rust source support to **dexcli visualize**, including Flow selection, indexed Attributes, Summary and Display RPCs, and Start input schemas.

**Changed**

- **dexcli dev** and **dexcli web** bundle **Dex Web** 1.45.19. See the [Dex Web change log](https://docs.superdurable.io/reference/web/changelog/#v1-45).
- Python and TypeScript indexed Attributes require **dex:indexed-attribute** and report **v2_indexed_attribute** when it is missing.
- Python and TypeScript view RPCs report **rpc_lock_unresolved** for unreadable locks, **v2_view_rpc_output** for unreadable output keys, **v2_rpc_signature** for input parameters, and **v2_view_rpc_side_effect** for writes.
- Python and TypeScript sources report the **start_input_unresolved** warning when the Start input type cannot be resolved in the file.

### 1.47.18 (2026-11-20) {#v1-47-18}

**Added**

- **dexcli codec-server -key-file key.json** adds **POST /encode** and **POST /decode** for local dev only. It binds 127.0.0.1, requires localhost **Host** and a random bearer token per start, and limits CORS to set Dex Web origins. [Codec](/reference/server/payload-encryption#dexcli-codec-server).
- **dexcli codec-server keygen -o key.json** writes a payload key file with one random 32-byte key and mode 0600. It refuses to replace an existing file unless you pass **-force**.
- **dexcli dev -codec-key-file key.json** starts that codec server next to Dex Web and hands its endpoint and token to Dex Web and to **dexcli flow** commands against the same local server. dexcli never generates a key.
- [**dexcli flow**](/reference/server/payload-encryption#dexcli-flow) decrypts **dex-encoded:** errors, encrypts **flow start** input, **flow stop --result** output and reasons via **--codec-key-file**/**--codec-endpoint** (**--codec-token-file**/**DEX_CODEC_TOKEN**). New Attributes are plaintext.
- Without a codec, a Stop, Time Travel, or clone-fork reason that starts with **dex-encoded:** is sent with one leading space, so readers never try to decrypt it.

### 1.47.8 (2026-11-15) {#v1-47-8}

**Added**

- **dexcli flow clone-fork SOURCE_FLOW_ID --flow-id NEW_FLOW_ID** calls **CloneForkFlow** to start a new Flow from a point in another run. **--type** selects the point and defaults to **current**. [Reference](/reference/cli/#time-travel-and-clone-fork).
- **dexcli flow time-travel** accepts **--type event-id** with the history event ID as **--target**, **--run-attempt** to search an earlier run attempt, and **--sub-flow-reset-policy** to decide what happens to restored SubFlow waits. Its output adds **runAttempt**.
- **dexcli api** lists the **CloneForkFlow** call of the FlowService and, as for other writes, calls it only with **--yes**.
- Flow analysis accepts the **agent.repeatOnUnknown** and **agent.maxSends** fields of a Connector package's **dex-connector.json**, and the published manifest schema declares them.

**Changed**

- **dexcli agents-tui** attaches pasted paths or dropped images immediately, removes **Attach NAME?**, and accepts multiple paths. A failed path stays as text, and pasting into a focused panel moves the paste to the input. [Reference](/reference/agents/cli#images).

- The release archives bundle **dex-server-zd** 0.1.33 instead of 0.1.30, so **dexcli dev** serves **CloneForkFlow**, Time Travel to an event ID, and the SubFlow reset policy (Server protocol version 6). [Reference](/reference/server/runtime-client#clone-fork).

**Fixed**

- **dexcli agents-tui** waits for pasted images to attach before sending on Enter. If one fails, the draft stays unsent with a notice, and pressing Enter again sends it without that image. [Reference](/reference/agents/cli#images).
- **dexcli agents-tui**: live output turns off only when the Dex server's Stream Store is disabled. Before, any failed precondition on reading the session's events turned it off for the rest of the chat; now such a failure is retried.

### 1.46.0 (2026-11-12) {#v1-46-0}

**Added**

- **dexcli agents-tui** shows approved plan starts as "Running plan revision N" notices and hides model-only notes after failed, steered, or canceled turns. It uses **AgentMessage.origin** from dex-agents 0.6.0.
- **dexcli agents-tui** pages full tool output with **Ctrl-O** or **/tools** and earlier stored messages with **/history**. Scroll with **j**/**k** or page keys, search with **/**, and close with **q**. [Reference](/reference/agents/cli#terminal-ui).
- Replies render tables, strikethrough, and task lists. Tool rows count the
  images a tool returned.
- The approval popup shows what a call acts on, what it does, and the diff
  of a file write, when the tool's source describes them; otherwise it shows
  the concrete arguments.
- Pasting the path of an image file, as a terminal does for a dropped file,
  asks whether to attach it. **Tab** completes the path after **/image** and
  keeps its quotes or backslash escapes; **/image** reads them the same way.
- The welcome area shows the Dex logo when the terminal is large enough.
- **/run** shows as unavailable in the command list, with the reason, until
  the session waits for approval of a draft plan.
- **dexcli agents-tui** adds **sessions** and **connectors** in contract 1. Paged sessions show title, last activity and turns, or ID, status and start time. **/** filters and searches Dex titles, Enter resumes running sessions, and in **connectors** **r** refreshes and **a** opens the Web page.
- **/sessions** opens a list and switches the chat to the chosen session with its history. **/sessions** and **/new** ask before dropping images and wait for pending requests. The chat warns when it discards messages or commands meant for the previous session.
- The hidden **dexcli agents-tui** command adds terminal UI contract 1 with **--channel-fd** and **--describe** for capability discovery. **chat** reads the session snapshot and live events directly and delegates local commands like **/image** and **/new** to the launcher.

**Changed**

- **dexcli agents-tui**: the exit summary now says the session keeps running
  and how to resume it, in the same words as the plain chat of the agents
  commands, instead of "stays in Dex".
- In the **dexcli agents-tui** chat, an idle **Ctrl-C** asks for a second
  press within two seconds before it exits. A first press still clears a
  draft. **Esc** on an empty input cancels the running turn, as **Ctrl-C**
  does; the status line names it.
- An approval or question that waited before the chat loaded the session
  stays in the pending bar until **Tab** opens it. One that arrives while the
  user types opens once the input stays empty for a second.
- In the pending bar, **Up** and **Down** pick the queued message that **s**
  and **x** act on. Any other letter returns to the input and is typed there.
- Typing in a question's choice list starts a free-text answer, when the
  question allows one.
- **write_todos** rows list the plan's steps as a checklist, and **Ctrl-P**
  shows the whole plan. **ask_user** rows show no raw result, and a waiting
  question is called a question.
- **/model** without an ID shows the current model and leaves **/model** in
  the input to type one; an ID with spaces is refused.
- The status line says "writing reply" while text streams. A stopped Worker
  dims the input. The welcome area keeps the session the chat started with,
  and the exit line names it after a switch.
- Paths under the home directory show as **~**. **/web** with the browser
  switched off shows the link as information.

**Fixed**

- The **dexcli agents-tui** chat shows the first reply after **/new** or
  **/sessions**, and counts the new session's turns and usage from zero.
- A reply that follows a tool call prints below its tool row, whole, even
  when the session reports the finished row after the reply's text.
- A finished reply keeps single line breaks, as it showed while streaming,
  so it no longer jumps when the turn ends.
- A resumed chat no longer labels the user's own queued messages as from
  another client, and marks the cancelled turns of its history.
- A cancelled turn says that the reply is incomplete only when part of it
  was shown.
- When the Dex server becomes unreachable, the chat says so once, instead
  of reporting that the session has not loaded.
- A suspend (SIGTSTP) stops the chat once, and **fg** brings it back. Before,
  the stop could come back as a second suspend, and keys typed then were
  lost. Without a job-control shell, as in a command started in its own
  session, the chat keeps running instead of stopping.

### 1.43.0 (2026-11-10) {#v1-43-0}

**Breaking**

- Removed **dexcli flow trigger-continue-as-new** and the **--follow-runs** flag from **dexcli flow watch**. **dexcli flow watch** stops when the watched run closes. [Reference](/reference/cli/#friendly-flow-operations).
- **dexcli flow start --config** and **dexcli flow update-config --config** ignore **continueAsNewThreshold** and **continueAsNewPageSizeInBytes** and no longer send them. Remove those JSON properties. [Reference](/reference/cli/#friendly-flow-operations).
- **dexcli api** response JSON uses **flowRunId** instead of **flowExecutionId**. **dexcli api call** rejects a request that still names a removed field, such as **includeContinuedAsNew** or **continueAsNewThreshold** in a **FlowConfig**. [Reference](/reference/cli/#complete-public-api-access).
- History output from **dexcli flow history**, **dexcli flow inspect**, **dexcli flow watch**, and **dexcli api** no longer contains **continuedStart** or **continuedToRunId**. Flow status is never **FLOW_STATUS_CONTINUED_AS_NEW**. [Reference](/reference/cli/#complete-public-api-access).

**Added**

- The Dex Web of **dexcli dev** and **dexcli web** can start a Dex Agents session, send it messages, and edit its settings from the **Agent session** tab. [Reference](/reference/web/dex-web#agent-new-session).
