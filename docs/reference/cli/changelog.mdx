# Change log

This page lists user-visible changes to dexcli, newest first; each section covers the changes since the previous release of this component.

## 1.45 {#v1-45}

Not released yet. The next minor release, cli-v1.45.0, ships these changes.

### Added

- **dexcli flow-definition upload** stores Flow Definition Graph 2.0 JSON files or directories on the server and prints the outcome for each Flow type. **--force** replaces a stored definition even when its generation time is later. **dexcli flow-definition list** lists the Flow types that have a stored definition. [Reference](/reference/cli/#flow-definition).

### Changed

- **dexcli dev** bundles server-zd 0.1.26, which stores uploaded Flow Definition Graphs. [Reference](/reference/server/changelog#v0-1-26).

### Fixed

- **dexcli visualize** writes an empty array, never **null**, for every list in the Flow Definition Graph. A WaitFor that only fails used to get **"conditions": null**. [Reference](/reference/web/flow-visualization#json-contract).

## 1.44 {#v1-44}

Released 2026-11-10 as [cli-v1.44.0](https://github.com/superdurable/dex/releases/tag/cli-v1.44.0).

### Added

- **dexcli visualize** recognizes the SDK Join helper in Go, Python, and TypeScript sources. A Join appears as a ChannelMap; the branch Steps and the join Step that **Fork** starts become transitions, marked ×N when the branches are built in a loop. The Go and Python graphs also show the Join's wait, publish, and read edges. [Reference](/reference/web/flow-visualization).

## 1.43 {#v1-43}

Released 2026-11-10 as [cli-v1.43.0](https://github.com/superdurable/dex/releases/tag/cli-v1.43.0).

### Breaking

- Removed **dexcli flow trigger-continue-as-new** and the **--follow-runs** flag from **dexcli flow watch**. **dexcli flow watch** stops when the watched run closes. [Reference](/reference/cli/#friendly-flow-operations).
- **dexcli flow start --config** and **dexcli flow update-config --config** ignore **continueAsNewThreshold** and **continueAsNewPageSizeInBytes** and no longer send them. Remove those JSON properties. [Reference](/reference/cli/#friendly-flow-operations).
- **dexcli api** response JSON uses **flowRunId** instead of **flowExecutionId**. **dexcli api call** rejects a request that still names a removed field, such as **includeContinuedAsNew** or **continueAsNewThreshold** in a **FlowConfig**. [Reference](/reference/cli/#complete-public-api-access).
- History output from **dexcli flow history**, **dexcli flow inspect**, **dexcli flow watch**, and **dexcli api** no longer contains **continuedStart** or **continuedToRunId**. Flow status is never **FLOW_STATUS_CONTINUED_AS_NEW**. [Reference](/reference/cli/#complete-public-api-access).

### Added

- The Dex Web of **dexcli dev** and **dexcli web** can start a Dex Agents session, send it messages, and edit its settings from the **Agent session** tab. [Reference](/reference/web/dex-web#agent-new-session).
- **dexcli dev** finds or starts the Dex Connectors MCP server and serves its agent tools at **/mcp** on the Dex Web port. It downloads and verifies a compatible release, and restarts the server when it stops. New flags: **--connectors-mcp**, **--connectors-mcp-version**, **--connectors-mcp-binary**, and **--connectors-mcp-connection**. [Reference](/reference/cli/#connectors-mcp).

### Changed

- The Dex Web of **dexcli web** answers its **/api/v2/connector-** routes with HTTP 404 **CONNECTOR_SETUP_UNAVAILABLE**, because it has no local Connector setup. **dexcli web** and **dexcli dev** still serve Dex Web at the root of their port. [Reference](/reference/web/embed-dex-web#limits).

## 1.42 {#v1-42}

Released 2026-11-10 as [cli-v1.42.0](https://github.com/superdurable/dex/releases/tag/cli-v1.42.0).

### Added

- **dexcli dev** serves a Dex Web **Connectors** page that can add a named connection that no loaded Flow uses, such as the Slack connection an agent tool opens, without **--flow-rendering-dir**. [Reference](/reference/web/local-connector-setup#add-a-connection).
- **dexcli dev** and **dexcli web** accept **--allowed-hosts**, a comma-separated list of host names that Dex Web **/api** requests may use. [Reference](/reference/web/dex-web#allowed-hosts).

### Changed

- The Dex Web of **dexcli dev** refuses an **/api** request whose **Host** is a DNS name other than a loopback name or an **--allowed-hosts** entry, with HTTP 403 **HOST_NOT_ALLOWED**. This stops DNS rebinding. Pass **--allowed-hosts** when a tunnel or a hosted development environment forwards Dex Web under its own name. [Reference](/reference/web/dex-web#allowed-hosts).

## 1.41 {#v1-41}

Released 2026-11-09 as [cli-v1.41.0](https://github.com/superdurable/dex/releases/tag/cli-v1.41.0). Patch release [cli-v1.41.1](https://github.com/superdurable/dex/releases/tag/cli-v1.41.1) followed on 2026-11-10.

### Breaking

- **dexcli web** and **dexcli dev** serve a Dex Web with one UI. The **v2** pages are removed, and every **/v2** URL redirects to its **/v1** equivalent. [Reference](/reference/web/dex-web#v1-pages).

### Added

- **dexcli web** and **dexcli dev** serve the Dex Web **Design** tab and the **Experimental** menu with **Designs**, **Work Queue**, and **Connectors**. [Reference](/reference/web/dex-web#run-tabs).

### Changed

- Since 1.41.1: **dexcli web** and **dexcli dev** open a run on the **Timeline** tab by default. [Reference](/reference/web/dex-web#run-tabs).
- Since 1.41.1: **dexcli web** and **dexcli dev** serve a Timeline overview where clicking a bar selects its event. [Reference](/reference/web/dex-web#v1-pages).
- Since 1.41.1: **dexcli web** and **dexcli dev** serve an **Agent session** tab that shows queued and skipped connector writes. [Reference](/reference/web/dex-web#agent-session-view).
- **dexcli visualize** opens the **Designs** page, which was called **Flow Rendering**. [Reference](/reference/web/flow-visualization).
- **dexcli web** and **dexcli dev** serve the Timeline overview histogram. [Reference](/reference/web/dex-web#v1-pages).

## 1.40 {#v1-40}

Released 2026-11-09 as [cli-v1.40.0](https://github.com/superdurable/dex/releases/tag/cli-v1.40.0). Patch releases [cli-v1.40.1](https://github.com/superdurable/dex/releases/tag/cli-v1.40.1) and [cli-v1.40.2](https://github.com/superdurable/dex/releases/tag/cli-v1.40.2) followed the same day.

### Breaking

- **dexcli dev** bundles server-zd 0.1.23. Its breaking changes apply to every **dexcli dev** data directory. Each run now chooses at start whether it offloads history, and the **history.offloadEnabled**, **history.deleteExpiredObjects**, and **history.maxRetainedSupersededBytes** keys are removed. A **history.offloadEnabled** value of false in a **--zd-config** file now fails startup. [Reference](/reference/server/changelog#v0-1-23).
- The default **history.windowEvents** for **dexcli dev** is 5,000 events, where it was 10,000. Runs keep the window they recorded at start.
- Do not run an earlier dexcli on a data directory after 1.40 has used it.

### Added

- **dexcli flow start --config** accepts **offloadHistory**. [Reference](/reference/server/configuration#history-offload).
- The Connector manifest schema accepts **agent.branches**, so **dexcli visualize** reads it without a diagnostic. [Reference](/reference/web/flow-visualization#connector-package-manifests).
- **dexcli web** and **dexcli dev** serve the Dex Web v1 Flows and Run pages redesign, including a horizontal Timeline and editing of a run's history window. [Reference](/reference/web/dex-web#v1-pages).

### Changed

- **FlowConfig.delete_expired_history_objects** is deprecated. **dexcli** no longer sends it.
- **dexcli dev** bundles server-zd 0.1.25 since 1.40.2. [Reference](/reference/server/changelog#v0-1-25).

## 1.39 {#v1-39}

Released 2026-11-09 as [cli-v1.39.0](https://github.com/superdurable/dex/releases/tag/cli-v1.39.0). Patch release [cli-v1.39.1](https://github.com/superdurable/dex/releases/tag/cli-v1.39.1) followed the same day.

### Added

- **dexcli visualize** reads Actions declared by Python and TypeScript applications, and emits their RPC lock edges. This arrived in 1.39.1. [Reference](/reference/web/flow-visualization#actions-in-python-and-typescript).
- **dexcli visualize** provides a Flow Definition Graph for Dex Agents session Flows.
- Dex Web sends the declared RPC locks when a person runs an Action. [Reference](/reference/web/dex-web#actions).
- Dex Web adds a Session tab for Dex Agents sessions and an agent inbox in the Work Queue. [Reference](/reference/web/dex-web#agent-session-view).

### Changed

- **dexcli** sends LoadBlobs requests in batches of at most 1,000 entries.
- **dexcli dev** bundles server-zd 0.1.22 since 1.39.1. This turns history offload on by default for **dexcli dev**. [Reference](/reference/server/changelog#v0-1-22).
- **dexcli flow start --config** accepts **deleteExpiredHistoryObjects**.

## 1.38 {#v1-38}

Released 2026-11-07 as [cli-v1.38.0](https://github.com/superdurable/dex/releases/tag/cli-v1.38.0).

### Added

- Dex Web v2 searches by active Step type and across Flow types, returns the output of an Action RPC, and accepts an Action without a condition. [Reference](/reference/web/dex-web#search-several-flow-types).
- **dexcli flow start --config** accepts **historyWindowEvents**, which sets how many history events a run keeps. [Reference](/reference/server/configuration#history-window).

### Changed

- **dexcli** splits a LoadBlobs request when the server rejects its response size.

## 1.37 {#v1-37}

Released 2026-11-06 as [cli-v1.37.0](https://github.com/superdurable/dex/releases/tag/cli-v1.37.0). Reference: [1.37.x](/reference/cli/1.37.x/).

### Breaking

- **dexcli dev** bundles server-zd 0.1.20 and creates 32-partition state directories. To retain an older 1024-partition directory, pass **--zd-config** with **cluster.partitionCount** set to 1024. [Reference](/reference/cli/#start-locally).

### Added

- **dexcli web** serves Dex Web against an existing **--server** using the CLI’s TLS and credential settings. It binds loopback by default and accepts **--flow-rendering-dir**. [Reference](/reference/cli/#web).

### Fixed

- Stopping embedded Dex Web no longer waits for an open Flow history long poll to finish. [Reference](/reference/cli/#web).

## 1.36 {#v1-36}

Released 2026-11-06 as [cli-v1.36.0](https://github.com/superdurable/dex/releases/tag/cli-v1.36.0). Reference: [1.36.x](/reference/cli/1.36.x/).

### Breaking

- **dexcli dev** bundles server-zd 0.1.19, which caps node Stream data at 1 GiB and each requested Stream capacity at 64 MiB by default. Set **streamStore.maxTotalBytes** and **streamStore.maxStreamCapacityBytes** through **--zd-config** for larger buffers. [Reference](/reference/cli/#start-locally).

## 1.35 {#v1-35}

Released 2026-11-06 as [cli-v1.35.0](https://github.com/superdurable/dex/releases/tag/cli-v1.35.0). Reference: [1.35.x](/reference/cli/).

### Breaking

- **dexcli dev** bundles server-zd 0.1.18 and defaults to strict durability, with slower writes that survive host crashes. Pass **--durability process-crash-safe** for the previous behavior. [Reference](/reference/cli/#start-locally).
- **dexcli dev** refuses data directories left unclean by server-zd releases before 0.1.4. Delete such a directory to start empty. [Reference](/reference/cli/#start-locally).

### Added

- **--durability** accepts **strict**, **process-crash-safe**, or **relaxed**. An explicit flag overrides **dev.durabilityMode** in **--zd-config**. [Reference](/reference/cli/#start-locally).

### Changed

- The bundled server supports protocol version 4, including durable Step queues and planned-stop draining. This CLI release can run SDK 1.35 applications locally. [Reference](/reference/cli/#start-locally).
- **dexcli visualize** uses **RPCOptions.Name** for Actions and Summary and Display RPCs when the name is a compile-time string. [Reference](/reference/cli/#start-locally).
