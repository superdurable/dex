### 1.45.19 (2026-11-25) {#v1-45-19}

**Added**

- Dex Web loads Flow Definition Graphs generated from Java and Rust sources.

**Fixed**

- The Step panel of a Design view now lists, under **Reached from**, every Step that moves to the start Step, after the Flow start. It showed only "the flow starts here" before.
- Keep the selected event details on the current Events page, format large event IDs and page sizes with thousands separators, and show the event range as the paging position.
- Let the Flow ID in the run header use the available space before truncating.

### 1.45.18 (2026-11-21) {#v1-45-18}

**Changed**

- Web time travel skips write reapply by default. Turn on [**Apply later writes again**](/reference/web/dex-web#time-travel-dialog) under **Advanced**. Client, **dexcli flow time-travel**, and **POST /api/flows/time-travel** with **skipWritesReapply** omitted (false) still reapply writes.
- The time travel and Clone fork dialogs show only their common fields. **SubFlow reset policy** moves under a collapsed **Advanced** section in both, and Clone fork also moves **Task queue** and **ID reuse policy** there. [Reference](/reference/web/dex-web#clone-fork).

### 1.45.17 (2026-11-20) {#v1-45-17}

**Added**

- [**Settings > Codec endpoint**](/reference/server/payload-encryption#dex-web) in **Custom** sends optional **Authorization: Bearer** on **/decode** and **/encode** only at its saved URL. **Remember on this browser** defaults on and shares it until deleted. Off uses inheritable session storage.

**Changed**

- The **Codec endpoint** setting shows **Auto** only when Dex Web provides a local codec server. Otherwise it shows **Custom** and **Off**, starts in **Custom**, and treats a saved **Auto** choice as **Custom** without changing the saved value.
- **Send cookies** is off by default for a new Custom codec endpoint. [Reference](/reference/server/payload-encryption#dex-web).

### 1.45.16 (2026-11-20) {#v1-45-16}

**Added**

- **GET /api/codec-server** returns the endpoint and token of a local codec server when the host configures one with **Config.LocalCodecServer**, as **dexcli dev -codec-key-file** does. Otherwise its **configured** field is false.
- [**Settings > Codec endpoint**](/reference/server/payload-encryption#dex-web) decrypts **dex/1** and **dex-encoded:** in page memory. **Auto** uses **dexcli dev -codec-key-file**. **Send cookies** supports SSO. The Web server gets no keys or plaintext. Locked values show key IDs, never ciphertext.
- Browser codecs encrypt Channel messages, Start inputs, stop outputs and reasons. Web passes **dex/1** intact via **encodedValue** on **POST /api/flows/channels/messages**/**PUT /api/flows/attributes**, **encodedOutput** on **POST /api/flows/stop**, and **encodedInput** on **POST /api/v2/start**.
- Set attribute creates plaintext and requires a codec for encrypted updates. Display edits, Action conditions and Action inputs from Attributes, view RPC outputs, agent sessions and inbox read only plaintext and flag encryption. [Ref](/reference/server/payload-encryption#dex-web).

**Changed**

- Web API JSON marks encrypted Values as **__dexEnvelope** and wraps objects with keys starting with **__dex** in **__dexEscapedObject** to prevent marker collisions. A failed request with an encrypted gRPC status message returns it in **encodedError** for browser decryption.

### 1.45.15 (2026-11-18) {#v1-45-15}

**Added**

- In **Graph**, **Folded** groups consecutive Rounds with the same Steps in **Exact** mode (default). **Similar** also groups Rounds of the same shape and counts varying Step types. [Reference](/reference/web/dex-web#v1-pages).

**Changed**

- **Timeline** draws the selected event's incoming and outgoing links. Edge markers jump to offscreen events, links reveal faded events hidden by **Filter**, and reduced motion keeps the lines still. [Reference](/reference/web/dex-web#v1-pages).
- The run page **Timeline** opens in **Tidy** label mode unless the viewer chose **Dense** before.

**Fixed**

- **Folded** in **Graph** starts Rounds at the repeated Step type whose finished Rounds most often have the same number of Steps, such as one **AgentDecisionStep** and one tool call per Round. [Reference](/reference/web/dex-web#v1-pages).

### 1.45.14 (2026-11-18) {#v1-45-14}

**Changed**

- In **Graph** with **Folded** on, **×N** opens consecutive executions of one Step type in place and **Hide** folds them again. Long runs show **… N more**, and open runs stay open as events arrive. [Reference](/reference/web/dex-web#v1-pages).
- A **×N** node folds only executions with the same Step decision, such as **GoTo** or **GracefulComplete**, and the same cancellations. Rounds also fold together only when their Step decisions match. [Reference](/reference/web/dex-web#v1-pages).

### 1.45.13 (2026-11-17) {#v1-45-13}

**Changed**

- **Graph** shows the SDK decision name on completed Execute events, such as **GoTo ×2**, **DeadEnd**, **ForceFail**, or **ForceCompleteIfChannelsEmpty** with Channel names. Cancellations show as **CancelSteps ×N**. [Reference](/reference/web/dex-web#v1-pages).
- **Graph** with **Folded** on stacks cards for multiple Rounds and shows their count, span and Step count, such as **×39 Rounds** and **1–39 · 78 Steps**. Single-type ranges keep titles like **SyncBatch ×900**. [Reference](/reference/web/dex-web#v1-pages).

**Fixed**

- **Folded** groups Rounds of Steps that run at the same time consistently, such as a Cron schedule.

### 1.45.12 (2026-11-17) {#v1-45-12}

**Added**

- **Folded** in **Graph** groups repeated Rounds and is off by default. **Show Steps**, **Show Rounds**, or selecting an event opens a group, and a card introduces folding on the first visit. [Reference](/reference/web/dex-web#v1-pages).
- The **Graph** mini map is always shown at the bottom right, colored by Step
  status, and moves the view on click or drag. A small button hides it to a
  map button, and the browser remembers the choice. It replaces the
  **Mini Map** button.
- **Graph** nodes drop their borders for soft shadows, rounded corners, and
  tinted WaitFor and Execute chips; edges are thinner, and edges into a
  waiting Step are dashed.
- **Filter** beside **Legend** counts filtered Timeline types and filters by type or Step type, RPC, Channel or Attribute name. **Select all** and **Clear all** work globally or per type. **Show all** resets the Flow type's saved filter. [Reference](/reference/web/dex-web#v1-pages).

**Changed**

- **Graph** replaces **Completed** with the Step decision: next Steps with **+N**, canceled Steps, **Dead end**, **Graceful complete**, **Force complete**, **Force fail**, or **Complete when channels are empty**. Hover for the whole decision. [Reference](/reference/web/dex-web#v1-pages).
- Timeline adds **Dense** and **Tidy** beside **Legend**. **Dense** is the default with slanted labels, and **Tidy** uses flat, wrapped labels such as **Send User Message** for **send_user_message**. [Reference](/reference/web/dex-web#v1-pages).
- Only an open run shows the end note at the Timeline lane's newest end; a
  closed run uses that room for events. When an open run's newest end is out of
  view, **Now**, with the live dot, goes back to the newest event.
- The run configuration field **Attribute stores** is now named **Sync
  Attribute stores**.
- A page wider than the Timeline lane shows which events are in view. A page
  that fits beside the run's end note shows every event from the first one, and
  an event scrolled past the lane's left edge shows no cut-off label.
- The run page opens on the tab chosen last, on any run. An agent session opens
  on **Conversation** only when no tab was chosen yet.
- The event panel gives Input and Output equal width and Context a narrow column. Objects, including JSON strings, show up to seven formatted lines with **Copy** and **Expand**, Channel conditions show counts, and Context shows milliseconds, dates on other days and full timestamps on hover.

### 1.45.11 (2026-11-16) {#v1-45-11}

**Added**

- Settings shows the connected server's engine, version and protocol range, plus the Web build. **GET /api/server-info** adds **serverVersion**, **minimumSupportedProtocolVersion**, and **webVersion**. See [v1 Flows and Run pages](/reference/web/dex-web#v1-pages).

**Fixed**

- The Run page offers **Clone fork…** and **Clone fork from here…** on every run when the server supports clone fork, including a Flow whose type has no uploaded Flow definition. Before, Dex Web hid them unless a loaded definition showed the Flow was not an agent session.
- Clone forks of agent sessions clear **SessionTerminalLease** and **SessionLastTerminalEnvironment**. A fork of a session on its own task queue gets a queue derived from the new Flow ID. [Reference](/reference/web/dex-web#clone-fork).

### 1.45.10 (2026-11-16) {#v1-45-10}

**Added**

- **Stop flow** adds **Graceful complete** and **Force complete** with optional JSON **Output** on server-zd 0.1.34+. **Cancel** remains the default, and **Flow closed** lists the result with **Step** set to **None (added by a stop request)**. [Reference](/reference/web/dex-web#v1-pages).

### 1.45.9 (2026-11-15) {#v1-45-9}

**Added**

- **Flows** adds a **Fields** panel for built-in fields and indexed Attributes from **GET /api/v2/catalog** and the results. Choose a field to add a filter row or query condition. [Reference](/reference/web/dex-web#flows-search-fields).
- **Flows** links to the [query syntax](/reference/server/search#query-syntax) reference from the **Fields** panel and under **Search query**.

**Changed**

- **Queries** on **Flows** lists **Saved** and **Recent** with counts and timestamps. Click to run, **Copy** any query, **Save** or **Remove** a recent query, **Delete** a saved query, or **Clear** the recent list. [Reference](/reference/web/dex-web#flows-saved-queries).
- **Save query** names the query in a field inside the panel instead of a browser prompt, so it also works inside an embedding page that blocks prompts. When the clipboard or browser storage is unavailable, the panel says so.

**Fixed**

- On **Flows**, **Add filter** shows its new filter row again after a status search, such as **All**, **Failed**, or a status query run from **Recent**. Before, the new row stayed hidden, so the button seemed to do nothing.

### 1.45.8 (2026-11-15) {#v1-45-8}

**Added**

- In **Conversation**, **Fork session** copies the session after its latest turn, and **Fork from this message** copies it after the chosen turn. A fork starts without a terminal lease and gets its own queue if the source had one. [Reference](/reference/web/dex-web#agent-session-fork).
- **POST /api/flows/clone-fork** takes **deleteAttributeKeys**, the Attributes the new run deletes after the copy. [Reference](/reference/web/dex-web#clone-fork).

**Fixed**

- [**Clone fork**](/reference/web/dex-web#clone-fork), session forks, **Event ID** and **SubFlow reset policy** need protocol 6+/server-zd 0.1.33+. Else Web omits **subFlowResetPolicy**. **POST /api/flows/clone-fork**/**POST /api/flows/time-travel** reject them (400 **SERVER_PROTOCOL_UNSUPPORTED**).
- **GET /api/server-info** returns **serverEngine** and **currentProtocolVersion**, and **GET /api/v2/catalog** adds **currentProtocolVersion**.

### 1.45.7 (2026-11-15) {#v1-45-7}

**Added**

- Flow details label the **SUB_FLOW_ABANDONED** error type as "SubFlow abandoned by a time travel" instead of "Unknown (7)".
- **Clone fork…** and **Clone fork from here…** open a dialog to start a new Flow at a chosen point. The new run links to its source run and event. **POST /api/flows/clone-fork** calls **CloneForkFlow**. [Reference](/reference/web/dex-web#clone-fork).
- The time travel dialog adds the **Event ID** point and a **SubFlow reset policy** choice. **POST /api/flows/time-travel** accepts **eventId** and **subFlowResetPolicy**.

### 1.45.6 (2026-11-15) {#v1-45-6}

**Breaking**

- Dex Web removes **New session** from **Conversation** and **Work Queue**, along with **POST /api/v2/agent-sessions/start**. Start sessions with an Agents CLI command or the application's Client, such as **AgentSessionClient.start_session** or **startAgentSession**, then use Dex Web to view the session, send messages, or edit settings. [Reference](/reference/web/dex-web#agent-new-session).

**Added**

- With **Target.HasHostNavigation**, **web/embedded** posts **dex-web:location** to the parent on route changes with the path relative to **BasePath** and the query string. See [Keep the page in the host URL](/reference/web/embed-dex-web#host-location).

**Changed**

- In the **Conversation** tab message box, Enter sends the message, or queues it while a turn runs, and Shift+Enter adds a line. Enter that commits input method text does not send. On a touch-only device, such as a phone, Enter adds a line and the button sends.
- The **Conversation** tab follows new messages while you are at the newest one, and offers **Jump to latest** when you have scrolled up. A message longer than about 30 lines shows its start with **Show more**.
- **Conversation** scrolls new approval or answer controls into view when you are at the newest item and aren't working in another waiting call. Select the waiting status to jump to its call. [Reference](/reference/web/dex-web#agent-session-view).

**Fixed**

- The **Conversation** tab shows a message that the session wrote itself, such as the note after a steered or stopped turn, as a closed **Dex note** row instead of a **User** message. Open the row to read the whole note. The Work Queue agent panel labels such a last message **Dex note** too.
- The **Conversation** tab hides an assistant message that the agent framework made up itself, such as the Claude Code "No response requested." entry, which Claude Code marks with its synthetic model value. The stored message is unchanged.

### 1.45.5 (2026-11-14) {#v1-45-5}

**Changed**

- **Connectors** uses a borderless list with status icons and relative token expiry. Expired connections offer **Reauthorize**, and missing connections offer **Set up**. [Reference](/reference/web/local-connector-setup).
- The authorization guide is a numbered list that you can fold away.
  Authentication methods are one segmented choice. Copy buttons are icons, and
  selections, buttons, and the guide change smoothly. Reduced motion turns this
  off.
- In a wide window, the authorization guide, the Redirect URI, the connection
  details, and the local store stay in a column beside the setup form while you
  scroll it.
- The **Events** switch on the run page has a third option, **Design**, on
  every run. Without a loaded design for the Flow type it says why and links to
  the docs. **?view=design** opens it.
- **Graph** and **Design** draw left to right in the strip's place, with the
  same selected event panel below. Switching views keeps the panel, the pager,
  and the selected event in place.
- Every run has the tabs **Events**, **State**, **Conversation**, **Actions**,
  and **Streams**, in that order, without the word **Experimental**. When
  **Conversation** or **Actions** has nothing to show, its panel says why and
  links to the docs. A Dex Agents session still opens on **Conversation**.
- Buttons, switches, and tabs change smoothly, and the switch's indicator
  slides. Reduced motion turns this off.
- **State** uses two columns on wide screens: live state on the left, and
  **Configuration**, **Identity**, **Start input**, **Completed outputs**, and
  **Queued steps** on the right. **Details** is now **Identity**.
- **Configuration** replaces **History settings**. It shows the run's settings in
  plain words, and while the run is active **Edit** changes the retention
  window, step durability, active step search, or Attribute stores.
- The selected event's related events read as **From** and **To**, and each
  link names only the other event, such as
  **ResumeTurn-1 · WaitFor completed · #8 · 44ms before**.
- **Configuration** edits open on the current value and keep **Save** off until
  the value changes. A smaller retention window warns before it deletes older
  events, and Attribute sync turns off only through an explicit choice.
  **Start input** no longer repeats the start-time Flow configuration.
- Dex Web adds the **PUT /api/flows/config** route for **Configuration** edits.
  An embedding page that allowlists Dex Web writes must allow it.
- The rail's Dex mark says **Dex Server unreachable** in red when Dex Web cannot
  reach the server, and keeps a faint dot otherwise.
- The **Conversation** tab drops its Working as banner and selector. Controls
  that Working as blocks offer **Work as** in place, and a line by the message
  box reads **Acting as** with **Change**.
- The horizontal Timeline gives each event its own label again, slanted at 30
  degrees, and draws the overview above the lane. A page that fits the strip
  puts each overview bar under its event dot; a longer page packs events
  closer, and its overview window is tinted, outlined, and dims the rest.
- The Timeline's label band is as tall as the page's longest label needs.
- **Work Queue** titles the list with the Flow type, wrapping long names to two lines, and searches as soon as you select a filter chip. Rows show a status icon, status text and time since start, and **Start Flow** is the only accent button.
- In **Work Queue**, an Action that only **Working as** locks offers a
  **Work as** button, as the **Conversation** tab does; choosing it sets
  **Working as** for the page and makes the Action available.
- With no run selected, **Work Queue** says what to do next and how many runs
  are listed. On a phone it shows the list or the selected run. Rows, chips,
  and panels change smoothly; reduced motion turns this off.

**Fixed**

- When **Work Queue** was the first page you opened, it showed **Running** but
  searched every status until you pressed **Search**. The first search now
  uses the **Running** filter.

### 1.45.4 (2026-11-14) {#v1-45-4}

**Added**

- A run's details show its **Task queue**, or **default** when the Flow runs on the default task queue. The Flow type is shown on its own row; the Flow type is no longer shown as the task queue.
- A Step attempt's routing shows the **Task queue** of its dispatch next to the serving Worker ID and the queue source. The queue source that was called Task queue is now **Flow type queue**. An RPC shows the Flow's task queue.
- **Start Flow** takes an optional **Task queue**. Leave it empty for the default task queue. Dex Web checks the name before it starts the Flow.

**Changed**

- Each page uses one bar for views, actions and settings. The jump box (⌘K or Ctrl+K) finds Flows by ID prefix, opens pasted run links and lists recent runs, and Flows returns to your last search. [Reference](/reference/web/dex-web#v1-pages).
- The run bar shows status, Flow ID and tabs. Its action is **Stop** while running, with **Time travel…** in the menu, **Time travel from #N** on failure, or **Time travel** on other ended runs. The event panel offers **Time travel from here…**. [Reference](/reference/web/dex-web#v1-pages).
- The event pager sits above Timeline and Graph and shows its page buttons only when there is more than one page. The selected event is kept in the address. State lists the run's parent and child Flows. The run attempt picker appears only after time travel.
- Refresh and Copy link are gone from the run page. Resuming Live reads the run again, and the address bar is the link.
- Run dialogs take focus on their first field, keep Tab inside, and close with Escape. Bar menus take arrow keys. A whole Flows row opens its run, the Run ID column is off by default, and status buttons search by status in one click. Run tabs are ARIA tabs.
- The expandable left rail shows server status by the Dex mark, then Flows and any available Experimental sections (Designs, Work Queue and Connectors). On phones, open it from the bar's menu. [Reference](/reference/web/dex-web#v1-pages).
- Early features carry the word **Experimental** in place of a violet dot.
- Events switches between Timeline and Graph (formerly Execution graph). Overview becomes State, Agent session becomes Conversation, and Designs replaces the Design run tab. Old Design links open under Events and other old tab links still work. [Reference](/reference/web/dex-web#run-tabs).
- Live moved out of the bar to the event range on Events. It reads **Live** while the page follows the run, and **Updates paused · Resume** after a click.
- **Input** and **Result** beside the event range on Events select Flow started and Flow closed, which show the run's start input and how it ended.
- **Group by type**, on by default, on the Flows page groups the page's runs by Flow type, with counts by status and a link to the type's design.
- **web/embedded**: **Target.HasHostNavigation** tells Dex Web that your page draws the navigation around it, so Dex Web draws no rail.
- Timeline is about half as tall and groups consecutive events by subject under flat labels like **SyncBatch ×20**. The overview moves below the lane and **Legend** opens over the strip. [Reference](/reference/web/dex-web#v1-pages).
- A running or ended run no longer has a line under the bar for its state. The Timeline lane's newest end says what the run does now, such as **Now · waiting · fires in 2d 6h**, and selects that event on click. A failed run keeps its error line.
- The event pager reads **Oldest**, **Older**, **Newer** and **Latest**, older pages on the left as in the strip.
- The selected event panel puts **JSON** in its header in place of the Details and Raw JSON switch, names related events in one line under the title, groups **Context** into Timing, Attempt, and Worker and retry, and shows a failure's stack trace open.
- Timeline keeps the event panel below the strip at every desktop width and removes the wide-screen event list and **Show lane**. The wheel scrolls the page, Shift+wheel or a sideways swipe scrolls the strip, and J, K and T work anywhere. [Reference](/reference/web/dex-web#v1-pages).

### 1.45.0 (2026-11-11) {#v1-45-0}

**Breaking**

- Each Flow type has its own definition revision. A request about a Flow type sends that Flow type's revision in **X-Dex-Flow-Definition-Revision**, from **GET /api/flow-definitions/by-type?flowType=FLOW_TYPE** or a **GET /api/v2/catalog** entry; a search of several Flow types sends theirs separated by commas. The catalog's top-level **definitionRevision** no longer passes the check. [Reference](/reference/web/dex-web#api-requests).
- **GET /api/flow-definitions** lists definitions without their graphs. Read a Flow type's graphs from **GET /api/flow-definitions/by-type?flowType=FLOW_TYPE**. [Reference](/reference/web/flow-visualization#definition-sources).

**Added**

- **dex-web**, **dexcli dev**, and embedded Dex Web load uploaded definitions without **--flow-rendering-dir** or **FlowRenderingDirectory**. The directory wins and is the only source without server definition RPCs. [Reference](/reference/web/flow-visualization#definition-sources).
- **GET /api/flow-definitions/by-type?flowType=FLOW_TYPE** returns definitions with graphs, v2 contract and revision, or 304 for matching **If-None-Match**. **GET /api/flow-definition-types** lists Flow types with definitions. [Reference](/reference/web/flow-visualization#definition-sources).
- **Designs** shows where each definition comes from, a directory file or an upload, and when an uploaded one was generated and uploaded. Without definitions, it explains how to upload them when a Worker starts. [Reference](/reference/web/flow-visualization#render-definitions-in-dex-web).
- Each **GET /api/v2/catalog** entry carries its **definitionRevision** and, for a Dex Agents session, **agentSession**. [Reference](/reference/web/dex-web#agent-session-view).
- Dex Web accepts the optional top-level **generatedAt** field in a Version 2.0 Flow Definition Graph and checks that it is an RFC 3339 timestamp. Earlier releases reject a graph that has the field. [Reference](/reference/web/flow-visualization#generated-at).

**Changed**

- Dex Web loads definitions only where a page uses them. A run page reads only its own Flow type, the header and **/readyz** read only Flow type names, and only **Designs**, **Work Queue**, and **Connectors** read every definition. [Reference](/reference/web/flow-visualization#definition-sources).
- Dex Web marks invalid, oversized, and duplicate definitions individually so the catalog and **/readyz** keep working. A directory file over the size limit lets the uploaded definition for that type show. [Reference](/reference/web/flow-visualization#definition-sources).
- Dex Web ignores unknown top-level fields of a Flow Definition Graph. Known fields are still validated strictly. [Reference](/reference/web/flow-visualization#definition-sources).
- The **Work Queue** link appears when any Flow type has a definition; the page itself says when none has a valid Version 2.0 contract. [Reference](/reference/web/flow-visualization#definition-sources).
- **Connectors** reads the list once on load and checks each release once per listing, up to 64 with four downloads at a time. It skips retrying missing releases for five minutes and shows Connector IDs past the limit. [Reference](/reference/web/local-connector-setup).
- Dex Web validates Flow definition nodes, edges and diagnostics and limits Step groups, Version 2.0 lists and start input fields. The page shows an error when it cannot draw a definition. [Reference](/reference/web/flow-visualization#definition-sources).
