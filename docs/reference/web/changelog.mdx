# Change log

This page lists user-visible changes to Dex Web, newest first; each section covers the changes since the previous release of this component.

## 1.41 {#v1-41}

Released 2026-11-09 as [web/v1.41.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.41.0).

### Breaking

- The **v2** pages are removed, including the Run workspace, its run overlay, and the **Debug** view. Every **/v2** URL redirects to its **/v1** equivalent and keeps its query and hash, and **/** opens **/v1/flows**. The **/api/v2** endpoints are unchanged. [Reference](/reference/web/dex-web#v1-pages).

### Added

- A **Design** tab on the run page draws the Flow design graph from the loaded Flow Definition Graph, with no history. [Reference](/reference/web/dex-web#flow-canvas).
- One **Experimental** header menu holds **Designs**, **Work Queue**, and **Connectors**. [Reference](/reference/web/dex-web#run-tabs).
- **?view=design**, **?view=session**, and **?view=actions** open a run tab directly. [Reference](/reference/web/dex-web#run-tabs).

### Changed

- The version picker is gone. **Work Queue**, **Connectors**, **Agent session**, and **Actions** are **Experimental**, and each shows only when it applies. **Agent session** and **Actions** are run tabs, and **Start Flow** is in the **Work Queue** list header. [Reference](/reference/web/dex-web#run-tabs).
- **Flow Rendering** is now **Designs**, at the same **/v1/rendering** URL, and draws both schema versions with one graph. [Reference](/reference/web/flow-visualization).
- The agent inbox URL is **/v1/work-queue?view=agents**. [Reference](/reference/web/dex-web#agent-inbox).
- Step cards no longer show outcome chips. The Step panel lists outcomes under **Paths out**. [Reference](/reference/web/dex-web#flow-canvas).
- The Timeline overview is a histogram: bars count events over time, red marks failed events and Steps retried after a failed attempt, and a shaded brush shows the events in the strip. A Step event that succeeded only after failed attempts carries a retry badge. [Reference](/reference/web/dex-web#v1-pages).
- The **Streams** tab offers the Stream names of a matching Flow Definition Graph in a menu, with **Other name…** for any other name. Its output shows a live status, text as a flowing transcript, structured values as collapsible JSON, and progress values as bars, and it follows new messages until you scroll up. [Reference](/reference/web/dex-web#v1-pages).

### Fixed

- A selected or focused WaitFor segment in the **Execution graph** keeps its whole outline, including the chevron tip, and each Channel name of its condition shows on its own line. [Reference](/reference/web/dex-web#v1-pages).

## 1.40 {#v1-40}

Released 2026-11-09 as [web/v1.40.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.40.0). Patch releases [web/v1.40.1](https://github.com/superdurable/dex/releases/tag/web%2Fv1.40.1) and [web/v1.40.2](https://github.com/superdurable/dex/releases/tag/web%2Fv1.40.2) followed the same day.

### Added

- **History settings** on the Run page shows the run's retention window, and **Edit** changes it through UpdateFlowConfig while the run is active. [Reference](/reference/web/dex-web#v1-pages).

### Changed

- The **v1** Run page is redesigned with a horizontal Timeline, a minimap, and a selected event panel with **Input**, **Output**, and **Context** columns. [Reference](/reference/web/dex-web#v1-pages).

### Fixed

- Long values stay inside their column in the event panel. This arrived in 1.40.1.
- Attribute and Context rows stack in the narrow Execution graph panel. This arrived in 1.40.2.

## 1.39 {#v1-39}

Released 2026-11-09 as [web/v1.39.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.39.0).

### Added

- A **Session** tab shows Dex Agents sessions in Dex Web v2. [Reference](/reference/web/dex-web#agent-session-view).
- The Work Queue shows an agent inbox. [Reference](/reference/web/dex-web#agent-inbox).
- Dex Web sends the declared RPC locks when a person runs an Action, and a Flow Definition Graph is available for Dex Agents session Flows. [Reference](/reference/web/dex-web#actions).

### Changed

- Dex Web sends LoadBlobs requests in batches of at most 1,000 entries.

## 1.38 {#v1-38}

Released 2026-11-07 as [web/v1.38.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.38.0).

### Added

- Dex Web v2 searches by active Step type and across several Flow types. [Reference](/reference/web/dex-web#search-several-flow-types).
- An Action RPC returns its output to the page, and an Action may have no condition. [Reference](/reference/web/dex-web#actions).

### Changed

- Large values in history events appear as value references, and Dex Web loads them on demand because server-zd 0.1.21 bounds history pages by the gRPC response limit. [Reference](/reference/server/changelog#v0-1-21).

## 1.37 {#v1-37}

Released 2026-11-06 as [web/v1.37.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.37.0). Reference: [1.37.x](/reference/web/1.37.x/).

### Fixed

- Dex Web stops promptly even while a Flow history long poll is open. [Release notes](https://github.com/superdurable/dex/releases/tag/web%2Fv1.37.0).

## 1.35 {#v1-35}

Released 2026-11-06 as [web/v1.35.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.35.0). Reference: [1.35.x](/reference/web/1.35.x/).

### Breaking

- Active Step invocation details require server-zd 0.1.17 or later and protocol version 4. Upgrade the server before upgrading Dex Web. [Reference](/reference/web/dex-web#worker-routing).

### Added

- Active Steps show each method’s phase, pending reason, attempt number, and wait time. History also shows when the attempt became scheduled. [Reference](/reference/web/dex-web#worker-routing).

## 1.29 {#v1-29}

Released 2026-10-31 as [web/v1.29.0](https://github.com/superdurable/dex/releases/tag/web%2Fv1.29.0). Reference: [1.29.x](/reference/web/).

### Added

- Related-event links jump to other pages and distinguish pruned events from unloaded events. The oldest retained page shows the pruned event range. [Reference](/reference/web/dex-web#run-against-server-zd).

### Changed

- The Run details Timeline loads history in pages of at most 1,000 events, with Older, Newer, Newest, and Back navigation. Event numbers are event IDs. [Reference](/reference/web/dex-web#run-against-server-zd).
- The v2 canvas loads a bounded recent history window and appends new events on polls. The Execution graph, Overview, and time-travel dialog also use the newest window. [Reference](/reference/web/dex-web#run-against-server-zd).

Older releases: [GitHub releases](https://github.com/superdurable/dex/releases?q=web%2F&expanded=true).
