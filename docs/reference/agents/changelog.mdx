### 0.6.16 (2026-11-22) {#v0-6-16}

**Added**

- The Go core offers Dex Connector operations to an agent as tools, as the Python and TypeScript cores do. The new package **connectortools** takes an operation's **sdkgo.AgentTool**, and **builtinloop.WithToolSources** offers its tools to a built-in loop agent. Each call runs in its own tool Step under the connector's Call ID and single-dispatch fence. A limited Mutation keeps its send cap on every attempt, and Connector writes of one model response run in the model's order. A call that waits for approval shows its arguments, without an approval display yet. Stop or drain the Go Workers of a Flow type built from 0.6.15 or earlier before a Worker with Connector tools serves it, and do not roll that Flow type back below 0.6.16 while a Connector call is queued or running.
- Go: the new module **github.com/superdurable/dex/agents/go/eino** runs CloudWeGo Eino ADK agents on the Go session Flow, one RunModel Step per model call and one Step per tool call. [Module](https://github.com/superdurable/dex/tree/main/agents/go/eino).
- Go Eino agents can call Connector operations as tools beside their own, and a deploy that changes the instruction or renames a tool takes effect at the next model call without breaking the open turn.
- The Go core reads a model API error's HTTP status from an **HTTPStatusCode** field too, as the go-openai and Volcengine Ark SDK errors that CloudWeGo eino-ext model clients return have, so their transient errors get the backoff and their other 4xx errors fail the turn at once.
- The Go core's **TurnCompleted.TurnError** ends a turn as failed without a retry, as **turn_error** in Python and **turnError** in TypeScript do: the session stores the turn's messages and usage, sets **last_turn_error**, and writes **turn_failed** instead of **turn_completed**.

**Changed**

- **RunModel** and **CompactContext** retry a transient model API error with exponential backoff and jitter, about two minutes in all, and fail the turn at once on any other HTTP 4xx. **ModelRetryPolicy** changes the backoff. [Reference](/reference/agents/workers#model-api-errors).

**Fixed**

- A Go runner's message with a role other than user, assistant, or tool now fails its turn at once, with the model call's usage recorded and no retry, instead of being stored and breaking **get_agent_snapshot** and **list_agent_messages** for the rest of the session.
- A Go session at the server's **limits.maxFlowStateBytes** now ends with the reason and status **failed**, as Python and TypeScript sessions do, instead of going on after a model answer or tool result that did not fit. The Go **AgentSessionClient** reports the failure even when the session had no room to store it, and a message sent to the failed session returns **AgentSessionFailedError** with the reason.

### 0.6.0 (2026-11-12) {#v0-6-0}

**Breaking**

- **dex-agents-deepagents**: file writes and shell commands no longer wait for approval by default, as in Deep Agents without **interrupt_on**. Name the tool in **approval.always** to make it wait. **local_tools.shell.allow** has no effect on this command, and its file tools are Deep Agents' own, which take absolute paths. [Reference](/reference/agents/cli#harness-tools).
- **dex-agents-pi**: file writes, edits, and **bash** no longer wait for approval by default, as in Pi. Name the tool in **approval.always** to make it wait. **local_tools.shell.allow** has no effect on this command. The file tools and **bash** have no workspace boundary. Without **workspace** in the file, the workspace is the directory the command starts in. [Reference](/reference/agents/cli#harness-tools).

**Added**

- Python/TypeScript **ToolExecutionResult** adds optional **is_finished_by_resumed_turn** (**isFinishedByResumedTurn**) for Steps that only approve a tool. The session records success and **tool_call_started**. The runner writes **tool_call_finished** when resumed **RunModel** runs the tool.
- Python/TypeScript approvals add optional **AgentInterrupt.display**. **AgentInterruptDisplay** carries a target, summary, and optional preview in **interrupt_raised**. **ConnectorToolSource** shows operation, connection, and args with best-effort credential redaction. Stored args stay unredacted.
- Python and TypeScript CLI approvals show the file diff as of the request, omitting credential files and content changed by redaction. Shell approvals show the working directory and mask common credential shapes. Connector approvals show operation, connection, and short arguments.
- **summary_attributes_indexed** (**summaryAttributesIndexed**) defaults off. It indexes the first user message as title, latest turn time, and turn count. **list_agent_sessions** and **listAgentSessions** list and search without a Worker. [Reference](/reference/agents/approvals#list-sessions).
- CLI **sessions.summary** defaults to **auto**, keeping summaries only with **dex.server: auto**. Use **on** for any server or **off** to disable. **sessions** sorts up to 250 by activity and shows available summaries. [Reference](/reference/agents/cli#resume).

**Changed**

- **dex-agents-claude-sdk**: the command loads no MCP servers and no claude.ai connectors from your Claude Code configuration or login. Its external tools come only from the Dex Connectors, which Dex approves and records.
- Agents CLI reference: **dex-agents-builtin** documents its built-in tools and
  plan mode, and the page describes the errors for an unreachable Dex server,
  a field with several forms, and a **DEXCLI** that names no executable file.
- When a shell command ends, the CLI sends SIGTERM then SIGKILL 0.5 seconds later to its leftover group processes. After cleanup it waits up to 1 second for output from processes outside the group and caps each stream at 64 KiB. [Workspace and local tools](/reference/agents/cli#local-tools).
- The CLI stops its own **dexcli dev** for **dex.server: auto**, including on SIGTERM or SIGHUP, and keeps reused servers and sessions. After SIGKILL, use **kill** to stop its server. [The local Dex server](/reference/agents/cli#dex-server).
- **dex-agents-deepagents** keeps native tools. Connector writes need approval. File tools reject paths outside the workspace via links too. **execute** runs with your permissions. **task** waits if **approval.always** names any Deep Agents tool. [Reference](/reference/agents/cli#harness-tools).
- Python LangGraph adapter: with **should_defer_tool_calls_before_middleware**, each tool Step attempt runs the tool node's middleware tool wrappers, such as Deep Agents' large-result eviction, and the tool runtime has the graph's store.
- LangGraph **should_defer_tool_calls_before_middleware** now defaults to **True**, applying middleware inside each tool Step with deferral outermost. Set **False** for the old order. In-flight turns keep their starting order across Workers without running wrappers twice.
- **dex-agents-pi** runs Pi's **read**, **grep**, **find**, **ls**, **write**, **edit**, and **bash** in tool Steps and adds Connector, web fetch, browser, and **ask_user** tools. Connector writes need approval and name clashes gain **connector_**. [Reference](/reference/agents/cli#harness-tools).
- Agents CLI reference: The chat describes the terminal UI, now the default at
  a terminal: its keys, slash commands, approval and question panels, the
  message queue, **--plain**, and when the command keeps the plain chat. Resume
  a session, Images, and Known limitations cover the terminal UI too.
- In the TypeScript CLI commands, a **run_shell_command** command that ends also ends what it left in its process group, such as a process it started in the background, so the call answers at once and leaves nothing running.

**Fixed**

- Python and TypeScript Claude Agent SDK adapters show the user's rejection of a Claude Code tool such as **Write** or **Bash** instead of a PreToolUse hook error. Deadline, planning-turn, and cancellation rejections keep their recorded text.
- Python/TypeScript adapters emit one **tool_call_started** and one **tool_call_finished** for each approved Claude Code tool call. Failures record **failed** and segments ending without results record **outcome_unknown**. **dex-agents-claude-sdk** prints each approved call once.
- **dex-agents-claude-sdk** (Python): Claude Code's standard error goes to the command's log file without terminal control sequences, so the chat no longer shows the cursor control code that Claude Code writes when it exits.

### 0.5.0 (2026-11-11) {#v0-5-0}

**Breaking**

- All packages pin Dex SDK 1.45.0 for **Join** and Worker-side graph upload. Before upgrading, check SDK 1.43 and 1.45 in the [Python](/reference/python/changelog#v1-45), [TypeScript](/reference/typescript/changelog#v1-45), and [Go](/reference/go/changelog#v1-45) change logs. Since 1.45, Step types containing a hyphen cannot start SubFlows. Dex Server requires protocol 4 (server-zd 0.1.17 or later).
- Python and TypeScript Connector tools now default to the Connector library's snake case, where **listStoryIDs** becomes **list_story_ids** and only ASCII capitals start words. Stored calls under old names are treated as removed tools unless you set **name** to the old value. [Name the tools](/reference/agents/connector-tools#connector-tools-offered).
- Python and TypeScript record a Mutation's **defect** as **outcome_unknown** without retry, regardless of **agent.branches**. A Query's **defect** follows **agent.branches**: **rejected** when marked as such, otherwise **failed**. **defect** and **uncertain** take precedence over required branches and no longer record **succeeded** on them. [Outcomes](/agent-frameworks/connectors-as-tools#connector-tools-outcomes).
- Python and TypeScript single-dispatch Mutations record **outcome_unknown** on non-success branches unless the fence proves no send. Single-attempt writes report “not sent; the provider asked to retry later” only when **notSent** or **canResend** shows nothing was sent. **classify_connector_branch** (**classifyConnectorBranch**) adds optional **may_have_dispatched** (**mayHaveDispatched**). [Reference](/reference/agents/connector-tools#crashes).

**Added**

- **McpToolSource** reads **io.superdurable.dex/effect** and **io.superdurable.dex/approval: recommended** from tool **_meta**, and keeps prior behavior without them. Policy can raise effect or approval but cannot lower effect, and writes follow model order.
- **McpToolSource.merge_tool_policies** (**mergeToolPolicies**) merges the application's tool policies by the same rule for a framework adapter.
- A tool result's **_meta** key **io.superdurable.dex/outcome** set to **unknown** records **outcome_unknown**, and **rejected** records **failed**. Either wins over **isError**.
- The new npm package **@superdurable/dex-agents-pi** runs Pi agents on the built-in agent loop. Dex runs the agent loop, pi-ai makes each model call, and Pi tools run as Dex tool Steps.
- Dex Agents CLI debuts with **dex-agents-cli-core** and six commands on PyPI and **@superdurable/dex-agents-cli-core** and six commands on npm. Each command runs one harness with Connector and local tools as Dex Steps. [Reference](/reference/agents/cli).
- Python and TypeScript user messages and tool results can carry images. State keeps an **AgentImageReference** and bytes live in a **MediaStore**. Models see images only with a store. Send them after all Workers of the Flow type reach 0.5.0. Go accepts no image input.
- **dex-agents-pi** sends **/image** attachments and images that **read** opens in the workspace to the model. A tool result sends up to 20 images, with refused or excess images shown as text notes. [Reference](/reference/agents/cli#images).
- Python, TypeScript, and Go add optional **runner_tool_state** (**runnerToolState**, **RunnerToolState**) to **ToolExecutionResult** and **AgentToolCall**. Successful calls store it for the runner, hidden from models, browser snapshots, and trace attributes. Pre-0.5.0 Workers ignore it.
- Python LangGraph supports **create_deep_agent** and root **DeltaChannel**. Tools use **ToolRuntime** or **InjectedState** for state, or return a **Command**. Writes apply once. Adds **excluded_tool_names**, **select_turn_chat_model**, and **should_defer_tool_calls_before_middleware**.
- In **@superdurable/dex-agents-pi**, **prepareArguments** converts arguments before schema checks. Plain errors follow the effective policy and record failure for **read** and **idempotent_write**, or **outcome_unknown** for **non_idempotent_write** and **unclassified**.
- **createPiAiModelClient** sends stored images, fails on missing bytes, and gives text placeholders to text-only models. **estimateInputTokens** adds **piAiEstimatedImageInputTokens** per image. **piAgentFunctionTool** and **piDurableFunctionTool** upload images with a media store.
- Python **session_flow_definition_document** and TypeScript **sessionFlowDefinitionDocument** let a Worker upload the session graph for Dex Web on startup. Upload requires server-zd 0.1.26 or later. [Reference](/reference/agents/dex-web#upload-the-graph).
- The Dex Agents CLI commands upload the session graph of their session Flow type, so their sessions appear in Dex Web. The session Actions require the permission **dex-agents-cli.operate**.
- Dex Agents CLI runs durable terminal sessions, with one command per harness on PyPI (**dex-agents-NAME-cli**) and npm (**@superdurable/dex-agents-NAME-cli**). Commands use **dexcli dev**, offer tools with approvals, and support **/image** and **--resume**. [Reference](/reference/agents/cli).
- Python **decide_turn_continuation** and TypeScript **decideTurnContinuation** decide whether to continue after each loop iteration. Return **end**, **default**, or **ContinueTurn** with a message. A ninth consecutive continuation after answers without tool calls ends with an error.
- Runner contract: the new **TurnContinued** outcome makes the session store its messages and run **RunModel** again, and **TurnCompleted.turn_error** (**turnError**) ends a turn as failed without a retry. Existing runners need no change.

**Changed**

- A tool task poll may raise **ToolOutcomeUnknownError**. The session records **outcome_unknown** and stops polling. It used to fail the poll attempt.
- Built-in loop moves to **dex_agents.builtin_loop**, **@superdurable/dex-agents/builtin-loop**, and **builtinloop**. Use **BuiltinLoopAgentRunner**, **builtin_agent_session_flow**, **createBuiltinAgentSessionFlow**, or **NewBuiltinAgentSessionFlow**. Old aliases are deprecated for one release.
- Built-in agent loop message and run-state errors now say “built-in” instead of “Stepwise.” Go nil-model or nil-definition panics start with **builtinloop:** instead of **stepwise:**. Python loggers move to **dex_agents.builtin_loop**.

**Fixed**

- Python and TypeScript Claude Agent SDK adapters: when the Claude Code CLI returns an error result, the turn's error now reads "the Claude Code CLI returned an error result (subtype ...)". It used to read "reported success" for an error result whose subtype is **success**, such as a failed login.

### 0.4.0 (2026-11-10) {#v0-4-0}

**Added**

- Manifests set Connector effect and default approval. Results default to 64 KiB. Writes run in order per reply. After an unsuccessful write, later writes are **failed** with **skipped**. [Connectors as tools](/agent-frameworks/connectors-as-tools#connectors-as-tools).
- Every Python and TypeScript framework adapter takes tool sources, through **tool_sources** (**toolSources**), with a listing timeout of 10 seconds by default. Each call of a source tool runs once in its own tool Step.
- Tool call contract: **ToolOutcomeUnknownError**, **DeferredToolExecution.context**, **ToolCallStepOptions**, and the **AgentToolCall** fields **ordered_write**, **write_queued**, **skipped**, and **truncated_output_bytes**. Records written by 0.2 decode unchanged.

**Changed**

- Claude Agent SDK adapters resume approved Claude Code calls with the recorded arguments, as the same tool and at most once per segment. Application PreToolUse hooks are skipped when the resumed call already has a final record.
- TypeScript Mastra: the new **mastraRunToolNames** names the tools Mastra adds itself. With **toolSources** or **mastraRunToolNames**, a **toolPolicies** key no longer allows such a tool by itself.
- TypeScript Vercel AI SDK: the **toolPolicies** type accepts any string key, so a source tool can have a policy.
- Python LangGraph: a model tool call without a tool call ID fails the **RunModel** attempt.

- Compaction in the OpenAI Agents SDK, Pydantic AI, LangChain and LangGraph, Google ADK, Vercel AI SDK, and Mastra adapters. Adapters compact only between turns. [Reference](/reference/agents/session-limits#compaction).
- **ModelSpendLimit** checks each model call before it runs and reports its usage after. A refused call ends the turn. [Reference](/reference/agents/spend-limits).
- **run_model_limit** (**runModelLimit**) sets the method timeout and attempts of **RunModel**. [Reference](/reference/agents/workers#long-model-calls).
- **AgentSessionClient.start_session** and **startAgentSession** make a new session searchable by the Step it waits in. [Reference](/reference/agents/approvals#find-sessions).

**Changed**

- Every package requires Dex SDK 1.38.0.
- A session over the server's state limit fails with the reason: its status becomes **failed**, and new messages raise **AgentSessionFailedError**. Upgrade every reader of a session before the Workers that write **failed**. [Reference](/reference/agents/session-limits#at-the-limit).

### 0.2.0 (2026-11-05) {#v0-2-0}

**Breaking**

- Stop every 0.1 Worker of a Flow type before any 0.2 Worker starts. 0.2 moves older messages into **AgentMessageChunks**, which a 0.1 Worker cannot read. [Reference](/reference/agents/upgrades).

**Added**

- The built-in agent loop, with questions, durable waits, plans and plan mode, MCP tool sources, and a scripted demo model.
- Steering and turn cancellation: **steer_user_message** and **cancel_turn**.
- Tool tasks: a tool can start long work and the session polls it in **PollToolTask**.
- Context compaction with the **CompactContext** Step, and message retention through **retained_message_limit**. [Reference](/reference/agents/session-limits#compaction).
- Messages are stored in chunks (**AgentMessageChunks**), so storing a message writes only that message.
- UI stream adapters for the AI SDK **useChat** and plain Server-Sent Events, which resume through the Dex resume token.
- OpenTelemetry GenAI spans for model calls and tool calls.
- The Go core, with the built-in agent loop and OpenAI and Anthropic model clients.
- A call whose tool Step never reached a Worker records **failed**, with an error that starts "the tool did not run, so it is safe to call again". [Reference](/reference/agents/failures#never-run-outcome-unknown).

**Changed**

- Every package requires Dex SDK 1.35.0.
- **resolve_interrupt** and **answer_question** can raise **RpcLockConflictError**. **AgentSessionClient** retries it for 5 seconds. [Reference](/reference/agents/approvals#rpc-locks).
