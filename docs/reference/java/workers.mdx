# Java Workers

This page shows how to start a Java Worker and lists the Java names of its
settings. [Workers and the task queue](/reference/server/workers) describes
how these settings behave in every SDK.

## Start a Worker

This example serves a Greeting Flow through a pull Worker. Its Step stores a
greeting, and the greeting RPC reads it. The Worker allows eight concurrent tasks
and keeps one slot for RPCs. See the [Java SDK README](https://github.com/superdurable/dex/blob/main/sdk-java/README.md#pull-workers) for
startup details.

```java
public final class PullGreetingExample {
    private PullGreetingExample() {
    }

    public static RunningPullGreeting start(
            final BlobCache cache, final String serverAddress) throws InterruptedException, TimeoutException {
        final GreetingFlow flow = new GreetingFlow();
        final Registry registry = new Registry(List.<Flow<?>>of(flow));
        final Worker worker = new Worker(registry, cache, WorkerOptions.newBuilder()
                .serverAddress(serverAddress)
                .pull(PullWorkerOptions.newBuilder()
                        .maxConcurrentTasks(8)
                        // Keep one slot for RPCs so Flows stay responsive.
                        .reservedRpcTasks(1)
                        .build())
                .build());
        final Client client = new Client(registry, cache, new ClientOptions(serverAddress));
        final CompletableFuture<Void> workerResult = new CompletableFuture<>();
        final Thread workerThread = new Thread(() -> {
            try {
                worker.start();
                workerResult.complete(null);
            } catch (final Throwable failure) {
                workerResult.completeExceptionally(failure);
            }
        }, "pull-greeting-worker");
        workerThread.start();
        final RunningPullGreeting running = new RunningPullGreeting(
                flow, worker, client, workerThread, workerResult);
        try {
            worker.waitPullRegistered(Duration.ofSeconds(30));
        } catch (final InterruptedException | TimeoutException | RuntimeException | Error failure) {
            try {
                running.close();
            } catch (final InterruptedException | RuntimeException | Error cleanupFailure) {
                failure.addSuppressed(cleanupFailure);
                if (cleanupFailure instanceof InterruptedException) {
                    Thread.currentThread().interrupt();
                }
            }
            throw failure;
        }
        return running;
    }

    public static boolean isPullGreetingReady(final Worker worker) {
        return worker.getPullRegistrationState().isReady();
    }

    public static PullGreetingDiagnostics getPullGreetingDiagnostics(final Worker worker) {
        return new PullGreetingDiagnostics(
                worker.getPullRegistrationState().isReady(), 0L);
    }

    // reservedRpcDeclines is deprecated and always 0: reserved execution slots never decline tasks.
    public record PullGreetingDiagnostics(boolean isReady, long reservedRpcDeclines) {
    }

    public record RunningPullGreeting(
            GreetingFlow flow, Worker worker, Client client, Thread workerThread,
            CompletableFuture<Void> workerResult) implements AutoCloseable {
        @Override
        public void close() throws InterruptedException {
            client.close();
            worker.close();
            workerThread.join();
            workerResult.join();
        }
    }
}
```

## Readiness

**waitPullRegistered(Duration)** waits until the Worker's slot streams have registered with
Dex. **getPullRegistrationState()** reports the current registration state. By default,
a Worker keeps retrying when Dex permanently rejects a slot stream. Set
**stopOnPermanentStreamRejection** to stop and drain the Worker instead when a permanent
rejection leaves a slot kind without registered streams. Since 1.14.0.

A **PullRegistrationError** reports **POLL_WORKER_SLOT_KIND_STEP_AND_RPC** or
**POLL_WORKER_SLOT_KIND_RPC_ONLY** as its slot kind.

Call the boolean helper from your probe endpoint and return 200 when true or
503 when false.

```java
    public static boolean isPullGreetingReady(final Worker worker) {
        return worker.getPullRegistrationState().isReady();
    }
```

## Upload Flow definitions {#upload-flow-definitions}

A Worker can upload Flow Definition Graph documents when it starts, so Dex Web
can draw the graph of each Flow type. Since 1.45.0.

| Setting | Java name |
| --- | --- |
| Files and directories of documents | **flowDefinitionPaths** |
| In-memory documents | **flowDefinitions** |

- A directory is read recursively for **.json** files. A JSON file without
  **flow.name** is skipped, so a directory may hold other JSON files.
- A file's Flow type is its **flow.name**. Its generation time is its
  top-level **generatedAt** (RFC 3339), or the file modification time.
- A **FlowDefinitionDocument** carries its Flow type, JSON bytes, and
  generation time. Pass a fixed time for a document built from a template.
- The **Worker** constructor reads the files. It throws
  **IllegalArgumentException** when two sources have the same Flow type, or an
  in-memory document is not JSON or names another Flow type. A missing or
  unreadable path is logged as a warning and skipped.
- **start** uploads the documents after protocol negotiation and Attribute
  index synchronization, before it opens task streams. It uploads only the Flow
  types that the **Registry** registers and logs the others at INFO.
- Before upload, an absolute **source.path** in a document becomes a path
  relative to the working directory, or the file name when the file is
  elsewhere. Nothing else in the document changes.
- The uploader is **java/** followed by the SDK version.
- Results are logged through **java.util.logging**: CREATED and REPLACED at
  INFO, UNCHANGED at FINE, and KEPT_EXISTING at WARNING with both digests and
  generation times.
- Every upload failure is logged as a WARNING and the Worker keeps starting.
  Each request uses the **attributeIndexSyncTimeout** deadline.
  This includes a Server without Flow definition storage, which returns
  UNIMPLEMENTED.

Deploy scripts can call **Client.uploadFlowDefinitions** instead. See
[Flow definitions](/reference/server/runtime-client#flow-definitions) for how
the Server decides between a stored and an uploaded document.

## Capacity and shutdown

| Setting | Java name |
| --- | --- |
| Concurrent tasks | **maxConcurrentTasks** |
| Reserved RPC slots | **reservedRpcTasks** |
| Stop drain timeout | **stopDrainTimeout** |
| Shutdown | **stop** |

The option names are builder methods.

The idle stream option, **idleStreamsPerQueue**, is deprecated. It is still accepted and
has no effect.

## Reserved RPC capacity

The reserve-decline counter, **getPullReservedRpcDeclines()**, is deprecated. It remains for
source compatibility and always reads zero.

Report registration readiness instead, as this diagnostics helper does. Its reserve-decline field
is always zero. A Worker with every slot busy stays ready.

```java
    public static PullGreetingDiagnostics getPullGreetingDiagnostics(final Worker worker) {
        return new PullGreetingDiagnostics(
                worker.getPullRegistrationState().isReady(), 0L);
    }

    public record PullGreetingDiagnostics(boolean isReady, long reservedRpcDeclines) {
    }
```
