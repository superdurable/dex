### 1.45.2 (2026-11-15) {#v1-45-2}

**Added**

- **Client.cloneForkFlow** copies run state to a new Flow without stopping the source. **CloneForkFlowOptions** selects the point and **CloneForkFlowResult** identifies it. Requires server-zd 0.1.33+ or throws **IllegalStateException**. [Reference](/reference/server/runtime-client#clone-fork).
- **TimeTravelType.EVENT_ID** with **TimeTravelOptions.Builder.eventId** targets the post-event state. **TimeTravelOptions.Builder.subFlowResetPolicy** governs restored SubFlow waits. **TimeTravelType.CURRENT** is for **cloneForkFlow** only. [Reference](/reference/server/runtime-client#time-travel).
- **FlowErrorType.SUB_FLOW_ABANDONED** replaces a **null** error type in failed child results when Time Travel’s SubFlow reset policy fails a restored wait. Handle it in exhaustive **FlowErrorType** matches. [Reference](/reference/server/runtime-client#sub-flows-across-a-time-travel).

**Fixed**

- Maven POM metadata links the Apache 2.0 license text shipped with the Java SDK.

### 1.45.1 (2026-11-14) {#v1-45-1}

**Added**

- **PullWorkerOptions.Builder.taskQueue**, **StartFlowOptions.Builder.taskQueue**, and **SubFlowOptions.Builder.taskQueue** name queues (protocol 5). **PullQueueRegistrationState.getTaskQueue** and **PullRegistrationError.getTaskQueue** report them. [Reference](/reference/java/workers#task-queues).

### 1.45.0 (2026-11-11) {#v1-45-0}

**Breaking**

- Steps with **-** in their Step type can no longer start SubFlows, and a **SubFlow.run** condition from **waitFor** fails the attempt without retry and fails the Flow under the default policy. Rename the Step type, for example via **getStepType**, which changes child Flow IDs for new starts. [Reference](/reference/java/subflow#step-types-that-start-subflows).

**Added**

- **WorkerOptions.Builder.flowDefinitionPaths** and **WorkerOptions.Builder.flowDefinitions** upload Flow graphs at startup for Dex Web and warn on failure. Use **FlowDefinitionDocument** for in-memory graphs. [Reference](/reference/java/workers#upload-flow-definitions).
- **Client.uploadFlowDefinitions** uploads documents from a deploy or CI script and returns a **FlowDefinitionUploadResult** with a **FlowDefinitionUploadOutcome** for each document. [Reference](/reference/java/client#api-names).

**Fixed**

- The **Join** documentation no longer recommends reporting a result for a cancelled branch from the cancelling RPC, which could count that branch twice. A cancelled branch never reports, and no other code can safely report for it. [Reference](/reference/java/waits).

### 1.44.0 (2026-11-10) {#v1-44-0}

**Added**

- **Join** and **JoinRound** coordinate parallel branches in one Flow. Start a round with **Join.fork** or **Join.forkWithRoundKey**, report results with **endBranch** or **reportBranchResult**, and reset with **forRemainingBranches**. [Reference](/reference/java/waits).
- **StepDecision.goToMany(List)** and **RPCResult.of(output, List)** accept a list of movements like the varargs forms. Passing literal **null** for the movements now fails to compile as ambiguous. It previously threw at runtime. [Reference](/reference/java/step-decisions#gotomulti).

### 1.43.0 (2026-11-10) {#v1-43-0}

**Breaking**

- Removed **Client.triggerContinueAsNew**, **FlowStatus.CONTINUED_AS_NEW**, **FlowConfig.Builder.continueAsNewThreshold**, **FlowConfig.Builder.continueAsNewPageSizeBytes**, **SearchFlowsOptions**, and the four-argument **Client.searchFlows** overload. - Generated bindings rename **FlowExecutionID** to **FlowRunID** and **getFlowExecutionId** to **getFlowRunId**. ProtoJSON uses **flowRunId**. [Reference](/reference/server/runtime-client#describe-a-flow).

## 1.35 {#v1-35}

| Version | Released | Changes | Release |
| --- | --- | --- | --- |
| [1.35.0](#v1-35-0) | 2026-11-06 | 5 breaking, 1 added, 2 changed, 1 deprecated | [sdk-java/v1.35.0](https://github.com/superdurable/dex/releases/tag/sdk-java%2Fv1.35.0) |

Reference: [1.35.x](/reference/java/).

### 1.35.0 (2026-11-06) {#v1-35-0}

**Breaking**

- Workers and the Client’s first call now require server-zd 0.1.17 or later (protocol version 4). Upgrade all server processes before upgrading the SDK. [Reference](/reference/server/upgrades).
- Worker startup fails when **maxConcurrentTasks** exceeds **matching.maxConcurrentTasksCap** (256 by default). Lower the Worker setting or raise the server cap and **matching.maxStreams** first. [Reference](/reference/java/workers#capacity-and-shutdown).
- **RetryPolicy.Builder.totalDuration** now starts at the first hand-out and only gates scheduling another retry. Set method timeouts to bound running attempts. [API reference](pathname:///api/java/latest/io/superdurable/dex/RetryPolicy.Builder.html).
- A Step with no available or supporting Worker waits durably without consuming a retry. Set a Flow timeout to bound that wait. [Reference](/reference/server/workers#step-task-queue).
- A Step attempt interrupted after its hand-out was committed fails with **NOT_COMPLETED** and consumes a retry. Review retry policies and side effects before upgrading. [Reference](/reference/java/failure-and-retries#same-attempt-redelivery).

**Added**

- **RecoveryErrorInfo.getAttemptProgress()** distinguishes a failed Step method that never started from one that may have run. [API reference](pathname:///api/java/latest/io/superdurable/dex/RecoveryErrorInfo.html).

**Changed**

- Workers open one execution stream per slot; **reservedRpcTasks** selects RPC-only slots. By default, a Worker with at least two slots reserves one for RPCs. [Reference](/reference/java/workers#capacity-and-shutdown).
- **stop** drains running handlers and returns tasks that did not start without consuming a retry. [Reference](/reference/java/workers#capacity-and-shutdown).

**Deprecated**

- **idleStreamsPerQueue** is accepted but ignored, and **getPullReservedRpcDeclines()** always reports zero. Use execution-slot capacity and queue metrics instead. [Reference](/reference/java/workers#reserved-rpc-capacity).
