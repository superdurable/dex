# Java SDK reference

This reference covers the Dex Java SDK. Check the resolved version of
**io.superdurable:dex-sdk** in your Gradle or Maven build before you rely on a
detail:

```bash
./gradlew dependencyInsight --dependency io.superdurable:dex-sdk
```

## Install

The Java SDK is the Maven Central artifact **io.superdurable:dex-sdk**. Pin an
exact release:

```text
io.superdurable:dex-sdk:1.45.0
```

The published classes target Java 8 bytecode. Releases use the tag
**sdk-java/vX.Y.Z**.

## Supported versions

| SDK minor | Server requirement |
| --- | --- |
| 1.45, 1.43, 1.41, 1.40, 1.37 | server-zd 0.1.17 or newer (protocol version 4) |

The [compatibility matrix](/reference/#compatibility-matrix) lists every component.

Minor numbers follow the shared Dex release train. A missing minor means the
Java SDK did not change in that release.
