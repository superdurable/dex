# Primitives

These pages list the Java SDK names for the six [primitives](/concepts/primitives).
Each page links the doc comments in the [Java SDK API reference](./index.mdx#api-reference).

- [Attribute](./attribute.mdx): Java names for Attributes and AttributeMaps.
- [RPC](./rpc.mdx): Java names for RPC handlers and their results.
- [Channel](./channel.mdx): Java names for Channels and ChannelMaps.
- [Stream](./stream.mdx): Java names for writing and reading Streams.
- [Timer](./timer.mdx): Java names for Timer conditions.
- [SubFlow](./subflow.mdx): Java names for SubFlow conditions and results.
