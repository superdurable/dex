# Client

This page lists the Python SDK names for the [Client](/concepts/client).
The doc comment of each API gives its parameters, defaults, and errors. Read
them in the [Python SDK API reference](./index.mdx#api-reference).

## API names {#api-names}

| Task | Python API | Dex behavior |
| --- | --- | --- |
| Create a Client | **Client** for blocking calls, or **AsyncClient** for asyncio, with **ClientOptions** | [Client requests](/reference/server/runtime-client) |
| Start a Flow | **start_flow**, with **StartFlowOptions** | [Start a Flow](/reference/server/runtime-client#start-a-flow) |
| Invoke an RPC | **invoke_rpc** | [Invoke an RPC](/reference/server/runtime-client#invoke-an-rpc) |
| Read Attributes | **get_attributes** | [Read Attributes](/reference/server/runtime-client#read-attributes) |
| Wait for a Flow to close | **wait_for_flow** | [Wait for a Flow](/reference/server/runtime-client#wait-for-a-flow) |
| Wait for a Step execution to complete | **wait_for_step_completion**, with **WaitForStepCompletionOptions** | [Wait for a Step](/reference/server/runtime-client#wait-for-a-step) |
| Wait until an Attribute matches | **wait_for_attribute_match**, with **WaitForAttributeOptions** | [Wait for an Attribute match](/reference/server/runtime-client#wait-for-an-attribute-match) |
| Describe a Flow | **describe_flow** | [Describe a Flow](/reference/server/runtime-client#describe-a-flow) |
| Search Flows | **search_flows** | [Search Flows](/reference/server/runtime-client#search-flows) |
| Stop a Flow | **stop_flow**, with **StopFlowOptions** | [Stop a Flow](/reference/server/runtime-client#stop-a-flow) |
| Skip a Timer | **skip_timer** | [Skip a Timer](/reference/server/runtime-client#skip-a-timer) |
| Update FlowConfig | **update_flow_config** | [Update FlowConfig](./flow.mdx#update-flow-config-with-a-client) |
| Write and read a Stream | **write_stream**, **read_stream**, and **list_stream_messages** | [Stream](./stream.mdx) |
| Time travel a Flow | **time_travel**, with **TimeTravelOptions** | [Time travel](/reference/server/runtime-client#time-travel) |
| Handle a failed request | **DexServiceError**, with **ErrorSubStatus** | [Client requests](/reference/server/runtime-client) |

**AsyncClient** has the same methods as **Client**. Each one is a coroutine.
