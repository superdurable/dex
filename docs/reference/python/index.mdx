# Python SDK reference

This reference covers the Dex Python SDK. Check the SDK version your
application uses before you rely on a detail:

```bash
python -c 'import importlib.metadata; print(importlib.metadata.version("dex-python-sdk"))'
```

## Install

The Python SDK is the PyPI package **dex-python-sdk**. Pin an exact release in
**pyproject.toml** or your lockfile:

```bash
pip install dex-python-sdk==1.35.0
```

The package requires Python 3.11 or newer. Releases use the tag
**sdk-python/vX.Y.Z**.

## Supported versions

| SDK minor | Server requirement |
| --- | --- |
| 1.35 | server-zd 0.1.17 or newer (protocol version 4) |
| 1.32, 1.30, 1.29, 1.28 | See the [compatibility matrix](/reference/#compatibility-matrix) |

Minor numbers follow the shared Dex release train. A missing minor means the
Python SDK did not change in that release.
