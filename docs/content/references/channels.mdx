# Channels

Channels unify former signal / internal / interstate channels. Publish from clients, RPCs, or Steps; wait with Conditions (`for_one`, `for_n`, combinations).

Flat all/any waits do not require Condition IDs. Every Condition referenced by
an any-combination wait must have a non-empty user ID. Dex does not generate an
internal ID, and the former internal-looking prefix is available as a normal
user ID.

During an RPC, ChannelMap map-size and all-instance-keys methods list only
non-empty instances, including messages published earlier in that invocation.
Keys are decoded and sorted. The existing per-instance `size` method is
unchanged.

Conditional completion when channels are empty uses the SDK's
`forceCompleteIfChannelsEmpty` spelling (language-native casing applies).
