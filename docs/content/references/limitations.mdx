# Limitations

Know the edges:

- Very high-churn tiny Steps cost history/actions on the underlying engine
- Large Attribute payloads should use blobs
- Worker availability is required to advance Flows
- Some advanced platform features (for example warehouse sync) may be roadmap/BYOC rather than OSS

Validate assumptions with load tests on your Temporal/Cadence backing store.
