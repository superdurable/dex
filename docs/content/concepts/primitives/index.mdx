# Primitives

Primitives are the building blocks a Flow uses: [Attribute](/concepts/primitives/attribute),
[RPC](/concepts/primitives/rpc), [Channel](/concepts/primitives/channel),
[Stream](/concepts/primitives/stream), [Timer](/concepts/primitives/timer), and
[SubFlow](/concepts/primitives/subflow). [Concepts](/concepts#the-primitives)
compares them and shows how they fit with Flow, Step, Client, and Connector.
