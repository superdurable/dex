# Get Started

Dex keeps a process running through crashes, restarts, and long waits. You write the process as a Flow of Steps in ordinary code. Dex records each Step's result, so after a failure the Flow continues from the last recorded Step.

## Choose where to start

- **Try it in 10 minutes.** The [Quick Start](/quick-start) runs a Flow, stops its Worker in the middle of a wait, and shows Dex continuing it.
- **Let your coding agent build it.** [Build with AI](/build-with-ai/dex-developer-skill) installs Dex Skills, so the agent writes correct Dex code.
- **Make an existing agent durable.** The [Agent Quick Start](/agent-frameworks/quick-start) runs your framework's agent as a durable session.
- **Learn the model first.** [Concepts](/concepts) covers Flow, Step, and the six primitives.

## Evaluating Dex

[Why Dex?](/intro/what-is-dex) walks through one order process. [Compared to Database](/intro/compared-to-database) and [Compared to Existing Durable Execution](/intro/compared-to-durable-execution) show how Dex differs from what you may use today.
