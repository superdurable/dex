# Get Started

Pick a path by your goal. Each row says how long it takes and what you have at the end.

:::info What you run

You run Dex Server yourself, next to your own Workers. It stores every Flow in object storage, such as Amazon S3 or an S3-compatible store, and can have a standby that takes over if it stops. Dex has no hosted service. Dex is in Beta, and Dex Server is at version 0.1. [Smallest real deployment](/components/production#smallest-deployment) lists what to set up, and [Performance and Maturity](/intro/performance-and-maturity) gives the numbers and the release status.

:::

## Evaluate Dex {#evaluate-dex}

1. [Why Dex?](/intro/what-is-dex) walks through one order process.
2. [Compared to Database](/intro/compared-to-database) builds that process on a database and queues, then as a Flow.
3. [Compared to Existing Durable Execution](/intro/compared-to-durable-execution) maps other tools' terms onto Dex and says when another tool fits better.
4. [Performance and Maturity](/intro/performance-and-maturity) gives measured numbers, the release status, and the license.
5. [Limits and Sharp Edges](/intro/limits-and-sharp-edges) lists what Dex does not do yet and the defaults to know before production.

## Fix a process that breaks halfway {#fix-a-process}

### First visit, about 20 minutes

1. [Why Dex?](/intro/what-is-dex) shows a charge that succeeds and a ship call that never runs.
2. [Quick Start](/quick-start) runs a small version and stops its Worker in the middle.
3. [Port Your Process to a Flow](/intro/port-your-process) splits your own function into Steps and ends with a checklist.

### Before you port

4. [Compared to Database](/intro/compared-to-database) builds the same process with status columns and queues, then as a Flow.
5. [Order Processing](/use-cases/order-processing) has the full process with approval, reminders, and a refund.
6. [Limits and Sharp Edges](/intro/limits-and-sharp-edges) lists what to know before production.
7. [Run Dex in Production](/components/production) lists what you run: one Dex Server node, an optional standby, and object storage.
