# Build with AI using Dex Skills

Dex Skills is the official coding-agent plugin for Dex. It helps Codex, Claude
Code, Cursor, and other Agent Skills clients design and build Dex applications,
work directly with the public Dex SDK, and contribute official
[Connectors](/primitives/connector).

The plugin contains developer guidance, not runtime code. Dex Server, Workers,
and applications do not load it.

:::tip Start with Dex App Builder

For a product, application, or business-process request, start with
**dex-app-builder**. It owns the end-to-end workflow and loads the specialist
skills when SDK or Connector work is required.

:::

## Requires a coding workspace

Dex Skills is a developer plugin, not a hosted application builder. To create
or modify an application, run it in Codex or another coding-agent host with a
writable repository or project workspace, file-editing tools, and command
execution. An existing repository or a new empty repository both work.

In an ordinary chat without repository and command access, the skills can still
help with business discovery, architecture, and an implementation handoff. They
cannot create project files, run tests, build artifacts, or deploy the
application. Move the confirmed plan into a repository-backed coding workspace
before implementation.

## Choose a skill

| Skill | Role | Use it for |
| --- | --- | --- |
| [**Dex App Builder**](./dex-developer-skill/dex-app-builder.mdx) | **Primary skill** | Discover, prototype, implement, and locally verify an end-to-end process product with a Go backend. |
| [**Dex SDK**](./dex-developer-skill/dex-sdk.mdx) | Specialist sub-skill | Implement, debug, test, and operate Dex applications in Python, Go, Java, TypeScript, or Rust. |
| [**Dex Connector Contributor**](./dex-developer-skill/dex-connector-contributor.mdx) | Specialist sub-skill | Create, verify, and upstream official Connector operations, Triggers, and configuration UI units. |

Use **dex-sdk** directly only for a standalone SDK task. Use
**dex-connector-contributor** directly only for standalone work in the official
Dex Connectors Library.

## How the skills work together

Dex App Builder is the primary coordinator. It loads Dex SDK when backend
design and implementation begin, uses released Connectors directly, and routes
a confirmed official Connector gap to Dex Connector Contributor. Connector
Contributor also loads Dex SDK when it needs shared Flow and Step semantics.

Install the complete plugin so the agent can route between all three skills.
The source and releases are maintained in
[superdurable/dex-skills](https://github.com/superdurable/dex-skills).

## Install for Codex

Add the Super Durable marketplace and install the Dex plugin:

~~~bash
codex plugin marketplace add superdurable/dex-skills
codex plugin add superdurable-dex@superdurable
~~~

Open an existing repository or create an empty one, then start a new task. For
product work, describe the application normally or invoke App Builder:

~~~text
$dex-app-builder Design and build this process application.
~~~

Codex can select **dex-app-builder** from the task context. The SDK and
Connector Contributor skills are explicit-only specialist entries, while App
Builder can still load them as part of the product workflow:

~~~text
$dex-sdk Diagnose this Flow retry behavior.
$dex-connector-contributor Add this capability to an official Connector.
~~~

## Install for Claude Code

Run these commands inside Claude Code:

~~~text
/plugin marketplace add superdurable/dex-skills
/plugin install superdurable-dex@superdurable
/reload-plugins
~~~

The three invocations, in recommended order, are:

~~~text
/superdurable-dex:dex-app-builder
/superdurable-dex:dex-sdk
/superdurable-dex:dex-connector-contributor
~~~

## Install for Cursor

Import [superdurable/dex-skills](https://github.com/superdurable/dex-skills)
from **Customize → From GitHub Repository**, then install
**superdurable-dex**. The three skills appear as:

~~~text
/dex-app-builder
/dex-sdk
/dex-connector-contributor
~~~

Agent Skills clients can install the complete bundle directly:

~~~bash
npx skills add superdurable/dex-skills --all
~~~

## Keep the plugin current

Agents use an installed or cached copy. They do not fetch the latest GitHub
content for every prompt, and an active task keeps the version loaded when that
task started.

- In Codex, upgrade the marketplace, reinstall the Dex plugin, and start a new
  task.
- In Claude Code, update the marketplace and reload plugins.
- In Cursor, refresh or reinstall the plugin, then reload the window.
- For a direct Agent Skills installation, rerun the installation command.

The plugin version is separate from the Dex SDK version. Each skill inspects
the application's installed dependencies and immutable released sources before
using an exact API.

## Trust and permissions

Install agent extensions only from sources you trust. The Dex plugin declares
no MCP server, hooks, credentials, or application runtime code. Creating a
GitHub fork, publishing a branch, opening a pull request, and mutating a running
Flow remain permissioned actions.

Continue with [Dex App Builder](./dex-developer-skill/dex-app-builder.mdx), the
primary workflow.
