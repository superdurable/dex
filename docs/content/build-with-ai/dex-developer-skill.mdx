# Build with AI

Dex Skills teaches a coding agent, such as Claude Code, Codex, or Cursor, to
design, build, and test Dex applications. It is guidance for the agent and
holds no runtime code. Install it once per agent.

## Install Dex Skills {#install-and-use-dex-skills}

<DexSkillHostTabs skill="all" />

<a id="copy-a-prompt"></a>

After the install, a page with a coding-agent box starts your agent on that
page with a one-line prompt. The [Quick Start](/quick-start) box also installs
Dex Skills.

## What is included {#whats-included}

Dex Skills is one plugin with a main skill and two sub-skills. You don't
choose a skill. Describe the task, and the main skill loads a sub-skill when
the work needs it.

| Skill | Role | Covers |
| --- | --- | --- |
| [Dex App Builder](./dex-developer-skill/dex-app-builder.mdx) | Main skill | Product, application, and business-process requests, from the process design to a tested, committed Go application |
| [Dex SDK](./dex-developer-skill/dex-sdk.mdx) | Sub-skill | SDK work in Python, Go, Java, TypeScript, or Rust, such as debugging a Flow or adding a Step |
| [Dex Connector Contributor](./dex-developer-skill/dex-connector-contributor.mdx) | Sub-skill | A new or fixed official Connector, operation, Trigger, or configuration UI unit |

## Docs for coding agents {#docs-for-coding-agents}

- Every page has a Markdown version. Add `.md` to its URL, for example
  `https://docs.superdurable.io/quick-start.md`.
- `https://docs.superdurable.io/llms.txt` lists every page.
  `llms-full.txt` holds the full docs, and `llms-full.python.txt`,
  `llms-full.go.txt`, `llms-full.typescript.txt`, `llms-full.java.txt`, and
  `llms-full.rust.txt` hold them for one SDK language.

## Trust and permissions

Install agent extensions only from sources you trust. The source and releases of Dex Skills are in
[superdurable/dex-skills](https://github.com/superdurable/dex-skills). Dex Skills adds no MCP
server, asks for no credentials, and contains no application runtime code. Its
optional hook reads the installed version and the public GitHub release
metadata. If a newer release exists, the hook tells you, but it does not
install it. The agent still needs your permission to create a GitHub fork,
push a branch, open a pull request, or change a running Flow.
