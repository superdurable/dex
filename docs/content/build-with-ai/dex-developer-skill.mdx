# Build with AI using Dex Skills

Dex Skills is the official guidance that teaches a coding agent, such as Codex,
Claude Code, or Cursor, to work with Dex. With it, the agent can design and
build Dex applications, use the public Dex SDK directly, and contribute
official [Connectors](/components/connector). You install it as a Plugin or as
a standalone bundle of three Skills.

The Skills are guidance for the agent only. They contain no runtime code. Dex
Server, Workers, and applications never load them.

:::tip Start with Dex App Builder

For a product, application, or business-process request, start with
**dex-app-builder**. It runs the whole job from start to finish. It loads the
other skills when the job needs SDK or Connector work.

:::

## Requires a coding workspace

Dex Skills is not a hosted application builder. To create or change an
application, run it in Codex or another coding-agent host that gives the agent
a writable repository or project, file-editing tools, and command execution.
The repository can be an existing one or a new, empty one.

In a plain chat without repository and command access, the skills can still
help you work out the business process, design the architecture, and write a
plan for implementation. They cannot create project files, run tests, build
artifacts, or deploy the application. Move the agreed plan into a coding
workspace with a repository before you implement it.

## Choose a skill

| Skill | Role | Use it for |
| --- | --- | --- |
| [**Dex App Builder**](./dex-developer-skill/dex-app-builder.mdx) | **Primary skill** | Work out a process, prototype it, then build and test it locally as a complete application with a Go backend. |
| [**Dex SDK**](./dex-developer-skill/dex-sdk.mdx) | Specialist sub-skill | Build, debug, test, and run Dex applications in Python, Go, Java, TypeScript, or Rust. |
| [**Dex Connector Contributor**](./dex-developer-skill/dex-connector-contributor.mdx) | Specialist sub-skill | Create, test, and contribute official Connector operations, Triggers, and configuration UI units. |

Use **dex-sdk** directly only for a standalone SDK task. Use
**dex-connector-contributor** directly only for standalone work in the official
Dex Connectors Library.

## How the skills work together

Dex App Builder is the main skill. It loads Dex SDK when it starts to design
and build the backend. It uses released Connectors directly. When it confirms
that an official Connector lacks something the application needs, it hands
that work to Dex Connector Contributor. Connector Contributor also loads Dex
SDK when it needs the rules for Flows and Steps.

Install all three Skills together, so that the agent can move between them.
The source and releases are in
[superdurable/dex-skills](https://github.com/superdurable/dex-skills).

## Choose one installation path

Use one of these paths, not both:

1. **Plugin (recommended)** installs all three Skills. You install, update,
   and remove them through the host's plugin marketplace.
2. **Standalone Skills** installs all three Skills directly with the Agent
   Skills CLI.

If you install both, the agent can end up with duplicate copies, and you
cannot tell which version it uses. On the same host, the two installations can
also be invoked with different syntax.

## Trust and permissions

Install agent extensions only from sources you trust. Dex Skills adds no MCP
server, asks for no credentials, and contains no application runtime code. Its
optional hook reads the installed version and the public GitHub release
metadata. If a newer release exists, the hook tells you, but it does not
install it. The agent still needs your permission to create a GitHub fork,
push a branch, open a pull request, or change a running Flow.
