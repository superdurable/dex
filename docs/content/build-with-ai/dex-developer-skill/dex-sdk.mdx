# Dex SDK

Dex SDK was the name of the skill for SDK work in Python, Go, Java,
TypeScript, and Rust. Its guidance is now part of
[Dex App Builder](./dex-app-builder.mdx), which handles both product work and
focused SDK work. See [SDK work](./dex-app-builder.mdx#sdk-work).

## Install and use

[Install Dex Skills](/build-with-ai/dex-developer-skill#install-and-use-dex-skills) once; it installs all three Skills. Invoking `dex-sdk` by name still works, for example in Codex and in Claude Code with the Plugin:

```text
$dex-sdk Diagnose why this Flow retries after the payment Step completes.
/superdurable-dex:dex-sdk Diagnose why this Flow retries after the payment Step completes.
```

The `dex-sdk` skill now holds one instruction: load Dex App Builder and take
its SDK route. Your agent picks Dex App Builder on its own for SDK requests,
so you do not need to name `dex-sdk`. A later Dex Skills release removes it.
