# Quick Start

Run your first Flow, stop its Worker in the middle of a wait, and watch Dex continue the Flow after a restart. It takes about 10 minutes.

## Build it with your coding agent

Copy this prompt into a coding agent that has [Dex Skills](/build-with-ai/dex-developer-skill):

```text
Build the Dex Quick Start app in this folder.

1. Read https://docs.superdurable.io/quick-start.md and treat it as the source
   of truth for package names, commands, and code.
2. Install Dex Skills.
3. Ask which language I want: Python, Go, Java, TypeScript, or Rust.
4. Start dexcli dev, run the Worker, and start one Flow.
5. Stop the Worker while the Flow waits on its Timer, restart it, and show me
   that the Flow completed.

Rules: stay inside this Quick Start. Do not invent APIs. Ask me before
installing anything else.
```

Or follow the steps below yourself.

## 1. Install Dex

```bash
brew install superdurable/tap/dexcli
dexcli dev
```

**dexcli dev** starts Dex Server and Dex Web. [Run Locally](/components/run-locally) lists the addresses and options.

## 5. Stop the Worker

Stop the Worker while the Flow waits on its Timer. Start it again. The Flow completes, and Charge does not run again.

## 6. See the run in Dex Web

Open the Flow in Dex Web. The Execution graph shows each Step that ran:

![Dex Web Execution graph](/img/quick-start/step-graph.png)

The Timeline tab shows the same run's events from left to right:

![Dex Web Timeline](/img/quick-start/timeline.png)

You have run your first durable Flow. Its Worker stopped in the middle of a wait, and the Flow finished without running Charge again.
