# Quick Start

Run your first Flow, stop its Worker in the middle of a wait, and watch Dex continue the Flow after a restart. It takes about 10 minutes.

## What you will build

An order Flow with two Steps:

- **Charge** charges the order through a mock payment API.
- **Ship** waits 30 seconds on a Timer, then ships the order through a mock shipping API.

The mock API prints each call, so the Worker's output shows which Steps ran. You start a Flow, stop the Worker while Ship waits, and start the Worker again. Ship runs when the Timer fires. Charge does not run a second time.

## Before you start

- macOS or Linux. **dexcli** does not run on Windows.
- **dexcli**, installed in step 1.
- The toolchain for your language: Python 3.11 or later with uv, Go, JDK 17 or later, Node.js 22.18 or later, or Rust 1.97 or later.
- Git, to get the example code.

## 2. Read the Flow

The code is already in the folder you cloned. This step and the next one walk through it.

A Flow is a process that Dex runs to completion. Each Step is one unit of work in it. Dex saves the result of each Step, so a Step that finished does not run again.

**Charge** calls the payment API with an idempotency key and moves to **Ship**. **Ship** waits on a 30-second Timer before it runs. The mock API comes in through the constructor.

```python
class Charge(Step[str]):
    def __init__(self, shop: ShopApi) -> None:
        self.shop = shop

    def execute(self, context: Context, input: str) -> StepDecision:
        self.shop.charge(input, idempotency_key=f"charge-{input}")
        return go_to(Ship, input)


class Ship(Step[str]):
    def __init__(self, shop: ShopApi) -> None:
        self.shop = shop

    def wait_for(self, context: Context, input: str) -> Wait:
        return Wait.until(
            Timer.by_duration(timedelta(seconds=30), condition_id=SHIP_DELAY_TIMER)
        )

    def execute(self, context: Context, input: str) -> StepDecision:
        self.shop.ship(input)
        return graceful_complete(f"shipped {input}")


class OrderFlow(Flow[str]):
    def __init__(self, shop: ShopApi) -> None:
        self.charge = Charge(shop)
        self.ship = Ship(shop)

    def get_steps(self) -> StepList[str]:
        return StepList.start_step(self.charge).other_steps(self.ship)
```

```go
// OrderFlow charges an order, waits 30 seconds, and then ships it.
type OrderFlow struct {
	dex.FlowDefaults
	shop *ShopAPI
}

// NewOrderFlow returns an OrderFlow whose Steps call shop.
func NewOrderFlow(shop *ShopAPI) *OrderFlow {
	return &OrderFlow{shop: shop}
}

// GetSteps returns Charge as the start Step, then Ship.
func (flow *OrderFlow) GetSteps() []dex.StepDef {
	return []dex.StepDef{
		dex.DefineStartStep(Charge{shop: flow.shop}),
		dex.DefineStep(Ship{shop: flow.shop}),
	}
}

// GetPersistenceSchema returns an empty schema: OrderFlow keeps no Attributes.
func (*OrderFlow) GetPersistenceSchema() dex.PersistenceSchema {
	return dex.PersistenceSchema{}
}

// Charge charges the order and moves to Ship.
type Charge struct {
	dex.StepDefaultsNoWaitFor[string]
	shop *ShopAPI
}

// Execute charges the order.
func (step Charge) Execute(_ dex.Context, orderID string) (*dex.StepDecision, error) {
	step.shop.Charge(orderID, "charge-"+orderID)
	return dex.GoTo(Ship{}, orderID), nil
}

// Ship waits on a 30-second Timer, then ships the order.
type Ship struct {
	dex.StepDefaults
	shop *ShopAPI
}

// WaitFor waits on the ship-delay Timer.
func (Ship) WaitFor(_ dex.Context, _ string) (*dex.Wait, error) {
	return dex.Until(dex.Timer(30*time.Second, dex.WithConditionID(ShipDelayTimer))), nil
}

// Execute ships the order and completes the Flow.
func (step Ship) Execute(_ dex.Context, orderID string) (*dex.StepDecision, error) {
	step.shop.Ship(orderID)
	return dex.GracefulComplete("shipped " + orderID), nil
}
```

public final class OrderFlow implements Flow<String> {
    public static final String SHIP_DELAY_TIMER = "ship-delay";

    private final Charge charge;
    private final Ship ship;

    public OrderFlow(final ShopApi shop) {
        this.charge = new Charge(shop);
        this.ship = new Ship(shop);
    }

    @Override
    public StepList<String> getSteps() {
        return StepList.startStep(charge).otherSteps(ship);
    }

    static final class Charge implements Step<String> {
        private final ShopApi shop;

        Charge(final ShopApi shop) {
            this.shop = shop;
        }

        @Override
        public Class<String> getInputType() {
            return String.class;
        }

        @Override
        public StepDecision execute(final Context context, final String orderId) {
            shop.charge(orderId, "charge-" + orderId);
            return StepDecision.goTo(Ship.class, orderId);
        }
    }

    static final class Ship implements Step<String> {
        private final ShopApi shop;

        Ship(final ShopApi shop) {
            this.shop = shop;
        }

        @Override
        public Class<String> getInputType() {
            return String.class;
        }

        @Override
        public Wait waitFor(final Context context, final String orderId) {
            return Wait.until(Timer.byDuration(Duration.ofSeconds(30), SHIP_DELAY_TIMER));
        }

        @Override
        public StepDecision execute(final Context context, final String orderId) {
            shop.ship(orderId);
            return StepDecision.gracefulComplete("shipped " + orderId);
        }
    }
}

#[derive(Clone)]
pub struct Charge {
    shop: ShopApi,
}

impl Step for Charge {
    type Input = String;

    fn execute(&self, _context: &mut Context, order_id: String) -> HandlerResult<StepDecision> {
        self.shop.charge(&order_id, &format!("charge-{order_id}"));
        let ship = Ship {
            shop: self.shop.clone(),
        };
        Ok(StepDecision::go_to(&ship, order_id))
    }
}

#[derive(Clone)]
pub struct Ship {
    shop: ShopApi,
}

impl Step for Ship {
    type Input = String;

    fn wait_for(&self, _context: &mut Context, _order_id: String) -> HandlerResult<Wait> {
        let delay = Timer::by_duration(Duration::from_secs(30)).with_id(SHIP_DELAY_TIMER);
        Ok(Wait::until(delay))
    }

    fn execute(&self, _context: &mut Context, order_id: String) -> HandlerResult<StepDecision> {
        self.shop.ship(&order_id);
        Ok(StepDecision::graceful_complete(format!(
            "shipped {order_id}"
        )))
    }
}

#[derive(Clone)]
pub struct OrderFlow {
    pub charge: Charge,
    pub ship: Ship,
}

impl OrderFlow {
    pub fn new(shop: ShopApi) -> Self {
        Self {
            charge: Charge { shop: shop.clone() },
            ship: Ship { shop },
        }
    }
}

impl Flow for OrderFlow {
    type StartInput = String;

    fn steps(&self) -> StepList<'_, String> {
        StepList::start(&self.charge).and(&self.ship)
    }
}

## 3. Add a Worker and a Client

The Worker runs the Steps. It connects out to Dex for work, so it needs no open port. The Client starts Flows.

Both programs build the same Flow and register it. The Client uses that registration to name the Flow type and encode the input. Its copy of the mock API is never called. Both programs also open a blob cache. This local cache keeps copies of large Flow values, so the program does not download them again.

    order_flow = OrderFlow(ShopApi())
    registry = Registry((order_flow,))
    cache = open_cache(Path(".dex-blob-cache/worker"))

```go
func run() (err error) {
	registry, err := dex.NewRegistry([]dex.Flow{quickstart.NewOrderFlow(&quickstart.ShopAPI{})})
	if err != nil {
		return err
	}
	cache, err := quickstart.OpenCache(".dex-blob-cache/worker")
	if err != nil {
		return err
	}
	defer func() { err = errors.Join(err, cache.Close()) }()
	worker, err := dex.NewWorker(registry, cache, dex.WorkerOptions{
		FlowServiceAddress: quickstart.ServerAddress(),
	})
	if err != nil {
		return err
	}
	workerResult := make(chan error, 1)
	go func() { workerResult <- worker.Start() }()

	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()
	startupCtx, cancel := context.WithTimeout(ctx, 30*time.Second)
	defer cancel()
	if err := worker.WaitPullRegistered(startupCtx); err != nil {
		return errors.Join(err, worker.Stop(context.Background()), <-workerResult)
	}
	fmt.Println("Worker is ready. Press Ctrl+C to stop it.")

	select {
	case err := <-workerResult:
		return err
	case <-ctx.Done():
		fmt.Println("Stopping the Worker.")
		return errors.Join(worker.Stop(context.Background()), <-workerResult)
	}
}
```

```rust
fn main() -> Result<(), Box<dyn Error>> {
    let config = QuickStartConfig::from_environment();
    let registry = Registry::new().register(OrderFlow::new(ShopApi::default()))?;
    let cache = open_blob_cache(".dex-blob-cache/worker")?;
    let options = WorkerOptions::new().server_address(config.server_address);
    let worker = Arc::new(Worker::try_new(registry, cache, options)?);
    let running_worker = Arc::clone(&worker);
    let worker_thread = thread::spawn(move || running_worker.start());

    let runtime = tokio::runtime::Builder::new_current_thread()
        .enable_all()
        .build()?;
    let outcome = runtime.block_on(async {
        tokio::time::timeout(Duration::from_secs(30), worker.wait_pull_registered()).await??;
        println!("Worker is ready. Press Ctrl+C to stop it.");
        tokio::signal::ctrl_c().await?;
        println!("Stopping the Worker.");
        Ok::<(), Box<dyn Error>>(())
    });

    worker.stop();
    let stopped = worker_thread
        .join()
        .map_err(|_| "the Worker thread panicked")?;
    outcome?;
    Ok(stopped?)
}
```

## 5. Stop the Worker

Within 30 seconds, press Ctrl+C in the Worker's terminal. Then start the Worker again with the same command.

When the Timer fires, the new Worker prints **Shipped order-...**. It does not print **Charged** again. Dex had saved the result of Charge, so only Ship ran.

A Step can still run more than once. Suppose the Worker stops in the middle of Charge, after the payment call but before Dex saves the result. Dex then runs Charge again. That is why Charge passes an idempotency key: the payment API charges each key only once. [Step guarantees](/concepts/step#guarantees) lists when a Step can run again.
