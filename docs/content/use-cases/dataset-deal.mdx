# Dataset Deal

Go-focused Dataset Deal DSL sample for composing deal Flows.

## Why this shape

Long-running backend processes need durable waits, retries, and external interaction. This use case shows how Dex primitives compose for that problem domain.



## Code examples

Go-only sample with its own UI (not on the shared playground). Run
**examples/go/dex-dataset-deal**, not the default **./dex-samples** binary. HTTP UI
**/products/dataset-deal/...**, API **/products/dataset-deal/api/...**. See
**examples/go/products/dataset-deal/README.md**.

```bash
# from examples/go; needs PostgreSQL on 127.0.0.1:15432 (or DATASET_DEAL_POSTGRES_URL)
docker compose -f dataset-deal/docker-compose.yml up -d --wait
dexcli dev
make bins
./dex-dataset-deal
```
