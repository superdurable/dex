# AI Agent

An AI agent talks with a user, calls tools, and acts on other systems. A real agent session can last for hours or days. It waits for the user, for a person to approve a write, or for a deadline. Dex runs each session as a durable Flow, so the session survives crashes, deploys, and long waits.

**SDKs:** Python · TypeScript

## What Dex adds to an agent

- **The conversation is durable.** Dex stores every message in Attributes. A Worker restart loses nothing.
- **A crash repeats little.** Model calls and tool calls run in Steps. A crash repeats only the Step that was running. Nothing replays the loop.
- **Writes run once.** A tool policy marks each tool as a read or a write. A write that must not repeat gets a single attempt.
- **Approvals can wait.** A tool call that needs approval waits in its own Step, for as long as it takes. No Worker holds the wait.
- **People can see and act.** Dex Web shows each session as a conversation. An operator approves or rejects a tool call there.

## Typical agents

- A support agent that reads orders and asks before it cancels or refunds one.
- An operations agent that reads dashboards and asks before it changes a system.
- A research agent that runs for hours, waits on a durable Timer, and reports back.
- An internal assistant that drafts a plan, waits for review, and then runs it.

## The AI Agent example

The AI Agent example is a general, long-running agent in Python and TypeScript. It uses the built-in agent loop. It chats with a user and calls trusted MCP tools. With a Slack connection, it can also reply in a Slack thread through a [Connector tool](/agent-frameworks/built-in-agent-loop#connect-connectors). It waits for approval before external writes. It asks the user questions, suspends itself on a durable Timer, and drafts plans for review before it runs them. A local demo model lets you try every feature without a provider key.

[Built-in Agent Loop](/agent-frameworks/built-in-agent-loop) walks through its code and shows how to run it. The code is under [examples/python/dex_examples/products/ai-agent](https://github.com/superdurable/dex/tree/main/examples/python/dex_examples/products/ai-agent) and [examples/typescript/src/products/ai-agent](https://github.com/superdurable/dex/tree/main/examples/typescript/src/products/ai-agent).
