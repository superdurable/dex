# Examples

Each example is a complete backend process built with Dex. A design pattern shows one technique. These examples combine several.

After the [Quick Start](/quick-start), start with [Order Processing](/use-cases/order-processing). It grows the Quick Start Flow into a full order process. For agents, start with the [Order Support Agent](/use-cases/order-support-agent).

## Examples

Every example has code in all five SDKs unless its entry names the SDKs it covers.

- [AI Agent](/use-cases/ai-agent) (Python, TypeScript): a general agent on the built-in agent loop, with approvals, questions, and MCP tools
- [Order Support Agent](/use-cases/order-support-agent) (Python, TypeScript): the same order support agent in each agent framework
- [Order Processing](/use-cases/order-processing): charge, seller approval with reminder, ship or refund
- [Subscription and Billing Lifecycle](/use-cases/subscription): trial and billing timers
- [User Onboarding Process](/use-cases/user-onboarding-process): email verification and two ordered setup tasks
- [Money Transfer](/use-cases/money-transfer): saga debit/credit with compensation
- [Job Seeker Engagement](/use-cases/job-seeker-engagement): reminders, opt-out, decline, and accept
- [Deal DSL](/use-cases/deal-dsl): durable deal interpreter for any sellable item
- [Microservice Orchestration](/use-cases/microservice-orchestration): concurrent APIs + channels/timers
- [Job Posting](/use-cases/job-post): locked updates feeding independent FIFO job-board consumers
- [Customer Refund](/use-cases/customer-refund) (Go only): deterministic and agentic refund handling


The runnable code is on GitHub under examples/go, examples/java, examples/python, examples/typescript, and examples/rust. Examples with an HTTP server serve it under /products/name/. You can run most of them from the [examples playground](https://github.com/superdurable/dex/tree/main/examples/playground). Deal DSL and AI agent email have their own UIs and are not on the playground.
