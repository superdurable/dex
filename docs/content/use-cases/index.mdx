# Product Examples

Product-style examples beyond design patterns. Each demonstrates composing Dex primitives for a real backend scenario.

## Shared examples

- [Order processing](/intro/what-is-dex) — charge, seller approval with reminder, ship or refund
- [Money transfer](/use-cases/money-transfer) — saga debit/credit with compensation
- [Microservice orchestration](/use-cases/microservice-orchestration) — concurrent APIs + channels/timers
- [Job seeker engagement](/use-cases/job-seeker-engagement) — reminders, opt-out, decline, and accept
- [Subscription](/use-cases/subscription) — trial and billing timers
- [User onboarding process](/use-cases/user-onboarding-process) — email verification and two ordered setup tasks
- [Job post](/use-cases/job-post) — CRUD with indexed Attributes
- [Shortlist candidates](/use-cases/shortlist-candidates) — opt-in singleton + delayed email

## Language-specific

- [Dataset Deal](/use-cases/dataset-deal) — Go DSL sample
- [AI agent email](/use-cases/ai-agent-email) — Python durable AI email app

Runnable code: examples/go, examples/java, examples/python, examples/typescript, and examples/rust on GitHub (HTTP prefix /products/name/... where applicable). Try shared samples from the examples playground (**examples/playground**); see **examples/README.md**. Dataset Deal and AI agent email have their own UIs and are not on the playground.
