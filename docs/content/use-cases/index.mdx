# Product Examples

Each example is a complete backend process built with Dex. A design pattern shows one technique. These examples combine several.

## Examples

- [AI Agent](/use-cases/ai-agent) — durable agent sessions with approvals, built with the Dex agent loop or an agent framework
- [Subscription & billing lifecycle](/use-cases/subscription) — trial and billing timers
- [User onboarding process](/use-cases/user-onboarding-process) — email verification and two ordered setup tasks
- [Money transfer](/use-cases/money-transfer) — saga debit/credit with compensation
- [Job seeker engagement](/use-cases/job-seeker-engagement) — reminders, opt-out, decline, and accept
- [Deal DSL](/use-cases/deal-dsl) — durable deal interpreter for any sellable item
- [Microservice orchestration](/use-cases/microservice-orchestration) — concurrent APIs + channels/timers
- [Job posting](/use-cases/job-post) — locked updates feeding independent FIFO job-board consumers
- [Customer refund](/use-cases/customer-refund) — deterministic and agentic refund handling

## Related example

- [Order processing](/intro/what-is-dex) — charge, seller approval with reminder, ship or refund

The runnable code is on GitHub under examples/go, examples/java, examples/python, examples/typescript, and examples/rust. Examples with an HTTP server serve it under /products/name/. You can run most of them from the examples playground (**examples/playground**); see **examples/README.md**. Deal DSL and AI agent email have their own UIs and are not on the playground.
