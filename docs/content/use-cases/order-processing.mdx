# Order Processing

Run the order Flow that [Why Dex?](/intro/what-is-dex) describes. You start Dex, run the samples app, start an order over HTTP, approve the shipment, and look at the run in Dex Web.

**SDKs:** Python · Go · TypeScript · Java · Rust

## 1. Start Dex

Start a local Dex with **dexcli dev**, as [Run locally](/components/run-locally) shows. Keep it running.

In a second terminal, get the examples. Every command below runs from the **dex** folder that this creates.

```bash
git clone https://github.com/superdurable/dex.git
cd dex
```


## 2. Flow, Steps, and RPCs

The code below is the Flow from [Why Dex?](/intro/what-is-dex), with its Steps, its approve and describe RPCs, and its Attribute.

Pass the mock payment and shipping API to the Flow constructor, so every Step has them from the moment the Worker registers the Flow. A setter or a global variable leaves a window in which a Step runs without them. See [Pass services to the Flow](/components/application#pass-services-to-the-flow).

Each Step passes an idempotency key built from the order ID, which is also the Flow ID. [Idempotency keys](/concepts/step#idempotency-keys) explains why.

The **order-status** Attribute is indexed, so you can search Flows by status. Its index key, `keyword1`, names a search slot. Each indexed Attribute takes one slot, so the limit on slots matters only when you index many Attributes. [Read and search Attributes](/concepts/primitives/attribute#read-and-search-attributes) explains slots.

Ship's options route its failure to Refund once its retries run out. The second `StepOptions` in that route apply to the Refund Step it moves to, here a short retry.

The `dex:group` and `dex:explanation` comments label each Step in the Flow graph that Dex Web and these docs draw. They do not change what the code does.

order_status = Attribute(
    "order-status",
    str,
    AttributeIndex(IndexType.KEYWORD, "keyword1"),
)
seller_ok = Channel[str]("seller-ok", str)


# dex:group group-id:payment group-label:"Payment"
# dex:explanation text:"Charge the customer for the order."
class Charge(Step[OrderRequest]):
    def __init__(self, service: MyDependencyService) -> None:
        self.service = service

    def get_step_options(self) -> StepOptions:
        return StepOptions(
            execute_retry=RetryPolicy(
                # One hour in production; 3 seconds keeps the demo short.
                total_duration=timedelta(seconds=3),
            )
        )

    def execute(self, context: Context, input: OrderRequest) -> StepDecision:
        self.service.charge_user(
            input.email,
            input.customer_id,
            input.amount,
            idempotency_key=f"charge-{input.order_id}",
        )
        order_status.set(context, "charged")
        return go_to(Ship, input)


# dex:group group-id:shipping group-label:"Shipping"
# dex:explanation text:"Wait for seller approval, remind after 24 hours, then ship the order."
class Ship(Step[OrderRequest]):
    def __init__(self, service: MyDependencyService) -> None:
        self.service = service

    def get_step_options(self) -> StepOptions:
        return StepOptions(
            execute_retry=RetryPolicy(
                # One hour in production; 3 seconds keeps the demo short.
                total_duration=timedelta(seconds=3),
            )
        ).on_execute_failure_proceed_to(
            Refund,
            StepOptions(
                execute_retry=RetryPolicy(
                    # One hour in production; 3 seconds keeps the demo short.
                    total_duration=timedelta(seconds=3),
                )
            ),
        )

    def wait_for(self, context: Context, input: OrderRequest) -> Wait:
        return Wait.any_of(
            seller_ok.for_one(),
            Timer.by_duration(timedelta(hours=24)),
        )

    def execute(self, context: Context, input: OrderRequest) -> StepDecision:
        if context.has_timer_fired():
            self.service.send_email(
                input.email,
                "Reminder: approve shipment",
                "Please approve or provide a tracking number.",
            )
            return go_to(Ship, input)
        self.service.ship_item(
            input.order_id,
            input.test_fail_at_shipping,
            idempotency_key=f"ship-{input.order_id}",
        )
        order_status.set(context, "shipped")
        return graceful_complete(f"shipped:{input.order_id}")


# dex:group group-id:refund group-label:"Refund"
# dex:explanation text:"Refund the order when shipping keeps failing."
class Refund(Step[OrderRequest]):
    def __init__(self, service: MyDependencyService) -> None:
        self.service = service

    def execute(self, context: Context, input: OrderRequest) -> StepDecision:
        self.service.update_external_system(
            f"refund {input.order_id}", idempotency_key=f"refund-{input.order_id}"
        )
        order_status.set(context, "refunded")
        return graceful_complete(f"refunded:{input.order_id}")


class OrderProcessingFlow(Flow[OrderRequest]):
    def __init__(self, service: MyDependencyService) -> None:
        self.service = service
        self.refund = Refund(service)
        self.ship = Ship(service)
        self.charge = Charge(service)

    def get_steps(self) -> StepList[OrderRequest]:
        return StepList.start_step(self.charge).other_steps(self.ship, self.refund)

    def get_persistence_schema(self) -> PersistenceSchema:
        return PersistenceSchema.of(order_status, seller_ok)

    @rpc
    def approve(self, context: Context, _note: str) -> RPCResult[str]:
        seller_ok.publish(context, "approved")
        return RPCResult("ok")

    @rpc
    def describe(self, context: Context) -> RPCResult[str]:
        return RPCResult(order_status.get(context))

	return []dex.RPCDef{
		dex.DefineRPC(flow.Approve, nil),
		dex.DefineRPC(flow.Describe, nil),

	}

	ctx dex.Context,
	_ string,

		return nil, err

		return nil, err
	}
	return &dex.RPCResult[string]{Output: status}, nil

pub struct OrderProcessingFlow {
    charge: Charge,
    ship: Ship,
    refund: Refund,
}

impl OrderProcessingFlow {
    pub fn new(service: MyDependencyService) -> Self {
        Self {
            charge: Charge {
                service: service.clone(),
            },
            ship: Ship {
                service: service.clone(),
            },
            refund: Refund { service },
        }
    }

    fn approve(&self, context: &mut Context, _note: String) -> HandlerResult<RpcResult<String>> {
        SELLER_OK.publish(context, "approved".to_string())?;
        Ok(RpcResult::new("ok".to_string()))
    }

    fn describe(&self, context: &mut Context) -> HandlerResult<RpcResult<String>> {
        Ok(RpcResult::new(ORDER_STATUS.get_required(context)?))
    }
}

impl Default for OrderProcessingFlow {
    fn default() -> Self {
        Self::new(MyDependencyService::default())
    }
}

impl Flow for OrderProcessingFlow {
    type StartInput = OrderRequest;

    fn flow_type(&self) -> &'static str {
        "OrderProcessingFlow"
    }

    fn steps(&self) -> StepList<'_, Self::StartInput> {
        StepList::start(&self.charge)
            .and(&self.ship)
            .and(&self.refund)

        PersistenceSchema::new()
            .attribute(&ORDER_STATUS)
            .channel(&SELLER_OK)

        RpcList::new()
            .function(APPROVE_ORDER, Self::approve)
            .function_without_input(DESCRIBE_ORDER, Self::describe)
    }
}

## 3. Worker and Client

Create a Registry, a Worker, and a Client that connect to `dexcli` at **127.0.0.1:8801**. Construct the Flow with the mock API service, then register it. The samples app registers every example Flow in one Registry, so the snippets below show only the lines for this Flow where they can. The Python samples app runs on an async web framework, so it uses `AsyncWorker` and `AsyncClient`. The [Quick Start](/quick-start) uses the synchronous **Worker** and **Client**, which work the same way.

The Worker connects out to `dexcli` to receive tasks, so it needs no open inbound port.

## 4. Controller

The HTTP controller has three handlers:

- **start** starts the Flow, then waits for the Charge Step with the Client **wait-for-Step-completion** API.
- **approve** calls the **approve** RPC, which publishes the approval to the seller Channel.
- **describe** calls the **describe** RPC, which reads **order-status**.

The controller gets the Client and the Flow from its constructor or factory arguments.

	controller := &controller{client: client, flow: flow}
	group := router.Group("/products/order-processing")
	group.GET("/start", controller.start)

	group.GET("/describe", controller.describe)

func (controller *controller) start(request *gin.Context) {
	flowID := httputil.NewFlowID("order-processing")
	input := OrderRequest{
		OrderID:            flowID,
		Email:              "buyer@example.com",
		CustomerID:         "customer-1",
		Amount:             42,
		TestFailAtShipping: request.Query("testFailAtShipping") == "true",
	}
	runID, err := controller.client.StartFlow(
		request.Request.Context(),
		controller.flow,
		flowID,
		input,
		sdk.StartFlowOptions{},
	)
	if err != nil {
		httputil.Respond(request, nil, err)
		return
	}
	waitContext, cancelWait := context.WithTimeout(request.Request.Context(), 5*time.Minute)
	defer cancelWait()
	err = controller.client.WaitForStepCompletion(
		waitContext,
		flowID,
		sdk.StepExecutionID{StepType: ChargeStepType},
		sdk.WaitForStepCompletionOptions{},
	)
	httputil.Respond(request, gin.H{"flowID": flowID, "runID": runID}, err)
}

func (controller *controller) approve(request *gin.Context) {
	flowID, found := requiredFlowID(request)
	if !found {
		return
	}
	var output string
	err := controller.client.InvokeRPC(
		request.Request.Context(),
		flowID,
		controller.flow.Approve,
		request.Query("notes"),
		&output,
	)
	httputil.Respond(request, output, err)
}

func (controller *controller) describe(request *gin.Context) {
	flowID, found := requiredFlowID(request)
	if !found {
		return
	}
	var output string
	err := controller.client.InvokeRPC(
		request.Request.Context(),
		flowID,
		controller.flow.Describe,
		nil,
		&output,
	)
	httputil.Respond(request, gin.H{"flowID": flowID, "status": output}, err)
}

// requiredFlowID reads the Flow ID from flowId, or from its alias workflowId.
func requiredFlowID(request *gin.Context) (string, bool) {
	if flowID := request.Query("workflowId"); flowID != "" {
		return flowID, true
	}
	return httputil.RequiredQuery(request, "flowId")
}

@RestController
@RequestMapping("/products/order-processing")
public class OrderProcessingController {
    private final Client client;
    private final OrderProcessingFlow flow;

    public OrderProcessingController(
            final Client client,
            final OrderProcessingFlow flow) {
        this.client = client;
        this.flow = flow;
    }

    @GetMapping("/start")
    public ResponseEntity<Map<String, String>> start(
            @RequestParam(defaultValue = "false") final boolean testFailAtShipping) {
        final String flowId = "order-processing-" + System.nanoTime();
        final OrderRequest request = new OrderRequest(
                flowId,
                "buyer@example.com",
                "customer-1",
                42,
                testFailAtShipping);
        final String runId = client.startFlow(flow, flowId, request, ExampleFlows.startOptions());
        client.waitForStepCompletion(
                flowId,
                StepExecutionId.of("Charge"),
                WaitForStepCompletionOptions.newBuilder().build());
        final Map<String, String> response = new LinkedHashMap<String, String>();
        response.put("flowID", flowId);
        response.put("runID", runId);
        return ResponseEntity.ok(response);
    }

    @GetMapping("/approve")
    public ResponseEntity<String> approve(
            @RequestParam(required = false) final String flowId,
            @RequestParam(required = false) final String workflowId,
            @RequestParam(defaultValue = "") final String notes) {
        final OrderProcessingFlow stub =
                client.newRpcStub(OrderProcessingFlow.class, requiredFlowId(flowId, workflowId));
        return ResponseEntity.ok(client.invokeRPC(stub::approve, notes));
    }

    @GetMapping("/describe")
    public ResponseEntity<Map<String, String>> describe(
            @RequestParam(required = false) final String flowId,
            @RequestParam(required = false) final String workflowId) {
        final String requiredFlowId = requiredFlowId(flowId, workflowId);
        final OrderProcessingFlow stub = client.newRpcStub(OrderProcessingFlow.class, requiredFlowId);
        final String status = client.invokeRPC(stub::describe);
        final Map<String, String> response = new LinkedHashMap<String, String>();
        response.put("flowID", requiredFlowId);
        response.put("status", status);
        return ResponseEntity.ok(response);
    }

    /** Returns the Flow ID from flowId, or from its alias workflowId. */
    private static String requiredFlowId(final String flowId, final String workflowId) {
        if (workflowId != null && !workflowId.isEmpty()) {
            return workflowId;
        }
        if (flowId == null || flowId.isEmpty()) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "flowId is required");
        }
        return flowId;
    }

export function createOrderProcessingRouter(
  client: Client,
  flow: OrderProcessingFlow,
): Router {
  const router = Router();

  router.get("/start", async (request, response) => {
    const flowId = `order-processing-${process.hrtime.bigint()}`;
    const input: OrderRequest = {
      orderId: flowId,
      email: "buyer@example.com",
      customerId: "customer-1",
      amount: 42,
      testFailAtShipping: String(request.query.testFailAtShipping ?? "") === "true",
    };
    const runId = await client.startFlow(flow, flowId, input, startOptions());
    await client.waitForStepCompletion(
      flowId,
      StepExecutionId.of("Charge"),
      {},
    );
    response.json({ flowID: flowId, runID: runId });
  });

  router.get("/approve", async (request, response) => {
    const flowId = flowIdFromQuery(request.query);
    const notes = String(request.query.notes ?? "");
    const output = await client.invokeRPC(flow.approve, flowId, notes);
    response.json(output);
  });

  router.get("/describe", async (request, response) => {
    const flowId = flowIdFromQuery(request.query);
    const status = await client.invokeRPC(flow.describe, flowId);
    response.json({ flowID: flowId, status });
  });

  return router;
}

/** Reads the Flow ID from flowId, or from its alias workflowId. */
function flowIdFromQuery(query: Record<string, unknown>): string {
  return String(query.workflowId ?? query.flowId ?? "");
}

async fn start(
    State(state): State<OrderProcessingState>,
    Query(query): Query<StartQuery>,
) -> impl IntoResponse {
    let OrderProcessingState { client, flow } = state;
    match run_blocking(move || {
        let flow_id = new_flow_id("order-processing");
        let input = OrderRequest {
            order_id: flow_id.clone(),
            email: "buyer@example.com".into(),
            customer_id: "customer-1".into(),
            amount: 42,
            test_fail_at_shipping: query.test_fail_at_shipping,
        };
        let run_id = client.start_flow(&flow, &flow_id, input)?;
        client.wait_for_step_completion(
            &flow_id,
            StepExecutionId::of(&Charge::default()),
            WaitForStepCompletionOptions::new(),
        )?;
        Ok(StartResponse { flow_id, run_id })
    }) {
        Ok(value) => ok_json(value),
        Err(error) => map_sdk_error(error).into_response(),
    }
}

async fn approve(
    State(state): State<OrderProcessingState>,
    Query(query): Query<WorkflowQuery>,
) -> impl IntoResponse {
    let flow_id = query.flow_id();
    let notes = query.notes;
    match run_blocking(move || state.client.invoke_rpc(&flow_id, APPROVE_ORDER, notes)) {
        Ok(value) => ok_json(value),
        Err(error) => map_sdk_error(error).into_response(),
    }
}

async fn describe(
    State(state): State<OrderProcessingState>,
    Query(query): Query<WorkflowQuery>,
) -> impl IntoResponse {
    let flow_id = query.flow_id();
    match run_blocking(move || {
        state
            .client
            .invoke_rpc_without_input(&flow_id, DESCRIBE_ORDER)
            .map(|status| json!({ "flowID": flow_id, "status": status }))
    }) {
        Ok(value) => ok_json(value),
        Err(error) => map_sdk_error(error).into_response(),
    }
}

### Try the refund path

Start an order whose shipping always fails:

```bash
curl -s 'http://127.0.0.1:8080/products/order-processing/start?testFailAtShipping=true'
```

Approve it as before. The Ship Step fails and retries for 3 seconds; the example shortens the one-hour production window so the demo ends quickly. Then the Flow moves to the Refund Step, which refunds the buyer and completes the Flow. Read its status:

```bash
curl -s "http://127.0.0.1:8080/products/order-processing/describe?flowId=FLOW_ID"
```

The status is **refunded**. In Dex Web, the Execution graph shows Charge, Ship, and then Refund.
