# Flow

**Flow** is the top-level durable program in Dex. A Flow owns typed Steps, a persistence schema of [Attributes](/primitives/attribute) and [Channels](/primitives/channel), and optional [RPC](/primitives/rpc) handlers.

- [Basics](/primitives/flow/basic) — identifiers, the Flow interface, and how Steps and persistence fit together
- [Flow options](/primitives/flow/flow-options) — **StartFlowOptions**, **FlowConfig**, timeout, retry, and runtime overrides

Runnable samples live under **examples/go**, **examples/java**, **examples/python**, **examples/typescript**, and **examples/rust**.
