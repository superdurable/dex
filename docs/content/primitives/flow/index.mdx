# Flow

**Flow** is the top-level primitive and concept in Dex.

A Flow is usually a business entity. It contains some [Steps](/primitives/step), a persistence schema of [Attributes](/primitives/attribute) and [Channels](/primitives/channel), and optional [RPC](/primitives/rpc) handlers.

- [Basics](/primitives/flow/basic) — basic concepts and interface
- [Flow options](/primitives/flow/flow-options) — advanced **StartFlowOptions**, **FlowConfig**
