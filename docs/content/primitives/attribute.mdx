# Attribute basics

An **Attribute** lets you store data within a Flow execution.

Dex Attributes make it easy to store data. This is especially useful for intermediate data during a Flow execution, without the work of setting up and managing a database dependency.

Each Attribute exists only for the lifetime of its Flow execution. Dex deletes it when it deletes the execution history, after the configurable retention period following Flow closure.

However, Dex allows you to sync Attribute values to your application database as permanent storage. This also lets you build more powerful database indexes to query Attributes.

## Define an Attribute {#define-an-attribute}

Define Attributes on the Flow, then list them in its persistence schema. That declaration is the contract for the Flow's durable state. Dex rejects a Step, RPC, or Client that tries to use an undeclared Attribute.

A handler reads the values from its current invocation and stages writes in the same invocation. If the handler attempt fails, the staged writes do not become Flow state. If it returns normally, Dex commits the writes together with the resulting Step decision or RPC result.

class AttributeStep(Step[str]):
    def __init__(self, flow: "AttributeFlow") -> None:
        self.flow = flow

    def wait_for(self, context: Context, input: str) -> Wait:
        self.flow.message.set(context, input)
        return Wait.skip_immediately()

    def execute(self, context: Context, input: str) -> StepDecision:
        del input
        return graceful_complete(self.flow.message.get(context))


class AttributeFlow(Flow[str]):
    message = Attribute("primitive-attribute-message", str)

    def __init__(self) -> None:
        self.start = AttributeStep(self)

    def get_steps(self) -> StepList[str]:
        return StepList.start_step(self.start)

    def get_persistence_schema(self) -> PersistenceSchema:
        return PersistenceSchema.of(self.message)

var Message = dex.DefineAttribute[string](messageAttributeName)

type AttributeFlow struct {
	dex.FlowDefaults
}

func (*AttributeFlow) GetPersistenceSchema() dex.PersistenceSchema {
	return dex.PersistenceSchema{Attributes: []dex.AttributeDef{Message}}
}

type attributeStep struct {
	dex.StepDefaults
}

func (attributeStep) WaitFor(ctx dex.Context, input string) (*dex.Wait, error) {
	if err := Message.Set(ctx, input); err != nil {
		return nil, err
	}
	return dex.SkipWaitImmediately(), nil
}

func (attributeStep) Execute(ctx dex.Context, _ string) (*dex.StepDecision, error) {
	value, err := Message.Get(ctx)
	if err != nil {
		return nil, err
	}
	return dex.GracefulComplete(value), nil
}

    private final Attribute<String> message =
            Attribute.define("primitive-attribute-message", String.class);
    private final AttributeStep start = new AttributeStep();

    @Override
    public StepList<String> getSteps() {
        return StepList.startStep(start);

    @Override
    public PersistenceSchema getPersistenceSchema() {
        return PersistenceSchema.of(message);
    }

    final class AttributeStep implements Step<String> {
        @Override
        public Wait waitFor(final Context context, final String input) {
            message.set(context, input);
            return Wait.skipImmediately();
        }

        @Override
        public StepDecision execute(final Context context, final String input) {
            return StepDecision.gracefulComplete(message.get(context));
        }
    }
}

class AttributeStep implements Step<string> {
  public readonly inputCodec = stringCodec;

  public constructor(private readonly flow: AttributeFlow) {}

  public getStepType(): string {
    return "AttributeStep";
  }

  public waitFor(context: Context, input: string): Wait {
    this.flow.message.set(context, input);
    return Wait.skipImmediately();
  }

  public execute(context: Context, _input: string): StepDecision {
    return gracefulComplete(this.flow.message.get(context));
  }
}

export class AttributeFlow implements Flow<string> {
  public readonly message = new Attribute("primitive-attribute-message", stringCodec);
  private readonly start = new AttributeStep(this);

  public getSteps() {
    return StepList.startStep(this.start);
  }

  public getPersistenceSchema(): PersistenceSchema {
    return { attributes: [this.message] };
  }
}

#[derive(Default)]
struct AttributeStep;

impl Step for AttributeStep {
    type Input = String;

    fn wait_for(&self, context: &mut Context, input: Self::Input) -> HandlerResult<Wait> {
        message().set(context, input)?;
        Ok(Wait::skip_immediately())
    }

    fn execute(&self, context: &mut Context, _input: Self::Input) -> HandlerResult<StepDecision> {
        Ok(StepDecision::graceful_complete(
            message().get_required(context)?,
        ))
    }

## What should be an Attribute? {#what-should-be-an-attribute}

| Value | Use it when |
| --- | --- |
| **Attribute** | The Flow needs durable state that more than one Step, RPC, or Client can read or update. |
| **Step input and output** | The value only moves along a particular Step path. |
| **Step execution local** | The value only belongs to one Step execution. |
| **Channel** | You need to deliver one or more messages, not hold the latest state. |

An Attribute is the latest value, not an event log. Do not append every business event to one large Attribute. Use a Channel for messages, or store a large body in your own database or Blob Store and keep a small identifier in the Attribute.

## Initial state and Client access {#initial-state-and-client-access}

**StartFlowOptions** can set initial Attributes when the Flow is created. Initial values and Flow creation are one operation, so the first Step sees them immediately. See [Flow options](/primitives/flow/flow-options#attributes).

Clients use **GetAttributes** and **SetAttributes** with the same registered Attribute definition. A Client can also use **WaitForAttributeEqual** to wait until a singleton Attribute or one AttributeMap instance reaches a scalar value. These are Flow operations through Dex Server; they do not read or write an application database directly. See [Client APIs](/primitives/client-apis).

## AttributeMap {#attributemap}

An **AttributeMap** is a family of Attributes with keys decided at runtime. Define and register the map once, then provide an instance key for each read, write, deletion, or lock.

For example, an invoice Flow may have one **payment-status** map. **payment-status** for **invoice-1** and **payment-status** for **invoice-2** are independent durable values. Updating one does not rewrite the other. An AttributeMap is useful for a changing set of small values; it is not a replacement for a queryable application table.

The map name and instance key form Dex's physical Attribute name. Dex escapes the instance key, so application code should always use the SDK definition instead of constructing that name itself. You can list the existing instance keys from a Step or RPC. The list includes writes staged by that invocation.
