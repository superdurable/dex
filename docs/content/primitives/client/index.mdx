# Client

**Client** is how application code outside a Worker interact with Dex Server on Flow executions.

- [Client basics](/primitives/client/basic) covers starting and stopping a Flow, calling an RPC, and reading or writing an Attribute.
- [Client advanced](/primitives/client/advanced) covers Channel input, waits, inspection, search, and operator controls.
