# Glossary

Short definitions of Dex terms. Use these terms, not the older Workflow and State names.

#### [Attribute](/concepts/primitives/attribute)

A durable, typed variable on a Flow. You can index it for search.

#### [Channel](/concepts/primitives/channel)

A durable message pipe. It carries messages from outside a Flow, or between parts of one Flow.

#### [Condition](/concepts/step#waitfor-and-execute)

What a Step waits for, returned from WaitFor: a Timer, a Channel, or a combination of them.

#### [dexcli](/quick-start)

The Dex CLI, installed with Homebrew. It runs server-zd and Dex Web on your machine.

#### [Execute](/concepts/step#waitfor-and-execute)

The Step method that runs after the WaitFor condition is met, or right away when the Step has no WaitFor.

#### [Flow](/concepts/flow)

The top-level durable program. It contains Steps, Attributes, Channels, and RPCs.

#### [Flow ID](/concepts/flow#identifiers)

The ID that your application assigns to a Flow run.

#### [GetAttributes](/reference/server/runtime-client#read-attributes)

A Client API that reads committed Attribute values from outside a Flow. It does not need a Worker.

#### [InvokeRPC](/concepts/primitives/rpc)

A Client API that calls a Flow's RPC handler on the Worker.

#### [Locking](/concepts/primitives/attribute#locking)

Making Steps and RPCs that access the same Attributes run one at a time.

#### [Movement](/concepts/step#stepdecision-movements)

A decision to go to another Step, or to complete or fail the Flow.

#### [Time Travel](/components/application)

Restarting a Flow run from an earlier Step, after a fix. The run keeps its Run ID.

#### [RPC](/concepts/primitives/rpc)

A Worker handler that reads or writes a running Flow from outside.

#### [Run ID](/concepts/flow#identifiers)

The ID that the engine assigns to each run of a Flow ID.

#### [Step](/concepts/step)

The unit of durable control flow. It has an optional WaitFor and an Execute.

#### [Step execution](/reference/server/runtime-client#wait-for-a-step)

One run of a Step type, identified by **step_type** and a number.

#### [Timer](/concepts/primitives/timer)

A durable sleep condition. When it fires, the waiting Step resumes.

#### [WaitFor](/concepts/step#waitfor-and-execute)

The Step method that registers the durable Conditions to wait for before Execute.

#### [Worker](/components/application)

The process that hosts Flow definitions and runs WaitFor, Execute, and RPC handlers.
