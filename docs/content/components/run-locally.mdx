# Run Locally

**dexcli dev** runs a complete Dex on your machine: Dex Server and Dex Web. Use it to build and test Flows before you deploy.

## Install dexcli

**dexcli** runs on macOS and Linux, on amd64 and arm64. Windows is not supported.

With Homebrew, on macOS or Linux:

```bash
brew install superdurable/tap/dexcli
brew update && brew upgrade superdurable/tap/dexcli   # when you want the latest
```

Without Homebrew, download the archive for your system from the [**dexcli** releases](https://github.com/superdurable/dex/releases?q=cli-v&expanded=true). Each release has a **cli-v** tag and one archive per system, such as **dexcli_v1.45.0_linux_amd64.tar.gz**. The archive holds **dexcli** and **dex-server-zd**. Keep both files in the same directory on your **PATH**:

```bash
tar xzf dexcli_v1.45.0_linux_amd64.tar.gz
sudo mv dexcli dex-server-zd /usr/local/bin/
dexcli version
```

The release also has **checksums.txt** to verify the download.

## Start Dex

```bash
dexcli dev
```

**dexcli dev** starts **Dex Server** (server-zd) and **Dex Web**. It stores state
on local disk, in **RocksDB** and an embedded **s3local** object store. When the
default ports are free, the addresses are:

| Service | Address |
| --- | --- |
| Dex Web | **http://127.0.0.1:8802** |
| Dex Server | **127.0.0.1:8801** |

## Run a second Dex

A second **dexcli dev** on the same machine picks other free ports and its own
state directory. Pass the **Dex Server** address that it prints to **--server**.
