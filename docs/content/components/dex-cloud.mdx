# Run on Dex Cloud

In Dex Cloud, Super Durable runs Dex Server for your application. Your Workers still run your Flow code, on your servers, your cloud, or your laptop.

## Get started {#get-started}

[Sign up for Dex Cloud](https://dex.superdurable.io/register), then create a server. For pricing, regions, and SLA, [contact Super Durable](https://superdurable.io/about/#contact).

## Connect Workers and Clients {#connect}

Each server you create in Dex Cloud has its own endpoint and API key. Your Workers and Clients connect to that endpoint over TLS with the key:

- The key goes in an [API key credential](/reference/server/authentication#sdk-credentials).
- TLS is the SDK's [TLS option](/reference/server/authentication#tls).

## What runs where {#what-runs-where}

The credentials your code uses for your own APIs stay in your Workers. [Where to run Dex Server](/components#where-to-run) compares Dex Cloud with a self-hosted server.
