# Running Dex in Depth

[Run Dex](/components) summarizes each component on one page. These pages hold the full detail for each one.

## Pages in this group {#pages}

- [Run Locally](/components/run-locally): install `dexcli` with or without Homebrew, start **dexcli dev**, and fix a port or connection problem.
- [Your Application](/components/application): add the SDK to a service, start a Worker, pass services to a Flow, and start Flows from a handler.
- [Dex Server](/components/server): what the server depends on, how it stores Flows, and what it does when a dependency fails.
- [CLI (dexcli)](/components/cli): what each `dexcli` command does.
- [Web (Dex Web)](/components/web): what Dex Web shows and how to run it in production.
- [Failover and Deploys](/concepts/failover-and-deploys): what runs again for each event, from a Worker crash to Time Travel.
