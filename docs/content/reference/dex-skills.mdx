# Dex Skills in Depth

Dex Skills teaches a coding agent to work with Dex. [Build with AI](/build-with-ai/dex-developer-skill)
installs the Skills and says which one to start with. Each page below covers one
Skill in full: when to call it, what it checks, and what it hands off.

- [Dex App Builder](/build-with-ai/dex-developer-skill/dex-app-builder): builds a complete Dex application, from the business process to a tested Go backend.
- [Dex SDK](/build-with-ai/dex-developer-skill/dex-sdk): builds, debugs, tests, and runs Dex applications in Python, Go, Java, TypeScript, or Rust.
- [Dex Connector Contributor](/build-with-ai/dex-developer-skill/dex-connector-contributor): creates, tests, and contributes official Connector operations, Triggers, and configuration UI units.
