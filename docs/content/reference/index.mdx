# Developer Reference

The Developer Reference holds the details that change from release to release:
configuration keys, flags, defaults, limits, metrics, edge cases, and version
differences. For the concepts, see [Concepts](/concepts) and
[Components](/components).

## Check your version first

Each component has its own reference. Before you rely on a detail, check
which version of the component you run. Each reference opens at the latest
release. To read another version, use the version selector in the left sidebar,
under the component. The [compatibility matrix](#compatibility-matrix) lists
the supported component combinations.

Dex releases follow a shared release train. A release tags only the components
that changed, so a component can skip minor numbers. When this reference names
release N for a component, it means that component's newest release at or
below N.

## SDK topic pages {#flows-and-steps}

Each SDK reference has one page for each topic in [Concepts](/concepts): Flow,
Step, Attribute, RPC, Channel, Stream, Timer, SubFlow, and Client. More pages
cover StartFlowOptions, StepOptions, Step decisions, waits, failure and
retries, and Workers. Each page uses the names and code of its language:
[Go](/reference/go/), [Python](/reference/python/), [Java](/reference/java/),
[TypeScript](/reference/typescript/), and [Rust](/reference/rust/).

## Compatibility matrix

Workers and Clients negotiate a protocol version with the server. server-zd
0.1.17 and newer provide protocol version 4.

| Component | Version | server-zd it needs |
| --- | --- | --- |
| Go, Python, Java, TypeScript, and Rust SDKs | 1.37, 1.35 | 0.1.17 or newer (protocol version 4) |
| Dex Web | 1.37, 1.35 | 0.1.17 or newer (protocol version 4) |

server-zd protocol version 4 does not raise the minimum protocol. SDK releases
before 1.35 keep working on server-zd 0.1.17 and newer. Upgrade the server
first, then the SDKs. See
[Upgrades and compatibility](/reference/server/upgrades).

Each `dexcli` release bundles one server-zd release, which **dexcli dev**
runs:

| dexcli | Bundled server-zd |
| --- | --- |
| 1.37 | 0.1.20 |
| 1.36 | 0.1.19 |
| 1.35 | 0.1.18 |
| 1.34 | 0.1.16 |
| 1.33 | 0.1.15 |

To run SDK 1.35 applications with **dexcli dev**, use `dexcli` 1.35 or newer.

## Release notes

Each component publishes release notes on GitHub, in
[Dex releases](https://github.com/superdurable/dex/releases). The server-zd
notes of every release list breaking changes, features, fixes, and upgrade
steps.
