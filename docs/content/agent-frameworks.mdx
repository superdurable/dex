# Durable Agents

Dex runs an AI agent as a durable agent session. Build the agent with the built-in agent loop of Dex Agents, or keep one you already wrote with an agent framework; both run on the same session Flow.

A durable agent on Dex has three parts:

- **Your app:** a web app or API that uses a Dex Client to start sessions, send messages, and stream replies.
- **Dex Server:** stores each session and hands its work to Workers. It runs in Dex Cloud or on your own infrastructure.
- **Your agent Worker:** your agent, written with your framework or the built-in loop, running through the Dex Agents adapter.

<AgentStackDiagram markdownDescription="Your app, a web app or API with a Dex Client, starts and drives sessions on Dex Server, which runs in Dex Cloud or self-hosted. Your agent keeps its framework and code. Dex runs each session as a Flow and records every model call, tool call, and approval as a Step when it finishes. After a Worker crash or a deploy, the session picks up after the last finished call.

## What Dex adds to your agent {#what-dex-adds}

Dex keeps your agent code and makes each session durable:

- **Durable sessions.** A session continues after a crash or a deploy from its last finished model call or tool call.
- **Tool calls with a policy.** Each tool call runs in its own Step: reads retry, and writes that are not idempotent run at most once.
- **Approvals that wait.** A call that needs a person waits for minutes or days, across restarts and deploys.
- **Connectors as tools.** The agent calls official Connector operations under the same tool policies.
- **Observability and control.** Dex Web shows each session, tracing covers each model call and tool call, and spend limits check model spend.

To see it, run the [Agent Quick Start](/agent-frameworks/quick-start). [Dex vs. Temporal](/intro/compared-to-durable-execution#agent-frameworks-on-a-durable-execution-engine) compares Dex with Temporal, framework checkpointers, and other engines, and the [Glossary](/glossary) defines the terms these pages use.
