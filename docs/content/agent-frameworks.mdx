# Durable Agents

Dex runs an AI agent as a durable agent session. You can build the agent with the built-in agent loop of Dex Agents, or keep an agent that you already wrote with an agent framework. Both run on the same session Flow, so sessions behave the same either way.

## Do you need this? {#do-you-need-this}

An agent that only answers questions in one request may not. A durable session helps when one of these can happen to your agent:

- **A crash or a deploy in the middle of a conversation.** Without Dex, the process loses the turn in progress, and the user has to ask again. With Dex, the session continues from the last finished model call or tool call.
- **A write tool runs twice.** A retry after a timeout can send a second email or a second refund. Dex runs a non-idempotent write at most once, with [one narrow exception](/agent-frameworks/tool-calls#tool-runs-twice). When a write may or may not have happened, Dex records an unknown outcome instead of running it again.
- **A person must approve a call.** The approval may take minutes or days. Dex keeps the call waiting without a running process.
- **A long wait between turns.** A session waits for the next message for as long as it needs, without holding a Worker.

Many agent frameworks can save the conversation after each step, with a checkpointer. That restores the messages after a crash. A checkpointer does not classify tools, so after a crash it cannot tell whether a write already ran. Dex gives each tool a policy, runs each call in its own Step, and records each call's outcome. You keep your framework.

To see it, run the [Agent Quick Start](/agent-frameworks/quick-start), or read the two complete examples: [AI Agent](/use-cases/ai-agent), a general agent on the built-in loop, and [Order Support Agent](/use-cases/order-support-agent), the same agent on each framework.

## Dex terms on these pages {#dex-terms}

| Term | Meaning |
| --- | --- |
| **Flow** | A durable process that Dex runs to completion. One agent session is one Flow run, and the session ID is its Flow ID. |
| **Step** | One unit of work in a Flow. Dex records each Step's result, so a Step that finished does not run again. |
| **Worker** | Your process that runs the Steps. It connects out to Dex, so it needs no open port. |
| **Client** | The part of your app that starts sessions and calls them. |
| **Attribute** | A named value that a Flow keeps. A session keeps its conversation and tool calls in Attributes. |
| **RunModel** | The Step that makes a model call. |
| **CallTool** | The Step that runs a read or an idempotent write. Dex may retry it. |
| **CallSingleAttemptTool** | The Step that runs any other write. Dex runs it at most once. |
| **AwaitToolApproval** | The Step that waits for a person to approve a tool call. It holds no Worker. |
| **ResumeTurn** | The Step that waits for every tool result of a model response, then calls the model again. |

## Choose a harness {#choose-a-harness}

A harness is the code that runs the agent loop: the built-in loop or a framework. Each framework link opens the Agent Quick Start on that framework's tab, with a runnable example and the steps to run it locally.

| Harness | Languages | How the loop maps onto Steps | Choose it when |
| --- | --- | --- | --- |
| [Claude Agent SDK](/agent-frameworks/quick-start/?framework=claude-agent-sdk) | Python, TypeScript | The Claude Code CLI runs a turn segment in one **RunModel** Step. Reads run inside it. A write ends the segment and runs in its own Step. | You want the Claude Code agent loop and its tools. |
| [Google ADK](/agent-frameworks/quick-start/?framework=google-adk) | Python | One model call per **RunModel** Step. Each tool call is its own Step. | You have a Google ADK agent. |
| [LangChain and LangGraph](/agent-frameworks/quick-start/?framework=langchain-langgraph) | Python | One **RunModel** Step runs the graph to its next tool calls. Each tool call is its own Step. | You have a LangChain **create_agent** agent or a LangGraph graph. |
| [Mastra](/agent-frameworks/quick-start/?framework=mastra) | TypeScript | One model call per **RunModel** Step. Each agent tool call is its own Step. | You have a Mastra agent. |
| [OpenAI Agents SDK](/agent-frameworks/quick-start/?framework=openai-agents-sdk) | Python, TypeScript | One model call per **RunModel** Step. Each function tool call is its own Step. | You have an OpenAI Agents SDK agent, with or without handoffs. |
| [Pydantic AI](/agent-frameworks/quick-start/?framework=pydantic-ai) | Python | One model call per **RunModel** Step. Each tool call is its own Step. | You have a Pydantic AI agent. |
| [Vercel AI SDK](/agent-frameworks/quick-start/?framework=vercel-ai-sdk) | TypeScript | One model call per **RunModel** Step. Each tool call is its own Step. | You have AI SDK tools and models in a TypeScript application. |
| [Built-in agent loop](/agent-frameworks/built-in-agent-loop) | Python, TypeScript | One model call per **RunModel** Step. Each tool call is its own Step. | You start a new agent. You want Dex to own the model input, with questions, durable waits, plans, and MCP tools. |
