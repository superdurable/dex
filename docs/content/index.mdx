# Dex Docs

Dex is **Durable Execution** — an abstraction over distributed systems for backend engineering. Durable storage persists data; Durable Execution persists **data and actions as execution**. Dex makes that idea structural: Flows, Steps, Attributes, Channels, and RPCs as ordinary application code.
