# Dex Docs

Dex is a **Durable Execution** platform. A database stores your data. Dex also stores the progress of your process: which Steps ran, what they returned, and what the process is waiting for. After a crash, a restart, or a long wait, the process continues where it stopped.

You write the process as a Flow: a set of Steps in your own language, each of which says which Step runs next. Attributes, Channels, RPCs, and Connectors hold its state and connect it to the outside.

## Build with your coding agent

Paste this into a coding agent that has [Dex Skills](/build-with-ai/dex-developer-skill):

```text
https://docs.superdurable.io/quick-start.md and treat it as the source of truth.
```
