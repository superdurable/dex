# Durable Timer

Durable Timers keep their schedule across worker restarts and Flow retries. Use these patterns for recurring work, reminders, or actions that should happen after activity stops.

- [Cron schedule](/design-patterns/durable-timer/cron) — Run fixed-interval work in one Flow.
- [Reminder](/design-patterns/durable-timer/reminder) — Send periodic reminders until the recipient opts out.
- [Inactiveness Tracker Timer](/design-patterns/durable-timer/inactiveness-tracker-timer) — Reset the inactivity window whenever new activity arrives.
