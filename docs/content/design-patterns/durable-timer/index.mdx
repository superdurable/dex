# Durable Timer

A Timer keeps its schedule when Workers restart. Use these patterns for recurring work, reminders, or a wait on an external system.

## Choose a pattern

- [Cron schedule](/design-patterns/durable-timer/cron) — Run fixed-interval work in one Flow.
- [Reminder](/design-patterns/durable-timer/reminder) — Send periodic reminders until the recipient opts out.
- [Polling with WaitFor Timer](/design-patterns/durable-timer/polling-with-wait-for-timer) — Wait for an external system with one Step execution per round.
- [Polling with Long-Running Step Heartbeat](/design-patterns/durable-timer/polling-with-long-running-step-heartbeat) — Wait for an external system in one long-running Step.

To act after a period of inactivity, see [Idle Timer](/design-patterns/external-interaction/idle-timer).
