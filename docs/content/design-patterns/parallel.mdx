# Parallel Steps

Choose how a Flow runs Steps at the same time and when it continues.

<a id="problem-and-approach"></a>

## Choose a pattern

- [Static parallel Steps](/design-patterns/parallel/static) — Fan out to a fixed set of distinct Step types.
- [Dynamic parallel Steps](/design-patterns/parallel/dynamic) — Fan out to a runtime-sized set of executions of one Step type.
- [Await parallel Steps](/design-patterns/parallel/await) — Wait until every dynamic execution has reported its result.
- [First-win parallel Steps](/design-patterns/parallel/first-win) — Let the first completed execution cancel its siblings.
- [Critical Section](/design-patterns/parallel/critical-section) — Let parallel branches take turns on a sequence of Steps.
