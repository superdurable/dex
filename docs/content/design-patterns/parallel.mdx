# Parallel Steps

Choose one of four ways to start and coordinate concurrent Step executions.

## Problem and approach

Each pattern starts concurrent Step executions with **GoToMany**. They differ in which Steps run and in when the Flow continues.

- [Static parallel Steps](/design-patterns/parallel/static) — Fan out to a fixed set of distinct Step types.
- [Dynamic parallel Steps](/design-patterns/parallel/dynamic) — Fan out to a runtime-sized set of executions of one Step type.
- [Await parallel Steps](/design-patterns/parallel/await) — Wait until every dynamic execution has published completion.
- [First-win parallel Steps](/design-patterns/parallel/first-win) — Let the first completed execution cancel its siblings.
