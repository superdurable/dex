# Graceful Timeout

Use Dex's built-in graceful timeout when an overall Flow deadline needs application-defined handling. The timeout belongs to the Flow execution, not to a competing Step.

**FlowGracefulTimeout** starts **LongWaitStep**. A positive timeout in **StartFlowOptions** uses the Flow's timeout handler. When the durable deadline expires, Dex invokes **handleTimeout** once and applies its decision with normal Execute semantics.

Use this when the Flow must record an outcome, compensate, move to another Step, or select a clear terminal result at its deadline.

## Core implementation

Implement the Flow timeout hook and start the Flow with a positive timeout. The handler policy is selected explicitly below; it is also the default when the Flow implements the hook.

```python
class FlowGracefulTimeout(Flow[bool]):
    def get_steps(self) -> StepList[bool]:
        return StepList.start_step(self.long_wait_step)

    def handle_timeout(self, context: Context) -> StepDecision:
        del context
        return force_fail("Workflow did not finish the task in time")

await client.start_flow(
    flow, flow_id, should_complete,
    StartFlowOptions(
        timeout=timedelta(minutes=1),
        timeout_policy=FlowTimeoutPolicy.HANDLER,
    ),
)
```

func (*FlowGracefulTimeout) HandleTimeout(_ dex.Context) (*dex.StepDecision, error) {
	return dex.ForceFail("Workflow did not finish the task in time"), nil
}

timeout := time.Minute
_, err := client.StartFlow(ctx, flow, flowID, shouldComplete, dex.StartFlowOptions{
	Timeout:       &timeout,
	TimeoutPolicy: dex.TimeoutHandler,
})
