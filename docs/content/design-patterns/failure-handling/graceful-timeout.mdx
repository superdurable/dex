# Graceful Timeout

Bound long work with a timeout handler that owns the final outcome.

![ExampleGracefulTimeoutFlow](/img/design-patterns/graceful-timeout-flow.png)

**ExampleGracefulTimeoutFlow** starts **LongWaitStep** and **TimeoutHandleStep** together. **LongWaitStep** waits for either immediate completion or work that lasts longer than the timeout. **TimeoutHandleStep** waits for the deadline. Whichever Step reaches **Execute** first forcefully completes or fails the Flow, ending the other branch.

Use this pattern when a deadline is part of the business outcome, rather than a client-side request timeout.

## Core implementation

The start Step fans out to **LongWaitStep** and **TimeoutHandleStep**. Both branches use a **Timer**. Their **Execute** methods use a force decision so that the first finished branch owns the Flow outcome.

```python
class LongWaitStep(Step[bool]):
    def wait_for(self, context: Context, succeeded: bool) -> Wait:
        del context
        return Wait.skip_immediately() if succeeded else Wait.until(Timer.by_duration(timedelta(seconds=65)))

    def execute(self, context: Context, succeeded: bool) -> StepDecision:
        del context, succeeded
        return force_complete("work completed before timeout")

class TimeoutHandleStep(Step[None]):
    def wait_for(self, context: Context, input: None) -> Wait:
        del context, input
        return Wait.until(Timer.by_duration(timedelta(seconds=60)))

    def execute(self, context: Context, input: None) -> StepDecision:
        del context, input
        return force_fail("work timed out")
```

```go
type longWaitStep struct{ dex.StepDefaults }
```

```java
final class LongWaitStep implements Step<Boolean> {
    @Override public Class<Boolean> getInputType() { return Boolean.class; }

    @Override public Wait waitFor(final Context context, final Boolean succeeded) {
        return Boolean.TRUE.equals(succeeded)
                ? Wait.skipImmediately()
                : Wait.until(Timer.byDuration(Duration.ofSeconds(65)));
    }

    @Override public StepDecision execute(final Context context, final Boolean succeeded) {
        return StepDecision.forceComplete("work completed before timeout");
    }
}

        return Wait.until(Timer.byDuration(Duration.ofSeconds(60)));
    }

    @Override public StepDecision execute(final Context context, final Void input) {
        return StepDecision.forceFail("work timed out");

}
```

```rust
impl Step for LongWaitStep {
    type Input = bool;

    fn wait_for(&self, _context: &mut Context, succeeded: Self::Input) -> HandlerResult<Wait> {
        Ok(if succeeded { Wait::skip_immediately() } else { Wait::until(Timer::by_duration(Duration::from_secs(65))) })
    }

    fn execute(&self, _context: &mut Context, _succeeded: Self::Input) -> HandlerResult<StepDecision> {
        Ok(StepDecision::force_complete("work completed before timeout"))
    }
}

impl Step for TimeoutHandleStep {
    type Input = ();

    fn wait_for(&self, _context: &mut Context, _input: Self::Input) -> HandlerResult<Wait> {
        Ok(Wait::until(Timer::by_duration(Duration::from_secs(60))))
    }

    fn execute(&self, _context: &mut Context, _input: Self::Input) -> HandlerResult<StepDecision> {
        Ok(StepDecision::force_fail("work timed out"))
    }
}
```
