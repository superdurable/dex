# Wait for Attribute Equal

Use **WaitForAttributeEqual** when the condition a caller needs is business state, not merely that a particular Step ran. The client waits until a singleton Attribute in the active Flow equals a primitive value. It returns immediately if the Attribute already has that value.

The **EngagementFlow** sample writes its initial status as it starts. Its start endpoint waits for that durable value, then returns the Flow and run identifiers. The object-model samples use **Initiated**; the Rust sample uses **pending**. The Flow remains active so a caller can later accept, decline, or opt out.

Only string, Boolean, and numeric Attribute values can be compared by this wait. Keep a compact Attribute for the condition when the richer result is an object or collection.

func (controller *controller) start(request *gin.Context) {
	flowID := httputil.NewFlowID("engagement")
	input := EngagementInput{
		EmployerID:  "test-employer-id",
		JobSeekerID: "test-job-seeker-id",
		Notes:       "test-notes",
	}
	runID, err := controller.client.StartFlow(
		request.Request.Context(),
		controller.flow,
		flowID,
		input,
		sdk.StartFlowOptions{},
	)
	if err != nil {
		httputil.Respond(request, nil, err)
		return
	}
	waitContext, cancelWait := context.WithTimeout(request.Request.Context(), 15*time.Second)
	defer cancelWait()
	err = controller.client.WaitForAttributeEqual(
		waitContext,
		flowID,
		EngagementStatus,
		StatusInitiated,
	)
	httputil.Respond(request, gin.H{"flowID": flowID, "runID": runID}, err)
}

async fn start(State(client): State<SharedClient>) -> impl IntoResponse {
