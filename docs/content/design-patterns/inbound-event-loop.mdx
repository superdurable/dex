# Inbound Event Loop

Use this pattern when a Flow takes inbound messages until a resolution arrives or the conversation goes quiet. Examples are replies in a support ticket, messages in a chat session, or answers in a review thread. It extends the [Inactiveness Tracker Timer](/design-patterns/durable-timer/inactiveness-tracker-timer): each message restarts the inactivity Timer, and a separate resolution message ends the loop.

<DocsFlowDefinitionGraph graph={flowDefinition} />

## How it works

An RPC validates each reply and publishes it to a reply Channel. Another RPC validates the resolution and publishes it to a resolution Channel.

One waiting Step returns `AnyOf` over the reply Channel, the resolution Channel, and the inactivity Timer. Its `Execute` checks which Condition won:

- Replies won: it appends them to the transcript and moves back to itself. The new execution registers a new wait, so the inactivity Timer restarts.
- The resolution won: it moves to the Step that closes the resolved ticket.
- The Timer won: it moves to the Step that closes the quiet ticket.

Each closing Step completes the Flow with `ForceCompleteIfChannelsEmpty`. When a message is still waiting, the Flow does not close. Dex moves back to the waiting Step instead.

## Rules

- The RPC only validates its input and publishes it to a Channel. It writes no Attribute that the waiting Step reads or locks.
- One waiting Step waits on `AnyOf` over the reply Channel, the resolution Channel, and the inactivity Timer.
- When several `AnyOf` Conditions are ready together, Timers win first. Among the Channels, the first one declared wins. Only the winner's messages are consumed.
- Declare the reply Channel before the resolution Channel. The declaration order is the priority between replies and the resolution. Replies accepted before the resolution are therefore recorded first.
- A Channel Condition consumes messages only when it wins. A reply that arrives while `Execute` runs stays queued for the next execution, so no reply is lost.
- `Execute` appends the consumed messages to an Attribute, such as a transcript. The waiting Step is the only writer of that Attribute.
- To take every queued reply at once, use an at-least-one Channel Condition. You can also take one reply per execution.
- Keep the transcript bounded. The example stores it in a [sequentially chunked AttributeMap](/design-patterns/sequentially-chunked-attribute-map). The waiting Step loads only the current chunk.

## Why the Step owns the transcript {#why-the-rpc-does-not-write-the-transcript}

If the RPC appended to the transcript, the waiting Step would have to lock the transcript, and the RPC would have to lock it too for its read-modify-write. Locks do not queue. Every RPC that arrives while the Step holds the lock, or while another RPC holds it, is rejected with a lock conflict, and the client must retry. Publishing to a Channel needs no lock, so concurrent replies never conflict.

## Messages at the close

Every closing Step completes with `ForceCompleteIfChannelsEmpty` on the reply Channel, as in [Drain External Channels](/design-patterns/draining-channel-for-external-publishing). Its fallback moves back to the waiting Step.

- The resolution closes only when no reply is waiting. Otherwise the fallback carries the resolution back to the waiting Step. That Step waits only for replies, records them, and moves to the resolution close again.
- The inactivity close also checks the resolution Channel. A reply or a resolution can arrive together with the deadline. The Timer wins that race, so the inactivity close runs first. Its check finds the message, and the fallback reopens the wait. The message is recorded, not lost.
- Keep the waiting Step the only consumer of the reply Channel.

The resolution RPC rejects an empty reason, because an empty pending resolution means "none".

A request that arrives while the Flow closes follows [Requests during Flow close](/reference/server/runtime-client#requests-during-flow-close).

When the caller must confirm each reply was handled, the waiting Step records the reply's business ID in the same commit, and the caller reads that record; see [Confirm that a message was handled](/reference/server/runtime-client#confirm-message-handled).

## Example

`SupportTicketFlow` takes replies to a support ticket. `sendTicketReply` rejects empty and overlong replies. `resolveTicket` rejects an empty reason. `AwaitTicketMessage` records replies, or moves to `CloseResolvedTicket` or `CloseInactiveTicket`. Its input is the pending resolution, which is empty until a resolution close falls back. The inactivity Timer is 24 hours. The tests skip it with the Client `SkipTimer` instead of shortening it.

```python
TICKET_REPLIES = Channel("ticketReplies", str)
TICKET_RESOLUTIONS = Channel("ticketResolutions", str)
TRANSCRIPT_CHUNKS = AttributeMap("transcriptChunks", TranscriptChunk)


class AwaitTicketMessage(Step[str]):
    """Waits for replies, a resolution, or inactivity; the input is a pending resolution."""

    def wait_for(self, context: Context, pending_resolution: str) -> Wait:
        if pending_resolution:
            return Wait.until(TICKET_REPLIES.at_least(1))
        # Replies come before the resolution, so earlier replies are recorded first.
        return Wait.any_of(
            TICKET_REPLIES.at_least(1),
            TICKET_RESOLUTIONS.for_one(),
            Timer.by_duration(INACTIVITY_TIMEOUT),
        )

    def execute(self, context: Context, pending_resolution: str) -> StepDecision:
        replies = TICKET_REPLIES.results(context)
        if replies:
            append_to_transcript(context, replies)
            if pending_resolution:
                return go_to(CloseResolvedTicket, pending_resolution)
            # A new execution registers a new wait, so the Timer restarts.
            return go_to(AwaitTicketMessage, "")
        resolutions = TICKET_RESOLUTIONS.results(context)
        if resolutions:
            return go_to(CloseResolvedTicket, resolutions[0])
        if context.has_timer_fired():
            return go_to(CloseInactiveTicket, None)
        raise RuntimeError("no Condition of the ticket wait completed")

    def get_step_options(self) -> StepOptions:
        return StepOptions(
            execute_load_attribute_map_instances=(
                TRANSCRIPT_CHUNKS.load(CURRENT_TRANSCRIPT_CHUNK),
            )
        )


class CloseResolvedTicket(Step[str]):
    def execute(self, context: Context, reason: str) -> StepDecision:
        return force_complete_if_channels_empty(
            f"resolved: {reason}",
            StepMovement.of(AwaitTicketMessage, reason),
            TICKET_REPLIES,
        )


class CloseInactiveTicket(Step[None]):
    def execute(self, context: Context, input: None) -> StepDecision:
        return force_complete_if_channels_empty(
            "closed after inactivity",
            StepMovement.of(AwaitTicketMessage, ""),
            TICKET_REPLIES,
            TICKET_RESOLUTIONS,
        )


class SupportTicketFlow(Flow[str]):
    @rpc
    def send_ticket_reply(self, context: Context, text: str) -> None:
        """Validates one reply and queues it for the waiting Step."""
        if not text.strip():
            raise ValueError("reply text is required")
        if len(text) > MAX_REPLY_LENGTH:
            raise ValueError(f"reply text exceeds {MAX_REPLY_LENGTH} characters")
        TICKET_REPLIES.publish(context, text)

    @rpc
    def resolve_ticket(self, context: Context, reason: str) -> None:
        """Queues the resolution; an empty reason would mean no resolution."""
        if not reason.strip():
            raise ValueError("resolution reason is required")
        TICKET_RESOLUTIONS.publish(context, reason)
```

```go
var (
	TicketReplies     = dex.DefineChannel[string]("ticketReplies")
	TicketResolutions = dex.DefineChannel[string]("ticketResolutions")
	TranscriptChunks  = dex.DefineAttributeMap[TranscriptChunk]("transcriptChunks")

// SendTicketReply validates one reply and queues it for the waiting Step.
func (*SupportTicketFlow) SendTicketReply(ctx dex.Context, text string) (*dex.RPCResult[dex.None], error) {
	if strings.TrimSpace(text) == "" {
		return nil, fmt.Errorf("reply text is required")
	}
	if len(text) > MaxReplyLength {
		return nil, fmt.Errorf("reply text exceeds %d characters", MaxReplyLength)
	}
	if err := TicketReplies.Publish(ctx, text); err != nil {
		return nil, err
	}
	return &dex.RPCResult[dex.None]{}, nil
}

// ResolveTicket queues the resolution; an empty reason would mean no resolution.
func (*SupportTicketFlow) ResolveTicket(ctx dex.Context, reason string) (*dex.RPCResult[dex.None], error) {
	if strings.TrimSpace(reason) == "" {
		return nil, fmt.Errorf("resolution reason is required")
	}
	if err := TicketResolutions.Publish(ctx, reason); err != nil {
		return nil, err
	}
	return &dex.RPCResult[dex.None]{}, nil
}

func (AwaitTicketMessage) WaitFor(_ dex.Context, pendingResolution string) (*dex.Wait, error) {
	if pendingResolution != "" {
		return dex.Until(TicketReplies.AtLeast(1)), nil
	}
	// Replies come before the resolution, so earlier replies are recorded first.
	return dex.AnyOf(
		TicketReplies.AtLeast(1),
		TicketResolutions.ForOne(),
		dex.Timer(InactivityTimeout),
	), nil
}

func (AwaitTicketMessage) Execute(ctx dex.Context, pendingResolution string) (*dex.StepDecision, error) {
	replies, err := TicketReplies.GetConditionResults(ctx)
	if err != nil {
		return nil, err
	}
	if len(replies) > 0 {
		if err := appendToTranscript(ctx, replies); err != nil {
			return nil, err
		}
		if pendingResolution != "" {
			return dex.GoTo(CloseResolvedTicket{}, pendingResolution), nil
		}
		// A new execution registers a new wait, so the Timer restarts.
		return dex.GoTo(AwaitTicketMessage{}, ""), nil
	}
	resolutions, err := TicketResolutions.GetConditionResults(ctx)
	if err != nil {
		return nil, err
	}
	if len(resolutions) > 0 {
		return dex.GoTo(CloseResolvedTicket{}, resolutions[0]), nil
	}
	if ctx.HasTimerFired() {
		return dex.GoTo(CloseInactiveTicket{}, nil), nil
	}
	return nil, errors.New("no Condition of the ticket wait completed")
}

func (AwaitTicketMessage) GetStepOptions() *dex.StepOptions {
	return &dex.StepOptions{
		ExecuteLoadAttributeMapInstances: []dex.AttributeMapLoad{
			TranscriptChunks.Load(CurrentTranscriptChunk),
		},
	}
}

func (CloseResolvedTicket) Execute(_ dex.Context, reason string) (*dex.StepDecision, error) {
	return dex.ForceCompleteIfChannelsEmpty(
		"resolved: "+reason,
		[]dex.ChannelDef{TicketReplies},
		dex.MovementOf(AwaitTicketMessage{}, reason),
	), nil
}

func (CloseInactiveTicket) Execute(dex.Context, dex.None) (*dex.StepDecision, error) {
	return dex.ForceCompleteIfChannelsEmpty(
		"closed after inactivity",
		[]dex.ChannelDef{TicketReplies, TicketResolutions},
		dex.MovementOf(AwaitTicketMessage{}, ""),
	), nil
}
```

```java
public static final Channel<String> ticketReplies =
        Channel.define("ticketReplies", String.class);
public static final Channel<String> ticketResolutions =
        Channel.define("ticketResolutions", String.class);
public static final AttributeMap<TranscriptChunk> transcriptChunks =
        AttributeMap.define("transcriptChunks", TranscriptChunk.class);

/** Validates one reply and queues it for the waiting Step. */
@RPC
public void sendTicketReply(final Context context, final String text) {
    if (text == null || text.isBlank()) {
        throw new IllegalArgumentException("reply text is required");
    }
    if (text.length() > MAX_REPLY_LENGTH) {
        throw new IllegalArgumentException(
                "reply text exceeds " + MAX_REPLY_LENGTH + " characters");
    }
    ticketReplies.publish(context, text);
}

/** Queues the resolution; an empty reason would mean no resolution. */
@RPC
public void resolveTicket(final Context context, final String reason) {
    if (reason == null || reason.isBlank()) {
        throw new IllegalArgumentException("resolution reason is required");
    }
    ticketResolutions.publish(context, reason);
}

/** Waits for replies, a resolution, or inactivity; the input is a pending resolution. */
static final class AwaitTicketMessage implements Step<String> {
    @Override
    public Class<String> getInputType() {
        return String.class;
    }

    @Override
    public Wait waitFor(final Context context, final String pendingResolution) {
        if (!pendingResolution.isEmpty()) {
            return Wait.until(ticketReplies.atLeast(1));
        }
        // Replies come before the resolution, so earlier replies are recorded first.
        return Wait.anyOf(
                ticketReplies.atLeast(1),
                ticketResolutions.forOne(),
                Timer.byDuration(INACTIVITY_TIMEOUT));
    }

    @Override
    public StepDecision execute(final Context context, final String pendingResolution) {
        final List<String> replies = ticketReplies.getConditionResults(context);
        if (!replies.isEmpty()) {
            appendToTranscript(context, replies);
            if (!pendingResolution.isEmpty()) {
                return StepDecision.goTo(CloseResolvedTicket.class, pendingResolution);
            }
            // A new execution registers a new wait, so the Timer restarts.
            return StepDecision.goTo(AwaitTicketMessage.class, "");
        }
        final List<String> resolutions = ticketResolutions.getConditionResults(context);
        if (!resolutions.isEmpty()) {
            return StepDecision.goTo(CloseResolvedTicket.class, resolutions.get(0));
        }
        if (context.hasTimerFired()) {
            return StepDecision.goTo(CloseInactiveTicket.class, null);
        }
        throw new IllegalStateException("no Condition of the ticket wait completed");
    }

    @Override
    public StepOptions getStepOptions() {
        return StepOptions.newBuilder()
                .addExecuteLoadAttributeMapInstance(transcriptChunks, CURRENT_TRANSCRIPT_CHUNK)
                .build();
    }
}

static final class CloseResolvedTicket implements Step<String> {
    @Override
    public Class<String> getInputType() {
        return String.class;
    }

    @Override
    public StepDecision execute(final Context context, final String reason) {
        return StepDecision.forceCompleteIfChannelsEmpty(
                "resolved: " + reason,
                StepMovement.of(AwaitTicketMessage.class, reason),
                ticketReplies);
    }
}

static final class CloseInactiveTicket implements Step<Void> {
    @Override
    public Class<Void> getInputType() {
        return Void.class;
    }

    @Override
    public StepDecision execute(final Context context, final Void input) {
        return StepDecision.forceCompleteIfChannelsEmpty(
                "closed after inactivity",
                StepMovement.of(AwaitTicketMessage.class, ""),
                ticketReplies,
                ticketResolutions);
    }
}
```

```rust
pub static TICKET_REPLIES: LazyLock<Channel<String>> =
    LazyLock::new(|| Channel::new("ticketReplies"));
pub static TICKET_RESOLUTIONS: LazyLock<Channel<String>> =
    LazyLock::new(|| Channel::new("ticketResolutions"));
pub static TRANSCRIPT_CHUNKS: LazyLock<AttributeMap<TranscriptChunk>> =
    LazyLock::new(|| AttributeMap::new("transcriptChunks"));

impl SupportTicketFlow {
    /// Validates one reply and queues it for the waiting Step.
    fn send_ticket_reply(&self, context: &mut Context, text: String) -> HandlerResult<()> {
        if text.trim().is_empty() {
            return Err(HandlerError::new(
                "SupportTicketFlow",
                "reply text is required",
            ));
        }
        if text.chars().count() > MAX_REPLY_LENGTH {
            return Err(HandlerError::new(
                "SupportTicketFlow",
                format!("reply text exceeds {MAX_REPLY_LENGTH} characters"),
            ));
        }
        TICKET_REPLIES.publish(context, text)
    }

    /// Queues the resolution; an empty reason would mean no resolution.
    fn resolve_ticket(&self, context: &mut Context, reason: String) -> HandlerResult<()> {
        if reason.trim().is_empty() {
            return Err(HandlerError::new(
                "SupportTicketFlow",
                "resolution reason is required",
            ));
        }
        TICKET_RESOLUTIONS.publish(context, reason)
    }
}

impl Step for AwaitTicketMessage {
    type Input = String;

    fn wait_for(
        &self,
        _context: &mut Context,
        pending_resolution: Self::Input,
    ) -> HandlerResult<Wait> {
        if !pending_resolution.is_empty() {
            return Ok(Wait::until(TICKET_REPLIES.at_least(1)));
        }
        // Replies come before the resolution, so earlier replies are recorded first.
        Ok(Wait::any_of([
            TICKET_REPLIES.at_least(1),
            TICKET_RESOLUTIONS.for_one(),
            Timer::by_duration(INACTIVITY_TIMEOUT),
        ]))
    }

    fn execute(
        &self,
        context: &mut Context,
        pending_resolution: Self::Input,
    ) -> HandlerResult<StepDecision> {
        let replies = TICKET_REPLIES.condition_results(context)?;
        if !replies.is_empty() {
            append_to_transcript(context, replies)?;
            if !pending_resolution.is_empty() {
                return Ok(StepDecision::go_to(
                    &CloseResolvedTicket,
                    pending_resolution,
                ));
            }
            // A new execution registers a new wait, so the Timer restarts.
            return Ok(StepDecision::go_to(&AwaitTicketMessage, String::new()));
        }
        let mut resolutions = TICKET_RESOLUTIONS.condition_results(context)?;
        if !resolutions.is_empty() {
            return Ok(StepDecision::go_to(
                &CloseResolvedTicket,
                resolutions.remove(0),
            ));
        }
        if context.has_any_timer_fired() {
            return Ok(StepDecision::go_to(&CloseInactiveTicket, ()));
        }
        Err(HandlerError::new(
            "AwaitTicketMessage",
            "no Condition of the ticket wait completed",
        ))
    }

    fn options(&self) -> StepOptions<Self::Input> {
        StepOptions::new()
            .execute_load_attribute_map_instance(TRANSCRIPT_CHUNKS.load(CURRENT_TRANSCRIPT_CHUNK))
    }
}

impl Step for CloseResolvedTicket {
    type Input = String;

    fn execute(&self, _context: &mut Context, reason: Self::Input) -> HandlerResult<StepDecision> {
        Ok(StepDecision::force_complete_if_channels_empty(
            format!("resolved: {reason}"),
            StepMovement::to(&AwaitTicketMessage, reason),
            [TICKET_REPLIES.when_empty()],
        ))
    }
}

impl Step for CloseInactiveTicket {
    type Input = ();

    fn execute(&self, _context: &mut Context, _input: Self::Input) -> HandlerResult<StepDecision> {
        Ok(StepDecision::force_complete_if_channels_empty(
            "closed after inactivity".to_string(),
            StepMovement::to(&AwaitTicketMessage, String::new()),
            [TICKET_REPLIES.when_empty(), TICKET_RESOLUTIONS.when_empty()],
        ))
    }
}
```
