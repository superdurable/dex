# Drain External Channels

Process Channel messages that clients publish, and complete the Flow as soon as the Channel is empty.

## Problem and approach

Use this pattern when messages come from outside the Worker, possibly in bursts. A Client calls an RPC that appends each message to the Channel. The Flow completes as soon as the Channel is empty, so it runs only while there is work. The next message starts it again.

The RPC only validates the message and publishes it to the Channel. It writes no Attribute that a Step reads or locks, such as a counter or a per-entity status. `ProcessMessage` owns that state, so concurrent RPCs never hit a lock conflict.

`ProcessMessage` returns a `ForceCompleteIfChannelsEmpty` decision. Dex checks the Channel when it saves that decision and records the close decision in the same commit. If the Channel is empty, the Flow completes. If the Channel still holds messages, or a Step has taken a message but not finished its `Execute`, Dex takes the fallback movement back to `ProcessMessage` instead.

Only one Step may consume a Channel checked by `ForceCompleteIfChannelsEmpty`.

```python
class ProcessMessage(Step[str]):
    def __init__(self, queue_channel: Channel[str]) -> None:
        self.queue_channel = queue_channel

    def wait_for(self, context: Context, input: str) -> Wait:
        if input is None:
            return Wait.until(self.queue_channel.for_one())
        return Wait.skip_immediately()

    def execute(self, context: Context, input: str) -> StepDecision:
        if input is not None:
            print(f"DrainingExternalChannelFlow process message: {input}")
        else:
            values = self.queue_channel.results(context)
            if not values:
                raise RuntimeError("No channel message found")
            value = values[0]
            if value is None:
                raise RuntimeError("No channel message value found")
            print(f"DrainingExternalChannelFlow process message: {value}")

        return force_complete_if_channels_empty(
            None,
            StepMovement.of(ProcessMessage, None),
            self.queue_channel,
        )

    def publish_external_channel_message(
```

```rust
        context: &mut Context,

        Ok(RpcResult::new(input))

impl Flow for DrainingExternalChannelFlow {
    type StartInput = String;

    fn steps(&self) -> StepList<'_, Self::StartInput> {
        StepList::start(&self.drain)
    }

    fn persistence(&self) -> PersistenceSchema {
        PersistenceSchema::new().channel(&EXTERNAL_QUEUE)
    }

    fn rpcs(&self) -> RpcList<Self> {
        RpcList::new().function(
            PUBLISH_EXTERNAL_CHANNEL_MESSAGE,
            Self::publish_external_channel_message,
        )
    }
}

#[derive(Default)]
struct DrainChannel;

impl Step for DrainChannel {
    type Input = String;

    fn wait_for(&self, _context: &mut Context, input: String) -> HandlerResult<Wait> {
        if input.is_empty() {
            return Ok(Wait::until(EXTERNAL_QUEUE.for_one()));
        }
        Ok(Wait::skip_immediately())
    }

    fn execute(&self, context: &mut Context, input: String) -> HandlerResult<StepDecision> {
        let item = if input.is_empty() {
            EXTERNAL_QUEUE
                .condition_results(context)?
                .into_iter()
                .next()
                .unwrap_or_default()
        } else {
            input
        };
        context.record_event("drained-channel", item)?;
        Ok(StepDecision::force_complete_if_channels_empty(
            String::new(),
            StepMovement::to(&DrainChannel, String::new()),
            [EXTERNAL_QUEUE.when_empty()],
        ))
    }
}
```

## Controller

Each entity has one stable Flow ID and at most one active run. The run handles messages in the order their publications commit.

The controller first starts a Flow run with the entity's Flow ID and the message as its start input. The start allows reuse of a Flow ID whose run closed. Its request ID is fixed per message, and it ignores the already-started error for that request ID. A retried start returns the original run while that run is still the latest run for the Flow ID and its start request ID matches. When a different start request owns the active run, the start reports that the Flow already started. The controller then calls the publishing RPC on that run, with a request ID derived from the message ID where the SDK offers RPC request IDs. If that run closed before the publish, the controller starts again. A success response means the run accepted the message, not that a Step handled it. After a few attempts, the controller returns HTTP 409 with the message ID: the outcome is unknown, and the caller sends the message again with the same ID. It returns any other error to its caller.

When the caller must confirm each message was handled, the consuming Step records the message's business ID in the same commit, and the caller reads that record; see [Confirm that a message was handled](/reference/server/runtime-client#confirm-message-handled).

```python
    """Restarts a closed Flow ID.

    A retried start returns the original run while that run is still the latest
    run for the Flow ID and its start request ID matches.
    """
    return replace(

        id_reuse_policy=IdReusePolicy.ALLOW_IF_NOT_RUNNING,
        request_id=f"start:{message_id}",
        ignore_already_started=True,
    )

    )

        message_id = optional_query("messageId", "") or str(uuid.uuid4())
        message = f"message {message_id}"
        for _ in range(START_OR_PUBLISH_ATTEMPTS):
            try:
                run_id = await app_state.client.start_flow(

                # A different start request owns the active run: publish this message to that run.

                await app_state.client.invoke_rpc(
                    app_state.drain_external.publish_external_channel_message,
                    flow_id,
                    message,
                )
                return f"Accepted message {message_id}", 200

                # That run closed before the publish: start again.
                continue

            f"message {message_id} is unconfirmed; send it again with the same messageId",
```

```go
// startOrPublishAttempts bounds how often a message that lost a start race is published again.
const startOrPublishAttempts = 3

// patternStartOptions restarts a closed Flow ID. A retried start returns the original run
// while that run is still the latest run for the Flow ID and its start request ID matches.
func patternStartOptions(messageID string) sdk.StartFlowOptions {
	timeout := time.Hour
	requestID := "start:" + messageID
	return sdk.StartFlowOptions{
		Timeout:        &timeout,
		IDReusePolicy:  sdk.IDReuseAllowIfNotRunning,
		RequestID:      &requestID,
		AlreadyStarted: &sdk.AlreadyStartedOptions{IgnoreError: true},
	}
}

func (controller *controller) startOrPublish(request *gin.Context) {
	flowID, found := httputil.RequiredQuery(request, "workflowId")
	if !found {
		return
	}
	messageID := request.Query("messageId")
	if messageID == "" {
		messageID = uuid.NewString()
	}
	message := "message " + messageID
	publishRequestID := "publish:" + messageID
	for attempt := 0; attempt < startOrPublishAttempts; attempt++ {
		runID, startErr := controller.client.StartFlow(
			request.Request.Context(),
			controller.flow,
			flowID,
			message,
			patternStartOptions(messageID),
		)
		if startErr == nil {
			httputil.RespondString(
				request,
				fmt.Sprintf("Accepted message %s as the start input of runId %s", messageID, runID),
				nil,
			)
			return
		}
		var alreadyStarted *sdk.FlowAlreadyStartedError
		if !errors.As(startErr, &alreadyStarted) {
			httputil.RespondString(request, "", startErr)
			return
		}
		// A different start request owns the active run: publish this message to that run.
		var output string
		err := controller.client.InvokeRPCWithOptions(
			request.Request.Context(),
			flowID,
			controller.flow.PublishExternalChannelMessage,
			message,
			&output,
			sdk.RPCInvokeOptions{RequestID: &publishRequestID},
		)
		if err == nil {
			httputil.RespondString(request, fmt.Sprintf("Accepted message %s", messageID), nil)
			return
		}
		var inactive *sdk.FlowNotActiveOrNotFoundError
		if !errors.As(err, &inactive) {
			httputil.RespondString(request, "", err)
			return
		}
		// That run closed before the publish: start again.
	}
	request.String(
		http.StatusConflict,
		fmt.Sprintf("message %s is unconfirmed; send it again with the same messageId", messageID),
	)
}
```

```typescript
/** Bounds how often a message that lost a start race is published again. */
const START_OR_PUBLISH_ATTEMPTS = 3;

/**
 * Restarts a closed Flow ID. A retried start returns the original run while that run is still
 * the latest run for the Flow ID and its start request ID matches.
 */
function externalPublishingStartOptions(messageId: string): StartFlowOptions {
  return startOptions({
    idReusePolicy: IdReusePolicy.ALLOW_IF_NOT_RUNNING,
    requestId: `start:${messageId}`,
    ignoreAlreadyStarted: true,
  });
}

export function createDrainingChannelRouter(client: Client): Router {
  const router = Router();

  router.get("/start-or-publish", async (request, response) => {
    const workflowId = String(request.query.workflowId ?? "");
    const messageId = String(request.query.messageId ?? "") || randomUUID();
    const message = `message ${messageId}`;
    for (let attempt = 0; attempt < START_OR_PUBLISH_ATTEMPTS; attempt++) {
      try {
        const runId = await client.startFlow(
          drainingExternalChannelFlow,
          workflowId,
          message,
          externalPublishingStartOptions(messageId),
        );
        response.send(
          `Accepted message ${messageId} as the start input of runId ${runId}`,
        );
        return;
      } catch (error) {
        // A different start request owns the active run: publish this message to that run.
        if (!isFlowAlreadyStarted(error)) {
          throw error;
        }
      }
      try {
        await client.invokeRPCWithOptions(
          drainingExternalChannelFlow.publishExternalChannelMessage,
          workflowId,
          message,
          { requestId: `publish:${messageId}` },
        );
        response.send(`Accepted message ${messageId}`);
        return;
      } catch (error) {
        // That run closed before the publish: start again.
        if (!isFlowMissingOrInactive(error)) {
          throw error;
        }
      }
    }
    response
      .status(409)
      .send(
        `message ${messageId} is unconfirmed; send it again with the same messageId`,
      );
  });

  return router;
}
```

```rust
async fn start_or_publish(
    State(client): State<SharedClient>,
    Query(query): Query<StartQuery>,
) -> impl IntoResponse {
    let flow_id = if query.workflow_id.is_empty() {
        new_flow_id("drain-external")
    } else {
        query.workflow_id
    };
    let message_id = if query.message_id.is_empty() {
        new_message_id()
    } else {
        query.message_id
    };
    match run_blocking(move || {
        let flow = DrainingExternalChannelFlow::default();
        let message = format!("message {message_id}");
        for _ in 0..START_OR_PUBLISH_ATTEMPTS {
            match client.start_flow_with_options(
                &flow,
                &flow_id,
                message.clone(),
                external_publishing_start_options(&message_id),
            ) {
                Ok(run_id) => {
                    return Ok(Ok(format!(
                        "Accepted message {message_id} as the start input of runId {run_id}"
                    )));
                }
                // A different start request owns the active run: publish this message to that run.
                Err(error) if is_already_started(&error) => {}
                Err(error) => return Err(error),
            }
            match client.invoke_rpc(&flow_id, PUBLISH_EXTERNAL_CHANNEL_MESSAGE, message.clone()) {
                Ok(_) => return Ok(Ok(format!("Accepted message {message_id}"))),
                // That run closed before the publish: start again.
                Err(error) if is_missing_or_inactive(&error) => {}
                Err(error) => return Err(error),
            }
        }
        Ok(Err(format!(
            "message {message_id} is unconfirmed; send it again with the same messageId"
        )))
    }) {
        Ok(Ok(message)) => ok_text(message),
        Ok(Err(unconfirmed)) => (StatusCode::CONFLICT, unconfirmed).into_response(),
        Err(error) => map_sdk_error(error).into_response(),
    }
}

/// Restarts a closed Flow ID. A retried start returns the original run while that run is
/// still the latest run for the Flow ID and its start request ID matches.
fn external_publishing_start_options(message_id: &str) -> StartFlowOptions {
    StartFlowOptions::new()
        .timeout(Duration::from_secs(60 * 60))
        .id_reuse_policy(IdReusePolicy::AllowIfNotRunning)
        .request_id(format!("start:{message_id}"))
        .ignore_already_started(true)
}

/// Returns a random 128-bit message ID for a caller that sent none.
fn new_message_id() -> String {
    format!("{:032x}", fastrand::u128(..))
}
```
