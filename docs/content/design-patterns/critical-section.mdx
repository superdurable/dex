# Critical Section

Use a Critical Section when parallel branches of one Flow must take turns on a sequence of Steps. Only one branch may be inside the sequence at a time.

An example is several reviewers who edit the same contract. Each edit takes two Steps. The first opens the contract and makes the change. The second saves it. Two edits must never interleave.

<DocsFlowDefinitionGraph graph={flowDefinition} />

## Why not an Attribute lock

An Attribute lock, such as **ExecuteLockAttributes**, covers one Step method. It does not cover a **WaitFor**, and it does not span several Steps. Use a lock when the protected work fits in one **Execute**. Use a token when the section spans Steps.

## How it works

A Channel holds exactly one message. That message is the token.

- One Step publishes the token once, before any branch enters.
- The first Step of the section waits for the token with **ForOne**. One message satisfies one wait, so only one branch gets it. The other branches keep waiting.
- The last Step of the section publishes the token back. One waiting branch consumes it and enters.

```pseudocode
StartContractEdits.execute(edits)
    ContractEditToken.publish("contract")
    goToMany(for each edit: EnterContractEdit(edit), FinishContractEdits(count))

EnterContractEdit.waitFor   -> Until(ContractEditToken.ForOne())
EnterContractEdit.execute   -> open the contract and edit it; goTo(SaveContractEdit)
SaveContractEdit.execute    -> save the edit; ContractEditToken.publish("contract"); deadEnd()

ReleaseContractEditToken.execute -> ContractEditToken.publish("contract"); deadEnd()
    // the ExecuteFailure route of EnterContractEdit and SaveContractEdit
```

Dex does not promise which waiting branch gets the token next. Do not rely on an order of entry.

## Every exit returns the token

The token is an ordinary message. A branch that leaves the section without publishing it back blocks every other branch forever. List each way out of the section, and publish the token on each one.

- **Normal exit.** The last Step of the section publishes the token.
- **Execute failure.** Route it with **ExecuteFailure** to a Step that publishes the token. Give every Step of the section that route. In the example, both **EnterContractEdit** and **SaveContractEdit** move to **ReleaseContractEditToken**.
- **WaitFor failure.** When a later Step of the section has its own **WaitFor**, give it a **WaitForFailure** policy that proceeds to its **Execute**. That **Execute** sees the failure and publishes the token.
- **Early exit.** An **Execute** that leaves the section with a business decision publishes the token in the same **Execute**.
- **Cancellation while entering.** Dex can cancel the Step that waits for the token, for example from an RPC or a sibling's decision. When the cancel lands after its wait consumed the token but before its **Execute** committed, Dex returns the token to the front of the Channel. The next waiting branch gets it. Cancellation is cooperative, so the canceled **Execute** may still be running when the next branch enters. Keep the entering Step's work idempotent, or do not cancel it while its **Execute** runs.
- **Cancellation inside the section.** Do not cancel a later Step of the section. A canceled Step publishes nothing, and its failure route does not run. The canceller cannot publish the token for it either. Dex picks the Steps to cancel when it commits, so the Step may already have published the token, and a second token would break mutual exclusion. To stop a branch early, send it a stop request that its Steps check, such as an Attribute an RPC sets. The Step that sees it leaves through an early exit that publishes the token.
- **Closing the Flow.** **ForceComplete**, **ForceFail**, a Flow timeout, and a Client **StopFlow** end every branch. No branch waits for the token any more.

Publications commit with the method that makes them, or not at all. A failed attempt never publishes a token, so a retry cannot create a second one.

## Rules

- Publish exactly one token. Publish it in the Step that starts the branches, or before.
- Use the token Channel for the token only.
- Keep the section short. Every other branch waits while one branch is inside.
- Keep the token value meaningless. Put the protected state in Attributes.

## Example

**ContractEditFlow** starts with a list of edits, one per reviewer. **StartContractEdits** publishes the token and starts one **EnterContractEdit** per edit, plus the join **FinishContractEdits**. Each edit records when it held the contract. The join completes the Flow with those records, which never overlap.

An edit can be marked to fail. Its **SaveContractEdit** fails twice, and the failure route **ReleaseContractEditToken** returns the token. The other reviewers still get their turn.

```python
CONTRACT_EDIT_TOKEN = Channel("contractEditToken", str)
CONTRACT_EDIT_FINISHED = Channel("contractEditFinished", ContractEditRecord)
CONTRACT_EDIT_RETRY = RetryPolicy(
    initial_interval=timedelta(seconds=1), maximum_attempts=2
)


class StartContractEdits(Step[list[ContractEdit]]):
    """Publishes the only token and starts one branch per reviewer."""

    def execute(self, context: Context, edits: list[ContractEdit]) -> StepDecision:
        CONTRACT_EDIT_TOKEN.publish(context, "contract")
        movements: list[StepMovement[Any]] = [
            StepMovement.of(EnterContractEdit, edit) for edit in edits
        ]
        movements.append(StepMovement.of(FinishContractEdits, len(edits)))
        return go_to_many(*movements)


class EnterContractEdit(Step[ContractEdit]):
    """Enters the section by consuming the token."""

    # A failure after the token was consumed routes to the Step that publishes it back.
    def get_step_options(self) -> StepOptions:
        return StepOptions(execute_retry=CONTRACT_EDIT_RETRY).on_execute_failure_proceed_to(
            ReleaseContractEditToken
        )

    def wait_for(self, context: Context, edit: ContractEdit) -> Wait:
        return Wait.until(CONTRACT_EDIT_TOKEN.for_one())

    async def execute(  # type: ignore[override]
        self, context: AsyncContext, edit: ContractEdit
    ) -> StepDecision:
        started_edit = replace(edit, started_at_millis=current_time_millis())
        await asyncio.sleep(CONTRACT_EDIT_SECONDS)
        return go_to(SaveContractEdit, started_edit)


class SaveContractEdit(Step[ContractEdit]):
    """The last Step of the section; it records the edit and publishes the token back."""

    def get_step_options(self) -> StepOptions:
        return StepOptions(execute_retry=CONTRACT_EDIT_RETRY).on_execute_failure_proceed_to(
            ReleaseContractEditToken
        )

    async def execute(  # type: ignore[override]
        self, context: AsyncContext, edit: ContractEdit
    ) -> StepDecision:
        await asyncio.sleep(CONTRACT_EDIT_SECONDS)
        if edit.should_fail_edit:
            raise ContractEditError("contract edit failed")
        CONTRACT_EDIT_FINISHED.publish(context, finish_contract_edit(edit, "saved"))
        CONTRACT_EDIT_TOKEN.publish(context, "contract")
        return dead_end()


class ReleaseContractEditToken(Step[ContractEdit]):
    """The failure exit of the section."""

    def execute(self, context: Context, edit: ContractEdit) -> StepDecision:
        CONTRACT_EDIT_FINISHED.publish(context, finish_contract_edit(edit, "failed"))
        CONTRACT_EDIT_TOKEN.publish(context, "contract")
        return dead_end()
```

```go
var (
	ContractEditToken    = dex.DefineChannel[string]("contractEditToken")
	ContractEditFinished = dex.DefineChannel[ContractEditRecord]("contractEditFinished")
	errContractEdit      = errors.New("contract edit failed")
	contractEditRetry    = &dex.RetryPolicy{InitialInterval: time.Second, MaximumAttempts: 2}
)

// StartContractEdits publishes the only token and starts one branch per reviewer.
type StartContractEdits struct {
	dex.StepDefaultsNoWaitFor[[]ContractEdit]
}

func (StartContractEdits) Execute(ctx dex.Context, edits []ContractEdit) (*dex.StepDecision, error) {
	if err := ContractEditToken.Publish(ctx, "contract"); err != nil {
		return nil, err
	}
	movements := make([]dex.StepMovement, 0, len(edits)+1)
	for _, edit := range edits {
		movements = append(movements, dex.MovementOf(EnterContractEdit{}, edit))
	}
	movements = append(movements, dex.MovementOf(FinishContractEdits{}, len(edits)))
	return dex.GoToMany(movements...), nil
}

// EnterContractEdit enters the section by consuming the token.
type EnterContractEdit struct{ dex.StepDefaults }

// GetStepOptions routes an Execute failure after the token was consumed to the
// Step that publishes it back.
func (EnterContractEdit) GetStepOptions() *dex.StepOptions {
	return &dex.StepOptions{
		ExecuteRetry:   contractEditRetry,
		ExecuteFailure: dex.ProceedToOnExecuteFailure(ReleaseContractEditToken{}, nil),
	}
}

func (EnterContractEdit) WaitFor(dex.Context, ContractEdit) (*dex.Wait, error) {
	return dex.Until(ContractEditToken.ForOne()), nil
}

func (EnterContractEdit) Execute(_ dex.Context, edit ContractEdit) (*dex.StepDecision, error) {
	edit.StartedAtMillis = time.Now().UnixMilli()
	time.Sleep(contractEditDuration)
	return dex.GoTo(SaveContractEdit{}, edit), nil
}

// SaveContractEdit is the last Step of the section; it publishes the token back.
type SaveContractEdit struct {
	dex.StepDefaultsNoWaitFor[ContractEdit]
}

func (SaveContractEdit) GetStepOptions() *dex.StepOptions {
	return &dex.StepOptions{
		ExecuteRetry:   contractEditRetry,
		ExecuteFailure: dex.ProceedToOnExecuteFailure(ReleaseContractEditToken{}, nil),
	}
}

func (SaveContractEdit) Execute(ctx dex.Context, edit ContractEdit) (*dex.StepDecision, error) {
	time.Sleep(contractEditDuration)
	if edit.ShouldFailEdit {
		return nil, errContractEdit
	}
	if err := leaveContractEdit(ctx, edit, "saved"); err != nil {
		return nil, err
	}
	return dex.DeadEnd(), nil
}

// ReleaseContractEditToken is the failure exit of the section.
type ReleaseContractEditToken struct {
	dex.StepDefaultsNoWaitFor[ContractEdit]
}

func (ReleaseContractEditToken) Execute(ctx dex.Context, edit ContractEdit) (*dex.StepDecision, error) {
	if err := leaveContractEdit(ctx, edit, "failed"); err != nil {
		return nil, err
	}
	return dex.DeadEnd(), nil
}

// leaveContractEdit records the edit and publishes the token for the next reviewer.
func leaveContractEdit(ctx dex.Context, edit ContractEdit, outcome string) error {
	record := ContractEditRecord{
		Reviewer:         edit.Reviewer,
		Outcome:          outcome,
		StartedAtMillis:  edit.StartedAtMillis,
		FinishedAtMillis: time.Now().UnixMilli(),
	}
	if err := ContractEditFinished.Publish(ctx, record); err != nil {
		return err
	}
	return ContractEditToken.Publish(ctx, "contract")
}
```

```java
public static final Channel<String> contractEditToken =
        Channel.define("contractEditToken", String.class);
public static final Channel<ContractEditRecord> contractEditFinished =
        Channel.define("contractEditFinished", ContractEditRecord.class);

/** Routes an execute failure after the token was consumed to the Step that returns it. */
private static StepOptions contractEditOptions() {
    return StepOptions.newBuilder()
            .executeRetry(RetryPolicy.newBuilder()
                    .initialInterval(Duration.ofSeconds(1))
                    .maximumAttempts(2)
                    .build())
            .onExecuteFailureProceedTo(ReleaseContractEditToken.class)
            .build();
}

/** Publishes the only token and starts one branch per reviewer. */
static final class StartContractEdits implements Step<ContractEdit[]> {
    @Override
    public Class<ContractEdit[]> getInputType() {
        return ContractEdit[].class;
    }

    @Override
    public StepDecision execute(final Context context, final ContractEdit[] edits) {
        contractEditToken.publish(context, TOKEN);
        final StepMovement<?>[] movements = new StepMovement<?>[edits.length + 1];
        for (int index = 0; index < edits.length; index++) {
            movements[index] = StepMovement.of(EnterContractEdit.class, edits[index]);
        }
        movements[edits.length] = StepMovement.of(FinishContractEdits.class, edits.length);
        return StepDecision.goToMany(movements);
    }
}

/** Enters the section by consuming the token. */
static final class EnterContractEdit implements Step<ContractEdit> {
    @Override
    public Class<ContractEdit> getInputType() {
        return ContractEdit.class;
    }

    @Override
    public StepOptions getStepOptions() {
        return contractEditOptions();
    }

    @Override
    public Wait waitFor(final Context context, final ContractEdit edit) {
        return Wait.until(contractEditToken.forOne());
    }

    @Override
    public StepDecision execute(final Context context, final ContractEdit edit) {
        final ContractEdit started = new ContractEdit(
                edit.reviewer(), edit.shouldFailEdit(), System.currentTimeMillis());
        holdContract();
        return StepDecision.goTo(SaveContractEdit.class, started);
    }
}

/** The last Step of the section; it publishes the token back. */
static final class SaveContractEdit implements Step<ContractEdit> {
    @Override
    public Class<ContractEdit> getInputType() {
        return ContractEdit.class;
    }

    @Override
    public StepOptions getStepOptions() {
        return contractEditOptions();
    }

    @Override
    public StepDecision execute(final Context context, final ContractEdit edit) {
        holdContract();
        if (edit.shouldFailEdit()) {
            throw new IllegalStateException("contract edit failed");
        }
        leaveContractEdit(context, edit, "saved");
        return StepDecision.deadEnd();
    }
}

/** The failure exit of the section. */
static final class ReleaseContractEditToken implements Step<ContractEdit> {
    @Override
    public Class<ContractEdit> getInputType() {
        return ContractEdit.class;
    }

    @Override
    public StepDecision execute(final Context context, final ContractEdit edit) {
        leaveContractEdit(context, edit, "failed");
        return StepDecision.deadEnd();
    }
}

/** Records the edit and publishes the token for the next reviewer. */
private static void leaveContractEdit(
        final Context context, final ContractEdit edit, final String outcome) {
    contractEditFinished.publish(context, new ContractEditRecord(
            edit.reviewer(), outcome, edit.startedAtMillis(), System.currentTimeMillis()));
    contractEditToken.publish(context, TOKEN);
}
```

```rust
pub static CONTRACT_EDIT_TOKEN: LazyLock<Channel<String>> =
    LazyLock::new(|| Channel::new("contractEditToken"));
pub static CONTRACT_EDIT_FINISHED: LazyLock<Channel<ContractEditRecord>> =
    LazyLock::new(|| Channel::new("contractEditFinished"));

/// Publishes the only token and starts one branch per reviewer.
#[derive(Default)]
struct StartContractEdits;

impl Step for StartContractEdits {
    type Input = Vec<ContractEdit>;

    fn execute(&self, context: &mut Context, edits: Self::Input) -> HandlerResult<StepDecision> {
        CONTRACT_EDIT_TOKEN.publish(context, CONTRACT_TOKEN.to_string())?;
        let edit_count = edits.len();
        let edit_branches = edits
            .into_iter()
            .map(|edit| StepMovement::to(&EnterContractEdit, edit));
        Ok(StepDecision::go_to_many(edit_branches.chain([
            StepMovement::to(&FinishContractEdits, edit_count),
        ])))
    }
}

/// Enters the section by consuming the token.
#[derive(Default)]
struct EnterContractEdit;

impl Step for EnterContractEdit {
    type Input = ContractEdit;

    /// Routes an Execute failure after the token was consumed to the Step
    /// that publishes it back.
    fn options(&self) -> StepOptions<Self::Input> {
        contract_edit_options()
    }

    fn wait_for(&self, _context: &mut Context, _edit: Self::Input) -> HandlerResult<Wait> {
        Ok(Wait::until(CONTRACT_EDIT_TOKEN.for_one()))
    }

    fn execute(
        &self,
        _context: &mut Context,
        mut edit: Self::Input,
    ) -> HandlerResult<StepDecision> {
        edit.started_at_millis = current_unix_millis()?;
        thread::sleep(CONTRACT_EDIT_DURATION);
        Ok(StepDecision::go_to(&SaveContractEdit, edit))
    }
}

/// The last Step of the section; it publishes the token back.
#[derive(Default)]
struct SaveContractEdit;

impl Step for SaveContractEdit {
    type Input = ContractEdit;

    fn options(&self) -> StepOptions<Self::Input> {
        contract_edit_options()
    }

    fn execute(&self, context: &mut Context, edit: Self::Input) -> HandlerResult<StepDecision> {
        thread::sleep(CONTRACT_EDIT_DURATION);
        if edit.should_fail_edit {
            return Err(HandlerError::new(
                "ContractEditFailed",
                "contract edit failed",
            ));
        }
        leave_contract_edit(context, edit, "saved")?;
        Ok(StepDecision::dead_end())
    }
}

/// The failure exit of the section.
#[derive(Default)]
struct ReleaseContractEditToken;

impl Step for ReleaseContractEditToken {
    type Input = ContractEdit;

    fn execute(&self, context: &mut Context, edit: Self::Input) -> HandlerResult<StepDecision> {
        leave_contract_edit(context, edit, "failed")?;
        Ok(StepDecision::dead_end())
    }
}

fn contract_edit_options() -> StepOptions<ContractEdit> {
    StepOptions::new()
        .execute_retry(
            RetryPolicy::new()
                .initial_interval(Duration::from_secs(1))
                .maximum_attempts(2),
        )
        .on_execute_failure_proceed_to(&ReleaseContractEditToken)
}

/// Records the edit and publishes the token for the next reviewer.
fn leave_contract_edit(
    context: &mut Context,
    edit: ContractEdit,
    outcome: &str,
) -> HandlerResult<()> {
    CONTRACT_EDIT_FINISHED.publish(
        context,
        ContractEditRecord {
            reviewer: edit.reviewer,
            outcome: outcome.to_string(),
            started_at_millis: edit.started_at_millis,
            finished_at_millis: current_unix_millis()?,
        },
    )?;
    CONTRACT_EDIT_TOKEN.publish(context, CONTRACT_TOKEN.to_string())
}
```

## Anti-patterns

- An Attribute lock used to protect several Steps.
- A boolean Attribute such as "isEditing" that Steps check and set. Nothing waits on it, and two branches can both see it clear.
- Returning the token only on the success path.
- Canceling a Step inside the section, or publishing the token from the RPC that cancels it.
- Publishing a new token to recover from a lost one while the old one may still exist. Two tokens break mutual exclusion.
