# Child Flows with Business Identity

Use this pattern when each child job has its own business number. People and other systems look the child up, retry it, or stop it by that number.

An example is an order that ships as several parcels. Each shipment has a shipment number. The carrier, the support team, and the order all find the shipment by that number. The order still needs to know how each shipment ended.

The order starts each shipment as its own top-level Flow. The shipment number is its Flow ID.

## How it works

1. `StartShipments` checks that every shipment number in the order is unique, then starts one branch per shipment. An order that repeats a number fails before it starts any shipment.
2. `StartShipment` starts a `ShipmentFlow` through the Client. Its Flow ID is the shipment number. Its request ID is a digest of the complete start request, so a retried Step repeats the same start. The shipment gets its own Flow timeout.
3. The shipment delivers. `DeliverShipment` stores its outcome in the `shipmentOutcome` Attribute.
4. `ReportShipmentOutcome` calls the order's `recordShipmentOutcome` RPC. The RPC fills the outcome in the shipment's record.
5. `AwaitShipment` reads the shipment at each interval. A running shipment is read again later. For a closed shipment, it records the terminal status, and the stored outcome when no report filled it.

def shipment_start_request_id(order_flow_id: str, shipment: Shipment) -> str:
    """Derives the start request ID from the complete start request.

    A retried Execute sends the same ID, so it repeats the same start. Any
    other request for the same shipment number sends another ID, so Dex
    rejects it as already started.

    Returns:
        ``start:`` followed by the hex SHA-256 digest of the encoded request.
    """
    request = json.dumps(
        [
            SHIPMENT_FLOW_TYPE,
            shipment.shipment_number,
            order_flow_id,
            shipment.destination,
            shipment.delivery_delay_seconds,
            int(SHIPMENT_TIMEOUT.total_seconds()),
            "disallow",
        ],
        separators=(",", ":"),
    )
    return "start:" + hashlib.sha256(request.encode("utf-8")).hexdigest()

class StartShipment(Step[TrackedShipment]):
    """Starts ShipmentFlow with the shipment number as its Flow ID."""

    def __init__(
        self,
        client_provider: Callable[[], AsyncClient],
        shipment_flow: ShipmentFlow,
    ) -> None:
        self.client_provider = client_provider
        self.shipment_flow = shipment_flow

    async def execute(  # type: ignore[override]
        self, context: AsyncContext, tracked: TrackedShipment
    ) -> StepDecision:
        number = tracked.shipment.shipment_number
        try:
            await self.client_provider().start_flow(
                self.shipment_flow,
                number,
                ShipmentRequest(order_flow_id=context.flow_id, shipment=tracked.shipment),
                StartFlowOptions(
                    timeout=SHIPMENT_TIMEOUT,
                    id_reuse_policy=IdReusePolicy.DISALLOW,
                    request_id=shipment_start_request_id(context.flow_id, tracked.shipment),
                    ignore_already_started=True,
                ),
            )
        except FlowAlreadyStartedError:
            # Another request owns this shipment number; this order does not track it.
            SHIPMENT_RECORDS.set(context, number, ShipmentRecord(status=SHIPMENT_REJECTED))
            return graceful_complete()
        return go_to(AwaitShipment, tracked)

class AwaitShipment(Step[TrackedShipment]):
    """Reads the shipment at each interval until it ends, then records it."""

    def __init__(self, client_provider: Callable[[], AsyncClient]) -> None:
        self.client_provider = client_provider

    def get_step_options(self) -> StepOptions:
        """Takes the same lock as the report RPC and loads the records."""
        return StepOptions(
            execute_lock_attributes=(SHIPMENT_RECORDS_LOCK.lock(),),
            execute_load_attribute_maps=(SHIPMENT_RECORDS,),
        )

    def wait_for(self, context: Context, tracked: TrackedShipment) -> Wait:
        return Wait.until(
            Timer.by_duration(timedelta(seconds=tracked.reconcile_interval_seconds))
        )

    async def execute(  # type: ignore[override]
        self, context: AsyncContext, tracked: TrackedShipment
    ) -> StepDecision:
        number = tracked.shipment.shipment_number
        reading = await reconcile_shipment(self.client_provider(), number)
        if reading.status == FlowStatus.RUNNING.value:
            return go_to(AwaitShipment, tracked)
        # Merge with the record, which may already hold the reported outcome.
        record = load_shipment_record(context, number)
        SHIPMENT_RECORDS.set(
            context,
            number,
            ShipmentRecord(
                status=reading.status,
                outcome=record.outcome or reading.outcome,
            ),
        )
        return graceful_complete()


def load_shipment_record(context: Context, number: str) -> ShipmentRecord:
    """Returns the loaded record of a shipment, or an empty record when it has none."""
    # A missing instance reads as None.
    record: ShipmentRecord | None = SHIPMENT_RECORDS.get(context, number)
    return record if record is not None else ShipmentRecord()


async def reconcile_shipment(client: AsyncClient, number: str) -> ShipmentRecord:
    """Reads a shipment: its status first, then its outcome.

    Returns a "running" record while the shipment runs and an "unavailable"
    record when the shipment does not exist. Any other failure raises, so the
    Step retries.
    """
    try:
        info = await client.describe_flow(number)
    except FlowNotFoundError:
        return ShipmentRecord(status=SHIPMENT_UNAVAILABLE)
    if info.status is FlowStatus.RUNNING:
        return ShipmentRecord(status=info.status.value)
    try:
        values = await client.get_attributes(number, SHIPMENT_OUTCOME)
    except FlowNotFoundError:
        return ShipmentRecord(status=info.status.value)
    # An unset outcome Attribute leaves the outcome empty: the shipment ended without one.
    return ShipmentRecord(
        status=info.status.value, outcome=values.get(SHIPMENT_OUTCOME, "")
    )

// ShipmentStartRequestID derives the start request ID from the complete start request.
// A retried Execute sends the same ID, so it repeats the same start. Any other request for
// the same shipment number sends another ID, so Dex rejects it as already started.
// It returns an error only when the request cannot be encoded.
func ShipmentStartRequestID(orderFlowID string, shipment Shipment) (string, error) {
	request, err := json.Marshal([]any{
		shipmentFlowType, shipment.ShipmentNumber, orderFlowID, shipment.Destination,
		shipment.DeliveryDelaySeconds, int64(ShipmentTimeout / time.Second), "disallow",
	})
	if err != nil {
		return "", err
	}
	digest := sha256.Sum256(request)
	return "start:" + hex.EncodeToString(digest[:]), nil
}

// dex:explanation text:"Starts the shipment as a top-level Flow named by its shipment number."
type StartShipment struct {
	dex.StepDefaultsNoWaitFor[TrackedShipment]
	getClient    func() *dex.Client
	shipmentFlow *ShipmentFlow
}

func (step StartShipment) Execute(ctx dex.Context, tracked TrackedShipment) (*dex.StepDecision, error) {
	client := step.getClient()
	if client == nil {
		return nil, errClientUnavailable
	}
	number := tracked.Shipment.ShipmentNumber
	requestID, err := ShipmentStartRequestID(ctx.FlowID(), tracked.Shipment)
	if err != nil {
		return nil, err
	}
	timeout := ShipmentTimeout
	_, err = client.StartFlow(ctx, step.shipmentFlow, number, ShipmentRequest{
		OrderFlowID: ctx.FlowID(),
		Shipment:    tracked.Shipment,
	}, dex.StartFlowOptions{
		Timeout:        &timeout,
		IDReusePolicy:  dex.IDReuseDisallow,
		RequestID:      &requestID,
		AlreadyStarted: &dex.AlreadyStartedOptions{IgnoreError: true},
	})
	var alreadyStarted *dex.FlowAlreadyStartedError
	if errors.As(err, &alreadyStarted) {
		// Another request owns this shipment number; this order does not track it.
		if err := ShipmentRecords.Set(ctx, number, ShipmentRecord{Status: ShipmentRejected}); err != nil {
			return nil, err
		}
		return dex.GracefulComplete(nil), nil
	}
	if err != nil {
		return nil, err
	}
	return dex.GoTo(AwaitShipment{}, tracked), nil
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Reads the shipment at each interval and records how it ended."
type AwaitShipment struct {
	dex.StepDefaults
	getClient func() *dex.Client
}

// GetStepOptions takes the same lock as the report RPC and loads the records.
func (AwaitShipment) GetStepOptions() *dex.StepOptions {
	return &dex.StepOptions{
		ExecuteLockAttributes:    []dex.AttributeLock{dex.LockAttribute(ShipmentRecordsLock)},
		ExecuteLoadAttributeMaps: []dex.AttributeDef{ShipmentRecords},
	}
}

func (AwaitShipment) WaitFor(_ dex.Context, tracked TrackedShipment) (*dex.Wait, error) {
	return dex.Until(dex.Timer(time.Duration(tracked.ReconcileIntervalSeconds) * time.Second)), nil
}

func (step AwaitShipment) Execute(ctx dex.Context, tracked TrackedShipment) (*dex.StepDecision, error) {
	client := step.getClient()
	if client == nil {
		return nil, errClientUnavailable
	}
	number := tracked.Shipment.ShipmentNumber
	reading, err := reconcileShipment(ctx, client, number)
	if err != nil {
		return nil, err
	}
	if reading.Status == dex.FlowRunning.String() {
		return dex.GoTo(AwaitShipment{}, tracked), nil
	}
	// Merge with the record, which may already hold the reported outcome.
	record, err := loadShipmentRecord(ctx, number)
	if err != nil {
		return nil, err
	}
	record.Status = reading.Status
	if record.Outcome == "" {
		record.Outcome = reading.Outcome
	}
	if err := ShipmentRecords.Set(ctx, number, record); err != nil {
		return nil, err
	}
	return dex.GracefulComplete(nil), nil
}

// loadShipmentRecord returns the loaded record of a shipment, or an empty record when it has none.
// It returns an error when the record cannot be read.
func loadShipmentRecord(ctx dex.Context, number string) (ShipmentRecord, error) {
	record, err := ShipmentRecords.Get(ctx, number)
	var notFound *dex.AttributeNotFoundError
	if errors.As(err, &notFound) {
		return ShipmentRecord{}, nil
	}
	return record, err
}

// reconcileShipment reads a shipment: its status first, then its outcome.
// It returns a "running" record while the shipment runs, an "unavailable" record when the
// shipment does not exist, and an error for any other failure so the Step retries.
func reconcileShipment(ctx context.Context, client *dex.Client, number string) (ShipmentRecord, error) {
	info, err := client.DescribeFlow(ctx, number)
	var notFound *dex.FlowNotFoundError
	if errors.As(err, &notFound) {
		return ShipmentRecord{Status: ShipmentUnavailable}, nil
	}
	if err != nil {
		return ShipmentRecord{}, err
	}
	record := ShipmentRecord{Status: info.Status.String()}
	if info.Status == dex.FlowRunning {
		return record, nil
	}
	// An unset outcome Attribute leaves Outcome empty: the shipment ended without one.
	_, err = client.GetAttributes(ctx, number, dex.ReadAttribute(ShipmentOutcome, &record.Outcome))
	if errors.As(err, &notFound) {
		return record, nil
	}
	return record, err
}

/**
 * Derives the start request ID from the complete start request. A retried Execute sends the
 * same ID, so it repeats the same start. Any other request for the same shipment number sends
 * another ID, so Dex rejects it as already started.
 *
 * @param orderFlowId the Flow ID of the order that starts the shipment
 * @param shipment the shipment to start
 * @return "start:" followed by the lowercase hex SHA-256 of the encoded start request
 */
public static String shipmentStartRequestId(final String orderFlowId, final Shipment shipment) {
    final List<Object> request = List.of(
            SHIPMENT_FLOW_TYPE,
            shipment.shipmentNumber(),
            orderFlowId,
            shipment.destination(),
            shipment.deliveryDelaySeconds(),
            SHIPMENT_TIMEOUT.toSeconds(),
            "disallow");
    try {
        final byte[] encoded = START_REQUEST_MAPPER.writeValueAsString(request)
                .getBytes(StandardCharsets.UTF_8);
        return "start:" + HexFormat.of().formatHex(
                MessageDigest.getInstance("SHA-256").digest(encoded));
    } catch (final JsonProcessingException | NoSuchAlgorithmException failure) {
        throw new IllegalStateException("cannot derive the shipment start request ID", failure);
    }
}

/**
 * Returns the loaded record of a shipment, or an empty record when it has none.
 *
 * @param context a context that loaded the shipmentRecords AttributeMap
 * @param number the shipment number
 * @return the shipment's record, or a record with no status and no outcome
 */
private static ShipmentRecord loadShipmentRecord(final Context context, final String number) {
    final ShipmentRecord record = shipmentRecords.get(context, number);
    return record == null ? new ShipmentRecord(null, null) : record;
}

// dex:group group-id:start group-label:"Start shipments"
// dex:explanation text:"Starts the shipment as a top-level Flow named by its shipment number."
static final class StartShipment implements Step<TrackedShipment> {
    private final ObjectProvider<Client> clientProvider;
    private final ShipmentFlow shipmentFlow;

    StartShipment(final ObjectProvider<Client> clientProvider, final ShipmentFlow shipmentFlow) {
        this.clientProvider = clientProvider;
        this.shipmentFlow = shipmentFlow;
    }

    @Override
    public Class<TrackedShipment> getInputType() {
        return TrackedShipment.class;
    }

    @Override
    public StepDecision execute(final Context context, final TrackedShipment tracked) {
        final Client client = clientProvider.getObject();
        final String number = tracked.shipment().shipmentNumber();
        final String requestId = shipmentStartRequestId(context.getFlowId(), tracked.shipment());
        try {
            client.startFlow(
                    shipmentFlow,
                    number,
                    new ShipmentRequest(context.getFlowId(), tracked.shipment()),
                    StartFlowOptions.newBuilder()
                            .timeout(SHIPMENT_TIMEOUT)
                            .idReusePolicy(IdReusePolicy.DISALLOW)
                            .requestId(requestId)
                            .ignoreAlreadyStarted(true)
                            .build());
        } catch (final FlowAlreadyStartedException alreadyStarted) {
            // Another request owns this shipment number; this order does not track it.
            shipmentRecords.set(context, number, new ShipmentRecord(SHIPMENT_REJECTED, null));
            return StepDecision.gracefulComplete();
        }
        return StepDecision.goTo(AwaitShipment.class, tracked);
    }
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Reads the shipment at each interval and records how it ended."
static final class AwaitShipment implements Step<TrackedShipment> {
    private final ObjectProvider<Client> clientProvider;

    AwaitShipment(final ObjectProvider<Client> clientProvider) {
        this.clientProvider = clientProvider;
    }

    @Override
    public Class<TrackedShipment> getInputType() {
        return TrackedShipment.class;
    }

    /** Takes the same lock as the report RPC and loads the records. */
    @Override
    public StepOptions getStepOptions() {
        return StepOptions.newBuilder()
                .addExecuteLock(AttributeLock.of(shipmentRecordsLock))
                .addExecuteLoadAttributeMap(shipmentRecords)
                .build();
    }

    @Override
    public Wait waitFor(final Context context, final TrackedShipment tracked) {
        return Wait.until(
                Timer.byDuration(Duration.ofSeconds(tracked.reconcileIntervalSeconds())));
    }

    @Override
    public StepDecision execute(final Context context, final TrackedShipment tracked) {
        final String number = tracked.shipment().shipmentNumber();
        final ShipmentRecord reading = reconcileShipment(clientProvider.getObject(), number);
        if (statusName(FlowStatus.RUNNING).equals(reading.status())) {
            return StepDecision.goTo(AwaitShipment.class, tracked);
        }
        // Merge with the record, which may already hold the reported outcome.
        final ShipmentRecord stored = loadShipmentRecord(context, number);
        final String outcome = stored.outcome() != null ? stored.outcome() : reading.outcome();
        shipmentRecords.set(context, number, new ShipmentRecord(reading.status(), outcome));
        return StepDecision.gracefulComplete();
    }

    /**
     * Reads a shipment: its status first, then its outcome.
     *
     * @return a "running" record while the shipment runs, an "unavailable" record when the
     *     shipment does not exist, or the terminal status with the stored outcome; any other
     *     failure throws so the Step retries
     */
    private static ShipmentRecord reconcileShipment(final Client client, final String number) {
        final FlowInfo info;
        try {
            info = client.describeFlow(number);
        } catch (final FlowNotFoundException notFound) {
            return new ShipmentRecord(SHIPMENT_UNAVAILABLE, null);
        }
        final String status = statusName(info.getStatus());
        if (info.getStatus() == FlowStatus.RUNNING) {
            return new ShipmentRecord(status, null);
        }
        try {
            // An unset outcome Attribute leaves the outcome empty: the shipment ended without one.
            final String outcome = client.getAttributes(number, ShipmentFlow.shipmentOutcome)
                    .get(ShipmentFlow.shipmentOutcome)
                    .orElse(null);
            return new ShipmentRecord(status, outcome);
        } catch (final FlowNotFoundException notFound) {
            return new ShipmentRecord(status, null);
        }
    }
}

/**

 *
 * A retried Execute sends the same ID, so it repeats the same start. Any other

  const request = JSON.stringify([
    SHIPMENT_FLOW_TYPE,
    shipment.shipmentNumber,
    orderFlowId,
    shipment.destination,
    shipment.deliveryDelaySeconds,
    SHIPMENT_TIMEOUT_MS / 1000,
    "disallow",
  ]);
  return `start:${createHash("sha256").update(request).digest("hex")}`;

class StartShipment implements Step<TrackedShipment> {
  public constructor(
    private readonly getClient: () => Client,
    private readonly shipmentFlow: ShipmentFlow,
  ) {}

  public getStepType(): string {
    return "StartShipment";
  }

  public async execute(context: Context, tracked: TrackedShipment): Promise<StepDecision> {
    // Calling a field through this would hide the Step class from the Flow visualizer.
    const getClient = this.getClient;
    const number = tracked.shipment.shipmentNumber;
    const requestId = shipmentStartRequestId(context.flowId, tracked.shipment);
    try {
      await getClient().startFlow(
        this.shipmentFlow,
        number,
        { orderFlowId: context.flowId, shipment: tracked.shipment },
        {
          timeoutMs: SHIPMENT_TIMEOUT_MS,
          idReusePolicy: IdReusePolicy.DISALLOW,
          requestId,
          ignoreAlreadyStarted: true,
        },
      );
    } catch (error) {
      if (!(error instanceof FlowAlreadyStartedError)) {
        throw error;
      }
      // Another request owns this shipment number; this order does not track it.
      shipmentRecords.set(context, number, { status: SHIPMENT_REJECTED });
      return gracefulComplete();
    }
    return goTo(AwaitShipment, tracked);
  }
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Reads the shipment at each interval and records how it ended."
class AwaitShipment implements Step<TrackedShipment> {
  public constructor(private readonly getClient: () => Client) {}

  public getStepType(): string {
    return "AwaitShipment";
  }

  /** Takes the same lock as the report RPC and loads the records. */
  public getStepOptions(): StepOptions {
    return {
      executeLockAttributes: [shipmentRecordsLock.lock()],
      executeLoadAttributeMaps: [shipmentRecords],
    };
  }

  public waitFor(_context: Context, tracked: TrackedShipment): Wait {
    return Wait.until(Timer.byDuration(tracked.reconcileIntervalSeconds * 1000));
  }

  public async execute(context: Context, tracked: TrackedShipment): Promise<StepDecision> {
    // Calling a field through this would hide the Step class from the Flow visualizer.
    const getClient = this.getClient;
    const number = tracked.shipment.shipmentNumber;
    const reading = await reconcileShipment(getClient(), number);
    if (reading.status === "running") {
      return goTo(AwaitShipment, tracked);
    }
    // Merge with the record, which may already hold the reported outcome.
    const record = loadShipmentRecord(context, number);
    shipmentRecords.set(context, number, {
      status: reading.status,
      outcome: record.outcome ?? reading.outcome,
    });
    return gracefulComplete();
  }
}

/**
 * Returns the loaded record of a shipment, or an empty record when it has none.
 *
 * @returns The stored record, or `{}` when the shipment has no record yet.
 */
function loadShipmentRecord(context: Context, number: string): ShipmentRecord {
  return (shipmentRecords.get(context, number) as ShipmentRecord | undefined) ?? {};
}

/**
 * Reads a shipment: its status first, then its outcome.
 *
 * @returns A "running" record while the shipment runs, an "unavailable" record
 * when the shipment does not exist, or the terminal status with the stored
 * outcome. It throws any other failure so the Step retries.
 */
async function reconcileShipment(client: Client, number: string): Promise<ShipmentRecord> {
  let status: FlowStatus;
  try {
    status = (await client.describeFlow(number)).status;
  } catch (error) {
    if (error instanceof FlowNotFoundError) {
      return { status: SHIPMENT_UNAVAILABLE };
    }
    throw error;
  }
  const record = { status: shipmentStatusOf(status) };
  if (status === "running") {
    return record;
  }
  try {
    // An unset outcome Attribute leaves outcome empty: the shipment ended without one.
    const [outcome] = await client.getAttributes(number, shipmentOutcome);
    return outcome === undefined ? record : { ...record, outcome };
  } catch (error) {
    if (error instanceof FlowNotFoundError) {
      return record;
    }
    throw error;
  }
}

/// Derives the start request ID from the complete start request.
///
/// A retried Execute sends the same ID, so it repeats the same start. Any other
/// request for the same shipment number sends another ID, so Dex rejects it as
/// already started.
pub fn shipment_start_request_id(order_flow_id: &str, shipment: &Shipment) -> String {
    let request = serde_json::to_vec(&(
        ShipmentFlow::default().flow_type(),
        &shipment.shipment_number,
        order_flow_id,
        &shipment.destination,
        shipment.delivery_delay_seconds,
        SHIPMENT_TIMEOUT.as_secs(),
        "disallow",
    ))
    .expect("a tuple of strings and integers always encodes as JSON");
    format!("start:{:x}", Sha256::digest(&request))
}

// dex:group group-id:start group-label:"Start shipments"
// dex:explanation text:"Starts the shipment as a top-level Flow named by its shipment number."
#[derive(Default)]
struct StartShipment {
    client: Option<Arc<Client>>,
}

impl Step for StartShipment {
    type Input = TrackedShipment;

    fn execute(&self, context: &mut Context, tracked: Self::Input) -> HandlerResult<StepDecision> {
        let client = require_client(self.client.as_ref())?;
        let order_flow_id = context.flow_id().to_string();
        let number = tracked.shipment.shipment_number.clone();
        let request_id = shipment_start_request_id(&order_flow_id, &tracked.shipment);
        let request = ShipmentRequest {
            order_flow_id,
            shipment: tracked.shipment.clone(),
        };
        let options = StartFlowOptions::new()
            .timeout(SHIPMENT_TIMEOUT)
            .id_reuse_policy(IdReusePolicy::Disallow)
            .request_id(request_id)
            .ignore_already_started(true);
        match client.start_flow_with_options(&ShipmentFlow::default(), &number, request, options) {
            Ok(_run_id) => Ok(StepDecision::go_to(&AwaitShipment::default(), tracked)),
            Err(SdkError::FlowAlreadyStarted { .. }) => {
                // Another request owns this shipment number; this order does not track it.
                let record = ShipmentRecord {
                    status: Some(SHIPMENT_REJECTED.to_string()),
                    outcome: None,
                };
                SHIPMENT_RECORDS.set(context, &number, record)?;
                Ok(StepDecision::graceful_complete(()))
            }
            Err(error) => Err(HandlerError::from_error(error)),
        }
    }
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Reads the shipment at each interval and records how it ended."
#[derive(Default)]
struct AwaitShipment {
    client: Option<Arc<Client>>,
}

impl Step for AwaitShipment {
    type Input = TrackedShipment;

    /// Takes the same lock as the report RPC and loads the records.
    fn options(&self) -> StepOptions<Self::Input> {
        StepOptions::new()
            .execute_lock(SHIPMENT_RECORDS_LOCK.lock())
            .execute_load_attribute_map(&SHIPMENT_RECORDS)
    }

    fn wait_for(&self, _context: &mut Context, tracked: Self::Input) -> HandlerResult<Wait> {
        Ok(Wait::until(Timer::by_duration(Duration::from_secs(
            tracked.reconcile_interval_seconds,
        ))))
    }

    fn execute(&self, context: &mut Context, tracked: Self::Input) -> HandlerResult<StepDecision> {
        let client = require_client(self.client.as_ref())?;
        let number = tracked.shipment.shipment_number.clone();
        let reading = match reconcile_shipment(client, &number)? {
            ShipmentReading::Running => {
                return Ok(StepDecision::go_to(&AwaitShipment::default(), tracked));
            }
            ShipmentReading::Closed(reading) => reading,
        };
        // Merge with the record, which may already hold the reported outcome.
        let mut record = load_shipment_record(context, &number)?;
        record.status = reading.status;
        if record.outcome.is_none() {
            record.outcome = reading.outcome;
        }
        SHIPMENT_RECORDS.set(context, &number, record)?;
        Ok(StepDecision::graceful_complete(()))
    }
}

/// Returns the loaded record of a shipment, or an empty record when it has none.
///
/// Returns an error when the record cannot be read.
fn load_shipment_record(context: &Context, number: &str) -> HandlerResult<ShipmentRecord> {
    Ok(SHIPMENT_RECORDS.get(context, number)?.unwrap_or_default())
}

/// What a reconcile read found.
enum ShipmentReading {
    Running,
    Closed(ShipmentRecord),
}

/// Reads a shipment: its status first, then its outcome.
///
/// Returns `Running` while the shipment runs, an "unavailable" record when the
/// shipment does not exist, and an error for any other failure so the Step retries.
fn reconcile_shipment(client: &Client, number: &str) -> HandlerResult<ShipmentReading> {
    let status = match client.describe_flow(number) {
        Ok(info) => info.status,
        Err(SdkError::FlowNotFound { .. }) => {
            return Ok(ShipmentReading::Closed(ShipmentRecord {
                status: Some(SHIPMENT_UNAVAILABLE.to_string()),
                outcome: None,
            }));
        }
        Err(error) => return Err(HandlerError::from_error(error)),
    };
    if status == FlowStatus::Running {
        return Ok(ShipmentReading::Running);
    }
    // An unset outcome Attribute leaves the outcome empty: the shipment ended without one.
    let outcome = match client.get_attributes(number, (&*SHIPMENT_OUTCOME,)) {
        Ok((outcome,)) => outcome,
        Err(SdkError::FlowNotFound { .. }) => None,
        Err(error) => return Err(HandlerError::from_error(error)),
    };
    Ok(ShipmentReading::Closed(ShipmentRecord {
        status: Some(flow_status_name(status).to_string()),
        outcome,
    }))
}

## Report after the outcome commits

The shipment commits its outcome in one Step and reports in the next. Both Steps declare SYNC durability for `Execute`. The report Step then starts only after the outcome is stored, even when the Flow defaults to ASYNC.

The report RPC keeps the first outcome it receives, so a repeated report changes nothing. When the Client accepts an RPC request ID, the report also carries a stable one: `report:` followed by the shipment number.

When the order has already closed, the report fails with a typed error. The shipment ends its attempts there. Its outcome stays readable through the Client.

## One record per shipment {#records}

The order keeps one record per shipment in the `shipmentRecords` AttributeMap, keyed by the shipment number. The record holds the outcome and the terminal status as separate fields. The report RPC fills the outcome. `AwaitShipment` fills the status, and the outcome when the record has none.

Both writers lock the singleton `shipmentRecordsLock` Attribute and load the records. A report and a reconcile write therefore never overwrite each other. The lock Attribute stores no value; it only serializes the two writers. A report that meets the lock fails with a lock conflict, and the shipment retries it.

`AwaitShipment` reads a shipment in this order:

1. Describe the shipment. A running shipment is read again at the next interval, even after its report arrived.
2. A closed shipment: record its status, then read its outcome Attribute. An unset Attribute means the shipment ended without an outcome.
3. A shipment that cannot be found is recorded as `unavailable`. That is a business policy.
4. Any other error fails the Step, so Dex retries it.

The support team can cancel a shipment by its number. A shipment canceled before its outcome commits has no outcome; the order records it as `canceled`. A shipment canceled after its outcome commits, or after it sent its report, can still have an outcome, and the order keeps it.

A shipment number belongs to one order. When another request already used the number, the start fails with a typed already-started error. The example records that shipment as `rejected` and does not track it. Give each business attempt its own shipment number.

func (controller *controller) cancelShipment(request *gin.Context) {
	number, _, found := controller.describeShipment(request)
	if !found {
		return
	}
	err := controller.client.StopFlow(request.Request.Context(), number, dex.StopOptions{
		Type:   dex.CancelFlow,
		Reason: "shipment canceled",
	})
	httputil.RespondString(request, "canceled", err)
}

// describeShipment describes the Flow named by the shipmentNumber query.
// It returns found as false after it responded: 404 when no ShipmentFlow has that Flow ID.
func (controller *controller) describeShipment(request *gin.Context) (string, dex.FlowInfo, bool) {
	number, found := httputil.RequiredQuery(request, "shipmentNumber")
	if !found {
		return "", dex.FlowInfo{}, false
	}
	info, err := controller.client.DescribeFlow(request.Request.Context(), number)
	var notFound *dex.FlowNotFoundError
	if errors.As(err, &notFound) || (err == nil && info.FlowType != shipmentFlowType) {
		request.JSON(http.StatusNotFound, gin.H{"error": "shipment " + number + " not found"})
		return "", dex.FlowInfo{}, false
	}
	if err != nil {
		httputil.Respond(request, nil, err)
		return "", dex.FlowInfo{}, false
	}
	return number, info, true
}

/// Describes the Flow named by the `shipmentNumber` query.
///
/// Returns the shipment number and its Flow info, or the error response to send:
/// 404 when no `ShipmentFlow` has that Flow ID.
async fn describe_shipment(
    client: &SharedClient,
    query: ShipmentQuery,
) -> Result<(String, FlowInfo), Response> {
    let number = query.shipment_number;
    if number.is_empty() {
        return Err(error_response(
            StatusCode::BAD_REQUEST,
            "shipmentNumber is required",
        ));
    }
    let lookup_client = Arc::clone(client);
    let lookup_number = number.clone();
    match run_blocking(move || lookup_client.describe_flow(&lookup_number)) {
        Ok(info) if info.flow_type == ShipmentFlow::default().flow_type() => Ok((number, info)),
        Ok(_) | Err(SdkError::FlowNotFound { .. }) => Err(error_response(
            StatusCode::NOT_FOUND,
            &format!("shipment {number} not found"),
        )),
        Err(error) => Err(map_sdk_error(error).into_response()),
    }
}

## Choose this or a SubFlow {#choose}

Choose a [SubFlow](/concepts/primitives/subflow) when the child exists only for its parent. Dex derives its Flow ID from the parent, and the parent waits for it with a Condition.

Choose a top-level child Flow when the child needs its own identity:

- People or systems look it up, retry it, or stop it by its own number.
- Something other than the parent can start it.
- It can outlive the parent, with its own Flow timeout.

The cost is more code. The parent starts the child, receives its report, and reads it until it ends.
