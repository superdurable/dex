# Child Flows with Business Identity

Use this pattern when each child job has its own business number. People and other systems look the child up, retry it, or stop it by that number.

An example is an order that ships as several parcels. Each shipment has a shipment number. The carrier, the support team, and the order all find the shipment by that number. The order still needs to know how each shipment ended.

The order starts each shipment as its own top-level Flow. The shipment number is its Flow ID.

## How it works

1. `StartShipments` starts one branch per shipment.
2. `StartShipment` starts a `ShipmentFlow` through the Client. Its Flow ID is the shipment number. The shipment gets its own Flow timeout. `StartShipment` passes the run ID that the start returns to the next Step.
3. `ClaimShipment` records that run ID as the claimed run. It also merges a report that arrived before the claim.
4. The shipment delivers. `DeliverShipment` stores its outcome in the `shipmentOutcome` Attribute.
5. `ReportShipmentOutcome` calls the order's report RPC with its own run ID. The RPC is `RecordShipmentOutcome` in Go, `record_shipment_outcome` in Python, and `recordShipmentOutcome` in Java, TypeScript, and Rust. It fills the outcome in the shipment's record.
6. `AwaitShipment` reads that run at each interval. A running shipment is read again later. For a closed shipment, `RecordShipmentEnd` records the terminal status, and the read outcome when no report filled it.

The report RPC and the Steps that write the records share one lock. An RPC never waits for a lock: it fails while a Step holds it. A Step's lock stays held through its retries and backoff. So the Steps that call the Client, `StartShipment` and `AwaitShipment`, take no lock. Each hands its result to a short locked Step that only writes the records.

A shipment that fails or times out on its own never reports, because its report Step never runs. The interval read in step 6 covers it. A child can also route its terminal failure to a recovery Step, or its timeout to a timeout handler, that reports to the parent. Keep each shipment's Flow timeout longer than its retry budget.

The [Production checklist](#production-checklist) covers the edge cases the example handles.

class StartShipment(Step[TrackedShipment]):
    """Starts ShipmentFlow with the shipment number as its Flow ID.

    It takes no lock: a report must never wait for the start call or its retries.
    """

    def __init__(
        self,
        client_provider: Callable[[], AsyncClient],
        shipment_flow: ShipmentFlow,
    ) -> None:
        self.client_provider = client_provider
        self.shipment_flow = shipment_flow

    async def execute(  # type: ignore[override]
        self, context: AsyncContext, tracked: TrackedShipment
    ) -> StepDecision:
        number = tracked.shipment.shipment_number
        try:
            run_id = await self.client_provider().start_flow(
                self.shipment_flow,
                number,
                ShipmentRequest(order_flow_id=context.flow_id, shipment=tracked.shipment),
                StartFlowOptions(
                    timeout=SHIPMENT_TIMEOUT,
                    id_reuse_policy=IdReusePolicy.DISALLOW,
                    request_id=shipment_start_request_id(context.flow_id, tracked.shipment),
                    ignore_already_started=True,
                ),
            )
        except FlowAlreadyStartedError:
            # Another request owns this shipment number; this order does not track it.
            return go_to(ClaimShipment, StartedShipment(tracked=tracked, rejected=True))
        return go_to(
            ClaimShipment,
            StartedShipment(tracked=dataclasses.replace(tracked, shipment_run_id=run_id)),
        )

class ClaimShipment(Step[StartedShipment]):
    """Records the claimed run, or the rejection, and merges a pending report of that run."""

    def get_step_options(self) -> StepOptions:
        """Takes the records lock, so the claim never races a report."""
        return StepOptions(
            execute_lock_attributes=(SHIPMENT_RECORDS_LOCK.lock(),),
            execute_load_attribute_maps=(PENDING_SHIPMENT_REPORTS,),
        )

    def execute(self, context: Context, started: StartedShipment) -> StepDecision:
        number = started.tracked.shipment.shipment_number
        pending: dict[str, ShipmentReport] | None = PENDING_SHIPMENT_REPORTS.get(context, number)
        # The claim or the rejection settles every early report of this shipment.
        if pending is not None:
            PENDING_SHIPMENT_REPORTS.delete(context, number)
        if started.rejected:
            SHIPMENT_RECORDS.set(context, number, ShipmentRecord(status=SHIPMENT_REJECTED))
            return graceful_complete()
        run_id = started.tracked.shipment_run_id
        # Claim the run: reports and reads of any other run of this number are ignored.
        report = (pending or {}).get(run_id)
        outcome = report.outcome if report is not None else ""
        SHIPMENT_RECORDS.set(
            context,
            number,
            ShipmentRecord(status=SHIPMENT_STARTED, run_id=run_id, outcome=outcome),
        )
        return go_to(AwaitShipment, started.tracked)

# dex:explanation text:"Reads the claimed shipment run at each interval until it ends."
class AwaitShipment(Step[TrackedShipment]):
    """Reads the claimed shipment run at each interval until it ends.

    It takes no lock: a report must never wait for the reads or their retries.
    """

    def __init__(self, client_provider: Callable[[], AsyncClient]) -> None:
        self.client_provider = client_provider

    def wait_for(self, context: Context, tracked: TrackedShipment) -> Wait:
        return Wait.until(
            Timer.by_duration(timedelta(seconds=tracked.reconcile_interval_seconds))
        )

    async def execute(  # type: ignore[override]
        self, context: AsyncContext, tracked: TrackedShipment
    ) -> StepDecision:
        number = tracked.shipment.shipment_number
        reading = await reconcile_shipment(
            self.client_provider(), number, tracked.shipment_run_id
        )
        if reading.status == FlowStatus.RUNNING.value:
            return go_to(AwaitShipment, tracked)
        return go_to(
            RecordShipmentEnd,
            EndedShipment(
                shipment_number=number,
                shipment_run_id=tracked.shipment_run_id,
                reading=reading,
            ),
        )


# dex:group group-id:track group-label:"Track shipment"
# dex:explanation text:"Records how the claimed shipment run ended."
class RecordShipmentEnd(Step[EndedShipment]):
    """Merges the terminal status, and the read outcome when no report filled it."""

    def get_step_options(self) -> StepOptions:
        """Takes the same lock as the report RPC and loads the records."""
        return StepOptions(
            execute_lock_attributes=(SHIPMENT_RECORDS_LOCK.lock(),),
            execute_load_attribute_maps=(SHIPMENT_RECORDS,),
        )

    def execute(self, context: Context, ended: EndedShipment) -> StepDecision:
        # Merge with the record, which may already hold the reported outcome.
        record, _ = load_shipment_record(context, ended.shipment_number)
        SHIPMENT_RECORDS.set(
            context,
            ended.shipment_number,
            ShipmentRecord(
                status=ended.reading.status,
                run_id=ended.shipment_run_id,
                outcome=record.outcome or ended.reading.outcome,
            ),
        )
        return graceful_complete()

async def reconcile_shipment(client: AsyncClient, number: str, run_id: str) -> ShipmentRecord:
    """Reads the claimed run of a shipment: its status first, then its outcome.

    Returns a "running" record while that run runs, and an "unavailable" record
    when that run no longer exists or another run replaced it. Keeps an outcome
    only when the run is still the claimed one after the read. Any other failure
    raises, so the Step retries.
    """
    info, found = await describe_claimed_run(client, number, run_id)
    if info is None or not found:
        return ShipmentRecord(status=SHIPMENT_UNAVAILABLE)
    if info.status is FlowStatus.RUNNING:
        return ShipmentRecord(status=info.status.value)
    try:
        values = await client.get_attributes(number, SHIPMENT_OUTCOME)
    except FlowNotFoundError:
        return ShipmentRecord(status=info.status.value)
    # The Attribute read targets the latest run, so confirm it is still the claimed one.
    _, still_claimed = await describe_claimed_run(client, number, run_id)
    if not still_claimed:
        return ShipmentRecord(status=info.status.value)
    # An unset outcome Attribute leaves the outcome empty: the shipment ended without one.
    return ShipmentRecord(
        status=info.status.value, outcome=values.get(SHIPMENT_OUTCOME, "")
    )

// dex:group group-id:start group-label:"Start shipments"
// dex:explanation text:"Starts the shipment as a top-level Flow named by its shipment number."
type StartShipment struct {
	dex.StepDefaultsNoWaitFor[TrackedShipment]
	getClient    func() *dex.Client
	shipmentFlow *ShipmentFlow
}

// Execute takes no lock: a report must never wait for the start call or its retries.
func (step StartShipment) Execute(ctx dex.Context, tracked TrackedShipment) (*dex.StepDecision, error) {
	client := step.getClient()
	if client == nil {
		return nil, errClientUnavailable
	}
	number := tracked.Shipment.ShipmentNumber
	requestID, err := ShipmentStartRequestID(ctx.FlowID(), tracked.Shipment)
	if err != nil {
		return nil, err
	}
	timeout := ShipmentTimeout
	runID, err := client.StartFlow(ctx, step.shipmentFlow, number, ShipmentRequest{
		OrderFlowID: ctx.FlowID(),
		Shipment:    tracked.Shipment,
	}, dex.StartFlowOptions{
		Timeout:        &timeout,
		IDReusePolicy:  dex.IDReuseDisallow,
		RequestID:      &requestID,
		AlreadyStarted: &dex.AlreadyStartedOptions{IgnoreError: true},
	})
	var alreadyStarted *dex.FlowAlreadyStartedError
	if errors.As(err, &alreadyStarted) {
		// Another request owns this shipment number; this order does not track it.
		return dex.GoTo(ClaimShipment{}, StartedShipment{Tracked: tracked, Rejected: true}), nil
	}
	if err != nil {
		return nil, err
	}
	tracked.ShipmentRunID = runID
	return dex.GoTo(ClaimShipment{}, StartedShipment{Tracked: tracked}), nil
}

// dex:group group-id:start group-label:"Start shipments"
// dex:explanation text:"Claims the started run and merges a report that arrived before the claim."
type ClaimShipment struct {
	dex.StepDefaultsNoWaitFor[StartedShipment]
}

// GetStepOptions takes the records lock, so the claim never races a report.
func (ClaimShipment) GetStepOptions() *dex.StepOptions {
	return &dex.StepOptions{
		ExecuteLockAttributes:    []dex.AttributeLock{dex.LockAttribute(ShipmentRecordsLock)},
		ExecuteLoadAttributeMaps: []dex.AttributeDef{PendingShipmentReports},
	}
}

func (ClaimShipment) Execute(ctx dex.Context, started StartedShipment) (*dex.StepDecision, error) {
	number := started.Tracked.Shipment.ShipmentNumber
	pending, err := loadPendingReports(ctx, number)
	if err != nil {
		return nil, err
	}
	// The claim or the rejection settles every early report of this shipment.
	if pending != nil {
		if err := PendingShipmentReports.Delete(ctx, number); err != nil {
			return nil, err
		}
	}
	if started.Rejected {
		if err := ShipmentRecords.Set(ctx, number, ShipmentRecord{Status: ShipmentRejected}); err != nil {
			return nil, err
		}
		return dex.GracefulComplete(nil), nil
	}
	runID := started.Tracked.ShipmentRunID
	// Claim the run: reports and reads of any other run of this number are ignored.
	record := ShipmentRecord{Status: ShipmentStarted, RunID: runID, Outcome: pending[runID].Outcome}
	if err := ShipmentRecords.Set(ctx, number, record); err != nil {
		return nil, err
	}
	return dex.GoTo(AwaitShipment{}, started.Tracked), nil
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Reads the claimed shipment run at each interval until it ends."
type AwaitShipment struct {
	dex.StepDefaults
	getClient func() *dex.Client
}

func (AwaitShipment) WaitFor(_ dex.Context, tracked TrackedShipment) (*dex.Wait, error) {
	return dex.Until(dex.Timer(time.Duration(tracked.ReconcileIntervalSeconds) * time.Second)), nil
}

// Execute takes no lock: a report must never wait for the reads or their retries.
func (step AwaitShipment) Execute(ctx dex.Context, tracked TrackedShipment) (*dex.StepDecision, error) {
	client := step.getClient()
	if client == nil {
		return nil, errClientUnavailable
	}
	number := tracked.Shipment.ShipmentNumber
	reading, err := reconcileShipment(ctx, client, number, tracked.ShipmentRunID)
	if err != nil {
		return nil, err
	}
	if reading.Status == dex.FlowRunning.String() {
		return dex.GoTo(AwaitShipment{}, tracked), nil
	}
	return dex.GoTo(RecordShipmentEnd{}, EndedShipment{
		ShipmentNumber: number,
		ShipmentRunID:  tracked.ShipmentRunID,
		Reading:        reading,
	}), nil
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Records how the claimed shipment run ended."
type RecordShipmentEnd struct {
	dex.StepDefaultsNoWaitFor[EndedShipment]
}

// GetStepOptions takes the same lock as the report RPC and loads the records.
func (RecordShipmentEnd) GetStepOptions() *dex.StepOptions {
	return &dex.StepOptions{
		ExecuteLockAttributes:    []dex.AttributeLock{dex.LockAttribute(ShipmentRecordsLock)},
		ExecuteLoadAttributeMaps: []dex.AttributeDef{ShipmentRecords},
	}
}

func (RecordShipmentEnd) Execute(ctx dex.Context, ended EndedShipment) (*dex.StepDecision, error) {
	// Merge with the record, which may already hold the reported outcome.
	record, _, err := loadShipmentRecord(ctx, ended.ShipmentNumber)
	if err != nil {
		return nil, err
	}
	record.Status = ended.Reading.Status
	record.RunID = ended.ShipmentRunID
	if record.Outcome == "" {
		record.Outcome = ended.Reading.Outcome
	}
	if err := ShipmentRecords.Set(ctx, ended.ShipmentNumber, record); err != nil {
		return nil, err
	}
	return dex.GracefulComplete(nil), nil
}

// reconcileShipment reads the claimed run of a shipment: its status first, then its outcome.
// It returns a "running" record while that run runs, and an "unavailable" record when that
// run no longer exists or another run replaced it. It keeps an outcome only when the run
// is still the claimed one after the read. It returns an error for any other failure so the Step retries.
func reconcileShipment(ctx context.Context, client *dex.Client, number string, runID string) (ShipmentRecord, error) {
	info, found, err := describeClaimedRun(ctx, client, number, runID)
	if err != nil || !found {
		return ShipmentRecord{Status: ShipmentUnavailable}, err
	}
	record := ShipmentRecord{Status: info.Status.String()}
	if info.Status == dex.FlowRunning {
		return record, nil
	}
	// An unset outcome Attribute leaves Outcome empty: the shipment ended without one.
	var outcome string
	_, err = client.GetAttributes(ctx, number, dex.ReadAttribute(ShipmentOutcome, &outcome))
	var notFound *dex.FlowNotFoundError
	if errors.As(err, &notFound) {
		return record, nil
	}
	if err != nil {
		return ShipmentRecord{}, err
	}
	// The Attribute read targets the latest run, so confirm it is still the claimed one.
	_, stillClaimed, err := describeClaimedRun(ctx, client, number, runID)
	if err != nil {
		return ShipmentRecord{}, err
	}
	if stillClaimed {
		record.Outcome = outcome
	}
	return record, nil
}

static final class StartShipment implements Step<TrackedShipment> {
    private final ObjectProvider<Client> clientProvider;
    private final ShipmentFlow shipmentFlow;

    StartShipment(final ObjectProvider<Client> clientProvider, final ShipmentFlow shipmentFlow) {
        this.clientProvider = clientProvider;
        this.shipmentFlow = shipmentFlow;
    }

    @Override
    public Class<TrackedShipment> getInputType() {
        return TrackedShipment.class;
    }

    /** Takes no lock: a report must never wait for the start call or its retries. */
    @Override
    public StepDecision execute(final Context context, final TrackedShipment tracked) {
        final Client client = clientProvider.getObject();
        final String number = tracked.shipment().shipmentNumber();
        final String requestId = shipmentStartRequestId(context.getFlowId(), tracked.shipment());
        final String runId;
        try {
            runId = client.startFlow(
                    shipmentFlow,
                    number,
                    new ShipmentRequest(context.getFlowId(), tracked.shipment()),
                    StartFlowOptions.newBuilder()
                            .timeout(SHIPMENT_TIMEOUT)
                            .idReusePolicy(IdReusePolicy.DISALLOW)
                            .requestId(requestId)
                            .ignoreAlreadyStarted(true)
                            .build());
        } catch (final FlowAlreadyStartedException alreadyStarted) {
            // Another request owns this shipment number; this order does not track it.
            return StepDecision.goTo(
                    ClaimShipment.class, new StartedShipment(tracked, true));
        }
        return StepDecision.goTo(ClaimShipment.class, new StartedShipment(new TrackedShipment(
                tracked.shipment(), tracked.reconcileIntervalSeconds(), runId), false));
    }
}

static final class ClaimShipment implements Step<StartedShipment> {
    @Override
    public Class<StartedShipment> getInputType() {
        return StartedShipment.class;
    }

    /** Takes the records lock, so the claim never races a report. */
    @Override
    public StepOptions getStepOptions() {
        return StepOptions.newBuilder()
                .addExecuteLock(AttributeLock.of(shipmentRecordsLock))
                .addExecuteLoadAttributeMap(pendingShipmentReports)
                .build();
    }

    @Override
    public StepDecision execute(final Context context, final StartedShipment started) {
        final String number = started.tracked().shipment().shipmentNumber();
        final PendingShipmentReports pending = pendingShipmentReports.get(context, number);
        // The claim or the rejection settles every early report of this shipment.
        if (pending != null) {
            pendingShipmentReports.delete(context, number);
        }
        if (started.rejected()) {
            shipmentRecords.set(
                    context, number, new ShipmentRecord(SHIPMENT_REJECTED, null, null));
            return StepDecision.gracefulComplete();
        }
        final String runId = started.tracked().shipmentRunId();
        // Claim the run: reports and reads of any other run of this number are ignored.
        final ShipmentReport report = pending != null ? pending.get(runId) : null;
        final String outcome = report != null ? report.outcome() : null;
        shipmentRecords.set(context, number, new ShipmentRecord(SHIPMENT_STARTED, runId, outcome));
        return StepDecision.goTo(AwaitShipment.class, started.tracked());
    }
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Reads the claimed shipment run at each interval until it ends."
static final class AwaitShipment implements Step<TrackedShipment> {
    private final ObjectProvider<Client> clientProvider;

    AwaitShipment(final ObjectProvider<Client> clientProvider) {
        this.clientProvider = clientProvider;
    }

    @Override
    public Class<TrackedShipment> getInputType() {
        return TrackedShipment.class;
    }

    @Override
    public Wait waitFor(final Context context, final TrackedShipment tracked) {
        return Wait.until(
                Timer.byDuration(Duration.ofSeconds(tracked.reconcileIntervalSeconds())));
    }

    /** Takes no lock: a report must never wait for the reads or their retries. */
    @Override
    public StepDecision execute(final Context context, final TrackedShipment tracked) {
        final String number = tracked.shipment().shipmentNumber();
        final ShipmentRecord reading = reconcileShipment(
                clientProvider.getObject(), number, tracked.shipmentRunId());
        if (statusName(FlowStatus.RUNNING).equals(reading.status())) {
            return StepDecision.goTo(AwaitShipment.class, tracked);
        }
        return StepDecision.goTo(RecordShipmentEnd.class,
                new EndedShipment(number, tracked.shipmentRunId(), reading));
    }

    /**
     * Reads the claimed run of a shipment: its status first, then its outcome. It keeps an
     * outcome only when the run is still the claimed one after the read.
     *
     * @return a "running" record while that run runs, an "unavailable" record when that run no
     *     longer exists or another run replaced it, or the terminal status with the stored
     *     outcome; any other failure throws so the Step retries
     */
    private static ShipmentRecord reconcileShipment(
            final Client client, final String number, final String runId) {
        final Optional<FlowInfo> claimed = describeClaimedRun(client, number, runId);
        if (claimed.isEmpty()) {
            return new ShipmentRecord(SHIPMENT_UNAVAILABLE, null, null);
        }
        final FlowInfo info = claimed.get();
        final String status = statusName(info.getStatus());
        if (info.getStatus() == FlowStatus.RUNNING) {
            return new ShipmentRecord(status, null, null);
        }
        final String outcome;
        try {
            // An unset outcome Attribute leaves the outcome empty: the shipment ended without one.
            outcome = client.getAttributes(number, ShipmentFlow.shipmentOutcome)
                    .get(ShipmentFlow.shipmentOutcome)
                    .orElse(null);
        } catch (final FlowNotFoundException notFound) {
            return new ShipmentRecord(status, null, null);
        }
        // The Attribute read targets the latest run, so confirm it is still the claimed one.
        final boolean stillClaimed = describeClaimedRun(client, number, runId).isPresent();
        return new ShipmentRecord(status, null, stillClaimed ? outcome : null);
    }

    /**
     * Describes the latest run of a shipment.
     *
     * @return the run's Flow info, or empty when the shipment does not exist or its latest run
     *     is not {@code runId}; any other failure throws
     */
    private static Optional<FlowInfo> describeClaimedRun(
            final Client client, final String number, final String runId) {
        final FlowInfo info;
        try {
            info = client.describeFlow(number);
        } catch (final FlowNotFoundException notFound) {
            return Optional.empty();
        }
        return runId != null && runId.equals(info.getRunId())
                ? Optional.of(info)
                : Optional.empty();
    }
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Records how the claimed shipment run ended."
static final class RecordShipmentEnd implements Step<EndedShipment> {
    @Override
    public Class<EndedShipment> getInputType() {
        return EndedShipment.class;
    }

    /** Takes the same lock as the report RPC and loads the records. */
    @Override
    public StepOptions getStepOptions() {
        return StepOptions.newBuilder()
                .addExecuteLock(AttributeLock.of(shipmentRecordsLock))
                .addExecuteLoadAttributeMap(shipmentRecords)
                .build();
    }

    @Override
    public StepDecision execute(final Context context, final EndedShipment ended) {
        // Merge with the record, which may already hold the reported outcome.
        final String storedOutcome = loadShipmentRecord(context, ended.shipmentNumber())
                .map(ShipmentRecord::outcome)
                .orElse(null);
        final String outcome = storedOutcome != null ? storedOutcome : ended.reading().outcome();
        shipmentRecords.set(context, ended.shipmentNumber(),
                new ShipmentRecord(ended.reading().status(), ended.shipmentRunId(), outcome));
        return StepDecision.gracefulComplete();
    }
}

// dex:group group-id:start group-label:"Start shipments"
// dex:explanation text:"Starts the shipment as a top-level Flow named by its shipment number."
class StartShipment implements Step<TrackedShipment> {
  public constructor(
    private readonly getClient: () => Client,
    private readonly shipmentFlow: ShipmentFlow,
  ) {}

  public getStepType(): string {
    return "StartShipment";
  }

  /** Takes no lock: a report must never wait for the start call or its retries. */
  public async execute(context: Context, tracked: TrackedShipment): Promise<StepDecision> {
    // Calling a field through this would hide the Step class from the Flow visualizer.
    const getClient = this.getClient;
    const number = tracked.shipment.shipmentNumber;
    const requestId = shipmentStartRequestId(context.flowId, tracked.shipment);
    let runId: string;
    try {
      runId = await getClient().startFlow(
        this.shipmentFlow,
        number,
        { orderFlowId: context.flowId, shipment: tracked.shipment },
        {
          timeoutMs: SHIPMENT_TIMEOUT_MS,
          idReusePolicy: IdReusePolicy.DISALLOW,
          requestId,
          ignoreAlreadyStarted: true,
        },
      );
    } catch (error) {
      if (!(error instanceof FlowAlreadyStartedError)) {
        throw error;
      }
      // Another request owns this shipment number; this order does not track it.
      return goTo(ClaimShipment, { tracked, rejected: true });
    }
    return goTo(ClaimShipment, { tracked: { ...tracked, shipmentRunId: runId } });
  }
}

// dex:group group-id:start group-label:"Start shipments"
// dex:explanation text:"Claims the started run and merges a report that arrived before the claim."
class ClaimShipment implements Step<StartedShipment> {
  public getStepType(): string {
    return "ClaimShipment";
  }

  /** Takes the records lock, so the claim never races a report. */
  public getStepOptions(): StepOptions {
    return {
      executeLockAttributes: [shipmentRecordsLock.lock()],
      executeLoadAttributeMaps: [pendingShipmentReports],
    };
  }

  public execute(context: Context, started: StartedShipment): StepDecision {
    const number = started.tracked.shipment.shipmentNumber;
    const pending = loadPendingReports(context, number);
    // The claim or the rejection settles every early report of this shipment.
    if (pending !== undefined) {
      pendingShipmentReports.delete(context, number);
    }
    if (started.rejected === true) {
      shipmentRecords.set(context, number, { status: SHIPMENT_REJECTED });
      return gracefulComplete();
    }
    const runId = started.tracked.shipmentRunId ?? "";
    // Claim the run: reports and reads of any other run of this number are ignored.
    const report = pending?.[runId];
    const record: ShipmentRecord =
      report === undefined
        ? { status: SHIPMENT_STARTED, runId }
        : { status: SHIPMENT_STARTED, runId, outcome: report.outcome };
    shipmentRecords.set(context, number, record);
    return goTo(AwaitShipment, started.tracked);
  }
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Reads the claimed shipment run at each interval until it ends."
class AwaitShipment implements Step<TrackedShipment> {
  public constructor(private readonly getClient: () => Client) {}

  public getStepType(): string {
    return "AwaitShipment";
  }

  public waitFor(_context: Context, tracked: TrackedShipment): Wait {
    return Wait.until(Timer.byDuration(tracked.reconcileIntervalSeconds * 1000));
  }

  /** Takes no lock: a report must never wait for the reads or their retries. */
  public async execute(_context: Context, tracked: TrackedShipment): Promise<StepDecision> {
    // Calling a field through this would hide the Step class from the Flow visualizer.
    const getClient = this.getClient;
    const number = tracked.shipment.shipmentNumber;
    const runId = tracked.shipmentRunId ?? "";
    const reading = await reconcileShipment(getClient(), number, runId);
    if (reading.status === "running") {
      return goTo(AwaitShipment, tracked);
    }
    return goTo(RecordShipmentEnd, { shipmentNumber: number, shipmentRunId: runId, reading });
  }
}

// dex:group group-id:track group-label:"Track shipment"
// dex:explanation text:"Records how the claimed shipment run ended."
class RecordShipmentEnd implements Step<EndedShipment> {
  public getStepType(): string {
    return "RecordShipmentEnd";
  }

  /** Takes the same lock as the report RPC and loads the records. */
  public getStepOptions(): StepOptions {
    return {
      executeLockAttributes: [shipmentRecordsLock.lock()],
      executeLoadAttributeMaps: [shipmentRecords],
    };
  }

  public execute(context: Context, ended: EndedShipment): StepDecision {
    // Merge with the record, which may already hold the reported outcome.
    const { record } = loadShipmentRecord(context, ended.shipmentNumber);
    shipmentRecords.set(context, ended.shipmentNumber, {
      status: ended.reading.status,
      runId: ended.shipmentRunId,
      outcome: record.outcome ?? ended.reading.outcome,
    });
    return gracefulComplete();
  }
}

/**
 * Reads the claimed run of a shipment: its status first, then its outcome.
 *
 * @returns A "running" record while that run runs, an "unavailable" record
 * when that run no longer exists or another run replaced it, or the terminal
 * status. It keeps an outcome only when the run is still the claimed one after
 * the read. It throws any other failure so the Step retries.
 */
async function reconcileShipment(client: Client, number: string, runId: string): Promise<ShipmentRecord> {
  const { info, found } = await describeClaimedRun(client, number, runId);
  if (info === undefined || !found) {
    return { status: SHIPMENT_UNAVAILABLE };
  }
  const record = { status: shipmentStatusOf(info.status) };
  if (info.status === "running") {
    return record;
  }
  let outcome: string | undefined;
  try {
    // An unset outcome Attribute leaves outcome empty: the shipment ended without one.
    [outcome] = await client.getAttributes(number, shipmentOutcome);
  } catch (error) {
    if (error instanceof FlowNotFoundError) {
      return record;
    }
    throw error;
  }
  // The Attribute read targets the latest run, so confirm it is still the claimed one.
  const { found: stillClaimed } = await describeClaimedRun(client, number, runId);
  return stillClaimed && outcome !== undefined ? { ...record, outcome } : record;
}

impl Step for ClaimShipment {

    fn options(&self) -> StepOptions<Self::Input> {
        StepOptions::new()
            .execute_lock(SHIPMENT_RECORDS_LOCK.lock())
            .execute_load_attribute_map(&PENDING_SHIPMENT_REPORTS)
    }

    fn execute(&self, context: &mut Context, started: Self::Input) -> HandlerResult<StepDecision> {
        let number = started.tracked.shipment.shipment_number.clone();
        let pending = PENDING_SHIPMENT_REPORTS.get(context, &number)?;
        // The claim or the rejection settles every early report of this shipment.
        if pending.is_some() {
            PENDING_SHIPMENT_REPORTS.delete(context, &number)?;
        }
        if started.rejected {
            let record = ShipmentRecord {
                status: Some(SHIPMENT_REJECTED.to_string()),
                ..ShipmentRecord::default()
            };
            SHIPMENT_RECORDS.set(context, &number, record)?;
            return Ok(StepDecision::graceful_complete(()));
        }
        let run_id = started.tracked.shipment_run_id.clone().unwrap_or_default();
        // Claim the run: reports and reads of any other run of this number are ignored.
        let outcome = pending
            .and_then(|mut reports| reports.remove(&run_id))
            .map(|report| report.outcome);
        let record = ShipmentRecord {
            status: Some(SHIPMENT_STARTED.to_string()),
            run_id: Some(run_id),
            outcome,
        };
        SHIPMENT_RECORDS.set(context, &number, record)?;
        Ok(StepDecision::go_to(
            &AwaitShipment::default(),
            started.tracked,
        ))
    }
}

/// Reads the claimed run of a shipment: its status first, then its outcome.
///
/// Returns `Running` while that run runs, and an "unavailable" record when that
/// run no longer exists or another run replaced it. Keeps an outcome only when
/// the run is still the claimed one after the read. Returns an error for any
/// other failure so the Step retries.
fn reconcile_shipment(
    client: &Client,
    number: &str,
    run_id: &str,
) -> HandlerResult<ShipmentReading> {
    let Some(info) = describe_claimed_run(client, number, run_id)? else {
        return Ok(ShipmentReading::Closed(ShipmentRecord {
            status: Some(SHIPMENT_UNAVAILABLE.to_string()),
            ..ShipmentRecord::default()
        }));
    };
    if info.status == FlowStatus::Running {
        return Ok(ShipmentReading::Running);
    }
    let mut record = ShipmentRecord {
        status: Some(flow_status_name(info.status).to_string()),
        ..ShipmentRecord::default()
    };
    // An unset outcome Attribute leaves the outcome empty: the shipment ended without one.
    let outcome = match client.get_attributes(number, (&*SHIPMENT_OUTCOME,)) {
        Ok((outcome,)) => outcome,
        Err(SdkError::FlowNotFound { .. }) => return Ok(ShipmentReading::Closed(record)),
        Err(error) => return Err(HandlerError::from_error(error)),
    };
    // The Attribute read targets the latest run, so confirm it is still the claimed one.
    if describe_claimed_run(client, number, run_id)?.is_some() {
        record.outcome = outcome;
    }
    Ok(ShipmentReading::Closed(record))
}

## Report after the outcome commits

The shipment commits its outcome in one Step and reports in the next. Both Steps declare SYNC durability for `Execute`. The report Step then starts only after the outcome is stored, even when the Flow defaults to ASYNC.

The report carries the shipment's own run ID. When the Client accepts an RPC request ID, the report also carries a stable one: `report:`, the shipment number, `:`, and the run ID.

When the order has already closed, the report fails with a typed error. The shipment ends its attempts there. Its outcome stays readable through the Client.

            }
            Err(error) => Err(HandlerError::from_error(error)),

## One record per shipment {#records}

The order keeps one record per shipment in the `shipmentRecords` AttributeMap, keyed by the shipment number. The record holds the status, the claimed run ID, and the outcome as separate fields.

The report RPC fills the outcome in the shipment's record. A report can arrive before `ClaimShipment` records the run. The RPC then keeps it in the `pendingShipmentReports` AttributeMap, keyed by the shipment number. Each entry holds the first report of each run ID. `ClaimShipment` merges the claimed run's report. The [Production checklist](#production-checklist) lists which reports it accepts.

// this order claimed; the first report wins, and any other report changes nothing.
// Before the claim, it keeps the first report of each run for ClaimShipment to merge.
// It returns an error only when the records cannot be read or written.
func (*OrderFulfillmentFlow) RecordShipmentOutcome(ctx dex.Context, report ShipmentReport) (*dex.RPCResult[dex.None], error) {
	record, found, err := loadShipmentRecord(ctx, report.ShipmentNumber)
	if err != nil {
		return nil, err
	}
	// Ignore an unknown shipment and a report without a run.
	if !found || report.ShipmentRunID == "" {
		return &dex.RPCResult[dex.None]{}, nil
	}
	if record.Status == ShipmentStarting {
		if err := keepPendingReport(ctx, report); err != nil {
			return nil, err
		}
		return &dex.RPCResult[dex.None]{}, nil
	}
	// Ignore a rejected shipment, another run, and a repeated report.
	if record.RunID == "" || record.RunID != report.ShipmentRunID || record.Outcome != "" {
		return &dex.RPCResult[dex.None]{}, nil
	}
	record.Outcome = report.Outcome
	if err := ShipmentRecords.Set(ctx, report.ShipmentNumber, record); err != nil {
		return nil, err
	}
	return &dex.RPCResult[dex.None]{}, nil
}

// keepPendingReport stores the first report of each run of a shipment the order has not claimed yet.
// It returns an error when the pending reports cannot be read or written.
func keepPendingReport(ctx dex.Context, report ShipmentReport) error {
	pending, err := loadPendingReports(ctx, report.ShipmentNumber)
	if err != nil {
		return err
	}
	if _, kept := pending[report.ShipmentRunID]; kept {
		return nil
	}
	if pending == nil {
		pending = map[string]ShipmentReport{}
	}
	pending[report.ShipmentRunID] = report
	return PendingShipmentReports.Set(ctx, report.ShipmentNumber, pending)
}

/// Fills the outcome of a shipment's record. It accepts only the run this
/// order claimed; the first report wins, and any other report changes nothing.
/// Before the claim, it keeps the first report of each run for
/// `ClaimShipment` to merge.
///
/// Returns an error only when the records cannot be read or written.
fn record_shipment_outcome(
    &self,
    context: &mut Context,
    report: ShipmentReport,
) -> HandlerResult<()> {
    // Ignore an unknown shipment and a report without a run.
    let Some(mut record) = load_shipment_record(context, &report.shipment_number)? else {
        return Ok(());
    };
    if report.shipment_run_id.is_empty() {
        return Ok(());
    }
    if record.status.as_deref() == Some(SHIPMENT_STARTING) {
        let mut pending = PENDING_SHIPMENT_REPORTS
            .get(context, &report.shipment_number)?
            .unwrap_or_default();
        if !pending.contains_key(&report.shipment_run_id) {
            let number = report.shipment_number.clone();
            pending.insert(report.shipment_run_id.clone(), report);
            PENDING_SHIPMENT_REPORTS.set(context, &number, pending)?;
        }
        return Ok(());
    }
    // Ignore a rejected shipment, another run, and a repeated report.
    if record.run_id.as_deref() != Some(report.shipment_run_id.as_str())
        || record.outcome.is_some()
    {
        return Ok(());
    }
    record.outcome = Some(report.outcome);
    SHIPMENT_RECORDS.set(context, &report.shipment_number, record)
}

`AwaitShipment` describes the shipment at each interval. A running shipment is read again at the next interval, even after its report arrived. For a closed shipment, `RecordShipmentEnd` records its status, and its outcome when no report filled it.

The support team can cancel a shipment by its number. A shipment canceled before its outcome commits has no outcome; the order records it as `canceled`. A shipment canceled after its outcome commits, or after it sent its report, can still have an outcome, and the order keeps it.

## Choose this or a SubFlow {#choose}

Choose a [SubFlow](/concepts/primitives/subflow) when the child exists only for its parent. Dex derives its Flow ID from the parent, and the parent waits for it with a Condition.

Choose a top-level child Flow when the child needs its own identity:

- People or systems look it up, retry it, or stop it by its own number.
- Something other than the parent can start it.
- It can outlive the parent, with its own Flow timeout.

The cost is more code. The parent starts the child, claims its run, receives its report, and reads it until it ends.

## Production checklist {#production-checklist}

- **Claim the child run.** After the start returns, `ClaimShipment` records the run ID. From then on, the order accepts reports and reads of that run only. This is a business choice: a shipment number can be reopened while the order waits, and the order must not mix runs. When a child number has only one run, the Flow ID is enough. The order first registers each number as `starting`. Every writer of the records locks the singleton `shipmentRecordsLock` Attribute: `StartShipments`, `ClaimShipment`, `RecordShipmentEnd`, and the report RPC. The lock Attribute stores no value; it lets one writer at a time change the records.
- **Keep Client calls out of locked Steps.** `StartShipment` and `AwaitShipment` call the Client and take no lock. A report that meets the lock fails with a lock conflict, and the shipment retries it. The locked Steps make no calls, so they hold the lock only briefly.
- **Accept reports only from the claimed run.** A shipment that is still `starting` has no claimed run yet. The RPC keeps the first report of each run under the shipment number in `pendingShipmentReports`. A report sent under another number never hides it. `ClaimShipment` merges the claimed run's report, then deletes the shipment's whole entry, so the outcome is counted once. A rejection deletes the entry too. A report for an unknown or `rejected` number, from another run, or for a record that already has an outcome changes nothing. Otherwise the RPC fills the outcome.
- **Read the result, then confirm the run.** `AwaitShipment` calls `reconcileShipment` (`reconcile_shipment` in Python and Rust). Its first Describe records `unavailable` only when the Flow is not found or its run ID differs from the claimed one. After it reads a terminal status, it reads the outcome Attribute. An unset Attribute means the shipment ended without an outcome. When the Attribute read returns FlowNotFound, the function keeps the status and skips the second Describe. The Attribute read sees the shipment's latest run. When it succeeds, the function describes the shipment again to check the run ID. When the run is gone or replaced, the function keeps the status and drops this read's outcome. Reports the order already received stay in the record.
- **Retry other read errors.** Any other error fails the `AwaitShipment` Step, so Dex retries it. The retries hold no lock, so reports still arrive.
- **Plan for a shipment number reused later.** When the shipment cannot be found, or another run of the same number replaced the claimed one, the order records `unavailable`. That is a business policy. The order learns the terminal status of a claimed run while the order runs and the run stays the shipment's latest run. Once another caller reopens the number, or the run's data is deleted, the order can no longer read it. A shipment number belongs to one order. When another request already used the number, the start fails with a typed already-started error. The example records that shipment as `rejected` and ignores reports for it. `rejected` is its own state, never ended or failed, and the order's records list it as rejected. The order never waits for, counts, or stops a rejected shipment, because that run belongs to another request. A reopened shipment keeps its shipment number as the Flow ID and runs as a new run. The order tracks the run ID it claimed, because Describe and the Attribute read see only the latest run.
- **Reject duplicate numbers in one order.** `StartShipments` checks the order before it starts anything: the reconcile interval is positive, no delivery delay is negative, and every shipment number is unique.
- **Hash the start request.** The request ID of the start is a digest of the complete start request. A retried Step repeats the same start while the original run is still the shipment's latest run. When another caller reopens the number before the claim, the retry gets the already-started error, and the order records `rejected`. A resend of the same start request keeps its request ID. A deliberate reopen of the shipment number is a new start request with a new request ID, and resends of that request keep the new one. The request ID of the latest run's start replays that start instead of reopening. The order's own start disallows ID reuse. A reopen uses a policy that allows the closed states the business reopens from. A policy reads only how the latest run closed, not what it saved. A shipment that records a business failure and then completes is closed as completed; to reopen it after that failure, close it with a force-fail decision or allow a completed run. Every entry point in this pattern uses a policy that rejects an active run, so no start terminates or replaces a run that is still active.
