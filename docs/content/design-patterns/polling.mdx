# Polling and Iteration

Use these patterns when a Flow must revisit external state or process a paginated collection over time.

## Problem and approach

Choose the control flow that matches the work:

1. [Backoff Polling](/design-patterns/polling/backoff) retries an expected not-ready error with an exponential backoff.

2. [Polling with Timer](/design-patterns/polling/timer) waits on an explicit Timer before each readiness check.

3. [Iteration](/design-patterns/polling/iteration) processes one page at a time and passes the next page token to the next Step input.

All three are durable loops: a completed Step either finishes the Flow or schedules its next execution.
