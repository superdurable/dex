# Parent–child Flows

Use a durable SubFlow when a parent Flow must start and wait for another Flow. SubFlows are
normal Temporal or Cadence Workflows with their own Flow IDs, history, retries, and lifecycle.

Choose an SDK (preference is sticky in this browser; default Python).

<SdkTabs>
<SdkSnippet lang="python">

```python
class ProcessInvoice(Step[Invoice]):
    def wait_for(self, context: Context, invoice: Invoice) -> Wait:
        return Wait.until(SubFlow.run(self.invoice_flow, invoice))

    def execute(self, context: Context, invoice: Invoice) -> StepDecision:
        result = SubFlow.get_condition_results(context)
        receipt = result.single_output(Receipt)
        return graceful_complete(receipt)
```

  <SdkSnippet lang="go">

```go
func (ProcessInvoice) WaitFor(_ dex.Context, invoice Invoice) (*dex.Wait, error) {
	return dex.Until(dex.SubFlow(InvoiceFlow{}, invoice)), nil
}

func (ProcessInvoice) Execute(ctx dex.Context, _ Invoice) (*dex.StepDecision, error) {
	result, err := dex.SubFlowResult(ctx)
	if err != nil {
		return nil, err
	}
	var receipt Receipt
	if err := result.DecodeSingleOutput(&receipt); err != nil {
		return nil, err
	}
	return dex.GracefulComplete(receipt), nil
}
```

`Wait.allOf` provides fan-out/fan-in without manual dynamic Channels. `Wait.anyOf` returns a
`RUNNING` snapshot for an unfinished loser; its generated Flow ID lets application code inspect or
stop that independent execution.

Dex resolves an existing execution using `SubFlowReusePolicy`, safely survives local activity
retries, and carries partial results across continue-as-new. Parent completion does not cancel
SubFlows.

See [SubFlow](/primitives/subflow) for reuse behavior, lifecycle limitations,
options, and cleanup. The runnable Java sample is under
`examples/java/src/main/java/io/superdurable/dex/patterns/workflow/parentchild`.

Every SDK exposes the same timeout and timeout-policy fields on `SubFlowOptions`.
Use fail, cancel, or handler to override the child Flow's registered default. The
child completes terminal coordination and reports its failed, canceled, or
handler-produced result to the parent before closing. Continue-as-new preserves
the child's deadline; a child retry receives a fresh timeout budget.
