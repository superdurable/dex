# Dex server operations

The Dex **server** interprets Flows on Temporal or Cadence and exposes the FlowService API to clients and Workers.

## Local development

Prefer:

```bash
brew install superdurable/tap/dexcli
dexcli dev
```

This supervises Temporal, Dex Server, and Dex Web for local use. See [CLI README](https://github.com/superdurable/dex/blob/main/cli/README.md).

## Production shape

- Run Dex server as a managed service with health checks
- Point it at a production Temporal/Cadence cluster
- Configure blob storage for large payloads
- Optionally configure MySQL/PostgreSQL Custom Attribute Stores
- Expose Dex Web (or your own UI) behind auth as needed

## Configuration

Server configuration is YAML/typed config for the Go server (not every knob is exposed on **dexcli dev**). For Docker-based deploys, see archived notes under **docs/archive/** and current **server/config** docs in the repo.

The blob section is named **blobStore**; the former **externalStorage** key is not
accepted. **BlobStoreConfig** contains **BlobStoreConfigEntry** values.

An optional **blobStore.blobCache** caches only S3-backed Attribute objects. A
non-empty **directory** enables it, must be exclusive to one Server process, and
defaults to a 1 GiB budget. Ristretto attempts SampledLFU eviction until an
eligible object fits, while TinyLFU may reject a colder candidate to preserve
hot entries. Oversized and rejected objects bypass the cache without failing
the source Blob Store operation. A corrupt entry is invalidated and refilled
from S3; initialization, recovery, and disk I/O errors remain strict
Server/system errors. Local blob storage and step-event input snapshots bypass
this cache.

See [Custom Attribute Store](/production/attribute-store) for table and retry
requirements.

## Backends

Dex currently interprets on Temporal (primary for **dexcli**) and can target Cadence in server builds that enable it. Production ops for the underlying workflow engine (persistence, multi-cluster, upgrades) follow that engine’s runbooks; Dex adds Flow-level semantics on top.
