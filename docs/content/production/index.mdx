# Deploy to Production

Operate Dex applications and servers safely in production.

- [Application operation](/production/application-operations) — Worker health,
  read-only debugging, recovery, and Flow-code versioning
- [Pull Workers](/production/pull-workers) — outbound Worker connections,
  routing, capacity, and shutdown
- [Deploy agents](/production/agents) — the Stream backend, Worker and Stream
  sizing, session limits, approvals, redeploys, and credentials for agent
  sessions
- [Dex Web](/production/dex-web) — the standalone dex-web binary and image,
  access control, v1 run search, and the v2 Run and Work Queue workspaces
- [server-zd operation](/production/server-zd-operations) — single-node
  Kubernetes deployment, lease, object storage, pull Worker dispatch, metrics,
  authentication, and backup
- [Custom Attribute Store](/production/attribute-store) — PostgreSQL
  projection, schema contracts, and retry semantics
