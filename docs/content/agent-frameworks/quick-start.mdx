# Agent Quick Start

Run an agent built with your framework as a durable Dex session, then stop it in the middle of a conversation and watch it carry on. It takes about 10 minutes.

Building a new agent without a framework? Start with the [Built-in Agent Loop](/agent-frameworks/built-in-agent-loop).

## What you will build {#what-you-will-build}

A small order support agent. It has two tools on an in-memory order desk:

- **look_up_order** reads an order. It is a read, so Dex may retry it.
- **cancel_order** cancels an order that has not shipped. It is a write, so it runs at most once, and only after a person approves it.

You install the adapter, wrap the agent in a session, and ask it to cancel an order. While the cancellation waits for approval, you stop the Worker and start it again. Then you approve the call and check what ran.

## Before you start {#before-you-start}

- **dexcli**, installed as [Run Locally](/components/run-locally) shows.
- **Python with uv**, or **Node.js with npm**, depending on your framework.
- An API key for your framework's model provider, such as **OPENAI_API_KEY** or **ANTHROPIC_API_KEY**.
- A clone of the [Dex repository](https://github.com/superdurable/dex). The example lives under **examples**.

The adapter wraps your agent in a session Flow. Each tool gets a policy: **look_up_order** is a read, and **cancel_order** is a write that waits for approval.

```python
def build_claude_agent_sdk_order_support_flow(
    order_desk: OrderDesk, model: str, slack_connection: slack.Connection | None
) -> AgentSessionFlow:
    """Builds the session Flow; ``model`` is a Claude model name, such as "claude-opus-5-5"."""

    # The tools are closures, so they call the OrderDesk passed in here.
    @tool(
        "look_up_order",
        "Look up one order by its order ID and return its items and status.",
        {"order_id": str},
    )
    async def look_up_order(arguments: dict[str, Any]) -> dict[str, Any]:
        order = order_desk.describe_order(arguments["order_id"])
        return {"content": [{"type": "text", "text": order}]}

    @tool(
        "cancel_order",
        "Cancel one order that has not shipped yet.",
        {"order_id": str, "reason": str},
    )
    async def cancel_order(arguments: dict[str, Any]) -> dict[str, Any]:
        result = order_desk.cancel_order(arguments["order_id"], arguments["reason"])
        return {"content": [{"type": "text", "text": result}]}

    # Every session gets the same options, so the factory does not read its context.
    def build_options(context: ClaudeAgentOptionsContext) -> ClaudeAgentOptions:
        return ClaudeAgentOptions(
            model=model,
            env=build_claude_cli_environment(os.environ),
            system_prompt=ORDER_SUPPORT_INSTRUCTIONS,
            # No Claude Code built-in tools: the agent uses only the order tools.
            tools=[],
            # Settings files could approve a tool before Dex asks for approval.
            setting_sources=[],
        )

    return claude_agent_session_flow(
        build_options,
        [look_up_order, cancel_order],
        flow_type=CLAUDE_AGENT_SDK_ORDER_SUPPORT_FLOW_TYPE,
        tool_sources=build_slack_tool_sources(slack_connection),
        tool_policies={
            "look_up_order": ToolPolicy(ToolEffect.READ),
            "cancel_order": ToolPolicy(ToolEffect.NON_IDEMPOTENT_WRITE),
        },
    )
```

```typescript
export function createClaudeAgentSdkOrderSupportFlow(
  orderDesk: OrderDesk,
  model: string,
  cliEnvironment: Readonly<Record<string, string>>,
  slack: Connection | undefined,
): AgentSessionFlow {
  const lookUpOrder = tool(
    "look_up_order",
    "Look up one order by its order ID and return its items and status.",
    { order_id: z.string() },
    async ({ order_id }) => ({ content: [{ type: "text", text: orderDesk.describeOrder(order_id) }] }),
  );
  const cancelOrder = tool(
    "cancel_order",
    "Cancel one order that has not shipped yet.",
    { order_id: z.string(), reason: z.string() },
    async ({ order_id, reason }) => ({ content: [{ type: "text", text: orderDesk.cancelOrder(order_id, reason) }] }),
  );
  return createClaudeAgentSessionFlow(
    {
      options: {
        model,
        systemPrompt: orderSupportInstructions,
        // No Claude Code built-in tools: the agent uses only the order tools.
        tools: [],
        // Settings files could approve a tool before Dex asks for approval.
        settingSources: [],
        // Only the variables in cliEnvironment reach the CLI, so no other Claude credential can take over.
        env: { ...cliEnvironment },
      },
      customTools: [lookUpOrder, cancelOrder],
      toolPolicies: {
        look_up_order: { effect: "read" },
        cancel_order: { effect: "non_idempotent_write" },
      },
      toolSources: createSlackConnectorToolSources(slack),
    },
    claudeAgentSdkOrderSupportFlowType,
  );
}
```

## 4. Stop the Worker while the agent waits {#stop-the-worker}

The agent looked up order 1002 and asked to cancel it. **cancel_order** needs approval, so the session waits in **AwaitToolApproval**. The wait holds no Worker.

1. Stop the example with Ctrl-C. The session keeps waiting in Dex.
2. Start the example again, with the same command as in step 3.
3. Open Dex Web at **http://127.0.0.1:8802**. Open the session's run, select the **Agent session** tab, and approve **cancel_order**.
4. Open the **Timeline**. **look_up_order** and the model calls before the restart ran once. **cancel_order** ran once, after the approval. The agent answered from the recorded results.

You have run your first durable agent. Its Worker went away in the middle of a conversation, and the session lost nothing and repeated nothing.
