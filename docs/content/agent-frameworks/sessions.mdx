# Sessions

A durable agent session is one Flow run that holds one conversation. Each model call and each tool call runs in a Step. So a crash, a deploy, or a long wait repeats nothing that already finished.

Inside it, your framework's agent loop runs as Steps: a model call (RunModel), a tool call (CallTool), an approval (AwaitToolApproval), then the next model call. Dex records each Step's result before the turn moves on, and the Steps call your models and tools." />

## A durable agent session {#a-durable-agent-session}

One Flow run is one agent session. The Flow ID is the session ID. Dex Agents builds the session Flow: the **dex-agents** package in Python and `@superdurable/dex-agents` in TypeScript. A framework adapter adds one agent framework to it.

The session stores the conversation in Attributes. A session waits for the next user message without using a Worker task slot.

Model calls run in a `RunModel` Step. In most harnesses, each `RunModel` Step makes one model call, and each tool call runs in its own Step. The Steps of one turn are:

| Step | What it does |
| --- | --- |
| `RunModel` | Makes one model call and records the response. |
| `CallTool` | Runs one call of a read or an idempotent write. Dex may retry it. |
| `CallSingleAttemptTool` | Runs one call of any other write. Dex runs it at most once. |
| `AwaitToolApproval` | Waits for a person to approve or reject a tool call. See [Approvals](/agent-frameworks/approvals). |
| `ResumeTurn` | Waits for every tool result of the model response, then moves back to `RunModel`. |

The tool calls of one model response run in parallel. When they all finish, `ResumeTurn` sends their results to the model.

### Latency and cost {#latency-and-cost}

Every session Step is SYNC: Dex commits the Step's start before the Worker gets it, and its result before the session moves on, each to object storage. A turn in which the model asks for three tools and then answers takes six Steps: two `RunModel`, three tool Steps, and one `ResumeTurn`. [Performance](/intro/performance#latency-below-the-peak) measured a p50 of about 105 ms for a SYNC Step on a 2-vCPU server at half of its peak load. The three tool Steps run in parallel, so the turn waits on four Steps in a row. At that p50, they add about 0.4 seconds to the turn, on top of the model and tool time.

A `RunModel` Step retries up to three attempts within 30 minutes. A retry sends the model call to the provider again, so you pay for its tokens again. `run_model_limit` in Python, or `runModelLimit` in TypeScript, lowers the attempts for an expensive call. [Step timeouts](/reference/agents/workers#timeouts) lists the defaults.

A crash repeats only the Step that was running. Dex does not replay the loop. So the agent code needs no determinism rules, and a code change takes effect at the next Step.

Two harnesses group more work into one Step:

- **Claude Agent SDK.** The Claude Code CLI runs a turn segment in one `RunModel` Step. The segment holds the model calls and the read tool calls, and a failed segment reruns as a whole. Writes leave the segment one at a time, each in its own Step, so they never run in parallel.
- **LangChain and LangGraph.** One `RunModel` Step runs the graph to its next tool calls. A graph can make several model calls on the way, and a retry repeats them together.

### What a session remembers {#what-a-session-remembers}

A session keeps one conversation: its messages, its tool calls, and their results. A new session starts empty. Dex Agents has no memory that one session shares with the next.

Keep long-term memory, such as a user's preferences or past orders, in a store that you own. That store can be your database or a Flow that you keep for each user. Give the agent a tool that reads it, and a tool that writes it with the right [policy](/agent-frameworks/tool-calls#tool-policies-and-approvals).

A stopped session stays readable for the retention period, and then Dex deletes it. [History and retention](/reference/agents/session-limits#history) has the defaults.

## Send a message once {#send-a-message-once}

`send_user_message` is an RPC. When its response is lost and your code sends again, Dex runs the RPC again, so the same message can be queued twice. [RPC guarantees](/concepts/primitives/rpc#guarantees) explains why, and [RPCs during a deploy](/agent-frameworks/production#rpcs-during-a-deploy) explains when it happens.

This helper sends a message once. Each tab shows the whole module. It retries a send that may not have arrived, checks the
session before each retry, and deletes an extra queued copy. It tells messages
apart by their text, so call it once for each message a user sends.

```python
"""Sends a user message to a session once, even when a send must be retried."""
from __future__ import annotations

import asyncio
from typing import Protocol

import grpc  # type: ignore[import-untyped]
from dex import DexServiceError
from dex_agents import AgentSnapshot, MessageRole

# A lost response leaves a send's outcome unknown; these codes mean "check first".
UNCERTAIN_CODES = (grpc.StatusCode.UNAVAILABLE, grpc.StatusCode.DEADLINE_EXCEEDED)

class MessageSessions(Protocol):
    async def get_agent_snapshot(self, session_id: str) -> AgentSnapshot: ...

    async def send_user_message(self, session_id: str, text: str) -> bool: ...

    async def delete_queued_message(self, session_id: str, message_id: str) -> bool: ...

async def send_user_message_once(
    sessions: MessageSessions,
    session_id: str,
    text: str,
    *,
    attempts: int = 5,
    retry_delay_seconds: float = 1.0,
) -> None:
    """Queues one user message, retrying a failed send without queuing it twice.

    Before each retry it reads the session, and stops when a new copy of the
    text is there. At the end it deletes any extra queued copy. It tells
    messages apart by their text, so call it once for each message a user sends.

    Raises:
        DexServiceError: When no attempt reached a Worker, or on any other error.
    """
    copies_before = _copies(await sessions.get_agent_snapshot(session_id), text)
    for attempt in range(1, attempts + 1):
        try:
            await sessions.send_user_message(session_id, text)
            break
        except DexServiceError as error:
            if error.code not in UNCERTAIN_CODES or attempt == attempts:
                raise
        await asyncio.sleep(retry_delay_seconds)
        if _copies(await sessions.get_agent_snapshot(session_id), text) > copies_before:
            break
    await _delete_extra_copies(sessions, session_id, text, copies_before + 1)

async def _delete_extra_copies(
    sessions: MessageSessions, session_id: str, text: str, wanted: int
) -> None:
    snapshot = await sessions.get_agent_snapshot(session_id)
    extra = _copies(snapshot, text) - wanted
    queued = [item for item in snapshot.queued_messages if item.message.text == text]
    if extra <= 0:
        return
    for item in reversed(queued[max(0, len(queued) - extra) :]):
        await sessions.delete_queued_message(session_id, item.message_id)

def _copies(snapshot: AgentSnapshot, text: str) -> int:
    delivered = sum(
        1 for message in snapshot.messages if message.role == MessageRole.USER and message.text == text
    )
    queued = sum(1 for item in snapshot.queued_messages if item.message.text == text)
    return delivered + queued
```

```ts
// Queues one user message without queuing it twice when a send is retried.

import { DexServiceError, type Client } from "@superdurable/dex";
import {
  readAgentSnapshot,
  sendAgentUserMessage,
  type AgentSessionFlow,
  type AgentSnapshot,
} from "@superdurable/dex-agents";

// gRPC codes UNAVAILABLE and DEADLINE_EXCEEDED: the send may or may not have arrived.
const UNCERTAIN_CODES: readonly number[] = [14, 4];

export interface MessageSessions {
  getAgentSnapshot(sessionId: string): Promise<AgentSnapshot>;
  sendUserMessage(sessionId: string, text: string): Promise<boolean>;
  deleteQueuedMessage(sessionId: string, messageId: string): Promise<boolean>;
}

export function messageSessions(client: Client, flow: AgentSessionFlow): MessageSessions {
  return {
    getAgentSnapshot: (sessionId) => readAgentSnapshot(client, flow, sessionId),
    sendUserMessage: (sessionId, text) => sendAgentUserMessage(client, flow, sessionId, { text }),
    deleteQueuedMessage: (sessionId, messageId) =>
      client.invokeRPC(flow.deleteQueuedMessage, sessionId, { messageId }),
  };
}

/**
 * Queues one user message, retrying a failed send without queuing it twice.
 * Before each retry it reads the session and stops when a new copy of the text is there.
 * At the end it deletes any extra queued copy. It tells messages apart by their text,
 * so call it once for each message a user sends.
 */
export async function sendUserMessageOnce(
  sessions: MessageSessions,
  sessionId: string,
  text: string,
  { attempts = 5, retryDelayMs = 1_000 }: { attempts?: number; retryDelayMs?: number } = {},
): Promise<void> {
  const copiesBefore = countCopies(await sessions.getAgentSnapshot(sessionId), text);
  for (let attempt = 1; attempt <= attempts; attempt++) {
    try {
      await sessions.sendUserMessage(sessionId, text);
      break;
    } catch (error) {
      const isUncertain = error instanceof DexServiceError && UNCERTAIN_CODES.includes(error.code);
      if (!isUncertain || attempt === attempts) {
        throw error;
      }
    }
    await new Promise((resolve) => setTimeout(resolve, retryDelayMs));
    if (countCopies(await sessions.getAgentSnapshot(sessionId), text) > copiesBefore) {
      break;
    }
  }
  await deleteExtraCopies(sessions, sessionId, text, copiesBefore + 1);
}

async function deleteExtraCopies(
  sessions: MessageSessions,
  sessionId: string,
  text: string,
  wanted: number,
): Promise<void> {
  const snapshot = await sessions.getAgentSnapshot(sessionId);
  const extra = countCopies(snapshot, text) - wanted;
  if (extra <= 0) {
    return;
  }
  const queued = (snapshot.queuedMessages ?? []).filter((item) => item.message.text === text);
  for (const item of queued.slice(Math.max(0, queued.length - extra)).reverse()) {
    await sessions.deleteQueuedMessage(sessionId, item.messageId);
  }
}

function countCopies(snapshot: AgentSnapshot, text: string): number {
  const delivered = snapshot.messages.filter((message) => message.role === "user" && message.text === text).length;
  const queued = (snapshot.queuedMessages ?? []).filter((item) => item.message.text === text).length;
  return delivered + queued;
}
```
