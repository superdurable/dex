# Dex primitives

Seven minimal examples, one per core Dex primitive:

| Directory | Primitive |
|-----------|-----------|
| [step/](step/) | Step transitions |
| [attribute/](attribute/) | Attribute persistence |
| [channel/](channel/) | Channel wait and publish |
| [timer/](timer/) | Timer wait |
| [rpc/](rpc/) | Flow RPC |
| [subflow/](subflow/) | SubFlow |
| [client-apis/](client-apis/) | Client search APIs |

HTTP prefix: `/primitives/<name>/...`
