# Temporal, 2.10 GHz host

The host was replaced mid-session by a 2.10 GHz, 4 vCPU host with the same memory.
These runs cover the remaining scenarios at concurrency 1, 4, 8, 16, 32, 64, and sequential-steps at concurrency 16, 32, 64.
Do not compute server-zd / Temporal ratios against the 2.80 GHz server-zd results: the CPUs differ.
Recovery is a server-zd-only scenario, so Temporal has no recovery result.
