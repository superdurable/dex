# server-zd v0.1.9 compared with Temporal

This directory combines `2026-10-27-quick-claude-cloud-4vcpu-zd-v0.1.9` with both Temporal result sets.
The server-zd results and part of the Temporal results ran on a 2.80 GHz, 4 vCPU host.
The other Temporal results ran on a 2.10 GHz, 4 vCPU host with the same memory.
Treat the ratios as approximate: the CPUs differ for those points.
It contains no new measurements; regenerate it with `dexbench chart` and `dexbench report` from the three source directories.
