# Temporal, 2.80 GHz host

These runs used the same 2.80 GHz, 4 vCPU host as `2026-10-27-quick-claude-cloud-4vcpu-zd-v0.1.9`.
They cover start-complete (concurrency 1, 4, 8, 16, 32, 64) and sequential-steps (concurrency 1, 4, 8).
`comparison-with-zd.md` compares exactly these points with the server-zd results.
The host was replaced during the session, so the remaining Temporal points are in the 2.10 GHz directory.
